    Coding-Decoding

    In a coding-decoding question a word is written in a code, and the candidate must either decode a coded word or encode a new word using the same rule. The whole chapter depends on finding the rule from one or two examples and then applying it without error. The rules are limited in number, and a candidate who knows the common kinds of rules can place a new question into a known type within seconds.

    The first kind of rule shifts each letter by a fixed number of places. If COLD is written as DPME, each letter has moved one place forward. If the shift is backwards, the letters move towards A. The shift may be different for different positions, for example the first letter forward by one, the second by two and the third by three, so the candidate must compare every letter of the example rather than only the first.

    The second kind reverses the word before shifting, or shifts before reversing. To tell which has been done, the candidate should try both on the example and keep the one that fits. A related rule replaces the word with the letters that are opposite in the alphabet, so that A becomes Z, B becomes Y and so on, and here the place value of the code letter is twenty-seven minus the place value of the original letter.

    The third kind codes the letters by their place values as numbers. A word may be written as the numbers one, two, three and so on, or as the products of the place values, or as the sums of the place values of neighbouring letters. The candidate should write the place values above the letters at once, because this makes the numerical rule visible and also allows a quick check of the answer.

    The fourth kind uses a code table or a fixed substitution in which each letter is replaced by a particular symbol or another letter. If the substitution is fixed, then the same letter in the question always becomes the same symbol, and the candidate can build a small table as the letters appear. This kind of question is solved by matching the most frequent letters first, just as in a simple cipher.

    The fifth kind uses a keyword. Sometimes the alphabet is written under a keyword and the code is read off from that arrangement. The candidate should write out the alphabet with the keyword placed under it, leaving out the repeated letters of the keyword, and then read the code directly. A variant places the keyword and then fills the rest of the alphabet after it, wrapping round to the start.

    The sixth kind codes numbers or words by their order, by the number of letters, or by the number of vowels and consonants. A question may give the code of a word as the position of its first letter, or as the sum of the place values of its letters, or as the number of letters between its first and last letters. The candidate should compute the suggested value for the example and confirm it before using it on the question.

    A useful general method is to write the example word and its code one above the other and to write the place values of both under each letter. The difference or the ratio between the two place values then shows the rule at a glance. For most questions of the shifting kind this single step gives the answer, and it also guards against a rule that holds for the first few letters but fails later.

    The commonest mistakes are to assume that a rule found in one part of the word holds for the whole word, and to forget the wrap round at the ends of the alphabet. A shift of three forwards from X gives A, and a shift of three backwards from C gives Z, and a candidate who forgets this will lose the question. Writing the alphabet at the top of the rough sheet, as in the alphabet test, prevents the second mistake.

    Practise the chapter by coding and decoding ordinary words yourself. Take a word such as REASON, apply a shift of two, then of minus two, then the reverse, and write the codes. Ten minutes of this work makes the rules familiar, so that in the examination hall the rule is recognised rather than searched for, and the question is answered in the time it takes to write the code.

    A very common rule codes a word by writing the letter that comes a fixed number of places after each letter, and the candidate should check whether the shift is the same for every letter or grows along the word. A growing shift, such as one for the first letter, two for the second and three for the third, is common in the harder questions, and it is found only by comparing every letter of the example rather than the first alone.

    Some rules operate on the positions rather than the letters. A word may be coded by writing its letters in reverse order, or by swapping the first and last letters, or by writing the second half first. These rules do not change any letter, so the code contains the same letters as the word. A candidate who notices that the letters are unchanged but the order is different should test the rearrangement rules before the shifting rules.

    Number codes are also frequent. A word may be coded by the sum of the place values of its letters, by the product of the first and last place values, or by the difference between the largest and smallest place values. The candidate should write the place values above the letters at once and then compute the suggested value for the example, checking that it matches before using it on the question.

    A pair code gives two words and their codes and asks for the code of a third word. Here the rule must be found from both examples together, and a rule that fits only one example is not the rule. The candidate should test the guessed rule on the second example as well, and only when it fits both should the third word be coded.

    Substitution codes, in which each letter is replaced by a fixed symbol, are solved by frequency. The most frequent letter in the coded text usually stands for the most frequent letter in ordinary language, and the common short words give further clues. The candidate should not try to guess the whole message at once but should fill in one letter at a time and check each guess against the words already solved.

    Conditional coding gives a rule that depends on the letters of the word, for example coding a letter by the one that is three places ahead if the letter is a vowel and three places behind if it is a consonant. The candidate must read the condition carefully and apply the correct branch to each letter. Writing the vowels and consonants of the word in two groups before coding prevents a mix-up.

    Some questions code a word by moving its letters by the position of the letter in the alphabet, so that the first letter moves one place, the second two places and so on. The method is the same as the growing shift, and the candidate should write the position of each letter above it before applying the shift. This kind of rule is easy to apply but easy to misapply, so a check at the end is worthwhile.

    When the code is given and the word must be found, the candidate works backwards. A forward shift of three is undone by a backward shift of three, a reversal is undone by another reversal, and a substitution is undone by reading the table the other way. Working backwards is the same skill as working forwards, and the candidate should not be frightened by a question that gives the code first.

    A useful check is to see whether the code is longer or shorter than the word, or whether it contains digits, because this tells the candidate what kind of rule is at work. A code of the same length and the same kind of letters suggests a shifting or substitution rule; a code of digits suggests a number rule; a code with repeated symbols suggests a substitution. Reading the shape of the code first saves time.

    Finally, practise by inventing codes. Take a word, decide a rule, write the code, and then decode it as if it were a fresh question. This habit makes the common rules second nature, so that in the examination hall the rule is recognised from the look of the code rather than searched for from scratch, and the question is answered in the time it takes to write the letters.

    • For a fixed substitution, match the most frequent letters first.

    Frequently Asked Questions

    What is the fastest way to find the coding rule?

    Write the example word and its code one above the other and write the place values of both under each letter; the difference shows the rule at once.

    What is the commonest mistake in this chapter?

    Forgetting that the alphabet wraps round, so a forward shift from X passes to A and a backward shift from C passes to Z.

    How do I solve a fixed substitution code?

    Match the most frequent letters first and build a small table as each letter appears, just as in a simple cipher.

    How do I solve a code in which each letter is replaced by a symbol?

    Use frequency: match the most frequent symbol to the most frequent letter and use the common short words as clues, filling in one letter at a time.

    What does it mean if the code has the same letters as the word but in a different order?

    The rule reorders the letters, for example by reversing the word or swapping the first and last letters, so no shifting is involved.

    সংকেত নিৰ্ণয়ৰ প্ৰশ্নত এটা শব্দ এটা সংকেতত লিখা থাকে, আৰু প্ৰাৰ্থীয়ে হয় এটা সংকেতিত শব্দ ভাঙিব লাগে, নহয় একেই নিয়মে এটা নতুন শব্দ সংকেতিত কৰিব লাগে। গোটেই অধ্যায়টো এটা বা দুটা উদাহৰণৰ পৰা নিয়মটো বিচৰা আৰু তাৰ পিছত ভুল নকৰাকৈ প্ৰয়োগ কৰাৰ ওপৰত নিৰ্ভৰশীল। নিয়মবোৰ সংখ্যাত সীমিত, আৰু সাধাৰণ ধৰণৰ নিয়ম জানা প্ৰাৰ্থীয়ে এটা নতুন প্ৰশ্নক কেইছেকেণ্ডৰ ভিতৰত জনা ধৰণত ৰাখিব পাৰে।

    প্ৰথম ধৰণৰ নিয়মে প্ৰতিটো আখৰ এটা নিৰ্দিষ্ট সংখ্যক স্থান লৰায়। COLD ক DPME হিচাপে লিখিলে, প্ৰতিটো আখৰ এটা স্থান আগুৱাইছে। লৰণ পিছলৈ হ'লে আখৰবোৰ A ৰ ফালে যায়। লৰণ বেলেগ বেলেগ অৱস্থানত বেলেগ হ'ব পাৰে, যেনে প্ৰথম আখৰ এটা আগলৈ, দ্বিতীয়টো দুটা আৰু তৃতীয়টো তিনি, গতিকে প্ৰাৰ্থীয়ে কেৱল প্ৰথমটো নহয়, উদাহৰণৰ প্ৰতিটো আখৰ তুলনা কৰিব লাগে।

    দ্বিতীয় ধৰণে লৰোৱাৰ আগতে শব্দটো ওলোটাই, বা ওলোটা কৰাৰ আগতে লৰায়। কোনটো কৰা হৈছে ক'বলৈ, প্ৰাৰ্থীয়ে উদাহৰণত দুয়োটা চেষ্টা কৰি যিটো মিলে সেয়া ৰাখিব লাগে। এটা সম্পৰ্কীয় নিয়মে শব্দটোক বৰ্ণমালাত বিৰুদ্ধ অখৰবোৰেৰে সলনি কৰে, যাতে A Z হয়, B Y হয়, ইত্যাদি, আৰু ইয়াত সংকেত আখৰৰ স্থানীয় মান মূল আখৰৰ স্থানীয় মানৰ পৰা সাতাইশ বিয়োগ কৰি পোৱা যায়।

    তৃতীয় ধৰণে আখৰবোৰক সংখ্যা হিচাপে তেওঁলোকৰ স্থানীয় মানেৰে সংকেতিত কৰে। এটা শব্দ এক, দুই, তিনি ইত্যাদি সংখ্যা হিচাপে, বা স্থানীয় মানৰ গুণফল হিচাপে, বা কাষৰীয়া আখৰবোৰৰ স্থানীয় মানৰ যোগফল হিচাপে লিখা হ'ব পাৰে। প্ৰাৰ্থীয়ে তৎক্ষণাত আখৰবোৰৰ ওপৰত স্থানীয় মান লিখা উচিত, কাৰণ ই সংখ্যাগত নিয়মটো দৃশ্যমান কৰে আৰু উত্তৰৰ দ্ৰুত পৰীক্ষাও দিয়ে।

    চতুৰ্থ ধৰণে এটা সংকেত তালিকা বা এটা নিৰ্দিষ্ট প্ৰতিস্থাপন ব্যৱহাৰ কৰে, য'ত প্ৰতিটো আখৰ এটা বিশেষ চিহ্ন বা আন এটা আখৰেৰে সলনি হয়। প্ৰতিস্থাপন নিৰ্দিষ্ট হ'লে, প্ৰশ্নৰ একেই আখৰ সদায় একেই চিহ্ন হয়, আৰু আখৰবোৰ ওলোৱাৰ লগে লগে প্ৰাৰ্থীয়ে এটা সৰু তালিকা বনাব পাৰে। এই ধৰণৰ প্ৰশ্ন আটাইতকৈ বেছি দেখা যোৱা আখৰবোৰ আগতে মিলাই সমাধান কৰা হয়, এটা সহজ চাইফাৰৰ দৰেই।

    পঞ্চম ধৰণে এটা কী-শব্দ ব্যৱহাৰ কৰে। কেতিয়াবা বৰ্ণমালা এটা কী-শব্দৰ তলত লিখা হয় আৰু সেই বিন্যাসৰ পৰা সংকেত পঢ়া হয়। প্ৰাৰ্থীয়ে কী-শব্দৰ পুনৰাবৃত্তি হোৱা আখৰবোৰ এৰি, বৰ্ণমালা কী-শব্দৰ তলত লিখি, তাৰ পিছত সংকেত পোনপটীয়াকৈ পঢ়িব লাগে। এটা ৰূপে কী-শব্দ ৰাখি তাৰ পিছত বাকী বৰ্ণমালা পূৰণ কৰে, আৰম্ভণিলৈ ঘূৰি।

    ষষ্ঠ ধৰণে সংখ্যা বা শব্দবোৰক তেওঁলোকৰ ক্ৰম, আখৰৰ সংখ্যা, বা স্বৰ আৰু ব্যঞ্জনৰ সংখ্যাৰে সংকেতিত কৰে। এটা প্ৰশ্নই এটা শব্দৰ সংকেত তাৰ প্ৰথম আখৰৰ অৱস্থান হিচাপে, তাৰ আখৰবোৰৰ স্থানীয় মানৰ যোগফল হিচাপে, বা তাৰ প্ৰথম আৰু শেষ আখৰৰ মাজৰ আখৰৰ সংখ্যা হিচাপে দিব পাৰে। প্ৰাৰ্থীয়ে উদাহৰণৰ বাবে প্ৰস্তাৱিত মানটো গণনা কৰি প্ৰশ্নত ব্যৱহাৰ কৰাৰ আগতে নিশ্চিত কৰিব লাগে।

    এটা উপযোগী সাধাৰণ পদ্ধতি হ'ল উদাহৰণ শব্দ আৰু তাৰ সংকেত এটা আনটোৰ ওপৰত লিখি প্ৰতিটো আখৰৰ তলত দুয়োটাৰ স্থানীয় মান লিখা। দুটা স্থানীয় মানৰ মাজৰ পাৰ্থক্য বা অনুপাতেই তৎক্ষণাত নিয়মটো দেখুৱায়। লৰণ ধৰণৰ বেছিভাগ প্ৰশ্নত এই এটা পদক্ষেপেই উত্তৰ দিয়ে, আৰু ই প্ৰথম কেইটামান আখৰত টিকা কিন্তু পিছত বিফল হোৱা নিয়মৰ পৰাও বচায়।

    আটাইতকৈ সাধাৰণ ভুল হ'ল শব্দৰ এটা অংশত পোৱা নিয়ম গোটেই শব্দত টিকি আছে বুলি ধৰি লোৱা, আৰু বৰ্ণমালাৰ মূৰত ঘূৰণ পাহৰা। X ৰ পৰা তিনি আগলৈ লৰালে A পোৱা যায়, আৰু C ৰ পৰা তিনি পিছলৈ লৰালে Z পোৱা যায়, আৰু ই পাহৰা প্ৰাৰ্থীয়ে প্ৰশ্নটো হেৰুৱাব। বৰ্ণমালা পৰীক্ষাৰ দৰেই মেজৰ কাগজৰ ওপৰত বৰ্ণমালা লিখিলে দ্বিতীয় ভুলটো নহয়।

    সাধাৰণ শব্দ নিজেই সংকেতিত আৰু ভাঙি এই অধ্যায়ৰ অভ্যাস কৰক। REASON দৰে এটা শব্দ লৈ, দুটাৰ লৰণ, তাৰ পিছত বিয়োগ দুই, তাৰ পিছত ওলোটা প্ৰয়োগ কৰি সংকেতবোৰ লিখক। দহ মিনিটৰ এই কামে নিয়মবোৰ চিনাকি কৰি তোলে, যাতে পৰীক্ষা কক্ষত নিয়ম বিচৰাৰ পৰিৱৰ্তে চিনি পোৱা যায়, আৰু সংকেত লিখিবলৈ লগা সময়তে প্ৰশ্নটোৰ উত্তৰ দিয়া যায়।

    এটা অতি সাধাৰণ নিয়মে এটা শব্দ প্ৰতিটো আখৰৰ পিছত এটা নিৰ্দিষ্ট সংখ্যক স্থানত অহা আখৰ লিখি সংকেতিত কৰে, আৰু প্ৰাৰ্থীয়ে লৰণটো প্ৰতিটো আখৰৰ বাবে একেই নে শব্দৰ লগে লগে বাঢ়ে সেয়া পৰীক্ষা কৰা উচিত। বাঢ়ি যোৱা লৰণ, যেনে প্ৰথম আখৰৰ বাবে এটা, দ্বিতীয়টোৰ বাবে দুই আৰু তৃতীয়টোৰ বাবে তিনি, কঠিন প্ৰশ্নবোৰত সাধাৰণ, আৰু সেয়া কেৱল প্ৰথমটোৰ পৰিৱৰ্তে উদাহৰণৰ প্ৰতিটো আখৰ তুলনা কৰিহে ধৰা পৰে।

    কিছুমান নিয়মে আখৰৰ সলনি অৱস্থানত কাম কৰে। এটা শব্দ ওলোটা ক্ৰমত আখৰ লিখি, বা প্ৰথম আৰু শেষ আখৰ সলনি কৰি, বা দ্বিতীয় আধা আগতে লিখি সংকেতিত কৰিব পাৰি। এই নিয়মবোৰে কোনো আখৰ সলনি নকৰে, গতিকে সংকেতত শব্দৰ দৰেই একেই আখৰ থাকে। আখৰবোৰ অপৰিৱৰ্তিত কিন্তু ক্ৰম বেলেগ বুলি লক্ষ্য কৰা প্ৰাৰ্থীয়ে লৰণ নিয়মৰ আগতে পুনৰ্বিন্যাস নিয়মবোৰ পৰীক্ষা কৰা উচিত।

    সংখ্যা সংকেতো সঘন। এটা শব্দ তাৰ আখৰবোৰৰ স্থানীয় মানৰ যোগফলেৰে, প্ৰথম আৰু শেষ স্থানীয় মানৰ গুণফলেৰে, বা আটাইতকৈ ডাঙৰ আৰু সৰু স্থানীয় মানৰ পাৰ্থক্যেৰে সংকেতিত হ'ব পাৰে। প্ৰাৰ্থীয়ে তৎক্ষণাত আখৰবোৰৰ ওপৰত স্থানীয় মান লিখি উদাহৰণৰ বাবে প্ৰস্তাৱিত মানটো গণনা কৰিব লাগে, প্ৰশ্নত ব্যৱহাৰ কৰাৰ আগতে সেয়া মিলে নে নাই পৰীক্ষা কৰি।

    এটা যোৰা সংকেতে দুটা শব্দ আৰু তেওঁলোকৰ সংকেত দি তৃতীয় এটা শব্দৰ সংকেত সোধে। ইয়াত নিয়মটো দুয়োটা উদাহৰণৰ পৰা একেলগে বিচাৰিব লাগে, আৰু কেৱল এটা উদাহৰণত মিলা নিয়ম নিয়ম নহয়। প্ৰাৰ্থীয়ে অনুমান কৰা নিয়মটো দ্বিতীয় উদাহৰণতো পৰীক্ষা কৰিব লাগে, আৰু দুয়োটাৰে মিলিলেহে তৃতীয় শব্দটো সংকেতিত কৰিব লাগে।

    প্ৰতিস্থাপন সংকেত, য'ত প্ৰতিটো আখৰ এটা নিৰ্দিষ্ট চিহ্নই সলনি কৰে, সঘনতাৰে সমাধান কৰা হয়। সংকেতিত লিখনিত আটাইতকৈ বেছি দেখা যোৱা আখৰটোৱে সাধাৰণ ভাষাৰ আটাইতকৈ বেছি দেখা যোৱা আখৰটো সূচায়, আৰু সাধাৰণ চুটি শব্দবোৰে আৰু সংকেত দিয়ে। প্ৰাৰ্থীয়ে গোটেই বাৰ্তাটো এবাৰতে অনুমান কৰিব নুখুজি এটা এটাকৈ আখৰ পূৰণ কৰি আগতে সমাধান হোৱা শব্দবোৰৰ সৈতে প্ৰতিটো অনুমান পৰীক্ষা কৰা উচিত।

    চৰ্তসাপেক্ষ সংকেতে এটা নিয়ম দিয়ে যি শব্দৰ আখৰবোৰৰ ওপৰত নিৰ্ভৰ কৰে, যেনে আখৰটো স্বৰ হ'লে তিনি স্থান আগৰ আখৰেৰে আৰু ব্যঞ্জন হ'লে তিনি স্থান পিছৰ আখৰেৰে সংকেতিত কৰা। প্ৰাৰ্থীয়ে চৰ্তটো সাৱধানে পঢ়ি প্ৰতিটো আখৰত সঠিক শাখা প্ৰয়োগ কৰিব লাগে। সংকেত কৰাৰ আগতে শব্দটোৰ স্বৰ আৰু ব্যঞ্জন দুটা গোটত লিখিলে মিহলি নহয়।

    কিছুমান প্ৰশ্নই এটা শব্দৰ আখৰবোৰ বৰ্ণমালাত তাৰ অৱস্থানেৰে লৰাই সংকেতিত কৰে, যাতে প্ৰথম আখৰ এটা স্থান, দ্বিতীয়টো দুটা স্থান ইত্যাদি লৰে। পদ্ধতি বাঢ়ি যোৱা লৰণৰ দৰেই, আৰু প্ৰাৰ্থীয়ে লৰণ প্ৰয়োগ কৰাৰ আগতে প্ৰতিটো আখৰৰ ওপৰত তাৰ অৱস্থান লিখিব লাগে। এই ধৰণৰ নিয়ম প্ৰয়োগ কৰা সহজ কিন্তু ভুল কৰাও সহজ, গতিকে শেষত এটা পৰীক্ষা কৰাটো মূল্যৱান।

    সংকেত দিয়া থাকি শব্দ বিচৰা হ'লে প্ৰাৰ্থীয়ে পিছলৈ কাম কৰে। তিনিৰ এটা আগলৈ লৰণ তিনিৰ এটা পিছলৈ লৰণেৰে ৰদ কৰা হয়, এটা ওলোটা কৰা আন এটা ওলোটা কৰাৰে, আৰু এটা প্ৰতিস্থাপন তালিকা আন দিশেৰে পঢ়ি ৰদ কৰা হয়। পিছলৈ কাম কৰা আগলৈ কাম কৰাৰ দৰেই একেই দক্ষতা, আৰু আগতে সংকেত দিয়া প্ৰশ্ন এটাই প্ৰাৰ্থীক ভয় খুৱাব নালাগে।

    এটা উপযোগী পৰীক্ষা হ'ল সংকেতটো শব্দতকৈ দীঘল নে চুটি, বা তাত অংক আছে নে নাই চোৱা, কাৰণ ই প্ৰাৰ্থীক কি ধৰণৰ নিয়ম চলি আছে কয়। একেই দীঘ আৰু একেই ধৰণৰ আখৰৰ সংকেতই এটা লৰণ বা প্ৰতিস্থাপন নিয়ম সূচায়; অংকৰ সংকেতই এটা সংখ্যা নিয়ম সূচায়; পুনৰাবৃত্তি হোৱা চিহ্নৰ সংকেতই এটা প্ৰতিস্থাপন সূচায়। প্ৰথমে সংকেতটোৰ আকৃতি পঢ়িলে সময় সাঁচে।

    শেষত, সংকেত উদ্ভাৱন কৰি অভ্যাস কৰক। এটা শব্দ লৈ, এটা নিয়ম ঠিক কৰি, সংকেত লিখি, তাৰ পিছত সেয়া এটা নতুন প্ৰশ্ন যেনেদৰে হয় সিদৰে ভাঙক। এই অভ্যাসে সাধাৰণ নিয়মবোৰ দ্বিতীয় স্বভাৱ কৰি তোলে, যাতে পৰীক্ষা কক্ষত নিয়মটো স্ক্ৰেটছৰ পৰা বিচৰাৰ পৰিৱৰ্তে সংকেতটোৰ চেহেৰাৰ পৰা চিনি পোৱা যায়, আৰু আখৰ লিখিবলৈ লগা সময়তে প্ৰশ্নটোৰ উত্তৰ দিয়া যায়।

    • প্ৰশ্নটো চোৱাৰ আগতে উদাহৰণৰ পৰা নিয়মটো বিচাৰক।
    • লৰণ নিয়মৰ বাবে, কেৱল প্ৰথমটো নহয়, প্ৰতিটো আখৰ তুলনা কৰক।
    • আখৰবোৰৰ তলত শব্দ আৰু তাৰ সংকেত দুয়োটাৰ স্থানীয় মান লিখক।
    • ঘূৰণ মনত ৰাখক: X ৰ পৰা তিনি আগলৈ লৰালে A।
    • নিৰ্দিষ্ট প্ৰতিস্থাপনৰ বাবে, আটাইতকৈ বেছি দেখা যোৱা আখৰবোৰ আগতে মিলাওক।
    • কী-শব্দ সংকেতৰ বাবে, কী-শব্দৰ তলত বৰ্ণমালা লিখি সংকেত পঢ়ক।
    • আখৰবোৰ অপৰিৱৰ্তিত কিন্তু পুনৰ্বিন্যস্ত হ'লে, প্ৰথমে ওলোটা কৰা আৰু সলনি কৰা নিয়মবোৰ পৰীক্ষা কৰক।
    • এটা যোৰা সংকেতৰ বাবে, নিয়মটো কেৱল এটাত নহয়, দুয়োটা উদাহৰণত মিলিব লাগে।
    • এটা প্ৰতিস্থাপন সংকেতৰ বাবে, আখৰৰ সঘনতা আৰু সাধাৰণ চুটি শব্দবোৰ ব্যৱহাৰ কৰক।
    • প্ৰথমে সংকেতটোৰ আকৃতি পঢ়ক: তাৰ দীঘ, আখৰৰ ধৰণ আৰু অংকৰ উপস্থিতি।

    সততে সোধা প্ৰশ্ন

    সংকেতৰ নিয়ম আটাইতকৈ দ্ৰুতকৈ কেনেকৈ বিচাৰোঁ?

    উদাহৰণ শব্দ আৰু তাৰ সংকেত এটা আনটোৰ ওপৰত লিখি প্ৰতিটো আখৰৰ তলত দুয়োটাৰ স্থানীয় মান লিখক; পাৰ্থক্যই তৎক্ষণাত নিয়মটো দেখুৱায়।

    এই অধ্যায়ৰ আটাইতকৈ সাধাৰণ ভুল কি?

    বৰ্ণমালা ঘূৰি আহে বুলি পাহৰা, গতিকে X ৰ পৰা আগলৈ লৰণ A লৈ যায় আৰু C ৰ পৰা পিছলৈ লৰণ Z লৈ যায়।

    এটা নিৰ্দিষ্ট প্ৰতিস্থাপন সংকেত কেনেকৈ সমাধান কৰোঁ?

    আটাইতকৈ বেছি দেখা যোৱা আখৰবোৰ আগতে মিলাই, প্ৰতিটো আখৰ ওলোৱাৰ লগে লগে এটা সৰু তালিকা বনাওক, এটা সহজ চাইফাৰৰ দৰেই।

    য'ত প্ৰতিটো আখৰ এটা চিহ্নই সলনি কৰে এনে সংকেত কেনেকৈ সমাধান কৰোঁ?

    সঘনতা ব্যৱহাৰ কৰক: আটাইতকৈ বেছি দেখা যোৱা চিহ্নটো আটাইতকৈ বেছি দেখা যোৱা আখৰৰ সৈতে মিলাওক আৰু সাধাৰণ চুটি শব্দবোৰ সংকেত হিচাপে লৈ এটা এটাকৈ আখৰ পূৰণ কৰক।

    সংকেতত শব্দৰ দৰেই একেই আখৰ কিন্তু বেলেগ ক্ৰমত থাকিলে কি বুজায়?

    নিয়মটোৱে আখৰবোৰ পুনৰ্বিন্যস্ত কৰে, যেনে শব্দটো ওলোটাই বা প্ৰথম আৰু শেষ আখৰ সলনি কৰি, গতিকে কোনো লৰণ জড়িত নহয়।
