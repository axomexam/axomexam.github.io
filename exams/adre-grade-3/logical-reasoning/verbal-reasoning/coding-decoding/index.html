    Q1. If CAT is coded as DBU, then DBU is coded as —
    যদি CAT ক DBU হিচাপে সংকেত কৰা হয়, তেন্তে DBU ক সংকেত কৰা হয় —
    (A) DBU DBU
    (B) ECV ECV
    (C) FDW FDW
    (D) ECW ECW
    Answer: B) ECV
    B) ECV
    Explanation: Each letter moves +1 step(s) in the alphabet, so DBU becomes ECV.
    প্ৰতিটো আখৰ বৰ্ণমালাত +1 খোজ যায়, গতিকে DBU এ ECV হয়।

    Coding-Decoding

    In coding-decoding a word or a number is written in a secret code and the same code must be applied to another word. Letter codes usually shift each letter forward or backward by a fixed number of places.

    Number codes may assign a number to each letter from its position in the alphabet, or they may reverse the word before coding it. Writing the alphabet with positions makes the pattern visible quickly.

    • Write the alphabet with position numbers 1 to 26.
    • Check for a constant forward or backward shift.
    • Some codes reverse the word first.
    • Apply the same rule found in the example.

    How should I start a letter coding question?

    Write the alphabet with its position numbers and compare the coded word with the original letter by letter to find the shift.

    সংকেত নিৰ্ণয়

    সংকেত নিৰ্ণয়ত এটা শব্দ বা সংখ্যা গোপন সংকেতত লিখা হয় আৰু একেই সংকেত আন এটা শব্দত প্ৰয়োগ কৰিব লাগে। আখৰৰ সংকেতত সাধাৰণতে প্ৰতিটো আখৰক এটা স্থিৰ সংখ্যক স্থান আগলৈ বা পিছলৈ সৰকোৱা হয়।

    সংখ্যা সংকেতত বৰ্ণমালাৰ স্থানৰ পৰা প্ৰতিটো আখৰক এটা সংখ্যা দিয়া হয়, বা সংকেত কৰাৰ আগতে শব্দটো ওলোটা কৰা হয়। স্থানৰ সৈতে বৰ্ণমালা লিখিলে আৰ্হিটো দ্ৰুতভাৱে দেখা যায়।

    • বৰ্ণমালা 1 ৰ পৰা 26 লৈকে স্থান সংখ্যাৰ সৈতে লিখক।
    • স্থিৰ আগলৈ বা পিছলৈ সৰকা আছে নে নাই পৰীক্ষা কৰক।
    • কিছুমান সংকেতত প্ৰথমে শব্দটো ওলোটা কৰা হয়।
