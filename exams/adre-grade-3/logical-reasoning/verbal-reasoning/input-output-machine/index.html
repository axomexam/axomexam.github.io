    Input-Output & Machine

    An input-output question shows a machine that rearranges a set of numbers or words in a fixed number of steps. The input is given, together with one or two steps of the output, and the question asks for a later step or for the final arrangement. The rule is hidden in the steps that are shown, and the task is to discover it.

    The rearrangement usually moves the smallest number to the left, or the largest number to the right, or arranges the words alphabetically, one item at a time. Compare the input with the first shown step to see which item moved and where. Once the rule is known, apply it step by step until the required step is reached. The same rule always applies at every step.

    • Compare the input with the first step to find what moved.
    • The machine usually places one item in order at each step.
    • Apply the same rule at every step.
    • Count the steps carefully to reach the step that is asked.

    ইনপুট-আউটপুট আৰু যন্ত্ৰ

    ইনপুট-আউটপুট প্ৰশ্নত এটা যন্ত্ৰ দেখুওৱা হয় যি এটা নিৰ্দিষ্ট সংখ্যক ধাপত সংখ্যা বা শব্দৰ এটা সমষ্টি পুনৰ্বিন্যাস কৰে। ইনপুটটো দিয়া থাকে, আৰু আউটপুটৰ এটা বা দুটা ধাপো, আৰু প্ৰশ্নই পিছৰ ধাপ বা অন্তিম বিন্যাস সোধে। দেখুওৱা ধাপবোৰত নিয়মটো লুকুৱাই থাকে, আৰু কামটো হ'ল তাক আৱিষ্কাৰ কৰা।

    পুনৰ্বিন্যাসে সাধাৰণতে সৰু সংখ্যাটো বাওঁফালে বা ডাঙৰটো সোঁফালে ঠেলে, বা শব্দবোৰ বৰ্ণমালাৰ ক্ৰমত এটা এটাকৈ সজায়। ইনপুটটো প্ৰথম দেখুওৱা ধাপৰ সৈতে তুলনা কৰি কোনটো বস্তু ক'লৈ গ'ল চাওক। নিয়ম জানিলে প্ৰয়োজনীয় ধাপ নোপোৱালৈকে তাক ধাপে ধাপে প্ৰয়োগ কৰক। একেটা নিয়মেই প্ৰতিটো ধাপত সদায় খাটে।

    • কি বস্তু লৰিছে বিচাৰিবলৈ ইনপুটটো প্ৰথম ধাপৰ সৈতে তুলনা কৰক।
    • যন্ত্ৰই সাধাৰণতে প্ৰতিটো ধাপত এটা বস্তু ক্ৰমত বহুৱায়।
    • প্ৰতিটো ধাপত একেই নিয়ম প্ৰয়োগ কৰক।
    • সোধা ধাপ পাবলৈ ধাপবোৰ সাৱধানে গণনা কৰক।
