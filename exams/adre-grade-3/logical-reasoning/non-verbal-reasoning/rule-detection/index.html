    Rule Detection

    In a rule detection question a rule is stated, such as every letter group must have its letters in alphabetical order, or every number must be divisible by a stated number, and the candidate must choose the option that obeys the rule. The rule is given, so no rule has to be discovered; the work is to test each option against it.

    The safe method is to check the options one by one against the stated rule and to stop at the first that satisfies it, after making sure that the others fail. A single counter-example is enough to reject an option. Reading the rule twice before testing avoids the common error of testing a different rule from the one that was given.

    • Read the given rule twice before testing.
    • Test each option against the rule, one by one.
    • One counter-example is enough to reject an option.
    • Confirm that the other options fail before choosing.

    নিয়ম নিৰ্ণয়ৰ প্ৰশ্নত এটা নিয়ম দিয়া থাকে, যেনে প্ৰতিটো আখৰৰ দলৰ আখৰবোৰ বৰ্ণমালাৰ ক্ৰমত থাকিব লাগে, বা প্ৰতিটো সংখ্যা এটা নিৰ্দিষ্ট সংখ্যাৰে বিভাজ্য হ'ব লাগে, আৰু প্ৰাৰ্থীয়ে নিয়মটো মানি চলা বিকল্পটো বাছনি কৰিব লাগে। নিয়মটো দিয়া থাকে, গতিকে কোনো নিয়ম আৱিষ্কাৰ কৰিব নালাগে; কামটো হ'ল প্ৰতিটো বিকল্প তাক পৰীক্ষা কৰা।

    সুৰক্ষিত পদ্ধতিটো হ'ল বিকল্পবোৰ এটা এটাকৈ দিয়া নিয়মৰ লগত পৰীক্ষা কৰা আৰু তাক পূৰণ কৰা প্ৰথমটোতে ৰোৱা, আনবোৰ বিফল হয় নে নাই নিশ্চিত কৰাৰ পিছত। এটা প্ৰতিভাও যথেষ্ট বিকল্প এটা বাদ দিবলৈ। পৰীক্ষা কৰাৰ আগতে নিয়মটো দুবাৰ পঢ়িলে দিয়া নিয়মৰ পৰা বেলেগ নিয়ম পৰীক্ষা কৰা সাধাৰণ ভুল এৰাই যায়।

    • পৰীক্ষা কৰাৰ আগতে দিয়া নিয়মটো দুবাৰ পঢ়ক।
    • প্ৰতিটো বিকল্প এটা এটাকৈ নিয়মৰ লগত পৰীক্ষা কৰক।
    • এটা প্ৰতিভাও যথেষ্ট বিকল্প এটা বাদ দিবলৈ।
    • বাছনি কৰাৰ আগতে আনবোৰ বিকল্প বিফল হয় নে নাই নিশ্চিত কৰক।
