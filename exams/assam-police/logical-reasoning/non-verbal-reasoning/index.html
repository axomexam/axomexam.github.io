      Sample questions with answers

      1. Find the odd one out among the four figures.
        Options: A / B / C / D
        Answer: A
        Explanation: Figures BCD are filled squares, while figure A is an empty square.
      2. Find the odd one out among the four figures.
        Options: A / B / C / D
        Answer: C
        Explanation: Figures ABD are circles (curved), while figure C is a square (straight sides).
      3. Find the odd one out among the four figures.
        Options: A / B / C / D
        Answer: D
        Explanation: Figures ABC are squares, while figure D is a circle.
      4. Find the odd one out among the four figures.
        Options: A / B / C / D
        Answer: B
        Explanation: Figures ACD are triangles, while figure B is a pentagon.
      5. Find the odd one out among the four figures.
        Options: A / B / C / D
        Answer: A
        Explanation: Figures BCD are pentagons (5 sides), while figure A is a hexagon (6 sides).
