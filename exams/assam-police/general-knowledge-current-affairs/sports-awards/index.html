      Sample questions with answers

      1. Which Indian state is Nayanmoni Saikia from?
        Options: Assam / Manipur / Meghalaya / Tripura
        Answer: Assam
        Explanation: Nayanmoni Saikia is from Assam and won gold in lawn bowls at CWG 2022.
      2. Which Indian state has produced the most Olympic medalists in hockey?
        Options: Punjab / Odisha / Jharkhand / Kerala
        Answer: Punjab
        Explanation: Punjab has produced many Olympic hockey medalists for India.
      3. Which Indian city hosted the 2010 Commonwealth Games?
        Options: New Delhi / Mumbai / Chennai / Kolkata
        Answer: New Delhi
        Explanation: New Delhi hosted the 2010 Commonwealth Games.
      4. Which Indian city hosted the 2017 FIFA U-17 World Cup?
        Options: Kolkata / New Delhi / Mumbai / Multiple cities
        Answer: Multiple cities
        Explanation: The 2017 FIFA U-17 World Cup was held across multiple Indian cities.
      5. Who is the first Indian woman to win an Olympic silver medal in badminton?
        Options: Saina Nehwal / P.V. Sindhu / Jwala Gutta / Ashwini Ponnappa
        Answer: P.V. Sindhu
        Explanation: P.V. Sindhu won a silver medal in badminton at the Rio Olympics 2016.
