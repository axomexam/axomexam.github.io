    Coding and Decoding

    Coding and Decoding is a regular topic of the reasoning paper of ADRE Grade IV. In these questions a word or a group of numbers is written in a secret form called a code, and the candidate has to find the rule by which the code was made and then apply the same rule to a new word. The questions look difficult at first glance, but almost every code is built on a simple and fixed pattern. Once the pattern is discovered, all the questions of that set can be answered quickly and correctly, which makes this a very rewarding topic.

    What is a Code

    A code is a system in which letters or numbers are replaced by other letters or numbers according to a fixed rule. In coding, a message is written in the normal language, and in decoding, the hidden message is read back into the normal language. The purpose of a code is to keep a message secret, but in reasoning tests the code follows a simple, discoverable logic. The candidate's task is to compare the given word with its code and to write down exactly what change has been made to each letter.

    Main Types of Coding

    Letter coding replaces each letter of a word by another letter, usually by shifting a fixed number of places in the alphabet. Number coding replaces letters by their position numbers in the alphabet. Substitution coding replaces whole words by other words or symbols. Mixed coding combines letters and numbers. Sometimes a code is based on reversing the word, exchanging the first and last letters, or moving letters in a particular order. Identifying which type is being used is the first and most important step.

    How to Solve a Coding Question

    1. Write the given word and its code one below the other.
    2. Compare the position of each letter in the word with the corresponding letter in the code.
    3. Note the change in terms of addition, subtraction or reversal.
    4. Check whether the same change works for every letter.
    5. Apply the discovered rule to the new word to get the answer.

    Common Coding Patterns

    • Shift by a fixed number — each letter moved forward by one or two places.
    • Shift by increasing numbers — first letter by one, second by two and so on.
    • Reverse the word — the last letter becomes the first.
    • Exchange positions — the first and last letters swap places.
    • Letter to number — A becomes 1, B becomes 2 and so on.
    • Opposite letter — A becomes Z, B becomes Y and so on.

    Worked Example

    Suppose "CAT" is coded as "DCB". Here C becomes D by moving forward one place, A becomes B by moving forward one place, and T becomes U by moving forward one place. So the rule is that every letter is moved one place forward. Now, to code "DOG", each letter is moved one place forward, giving "EPH". If instead the rule were to move each letter one place backward, "DOG" would become "CNF". This comparison shows why the rule must be tested on every letter before it is used.

    How This Topic Appears in the Examination

    Coding and decoding usually appears as three to five objective questions of one mark each. Sometimes a single set of two or three codes is given, and two or three questions are asked from the same set, so finding the rule once helps in answering all of them. The questions are usually of a simple letter-shift type, with occasional number codes. A candidate who can quickly compare the letters of the word and its code can answer these questions in a few seconds.

    Memory Tips

    Write the alphabet and number the letters from 1 to 26 and from 26 down to 1 on rough paper before starting. Compare the first letter of the word and its code first, since the pattern is often visible there. Test the rule on the second and third letters to make sure it is correct. Remember that the shift may increase or decrease, so check the differences one by one. When a code is given for two words, compare them to cross-check the rule.

    Common Mistakes to Avoid

    • Assuming a rule after comparing only the first letter.
    • Confusing a forward shift with a backward shift.
    • Forgetting that the shift may change from letter to letter.
    • Making an error in the position of letters near the ends of the alphabet.
    • Applying the rule to the given word instead of the new word.

    How to Prepare This Topic

    1. Memorise the positions of all letters in the alphabet.
    2. Practise at least fifteen coding questions every day.
    3. Work with two given codes to confirm the rule whenever possible.
    4. Keep a list of the different types of coding patterns.
    5. Time yourself so that each question takes less than a minute.

    Frequently Asked Questions

    What is coding and decoding?

    Coding means writing a message in a secret form using a fixed rule, and decoding means reading that secret form back into the original message. In reasoning questions you must find the rule and apply it.

    What is the most common type of coding question?

    Letter coding with a fixed shift is the most common. Each letter of the word is moved forward or backward by a fixed number of places in the alphabet.

    How do I find the rule of a code?

    Write the word and its code one below the other, compare each letter's position, and note the change. Then check that the same change works for every letter.

    Why should I test the rule on more than one letter?

    Because a rule that fits the first letter may not fit the others. The shift can increase or decrease, or the letters may be reversed, so testing every letter avoids a wrong answer.

    Can coding questions be based on numbers?

    Yes. In number coding each letter is replaced by its position number in the alphabet, so A becomes 1, B becomes 2, and so on. Some codes mix letters and numbers.

    সংকেত হৈছে এনে এটা পদ্ধতি য'ত আখৰ বা সংখ্যাক এটা নিৰ্দিষ্ট নিয়ম অনুসৰি আন আখৰ বা সংখ্যাৰে সলনি কৰা হয়। সংকেতীকৰণত এটা বাৰ্তা স্বাভাৱিক ভাষাত লিখা হয়, আৰু সংকেত-ভঙ্গত লুকুৱা বাৰ্তাটো পুনৰ স্বাভাৱিক ভাষালৈ পঢ়া হয়। সংকেতৰ উদ্দেশ্য হৈছে বাৰ্তা গোপন ৰখা, কিন্তু বিচাৰ পৰীক্ষাত সংকেত এটা সহজ, ধৰা পেলাব পৰা যুক্তি অনুসৰণ কৰে। প্ৰাৰ্থীৰ কাম হৈছে দিয়া শব্দটো ইয়াৰ সংকেতৰ সৈতে তুলনা কৰি প্ৰতিটো আখৰত কৰা পৰিৱৰ্তন লিখি উলিওৱা।

    সংকেতৰ মূল প্ৰকাৰ

    আখৰ সংকেতই শব্দৰ প্ৰতিটো আখৰক আন এটা আখৰেৰে সলনি কৰে, সাধাৰণতে বৰ্ণমালাত এটা নিৰ্দিষ্ট সংখ্যক স্থান সৰকাই। সংখ্যা সংকেতই আখৰক বৰ্ণমালাত ইয়াৰ স্থান নম্বৰেৰে সলনি কৰে। প্ৰতিস্থাপন সংকেতই গোটেই শব্দক আন শব্দ বা চিহ্নেৰে সলনি কৰে। মিশ্ৰ সংকেতত আখৰ আৰু সংখ্যা একেলগে থাকে। কেতিয়াবা সংকেত এটা শব্দ ওলোটা কৰা, প্ৰথম আৰু শেষ আখৰ বদল কৰা, বা এটা বিশেষ ক্ৰমত আখৰ লৰোৱাৰ ওপৰত আধাৰিত। কোন প্ৰকাৰ ব্যৱহাৰ হৈছে চিনাক্ত কৰাটোৱেই প্ৰথম আৰু আটাইতকৈ গুৰুত্বপূৰ্ণ খোজ।

    সংকেত প্ৰশ্ন কেনেকৈ সমাধান কৰিব

    1. দিয়া শব্দটো আৰু ইয়াৰ সংকেত এটাৰ তলত এটা লিখক।
    2. শব্দৰ প্ৰতিটো আখৰৰ স্থান সংকেতৰ সংশ্লিষ্ট আখৰৰ সৈতে তুলনা কৰক।
    3. যোগ, বিয়োগ বা ওলোটা কৰাৰ দিশত পৰিৱৰ্তনটো টোকা কৰক।
    4. একেই পৰিৱৰ্তনে প্ৰতিটো আখৰত কাম কৰেনে নাই পৰীক্ষা কৰক।
    5. উলিওৱা নিয়মটো নতুন শব্দত প্ৰয়োগ কৰি উত্তৰ পাওক।

    সাধাৰণ সংকেতৰ আৰ্হি

    • নিৰ্দিষ্ট সংখ্যক সৰকা — প্ৰতিটো আখৰ এটা বা দুটা স্থান আগলৈ।
    • বঢ়া সংখ্যাই সৰকা — প্ৰথম আখৰ এটা, দ্বিতীয় দুটা ইত্যাদি।
    • শব্দ ওলোটা কৰা — শেষ আখৰ প্ৰথম হয়।
    • স্থান বদল কৰা — প্ৰথম আৰু শেষ আখৰ ঠাই সলনি কৰে।
    • আখৰৰপৰা সংখ্যা — A ৰপৰা ১, B ৰপৰা ২ ইত্যাদি।
    • বিপৰীত আখৰ — A ৰপৰা Z, B ৰপৰা Y ইত্যাদি।

    কৰা উদাহৰণ

    ধৰক "CAT" ক "DCB" হিচাপে সংকেত কৰা হৈছে। ইয়াত C এ এটা স্থান আগলৈ গৈ D হয়, A এ এটা স্থান আগলৈ গৈ B হয়, আৰু T এ এটা স্থান আগলৈ গৈ U হয়। সেয়ে নিয়মটো হৈছে প্ৰতিটো আখৰ এটা স্থান আগলৈ লৈ যোৱা। এতিয়া "DOG" সংকেত কৰিবলৈ প্ৰতিটো আখৰ এটা স্থান আগলৈ লৈ গলে "EPH" পোৱা যায়। যদি নিয়মটো প্ৰতিটো আখৰ এটা স্থান পিছলৈ লৈ যোৱা হ'লহেঁতেন, "DOG" এ "CNF" হ'লহেঁতেন। এই তুলনাই দেখুৱায় যে ব্যৱহাৰ কৰাৰ আগতে নিয়মটো প্ৰতিটো আখৰত পৰীক্ষা কৰিব লাগে।

    পৰীক্ষাত এই বিষয় কেনেকৈ আহে

    সংকেতীকৰণ আৰু সংকেত-ভঙ্গ সাধাৰণতে তিনিটাৰপৰা পাঁচটা বস্তুনিষ্ঠ প্ৰশ্ন হিচাপে, প্ৰতিটোৰ এক নম্বৰ, আহে। কেতিয়াবা দুটা বা তিনিটা সংকেতৰ এটা গোট দিয়া হয়, আৰু একেই গোটৰপৰা দুটা বা তিনিটা প্ৰশ্ন সোধা হয়, সেয়ে নিয়মটো এবাৰ উলিয়ালে সেইবোৰ সবৰ উত্তৰ দিয়াত সহায় হয়। প্ৰশ্নবোৰ সাধাৰণতে সহজ আখৰ-সৰকা ধৰণৰ, লগতে মাজে মাজে সংখ্যা সংকেত। যি প্ৰাৰ্থীয়ে শব্দ আৰু ইয়াৰ সংকেতৰ আখৰবোৰ দ্ৰুতভাৱে তুলনা কৰিব পাৰে তেওঁ এই প্ৰশ্নবোৰ কেইটামান ছেকেণ্ডত উত্তৰ দিব পাৰে।

    মনত ৰখাৰ টিপছ

    আৰম্ভ কৰাৰ আগতে মোটা কাগজত বৰ্ণমালা লিখি আখৰবোৰ ১ ৰপৰা ২৬ লৈ আৰু ২৬ ৰপৰা ১ লৈ নম্বৰ দিয়ক। শব্দ আৰু ইয়াৰ সংকেতৰ প্ৰথম আখৰটো আগতে তুলনা কৰক, কাৰণ আৰ্হিটো প্ৰায়ে তাতেই দেখা যায়। নিয়মটো সঠিক হয়নে নাই নিশ্চিত হ'বলৈ দ্বিতীয় আৰু তৃতীয় আখৰত পৰীক্ষা কৰক। মনত ৰাখক যে সৰকাটো বাঢ়িব বা কমিব পাৰে, সেয়ে পাৰ্থক্যবোৰ এটা এটাকৈ পৰীক্ষা কৰক। দুটা শব্দৰ বাবে সংকেত দিয়া থাকলে, নিয়মটো পাৰস্পৰিকভাৱে পৰীক্ষা কৰিবলৈ সিহঁতক তুলনা কৰক।

    এৰাই চলিবলগীয়া সাধাৰণ ভুল

    • কেৱল প্ৰথম আখৰ তুলনা কৰিয়েই এটা নিয়ম ধৰি লোৱা।
    • আগলৈ সৰকা আৰু পিছলৈ সৰকা মিলাই পেলোৱা।
    • সৰকাটো আখৰে আখৰে সলনি হ'ব পাৰে বুলি পাহৰি যোৱা।
    • বৰ্ণমালাৰ দুই মূৰৰ আখৰৰ স্থানত ভুল কৰা।
    • নতুন শব্দৰ পৰিবৰ্তে দিয়া শব্দটোত নিয়ম প্ৰয়োগ কৰা।

    4. বিভিন্ন ধৰণৰ সংকেত আৰ্হিৰ এটা তালিকা ৰাখক।
    5. সময় মাপি চলক যাতে প্ৰতিটো প্ৰশ্ন এক মিনিটতকৈ কমত হয়।

    অধিক সমাধান কৰা উদাহৰণ

    যদি "CAT" ক "DBU" বুলি কোড কৰা হয়, তেন্তে প্ৰতিটো আখৰ এটা আগবাঢ়িছে, সেয়ে "DOG" ক "EPH" বুলি লিখা হ'ব। সংখ্যা কোডত A=1, B=2 ধৰি "BAD" ৰ মান 2+1+4=7 হ'লে একেই নিয়মে "CAB" ৰ মান 3+1+2=6। কেতিয়াবা ওলোটা ক্ৰমত কোড কৰা হয়, যেনে "MOTHER" ক "REHTOM" বুলি, তেতিয়া শব্দটো ওলোটাই দিলেই উত্তৰ ওলায়। যদি প্ৰশ্নত কোৱা হয় "চিকিৎসকক নাৰ্চ বোলা হয়, নাৰ্চক ৰোগী বোলা হয়", তেন্তে চিকিৎসালয়ত কাম কৰাজনক কি বুলি সোধা হ'লে উত্তৰত "নাৰ্চ" (যাক ৰোগী বোলা হয়) দিব লাগে। এনে প্ৰশ্নত প্ৰতিস্থাপনৰ দিশটো সাৱধানে পঢ়িব লাগে।

    উন্নত টিপছ

    কোডৰ নিয়ম বিচাৰোতে প্ৰথম আখৰ আৰু শেষ আখৰৰ পৰিৱৰ্তন তুলনা কৰক, কাৰণ ইয়াৰপৰা স্থানান্তৰৰ দিশ আৰু পৰিমাণ সহজে ধৰা পৰে। যদি আখৰবোৰৰ ক্ৰম সলনি হৈছে, তেন্তে ওলোটা কৰা হৈছেনে নাই চাওক। সংখ্যা কোডত আখৰৰ স্থান (A=1, Z=26) মনত ৰাখিলে দ্ৰুত কাম হয়। এটা উদাহৰণৰপৰা নিয়ম উলিয়াই তাক দ্বিতীয় শব্দত প্ৰয়োগ কৰি প্ৰথমে পৰীক্ষা কৰক, তাৰ পিছতহে উত্তৰৰ বিকল্পত লগাওক। এই পদ্ধতিয়ে ভুল এৰাই চলাত সহায় কৰে আৰু আত্মবিশ্বাস বঢ়ায়।

    সংকেতীকৰণ মানে এটা নিৰ্দিষ্ট নিয়মেৰে বাৰ্তা গোপন ৰূপত লিখা, আৰু সংকেত-ভঙ্গ মানে সেই গোপন ৰূপক মূল বাৰ্তালৈ পঢ়া। বিচাৰ প্ৰশ্নত আপুনি নিয়মটো উলিয়াই প্ৰয়োগ কৰিব লাগে।

    আটাইতকৈ সাধাৰণ সংকেত প্ৰশ্নৰ প্ৰকাৰ কি?

    নিৰ্দিষ্ট সৰকাৰ সৈতে আখৰ সংকেত আটাইতকৈ সাধাৰণ। শব্দৰ প্ৰতিটো আখৰ বৰ্ণমালাত এটা নিৰ্দিষ্ট সংখ্যক স্থান আগলৈ বা পিছলৈ লৈ যোৱা হয়।

    এটা সংকেতৰ নিয়ম কেনেকৈ উলিয়াম?

    শব্দ আৰু ইয়াৰ সংকেত এটাৰ তলত এটা লিখি প্ৰতিটো আখৰৰ স্থান তুলনা কৰি পৰিৱৰ্তনটো টোকা কৰক। তাৰ পিছত একেই পৰিৱৰ্তন প্ৰতিটো আখৰত কাম কৰেনে নাই পৰীক্ষা কৰক।

    নিয়ম এটাক একাধিক আখৰত কিয় পৰীক্ষা কৰিব লাগে?

    কাৰণ প্ৰথম আখৰত খাপ খোৱা নিয়মে আনবোৰত নাখাপ খাব পাৰে। সৰকাটো বাঢ়িব বা কমিব পাৰে, বা আখৰবোৰ ওলোটা হ'ব পাৰে, সেয়ে প্ৰতিটো আখৰ পৰীক্ষা কৰিলে ভুল উত্তৰ এৰাই চলা যায়।

    সংকেত প্ৰশ্নবোৰ সংখ্যাৰ ওপৰত আধাৰিত হ'ব পাৰেনে?

    হয়। সংখ্যা সংকেতত প্ৰতিটো আখৰ বৰ্ণমালাত ইয়াৰ স্থান নম্বৰেৰে সলনি কৰা হয়, সেয়ে A ৰপৰা ১, B ৰপৰা ২ ইত্যাদি। কিছুমান সংকেতত আখৰ আৰু সংখ্যা মিলি থাকে।
