      Sample questions with answers

      1. Find the next number in the series: 3, 6, 9, 12, 15, ?
        Options: 18 / 19 / 17 / 20
        Answer: 18
        Explanation: The series increases by 3 each time, so 15 + 3 = 18.
      2. Find the next number in the series: 5, 10, 20, 40, ?
        Options: 81 / 80 / 79 / 82
        Answer: 80
        Explanation: Each term is doubled, so 40 x 2 = 80.
      3. Find the next number in the series: 2, 4, 8, 16, 32, ?
        Options: 65 / 63 / 64 / 66
        Answer: 64
        Explanation: Each term is doubled, so 32 x 2 = 64.
      4. Find the next number in the series: 1, 4, 9, 16, 25, ?
        Options: 37 / 35 / 38 / 36
        Answer: 36
        Explanation: These are perfect squares (1², 2², 3², 4², 5²), so the next is 6² = 36.
      5. Find the next number in the series: 1, 8, 27, 64, ?
        Options: 125 / 126 / 124 / 127
        Answer: 125
        Explanation: These are perfect cubes (1³, 2³, 3³, 4³), so the next is 5³ = 125.
