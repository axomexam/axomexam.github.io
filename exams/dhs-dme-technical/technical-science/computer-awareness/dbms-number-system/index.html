    Q1. In a relational database, data is stored in
    সম্পৰ্কীয় ডাটাবেছত তথ্য ৰখা হয়
    (A) images only কেৱল ছবিত
    (B) tables made of rows and columns শাৰী আৰু স্তম্ভৰ তালিকাত
    (C) a single long text file এটা দীঘল লিখা ফাইলত
    (D) folders only কেৱল ফোল্ডাৰত
    Answer: B) tables made of rows and columns
    B) শাৰী আৰু স্তম্ভৰ তালিকাত
    Explanation: A relation is a table: each row is a record and each column a field. This structure is what makes SQL queries possible.
    সম্পৰ্ক এটা তালিকা: প্ৰতিটো শাৰী অভিলেখ আৰু প্ৰতিটো স্তম্ভ ক্ষেত্ৰ। এই গঠনে SQL প্ৰশ্ন সম্ভৱ কৰে।
    Q2. The binary equivalent of the decimal number 10 is
    দশমিক সংখ্যা ১০ ৰ দ্বিমিক ৰূপ
    (A) 1010 ১০১০
    (B) 1100 ১১০০
    (C) 1001 ১০০১
    (D) 1110 ১১১০
    Answer: A) 1010
    A) ১০১০
    Explanation: Ten is eight plus two, which sets the eight and two place values, giving 1010. Reversing the last two digits gives the wrong 1001.
    দহ মানে আঠ যোগ দুই, সেয়ে আঠ আৰু দুইৰ স্থানত এক, অৰ্থাৎ ১০১০। শেষৰ দুটা অংক ওলোটালে ভুলকৈ ১০০১ হয়।
    Q3. The primary key in a database table is used to
    ডাটাবেছ তালিকাৰ প্ৰাথমিক চাবি কিৰ বাবে ব্যৱহৃত হয়
    (A) sort the table by name তালিকা নামেৰে সজাবলৈ
    (B) encrypt the table তালিকা এনক্ৰিপ্ট কৰিবলৈ
    (C) count the rows শাৰী গণিবলৈ
    (D) uniquely identify each record প্ৰতিটো অভিলেখ অদ্বিতীয়ভাৱে চিনাক্ত কৰিবলৈ
    Answer: D) uniquely identify each record
    D) প্ৰতিটো অভিলেখ অদ্বিতীয়ভাৱে চিনাক্ত কৰিবলৈ
    Explanation: A primary key must be unique and not null, so no two rows can be confused. A sort order is a separate matter.
    প্ৰাথমিক চাবি অদ্বিতীয় আৰু শূন্য নহ'ব লাগে, সেয়ে দুটা শাৰী মিলি নাযায়। সজোৱা ক্ৰম বেলেগ কথা।
    Q4. The decimal value of the binary number 1111 is
    দ্বিমিক সংখ্যা ১১১১ ৰ দশমিক মান
    (A) 16 ১৬
    (B) 8 ৮
    (C) 15 ১৫
    (D) 11 ১১
    Answer: C) 15
    C) ১৫
    Explanation: Four ones mean eight plus four plus two plus one, that is fifteen. Sixteen would need a fifth bit set.
    চাৰিটা এক মানে আঠ যোগ চাৰি যোগ দুই যোগ এক = পোন্ধৰ। ষোল্ললৈ পঞ্চম বিট লাগিব।
    Q5. Which language is used to query a relational database?
    সম্পৰ্কীয় ডাটাবেছত প্ৰশ্ন সোধাৰ বাবে কোন ভাষা ব্যৱহৃত হয়
    (A) XML
    (B) SQL
    (C) HTML
    (D) CSS
    Answer: B) SQL
    Explanation: Structured query language selects, inserts and updates records. HTML marks up pages and CSS styles them.
    SQL এ অভিলেখ বাছে, সুমুৱায় আৰু আপডেট কৰে। HTML এ পৃষ্ঠা চিহ্নিত কৰে আৰু CSS এ ৰূপ দিয়ে।
    Q6. The hexadecimal number system has a base of
    হেক্সাডেচিমেল সংখ্যা পদ্ধতিৰ ভিত্তি
    (A) 16 ১৬
    (B) 10 ১০
    (C) 8 ৮
    (D) 2 ২
    Answer: A) 16
    A) ১৬
    Explanation: Hexadecimal uses sixteen symbols, zero to nine plus A to F. Base eight is octal and base two is binary.
    হেক্সাডেচিমেলে ষোল্ল চিহ্ন, শূন্যৰপৰা ন আৰু A ৰপৰা F। ভিত্তি আঠ অষ্টাল আৰু ভিত্তি দুই দ্বিমিক।
    Q7. In a database, a field that refers to the primary key of another table is called a
    ডাটাবেছত আন তালিকাৰ প্ৰাথমিক চাবিলৈ দেখুওৱা ক্ষেত্ৰক কি বোলা হয়
    (A) primary key প্ৰাথমিক চাবি
    (B) candidate key প্ৰাৰ্থী চাবি
    (C) super key ছুপাৰ চাবি
    (D) foreign key বহিঃ চাবি
    Answer: D) foreign key
    D) বহিঃ চাবি
    Explanation: A foreign key links two tables and enforces that the referenced row exists, which is how relationships are built.
    বহিঃ চাবিয়ে দুটা তালিকা জোড়ে আৰু নিৰ্দেশিত শাৰী আছে বুলি নিশ্চিত কৰে, সেয়ে সম্পৰ্ক গঢ়ে।
    Q8. The binary addition of 101 and 11 gives
    ১০১ আৰু ১১ ৰ দ্বিমিক যোগফল
    (A) 111 ১১১
    (B) 1010 ১০১০
    (C) 1000 ১০০০
    (D) 110 ১১০
    Answer: C) 1000
    C) ১০০০
    Explanation: Five plus three is eight, and eight in binary is 1000. Writing 111 would ignore the carry.
    পাঁচ যোগ তিনি = আঠ, আৰু দ্বিমিকে আঠ ১০০০। ১১১ লিখিলে হাত বঢ়োৱা উপেক্ষা হয়।
    Q9. Which SQL statement is used to retrieve data from a table?
    তালিকাৰপৰা তথ্য অনাৰ বাবে কোন SQL নিৰ্দেশ ব্যৱহৃত হয়
    (A) UPDATE
    (B) SELECT
    (C) INSERT
    (D) DELETE
    Answer: B) SELECT
    Explanation: SELECT reads rows. INSERT adds, UPDATE changes and DELETE removes them.
    SELECT এ শাৰী পঢ়ে। INSERT এ যোগ, UPDATE এ সলনি আৰু DELETE এ মচে।
    Q10. One nibble is equal to
    এক নিবল কিৰ সমান
    (A) 4 bits ৪ বিট
    (B) 8 bits ৮ বিট
    (C) 2 bits ২ বিট
    (D) 16 bits ১৬ বিট
    Answer: A) 4 bits
    A) ৪ বিট
    Explanation: A nibble is half a byte, that is four bits, and it is exactly one hexadecimal digit.
    নিবল আধা বাইট, অৰ্থাৎ চাৰি বিট, আৰু ই ঠিক এটা হেক্সাডেচিমেল অংক।
    Q11. Redundancy in a database leads to
    ডাটাবেছত বাহুল্যই কিৰ সৃষ্টি কৰে
    (A) faster queries always সদায় দ্ৰুত প্ৰশ্ন
    (B) better security উত্তম সুৰক্ষা
    (C) smaller files সৰু ফাইল
    (D) wasted space and inconsistent data অপচয় ঠাই আৰু অসামঞ্জস্য তথ্য
    Answer: D) wasted space and inconsistent data
    D) অপচয় ঠাই আৰু অসামঞ্জস্য তথ্য
    Explanation: Storing the same fact in many places wastes space and lets copies disagree. Normalisation removes such repetition.
    একেই তথ্য বহু ঠাইত ৰাখিলে ঠাই নষ্ট হয় আৰু নকলবোৰ বেলেগ হ'ব পাৰে। নৰ্মেলাইজেশনে পুনৰাবৃত্তি আঁতৰায়।
    Q12. The decimal number 25 in binary is
    দশমিক সংখ্যা ২৫ ৰ দ্বিমিক ৰূপ
    (A) 11010 ১১০১০
    (B) 10011 ১০০১১
    (C) 11001 ১১০০১
    (D) 10101 ১০১০১
    Answer: C) 11001
    C) ১১০০১
    Explanation: Twenty-five is sixteen plus eight plus one, so bits four, three and zero are set, giving 11001.
    পঁচিশ মানে ষোল্ল যোগ আঠ যোগ এক, সেয়ে চাৰি, তিনি আৰু শূন্য স্থানত এক, অৰ্থাৎ ১১০০১।
    Q13. A DBMS is used mainly to
    DBMS মূলতঃ কিৰ বাবে ব্যৱহৃত হয়
    (A) scan documents ডকুমেণ্ট স্কেন কৰা
    (B) store, retrieve and manage large amounts of data বহু তথ্য ৰখা, অনা আৰু চলোৱা
    (C) design web pages ৱেব পৃষ্ঠা ডিজাইন কৰা
    (D) edit photographs ফট'গ্ৰাফ সম্পাদনা কৰা
    Answer: B) store, retrieve and manage large amounts of data
    B) বহু তথ্য ৰখা, অনা আৰু চলোৱা
    Explanation: A database management system controls access, keeps data consistent and answers queries. It is not a design tool.
    DBMS এ প্ৰৱেশ নিয়ন্ত্ৰণ কৰি তথ্য সামঞ্জস্য ৰাখি প্ৰশ্নৰ উত্তৰ দিয়ে। ই ডিজাইন সজুলি নহয়।
    Q14. The octal equivalent of the decimal number 8 is
    দশমিক সংখ্যা ৮ ৰ অষ্টাল ৰূপ
    (A) 10 ১০
    (B) 8 ৮
    (C) 12 ১২
    (D) 18 ১৮
    Answer: A) 10
    A) ১০
    Explanation: In base eight the digits run only to seven, so eight is written as one zero. The symbol 8 does not exist in octal.
    ভিত্তি আঠত অংক কেবল সাতলৈকে, সেয়ে আঠক এক শূন্য লিখা হয়। অষ্টালত ৮ চিহ্ন নাই।
    Q15. Which of the following is a database constraint that prevents null values?
    শূন্য মান ৰোধ কৰা ডাটাবেছ বাধ্যতামূলক চৰ্তটো
    (A) UNIQUE only কেৱল UNIQUE
    (B) DEFAULT
    (C) INDEX
    (D) NOT NULL
    Answer: D) NOT NULL
    Explanation: NOT NULL forces a value in every row. UNIQUE prevents duplicates but still permits a null in many systems.
    NOT NULL এ প্ৰতিটো শাৰীত মান বাধ্যতামূলক কৰে। UNIQUE এ নকল ৰোধ কৰে কিন্তু বহু চিষ্টেমত শূন্য মান দিব পাৰি।
    Q16. The binary number 100000 has the decimal value

    (B) 8 ৮
    (C) 32 ৩২
    (D) 16 ১৬
    Answer: C) 32
    C) ৩২

    একৰ পিছত পাঁচটা শূন্য মানে দুইৰ ঘাত পাঁচ স্থানত এক, অৰ্থাৎ বত্ৰিশ।
    Q17. In a table of students, the column that stores the date of birth is a

    (A) relation সম্পৰ্ক
    (B) field ক্ষেত্ৰ

    (D) primary key প্ৰাথমিক চাবি
    Answer: B) field
    B) ক্ষেত্ৰ
    Explanation: A column is a field describing one attribute. A whole row about one student is a record.
    স্তম্ভ এটা ক্ষেত্ৰ যি এটা গুণ বৰ্ণনা কৰে। এজন শিক্ষাৰ্থীৰ গোটেই শাৰী এটা অভিলেখ।
    Q18. The result of subtracting 1 from the binary number 1000 is
    দ্বিমিক সংখ্যা ১০০০ ৰপৰা ১ বিয়োগ কৰিলে পোৱা ফল
    (A) 111 ১১১
    (B) 0111 only কেৱল ০১১১
    (C) 1001 ১০০১
    (D) 999 ৯৯৯
    Answer: A) 111
    A) ১১১
    Explanation: Eight minus one is seven, which is 111 in binary. Nine would be addition, not subtraction.
    আঠ বিয়োগ এক = সাত, যি দ্বিমিকে ১১১। ন হ'লে যোগ হ'ব, বিয়োগ নহয়।
    Q19. A view in a database is
    ডাটাবেছত ভিউ হ'ল
    (A) a copy of the whole database গোটেই ডাটাবেছৰ নকল
    (B) a type of index এবিধ সূচী
    (C) a backup file এটা বেকআপ ফাইল
    (D) a stored query that behaves like a virtual table সাঁচি ৰখা প্ৰশ্ন যি আভাসিক তালিকা যেন কাম কৰে
    Answer: D) a stored query that behaves like a virtual table
    D) সাঁচি ৰখা প্ৰশ্ন যি আভাসিক তালিকা যেন কাম কৰে
    Explanation: A view holds no data of its own; it runs its query and shows the result, which also limits what a user can see.
    ভিউৱে নিজৰ তথ্য নৰাখে; ই প্ৰশ্ন চলাই ফল দেখুৱায়, যিয়ে ব্যৱহাৰকাৰীয়ে দেখা সমলো সীমিত কৰে।
    Q20. The hexadecimal digit F has the decimal value
    হেক্সাডেচিমেল অংক F ৰ দশমিক মান
    (A) 10 ১০
    (B) 5 ৫
    (C) 15 ১৫
    (D) 16 ১৬
    Answer: C) 15
    C) ১৫
    Explanation: The digits run 0 to 9 and then A to F, so F is the sixteenth value counting from zero, that is fifteen.
    অংক শূন্যৰপৰা ন, তাৰ পিছত A ৰপৰা F, সেয়ে F শূন্যৰপৰা গণি ষোল্লতম, অৰ্থাৎ পোন্ধৰ।
    Q21. Which normal form removes partial dependency on a composite primary key?
    কোন নৰ্মেল ৰূপে যৌগিক প্ৰাথমিক চাবিৰ আংশিক নিৰ্ভৰতা আঁতৰায়
    (A) fourth normal form চতুৰ্থ নৰ্মেল ৰূপ
    (B) second normal form দ্বিতীয় নৰ্মেল ৰূপ
    (C) first normal form প্ৰথম নৰ্মেল ৰূপ
    (D) third normal form তৃতীয় নৰ্মেল ৰূপ
    Answer: B) second normal form
    B) দ্বিতীয় নৰ্মেল ৰূপ
    Explanation: Second normal form requires every non-key attribute to depend on the whole key, not part of it. First normal form only removes repeating groups.
    দ্বিতীয় নৰ্মেল ৰূপত প্ৰতিটো অ-চাবি গুণ গোটেই চাবিৰ ওপৰত নিৰ্ভৰ কৰিব লাগে, তাৰ অংশৰ ওপৰত নহয়। প্ৰথমটোৱে কেবল পুনৰাবৃত্ত গোট আঁতৰায়।
    Q22. The binary equivalent of the decimal number 7 is

    (A) 111 ১১১
    (B) 101 ১০১
    (C) 110 ১১০
    (D) 1000 ১০০০
    Answer: A) 111
    A) ১১১
    Explanation: Seven is four plus two plus one, so the first three bits are set. Eight would be 1000.
    সাত মানে চাৰি যোগ দুই যোগ এক, সেয়ে প্ৰথম তিনি বিটত এক। আঠ হ'লে ১০০০।
    Q23. An index in a database is created mainly to
    ডাটাবেছত সূচী সজা হয় মূলতঃ কিৰ বাবে
    (A) save disk space ডিস্কৰ ঠাই ৰাখিবলৈ
    (B) encrypt the column স্তম্ভ এনক্ৰিপ্ট কৰিবলৈ
    (C) delete duplicate rows নকল শাৰী মচিবলৈ
    (D) speed up searches on that column সেই স্তম্ভত সন্ধান দ্ৰুত কৰিবলৈ
    Answer: D) speed up searches on that column

    DBMS & Number System: study notes

    Read this before you attempt the questions. It is written for the DHS & DME Technical Grade III paper.

    What this topic actually contains

    The topic name joins two different things, and the paper keeps them separate. The first half is database management: what a database is, what the words table, row, column, key and query mean, and what SQL is used for. The second half is number systems: binary, octal, decimal and hexadecimal, and the conversions between them. The database half is definition and matching; the number half is two or three small calculations. Both are quick to secure.

    The conversion questions are the only place in this paper where arithmetic can go wrong for a reason other than a formula, so the method matters more than the answer. Learn the four place values in binary, and every conversion in the block can be done on the rough sheet in under a minute.

    Database, in the words the paper uses

    Data is a raw fact; information is data organised so that it means something. A database is an organised collection of related data, stored so that it can be searched and updated without duplication and inconsistency. A database management system, or DBMS, is the software that creates and manages the database, controls access, and lets several users work at once. When the database is organised as tables related to each other, it is called a relational database, and the software is an RDBMS; MySQL, Oracle, PostgreSQL and SQL Server are the standard examples.

    A table is a collection of related records, and it is also called a relation. A row is one complete record and is also called a tuple. A column is one field, describing one attribute of every record. A primary key uniquely identifies each row and cannot be null or repeated, which is why a roll number works and a name does not. A foreign key is a column that refers to the primary key of another table, and it is what links two tables together. A candidate key is any column that could serve as the primary key, and a composite key is a primary key made of two or more columns.

    The commands, and the four letters that matter

    SQL, structured query language, is the standard language for working with a relational database. Its commands are grouped in four families. DDL, data definition language, defines the structure: CREATE, ALTER, DROP. DML, data manipulation language, changes the contents: INSERT, UPDATE, DELETE. DQL, data query language, reads data: SELECT. DCL, data control language, manages permissions: GRANT, REVOKE. A question that names a command and asks which family it belongs to is answered from this list alone.

    Four properties of a good database are asked as the acronym ACID: atomicity, meaning a transaction happens completely or not at all; consistency, meaning the database moves from one valid state to another; isolation, meaning simultaneous transactions do not interfere; and durability, meaning a completed transaction survives a crash. Normalisation is the process of organising tables to remove repeated data, and it is the standard answer to why a database is split into several tables.

    Number systems, and the four place values

    Binary uses two digits, 0 and 1, and the place values from the right are 1, 2, 4, 8, 16, 32, 64 and so on, doubling each time. Octal uses eight digits, 0 to 7, with place values 1, 8, 64 and so on. Decimal uses ten digits and the familiar place values. Hexadecimal uses sixteen symbols, 0 to 9 and then A to F for ten to fifteen, with place values 1, 16, 256 and so on. A subscript is often written after the number to show the base, as in 1010 with a subscript 2.

    To convert binary to decimal, multiply each bit by its place value and add. Binary 1101 is 8 + 4 + 0 + 1, which is 13. To convert decimal to binary, divide by two repeatedly and read the remainders upwards: 13 gives remainders 1, 0, 1, 1 from the first division onwards, which read upwards is 1101. To convert binary to octal, group the bits in threes from the right and read each group; to convert binary to hexadecimal, group them in fours from the right. That grouping trick is the fastest route between the three machine bases, and it is what the paper expects.

    Two questions worked the short way

    A question asks for the decimal value of binary 1011. The place values are 8, 4, 2, 1, so 1011 is 8 + 0 + 2 + 1, which is 11. Writing the four place values above the bits before adding prevents the common slip of reading the string in the wrong direction.

    A question asks which key uniquely identifies a record. The answer is the primary key. The distractor is usually the foreign key, which links tables but does not identify a row uniquely, or the candidate key, which could be a primary key but has not been chosen as one. Read whether the question says identifies or links.

    Where marks are lost

    Why a database is used at all

    The advantages are asked as a list. A database reduces duplication, because each fact is stored once. It keeps the data consistent, because there is only one copy to update. It shares data among several users and applications. It enforces security through permissions, so each user sees only what is allowed. It supports backup and recovery. And it allows queries that would be impossible in a pile of separate files. The single word that covers most of this is controlled redundancy.

    The people who work with a database are also named. A database administrator creates the structure, manages users and permissions, takes backups and tunes performance. An application programmer writes the programs that use the data. An end user simply uses those programs. A question that asks who grants permission is asking for the administrator.

    Three conversions, worked in full

    Binary 10110 to decimal: the place values from the right are 16, 8, 4, 2, 1, so 10110 is 16 + 0 + 4 + 2 + 0, which is 22. Decimal 25 to binary: divide by two and read the remainders upwards, giving 11001. Binary 110101 to octal: group from the right as 110 and 101, which are 6 and 5, so the answer is 65 in octal. Binary 1101 to hexadecimal: group from the right as 1101, which is 13, written as D.

    How the machine stores a number

    A fixed number of bits is used for each value, and that limit is what a data type declares. Eight bits hold values from 0 to 255 in unsigned form, or -128 to 127 if one bit is reserved for the sign. Sixteen bits hold up to 65,535 unsigned. That is why an older system could not count past a certain figure, and why the year 2000 problem existed: two digits were stored for the year and 99 rolled over to 00.

    Three errors recur. DML and DDL are swapped, so CREATE is placed among the data commands. The primary key is described as repeatable, when uniqueness is its whole purpose. And in conversion, the bits are read from the left as place value 1 instead of from the right, which reverses the number. Check the direction and the family before choosing.

    • DBMS manages the database; RDBMS stores it as related tables.
    • Row is a record, column is a field, primary key is unique, foreign key links tables.
    • DDL creates structure, DML changes data, DQL reads data, DCL grants permission.
    • Binary place values 1, 2, 4, 8, 16; octal 1, 8, 64; hexadecimal 1, 16, 256.
    • Binary to octal group by three, binary to hexadecimal group by four, from the right.
    Exam tip: For any conversion, write the place values over the digits first and only then add. Almost every wrong answer in this block comes from adding in the wrong direction.

    অধ্যায়ৰ নামে দুটা বেলেগ বস্তু জোৰা লগাইছে, আৰু প্ৰশ্নকাকতে সেইবোৰ পৃথকে ৰাখে। প্ৰথম ভাগ ডেটাবেছ পৰিচালনা: ডেটাবেছ কি, টেবুল, শাৰী, স্তম্ভ, কি আৰু কুৱেৰি শব্দৰ অৰ্থ কি, আৰু SQL কি বাবে ব্যৱহাৰ হয়। দ্বিতীয় ভাগ সংখ্যা পদ্ধতি: বাইনেৰি, অক্টেল, দশমিক আৰু হেক্সাডেচিমেল, আৰু তাৰ মাজৰ ৰূপান্তৰ। ডেটাবেছৰ ভাগ সংজ্ঞা আৰু মিলোৱা; সংখ্যাৰ ভাগ দুই-তিনিটা সৰু গণনা। দুয়োটা সোনকালে আয়ত্ত কৰিব পৰা যায়।

    ৰূপান্তৰৰ প্ৰশ্নই এই প্ৰশ্নকাকতৰ একমাত্ৰ ঠাই য'ত সূত্ৰৰ বাহিৰে আন কাৰণত গণনা ভুল হ'ব পাৰে, সেয়ে উত্তৰতকৈ পদ্ধতিটো বেছি গুৰুত্বপূৰ্ণ। বাইনেৰিৰ চাৰিটা স্থান মান শিকি লোৱা, তেতিয়া এই অংশৰ প্ৰতিটো ৰূপান্তৰ ৰাফ শ্বীটত এক মিনিটৰ ভিতৰত কৰিব পাৰি।

    ডেটাবেছ, প্ৰশ্নকাকতে ব্যৱহাৰ কৰা শব্দৰে

    ডেটা হ'ল কেঁচা তথ্য; তথ্য হ'ল এনে ডেটা যাক সজাই অৰ্থবহ কৰা হৈছে। ডেটাবেছ হ'ল সম্পৰ্কিত ডেটাৰ সজাই ৰখা সংগ্ৰহ, যাক পুনৰাবৃত্তি আৰু অসঙ্গতি নোহোৱাকৈ সন্ধান আৰু আপডেট কৰিব পৰা যায়। ডেটাবেছ মেনেজমেণ্ট চিষ্টেম, বা DBMS, হ'ল সেই চফ্টৱেৰ যি ডেটাবেছ সৃষ্টি আৰু পৰিচালনা কৰে, প্ৰৱেশ নিয়ন্ত্ৰণ কৰে, আৰু কেইবাজনক একেলগে কাম কৰিব দিয়ে। ডেটাবেছ যেতিয়া ইটোৱে সিটোৰ লগত সম্পৰ্কিত টেবুল হিচাপে সজা হয়, তাক সম্পৰ্কীয় ডেটাবেছ বোলে, আৰু চফ্টৱেৰক RDBMS; MySQL, Oracle, PostgreSQL আৰু SQL Server চিনাকি উদাহৰণ।

    টেবুল হ'ল সম্পৰ্কিত অভিলেখৰ সংগ্ৰহ, যাক relationও বোলে। শাৰী এটা সম্পূৰ্ণ অভিলেখ আৰু তাক tupleও বোলে। স্তম্ভ এটা ফিল্ড, যি প্ৰতিটো অভিলেখৰ এটা বৈশিষ্ট্য বৰ্ণনা কৰে। প্ৰাথমিক কি প্ৰতিটো শাৰীক অদ্বিতীয়ভাৱে চিনাক্ত কৰে আৰু ই শূন্য বা পুনৰাবৃত্ত হ'ব নোৱাৰে, সেয়ে ৰোল নম্বৰে কাম কৰে কিন্তু নামে নকৰে। বিদেশী কি আন এখন টেবুলৰ প্ৰাথমিক কিৰ সৈতে সম্পৰ্ক ৰাখে, আৰু সেয়াই দুখন টেবুল জোৰা লগায়। প্ৰাৰ্থী কি সেই স্তম্ভ যি প্ৰাথমিক কি হ'ব পাৰে, আৰু যৌগিক কি দুটা বা ততোধিক স্তম্ভৰে গঠিত প্ৰাথমিক কি।

    আদেশবোৰ, আৰু গুৰুত্বপূৰ্ণ চাৰিটা আখৰ

    SQL, ষ্ট্ৰাকচাৰ্ড কুৱেৰি লেংগুৱেজ, সম্পৰ্কীয় ডেটাবেছৰ লগত কাম কৰাৰ মানক ভাষা। তাৰ আদেশবোৰ চাৰিটা পৰিয়ালত ভাগ কৰা হয়। DDL, ডেটা ডেফিনিচন লেংগুৱেজে গঠন নিৰ্ধাৰণ কৰে: CREATE, ALTER, DROP। DML, ডেটা মেনিপুলেচন লেংগুৱেজে বিষয়বস্তু সলায়: INSERT, UPDATE, DELETE। DQL, ডেটা কুৱেৰি লেংগুৱেজে ডেটা পঢ়ে: SELECT। DCL, ডেটা কণ্ট্ৰ'ল লেংগুৱেজে অনুমতি চম্ভালে: GRANT, REVOKE। এটা আদেশৰ নাম দি কোন পৰিয়ালৰ সোধা প্ৰশ্ন এই তালিকাৰ পৰাই উত্তৰ পায়।

    ভাল ডেটাবেছৰ চাৰিটা ধৰ্ম ACID হিচাপে সোধা হয়: এটমিচিটি, অৰ্থাৎ লেনদেন সম্পূৰ্ণৰূপে হয় বা নহয়; কনচিচটেন্সি, অৰ্থাৎ ডেটাবেছ এটা বৈধ অৱস্থাৰ পৰা আন এটালৈ যায়; আইছ'লেচন, অৰ্থাৎ একেলগে হোৱা লেনদেনে ইটোৱে সিটোত হস্তক্ষেপ নকৰে; আৰু ডিউৰেবিলিটি, অৰ্থাৎ সম্পূৰ্ণ লেনদেন ক্ৰেশৰ পিছতো থাকে। নৰ্মেলাইজেচন হ'ল পুনৰাবৃত্ত ডেটা আঁতৰাবলৈ টেবুল সজোৱা প্ৰক্ৰিয়া, আৰু ডেটাবেছ কিয় কেইবাখন টেবুলত ভগোৱা হয় তাৰ চিনাকি উত্তৰ এইটোৱেই।

    সংখ্যা পদ্ধতি, আৰু চাৰিটা স্থান মান

    বাইনেৰিত দুটা অঙ্ক, 0 আৰু 1, আৰু সোঁফালৰ পৰা স্থান মান 1, 2, 4, 8, 16, 32, 64 আৰু এনেকৈ দুগুণ হৈ যায়। অক্টেলত আঠটা অঙ্ক, 0 ৰ পৰা 7, স্থান মান 1, 8, 64 আৰু এনেকৈ। দশমিকত দহটা অঙ্ক আৰু চিনাকি স্থান মান। হেক্সাডেচিমেলত ষোল্লটা চিহ্ন, 0 ৰ পৰা 9 আৰু তাৰ পিছত A ৰ পৰা F লৈকে দহৰ পৰা পোন্ধৰলৈ, স্থান মান 1, 16, 256 আৰু এনেকৈ। ভিত্তি দেখুৱাবলৈ সংখ্যাৰ পিছত সৰু অঙ্কত 2, 8 বা 16 লিখা হয়।

    বাইনেৰিক দশমিকলৈ ৰূপান্তৰ কৰিবলৈ প্ৰতিটো বিটক তাৰ স্থান মানেৰে পূৰণ কৰি যোগ কৰা। বাইনেৰি 1101 = 8 + 4 + 0 + 1 = 13। দশমিকক বাইনেৰিলৈ কৰিবলৈ বাৰে বাৰে দুইৰে হৰণ কৰি ভাগশেষবোৰ তলৰ পৰা ওপৰলৈ পঢ়া: 13 ৰ ভাগশেষ 1, 0, 1, 1, যি ওপৰলৈ পঢ়িলে 1101। বাইনেৰিক অক্টেললৈ কৰিবলৈ সোঁফালৰ পৰা তিনি বিটৰ গোট কৰি প্ৰতিটো গোট পঢ়া; হেক্সাডেচিমেললৈ কৰিবলৈ সোঁফালৰ পৰা চাৰি বিটৰ গোট কৰা। এই গোট কৰাৰ কৌশলেই তিনি যন্ত্ৰ-ভিত্তিৰ মাজৰ আটাইতকৈ দ্ৰুত পথ, আৰু প্ৰশ্নকাকতে সেয়াই বিচাৰে।

    চুটিকৈ কৰা দুটা প্ৰশ্ন

    বাইনেৰি 1011 ৰ দশমিক মান সোধা হ'ল। স্থান মান 8, 4, 2, 1, সেয়ে 1011 = 8 + 0 + 2 + 1 = 11। যোগ কৰাৰ আগতে বিটবোৰৰ ওপৰত চাৰিটা স্থান মান লিখি থ'লে উলটি দিশত পঢ়াৰ সাধাৰণ ভুল নহয়।

    কোন কিয়ে অভিলেখক অদ্বিতীয়ভাৱে চিনাক্ত কৰে সোধা হ'ল। উত্তৰ প্ৰাথমিক কি। ফান্দ সাধাৰণতে বিদেশী কি, যি টেবুল জোৰা লগায় কিন্তু শাৰী অদ্বিতীয়ভাৱে চিনাক্ত নকৰে, বা প্ৰাৰ্থী কি, যি প্ৰাথমিক কি হ'ব পাৰে কিন্তু হিচাপে বাছনি কৰা হোৱা নাই। প্ৰশ্নত চিনাক্ত নে জোৰা লগোৱা সেয়া পঢ়া।

    ক'ত নম্বৰ যায়

    ডেটাবেছ কিয় ব্যৱহাৰ কৰা হয়

    সুবিধাবোৰ তালিকা হিচাপে সোধা হয়। ডেটাবেছে পুনৰাবৃত্তি কমায়, কাৰণ প্ৰতিটো তথ্য এটাবাৰহে সাঁচি ৰখা হয়। ই ডেটা সংগতিশীল ৰাখে, কাৰণ আপডেট কৰিবলৈ এটাহে কপি থাকে। ই কেইবাজন ব্যৱহাৰকাৰী আৰু কাৰ্যসূচীৰ মাজত ডেটা ভাগ কৰে। ই অনুমতিৰ জৰিয়তে নিৰাপত্তা বলবৎ কৰে, যাতে প্ৰত্যেকে কেৱল অনুমোদিত অংশ দেখে। ই বেকআপ আৰু পুনৰুদ্ধাৰ সমৰ্থন কৰে। আৰু ই এনে কুৱেৰি কৰিব দিয়ে যি পৃথক ফাইলৰ দমত অসম্ভৱ। এইখিনিৰ বেছিভাগ সামৰি লোৱা এটা শব্দ হ'ল নিয়ন্ত্ৰিত পুনৰাবৃত্তি।

    ডেটাবেছৰ লগত কাম কৰা মানুহবোৰৰ নামো সোধা হয়। ডেটাবেছ প্ৰশাসকে গঠন সৃষ্টি কৰে, ব্যৱহাৰকাৰী আৰু অনুমতি পৰিচালনা কৰে, বেকআপ লয় আৰু কাৰ্যক্ষমতা উন্নত কৰে। এপ্লিকেচন প্ৰগ্ৰামাৰে ডেটা ব্যৱহাৰ কৰা কাৰ্যসূচী লিখে। শেষ ব্যৱহাৰকাৰীয়ে কেৱল সেই কাৰ্যসূচী ব্যৱহাৰ কৰে। অনুমতি কোনে দিয়ে সোধা প্ৰশ্নৰ উত্তৰ প্ৰশাসক।

    তিনিটা ৰূপান্তৰ, সম্পূৰ্ণকৈ কৰা

    বাইনেৰি 10110 দশমিকলৈ: সোঁফালৰ পৰা স্থান মান 16, 8, 4, 2, 1, সেয়ে 10110 = 16 + 0 + 4 + 2 + 0 = 22। দশমিক 25 বাইনেৰিলৈ: দুইৰে হৰণ কৰি ভাগশেষ ওপৰলৈ পঢ়িলে 11001 পোৱা যায়। বাইনেৰি 110101 অক্টেললৈ: সোঁফালৰ পৰা 110 আৰু 101 গোট কৰা, যি 6 আৰু 5, সেয়ে অক্টেলত উত্তৰ 65। বাইনেৰি 1101 হেক্সাডেচিমেললৈ: সোঁফালৰ পৰা 1101 গোট, যি 13, তাক D লিখা হয়।

    যন্ত্ৰই সংখ্যা কেনেকৈ সাঁচি ৰাখে

    প্ৰতিটো মানৰ বাবে নিৰ্দিষ্ট সংখ্যক বিট ব্যৱহাৰ হয়, আৰু সেই সীমাই ডেটা প্ৰকাৰে ঘোষণা কৰে। আঠ বিটত চিহ্ন নোহোৱাকৈ 0 ৰ পৰা 255 লৈকে, বা এটা বিট চিহ্নৰ বাবে ৰাখিলে -128 ৰ পৰা 127 লৈকে ধৰে। ষোল্ল বিটত চিহ্ন নোহোৱাকৈ 65,535 লৈকে ধৰে। সেয়ে পুৰণি চিষ্টেমে এটা নিৰ্দিষ্ট সংখ্যাৰ ওপৰলৈ গণিব পৰা নাছিল, আৰু সেয়ে 2000 চনৰ সমস্যা আছিল: বছৰৰ বাবে দুটা অঙ্কহে সাঁচি ৰখা হৈছিল আৰু 99 এ 00 লৈ ঘূৰি গৈছিল।

    কুৱেৰি আৰু প্ৰতিবেদন

    কুৱেৰি হ'ল ডেটাবেছত কৰা প্ৰশ্ন। SQL ত কুৱেৰিৰ সাধাৰণ ৰূপটো হ'ল: SELECT স্তম্ভ FROM টেবুল WHERE চৰ্ত। WHERE অংশই শাৰীবোৰ ছাঁনি কৰে, ORDER BY য়ে সজায়, আৰু GROUP BY য়ে একে মানবোৰ গোট কৰে। প্ৰতিবেদন হ'ল কুৱেৰিৰ ফলাফল সজাই দিয়া ৰূপ। এই চাৰিটা শব্দৰ কাম জানিলে SQL ৰ প্ৰায় প্ৰতিটো প্ৰশ্নৰ উত্তৰ দিব পৰা যায়।

    ডেটাৰ অখণ্ডতাৰ দুটা নিয়মো সোধা হয়: প্ৰাথমিক কি কেতিয়াও শূন্য বা পুনৰাবৃত্ত হ'ব নোৱাৰে, আৰু বিদেশী কিৰ মান মূল টেবুলত থকা মানৰ লগত মিলিব লাগে। এই নিয়ম নাথাকিলে ডেটাবেছত এনে অভিলেখ থাকিব যি কোনো টেবুলৰ লগত নিমিলে, আৰু তাক এনাথ অভিলেখ বোলে।

    তিনিটা ভুল বাৰে বাৰে আহে। DML আৰু DDL ওলোটাকৈ লোৱা হয়, সেয়ে CREATE ক ডেটা আদেশৰ মাজত ৰখা হয়। প্ৰাথমিক কিক পুনৰাবৃত্ত হ'ব পৰা বুলি কোৱা হয়, অথচ অদ্বিতীয়তাই তাৰ গোটেই উদ্দেশ্য। আৰু ৰূপান্তৰত বিটবোৰ সোঁফালৰ পৰা নহয় বাঁওফালৰ পৰা স্থান মান 1 ধৰি পঢ়া হয়, যাৰ ফলত সংখ্যা উলটি যায়। বাছনিৰ আগতে দিশ আৰু পৰিয়াল চোৱা।

    • DBMS এ ডেটাবেছ পৰিচালনা কৰে; RDBMS এ সম্পৰ্কিত টেবুল হিচাপে ৰাখে।
    • শাৰী অভিলেখ, স্তম্ভ ফিল্ড, প্ৰাথমিক কি অদ্বিতীয়, বিদেশী কিয়ে টেবুল জোৰে।
    • DDL এ গঠন, DML এ ডেটা সলায়, DQL এ ডেটা পঢ়ে, DCL এ অনুমতি দিয়ে।
    • বাইনেৰিৰ স্থান মান 1, 2, 4, 8, 16; অক্টেল 1, 8, 64; হেক্সাডেচিমেল 1, 16, 256।
    • বাইনেৰিৰ পৰা অক্টেললৈ তিনিটাকৈ, হেক্সাডেচিমেললৈ চাৰিটাকৈ, সোঁফালৰ পৰা গোট কৰা।

    ফাইল সংৰক্ষণ আৰু ডেটাৰ প্ৰকাৰ

    ডেটা ফাইলত সংৰক্ষণ কৰাৰ দুটা পদ্ধতি সোধা হয়: ক্ৰমিক ফাইল, য'ত অভিলেখ এটা নিৰ্দিষ্ট ক্ৰমত থাকে আৰু বিচাৰিবলৈ আৰম্ভণিৰ পৰা পঢ়িব লাগে, আৰু ৰেণ্ডম বা প্ৰত্যক্ষ প্ৰৱেশ ফাইল, য'ত অভিলেখক তাৰ ঠিকনাৰে পোনপটীয়াকৈ পোৱা যায়। ডেটাবেছত সাধাৰণতে দ্বিতীয়টো ব্যৱহাৰ হয় কাৰণ সন্ধান দ্ৰুত।

    ডেটাৰ প্ৰকাৰো এশাৰীত সোধা হয়: পূৰ্ণসংখ্যা (integer), দশমিক সংখ্যা (float), আখৰ শৃংখল (varchar), তাৰিখ (date), আৰু বুলিয়ান (true/false)। এটা স্তম্ভৰ বাবে সঠিক প্ৰকাৰ বাছনি কৰাটো ডেটাবেছৰ প্ৰথম ভাল অভ্যাস, কাৰণ ভুল প্ৰকাৰে স্থান নষ্ট কৰে আৰু গণনা ভুল কৰায়।

    অক্টেল আৰু হেক্সাডেচিমেল কিয় লাগে

    মানুহৰ বাবে বাইনেৰি দীঘল আৰু পঢ়িবলৈ কঠিন। সেয়ে কম্পিউটাৰৰ লগত কাম কৰোঁতে অক্টেল আৰু হেক্সাডেচিমেল ব্যৱহাৰ কৰা হয়, কাৰণ প্ৰতিটো অক্টেল অঙ্কই তিনি বিট আৰু প্ৰতিটো হেক্সাডেচিমেল অঙ্কই চাৰি বিট সূচায়। মেম'ৰি ঠিকনা প্ৰায়ে হেক্সাডেচিমেলত লিখা হয়, আৰু পুৰণি চিষ্টেমত ফাইল অনুমতি অক্টেলত লিখা হৈছিল।

    পৰীক্ষাৰ টিপ: ৰূপান্তৰৰ যিকোনো প্ৰশ্নত আগতে অঙ্কবোৰৰ ওপৰত স্থান মান লিখা, তাৰ পিছতহে যোগ কৰা। এই অংশত প্ৰায় প্ৰতিটো ভুল উত্তৰ উলটি দিশত যোগ কৰাৰ পৰা আহে।
