    (A) Ctrl + V
    (B) Ctrl + X
    (C) Ctrl + S
    (D) Ctrl + P

    MS Office Suite: study notes

    Read this before you attempt the questions. It is written for the DHS & DME Technical Grade III paper.

    What the MS Office block asks

    This topic is the four everyday office programs and the small facts that surround them: what each program is for, what a cell or a slide or a mail merge is, which shortcut does which job, and which file extension belongs to which program. Nothing here is difficult, but the questions are exact, so a half-remembered shortcut or a swapped extension loses the mark.

    The fastest way to revise is three short tables - the four programs and their extensions, the ten shortcuts, and the five Excel functions. Write them once, then test yourself by covering one column. That is a fifteen minute job that covers almost every question the paper can set here.

    The four programs, one line each

    Word is a word processor for letters, reports and notices, and its files are .docx. Excel is a spreadsheet for calculations, lists and charts, and its files are .xlsx. PowerPoint is a presentation program for slides, and its files are .pptx. Access is a database program for tables, queries, forms and reports, and its files are .accdb. Older extensions still appear in questions: .doc, .xls and .ppt are the pre-2007 forms of the same three.

    The parts of the window are also asked. The title bar shows the file name, the ribbon or menu bar holds the commands, the formula bar sits above the grid in Excel, the status bar runs along the bottom, and the task pane appears at the side. In Word the ruler shows margins, and the insertion point is where the next character will go. A question that names a bar and asks its job is answered from this short list.

    Word: the four things that are asked

    Formatting changes how text looks, and it is of two kinds: character formatting such as font, size, bold, italic and underline, and paragraph formatting such as alignment, line spacing and indentation. A header or footer repeats text at the top or bottom of every page, which is where a page number goes. Mail merge produces many personalised letters from one template and a list of names and addresses, and it is the most-asked Word feature. A table organises text in rows and columns, and a section break lets one document carry different page layouts.

    Print preview shows the page as it will print, and page setup controls paper size, orientation - portrait or landscape - and margins. Those three words are enough for the printing questions, which usually ask which setting turns the page sideways; the answer is landscape.

    Excel: cell, formula, function

    A workbook is the file and a worksheet is one sheet inside it, and a workbook can hold several sheets. A cell is the box where a row and a column meet, and its address is the column letter followed by the row number, as in A1. A range is written with a colon, as in A1:A10. A formula always begins with an equals sign, and it can use cell references so that the result updates when the data changes. That is the whole advantage of a spreadsheet over a typed table.

    Five functions cover the questions: SUM adds a range, AVERAGE gives the mean, MAX and MIN give the largest and smallest, and COUNT counts numeric cells. IF returns one value when a condition is true and another when it is false. A cell reference is relative by default, which means it shifts when copied; an absolute reference is fixed with dollar signs, as in $A$1, and stays put. That difference is the single most examined point in this program.

    A chart turns numbers into a picture. A column chart compares values, a line chart shows a trend over time, and a pie chart shows parts of a whole, so the choice of chart type is a standard question. Sorting arranges rows, filtering hides rows that do not match a condition, and the auto fill handle copies a pattern down a column.

    PowerPoint and Access

    A presentation is a set of slides. A slide layout decides where the title and content placeholders sit. A transition is the effect between one slide and the next, while an animation is the effect applied to an object on a slide. Slide show view runs the presentation full screen, and the presenter view shows notes on the speaker's screen only. A master slide controls the design of every slide at once.

    Access has four objects. A table stores the data, a query asks a question of it, a form is the screen for entering or viewing one record at a time, and a report is the printable output. A primary key is required in every table, and relationships between tables are made on those keys. Questions in this topic usually ask which object is used for printing, and the answer is the report.

    The shortcuts that are asked

    Ctrl + C copies, Ctrl + X cuts, Ctrl + V pastes, Ctrl + Z undoes, Ctrl + Y redoes, Ctrl + S saves, Ctrl + P prints, Ctrl + A selects all, Ctrl + F finds, Ctrl + H replaces, Ctrl + B makes bold and Ctrl + U underlines. F5 starts a slide show in PowerPoint and updates a field in Word, F7 checks spelling, and Ctrl + Home jumps to the beginning of a document. Learn them in pairs - copy and paste, undo and redo, find and replace - because the questions usually offer the pair.

    Two questions worked the short way

    A question asks which file extension belongs to a spreadsheet. The answer is .xlsx, with .xls as the older form. .docx is a document and .pptx a presentation. If the option list mixes all three, sort by the first letter of the program name - Word, Excel, PowerPoint - which is also the first letter of the extension.

    A question asks which function finds the average of a range. The answer is AVERAGE, and the distractor is usually SUM divided by hand or COUNT, which counts rather than averages. Attach one verb to each function - add, average, largest, smallest, count - and the family is settled.

    Where marks are lost

    Excel in the office, in five more lines

    Freeze panes keeps a heading row visible while the sheet scrolls, which is the answer to how a long list is read comfortably. Conditional formatting changes a cell's colour by a rule, so a low stock figure turns red on its own. Data validation restricts what may be typed into a cell. A pivot table summarises a long list into totals by category, and it is the standard answer for a summary that must be built quickly. Print area and page break preview control what actually reaches paper.

    Errors have names too. A cell full of hash marks means the column is too narrow, not that the number is wrong. A #DIV/0! error means a division by zero or by an empty cell. A #REF! error means a reference points at a cell that was deleted. Those three are asked as matches, and each answer is one line.

    Word and PowerPoint, three more each

    In Word, a style applies a whole set of formatting at once, and it is what makes an automatic table of contents possible. Track changes records edits for review, and comments attach a note to a selection without changing the text. In PowerPoint, the slide sorter view shows all slides as thumbnails for reordering, the notes pane holds what the speaker will say, and rehearse timings records how long each slide takes.

    Three errors recur. Transition and animation are swapped, so the effect between slides is called an animation. A relative reference is described as fixed, when only an absolute reference with dollar signs is fixed. And .pptx is given for a word document, which is a plain slip from reading the options too quickly. Check the program name first, then the answer.

    • Word .docx, Excel .xlsx, PowerPoint .pptx, Access .accdb.
    • Workbook holds worksheets; a cell address is column then row; a range uses a colon.
    • SUM, AVERAGE, MAX, MIN, COUNT, IF; a formula starts with an equals sign.
    • $A$1 is absolute and stays put; A1 is relative and shifts when copied.
    • Transition is between slides, animation is on an object; report is the printable Access object.
    Exam tip: For any shortcut question, say the action aloud first - copy, paste, undo, print - and the key pair follows. The letters are the first letter of the English action in most cases.

    MS Office ছুইট: অধ্যয়ন টোকা

    প্ৰশ্নবোৰত হাত দিয়াৰ আগতে এইখিনি পঢ়ি লওক। তলৰ প্ৰতিটো কথা DHS আৰু DME কাৰিকৰী গ্ৰেড III পৰীক্ষাৰ বাবে লিখা।

    MS Office ৰ এই অংশত কি সোধা হয়

    এই অধ্যায়ত দৈনন্দিন চাৰিটা কাৰ্যালয় কাৰ্যসূচী আৰু তাৰ চাৰিওফালৰ সৰু তথ্য: প্ৰতিটো কাৰ্যসূচী কি বাবে, কোষ, স্লাইড বা মেইল মাৰ্জ কি, কোন চৰ্টকাটে কি কাম কৰে, আৰু কোন ফাইলৰ এক্সটেনচন কোন কাৰ্যসূচীৰ। ইয়াত একো কঠিন নাই, কিন্তু প্ৰশ্নবোৰ সঠিক, সেয়ে আধা মনত থকা চৰ্টকাট বা ওলোটা এক্সটেনচনে নম্বৰ হেৰুৱায়।

    আটাইতকৈ দ্ৰুত পুনৰাবৃত্তি তিনি এখন চুটি তালিকা - চাৰিটা কাৰ্যসূচী আৰু তাৰ এক্সটেনচন, দহটা চৰ্টকাট, আৰু পাঁচটা Excel ফলন। এবাৰ লিখি তাৰ পিছত এটা স্তম্ভ ঢাকি নিজকে পৰীক্ষা কৰা। পোন্ধৰ মিনিটৰ এই কামেই এই অংশৰ প্ৰায় প্ৰতিটো প্ৰশ্ন সামৰি লয়।

    চাৰিটা কাৰ্যসূচী, প্ৰতিটোৰে এশাৰী

    Word এখন শব্দ প্ৰক্ৰিয়াকৰণ কাৰ্যসূচী চিঠি, প্ৰতিবেদন আৰু জাননীৰ বাবে, আৰু তাৰ ফাইল .docx। Excel এখন স্প্ৰেডশ্বীট গণনা, তালিকা আৰু চাৰ্টৰ বাবে, আৰু তাৰ ফাইল .xlsx। PowerPoint এখন স্লাইডৰ প্ৰজেণ্টেচন কাৰ্যসূচী, আৰু তাৰ ফাইল .pptx। Access এখন ডেটাবেছ কাৰ্যসূচী টেবুল, কুৱেৰি, ফৰ্ম আৰু প্ৰতিবেদনৰ বাবে, আৰু তাৰ ফাইল .accdb। পুৰণি এক্সটেনচনো প্ৰশ্নত আহে: .doc, .xls আৰু .ppt সেই তিনিওটাৰ 2007 ৰ আগৰ ৰূপ।

    উইণ্ড'ৰ অংশবোৰো সোধা হয়। শিৰোনাম বাৰত ফাইলৰ নাম দেখুৱায়, ৰিবন বা মেনু বাৰত আদেশ থাকে, Excel ত গ্ৰিডৰ ওপৰত ফৰ্মুলা বাৰ থাকে, তলত ষ্টেটাছ বাৰ থাকে, আৰু কাষত টাস্ক পেনে আহে। Word ত ৰুলাৰে মাৰ্জিন দেখুৱায়, আৰু ইনছাৰশন পইণ্ট হ'ল পৰৱৰ্তী আখৰ য'ত যাব সেই ঠাই। এটা বাৰৰ নাম দি তাৰ কাম সোধা প্ৰশ্ন এই চুটি তালিকাৰ পৰাই উত্তৰ পায়।

    Word: সোধা চাৰিটা কথা

    ফৰ্মেটিঙে লিখনী কেনেকৈ দেখাব সেয়া সলায়, আৰু ই দুধৰণৰ: আখৰৰ ফৰ্মেটিং যেনে ফণ্ট, আকাৰ, বোল্ড, ইটালিক আৰু আণ্ডাৰলাইন, আৰু অনুচ্ছেদৰ ফৰ্মেটিং যেনে এলাইনমেণ্ট, শাৰীৰ ব্যৱধান আৰু ইণ্ডেনটেচন। হেডাৰ বা ফুটাৰে প্ৰতিটো পৃষ্ঠাৰ ওপৰত বা তলত লিখনী পুনৰাবৃত্তি কৰে, আৰু পৃষ্ঠা নম্বৰ তাতেই যায়। মেইল মাৰ্জে এখন টেমপ্লেট আৰু নাম-ঠিকনাৰ তালিকাৰ পৰা বহু ব্যক্তিগত চিঠি বনায়, আৰু সেয়াই Word ৰ আটাইতকৈ বেছি সোধা সুবিধা। টেবুলে লিখনীক শাৰী-স্তম্ভত সজায়, আৰু ছেকচন ব্ৰেকে এখন নথিত বেলেগ বেলেগ পৃষ্ঠা সজ্জা দিব দিয়ে।

    প্ৰিণ্ট প্ৰিভিউৱে পৃষ্ঠা ছপা হোৱাৰ দৰে দেখুৱায়, আৰু পেজ ছেটআপে কাগজৰ আকাৰ, দিশ - প'ৰ্ট্ৰেইট বা লেণ্ডস্কেপ - আৰু মাৰ্জিন নিয়ন্ত্ৰণ কৰে। এই তিনি শব্দই ছপা কৰাৰ প্ৰশ্নৰ বাবে যথেষ্ট, আৰু সাধাৰণতে সোধা হয় কোন ছেটিঙে পৃষ্ঠা কাষলতিকৈ কৰে; উত্তৰ লেণ্ডস্কেপ।

    Excel: কোষ, সূত্ৰ, ফলন

    ৱাৰ্কবুক হ'ল ফাইল আৰু ৱাৰ্কশ্বীট তাৰ ভিতৰৰ এখন পৃষ্ঠা, আৰু এখন ৱাৰ্কবুকত কেইবাখন ৱাৰ্কশ্বীট থাকিব পাৰে। কোষ হ'ল শাৰী আৰু স্তম্ভ মিলা বাকচ, আৰু তাৰ ঠিকনা স্তম্ভৰ আখৰ তাৰ পিছত শাৰীৰ নম্বৰ, যেনে A1। ৰেঞ্জ ক'লন চিহ্নৰে লিখা হয়, যেনে A1:A10। সূত্ৰ সদায় সমান চিহ্নৰে আৰম্ভ হয়, আৰু ইয়াত কোষৰ উল্লেখ ব্যৱহাৰ কৰিব পাৰি যাতে তথ্য সলনি হ'লে ফল নিজেই সলনি হয়। টাইপ কৰা টেবুলতকৈ স্প্ৰেডশ্বীটৰ গোটেই সুবিধা এইটোৱেই।

    পাঁচটা ফলনে প্ৰশ্নবোৰ সামৰি লয়: SUM এ ৰেঞ্জ যোগ কৰে, AVERAGE এ গড় দিয়ে, MAX আৰু MIN এ ডাঙৰ আৰু সৰু মান দিয়ে, আৰু COUNT এ সংখ্যাযুক্ত কোষ গণে। IF এ চৰ্ত সঁচা হ'লে এটা মান আৰু মিছা হ'লে আন এটা মান দিয়ে। কোষৰ উল্লেখ সাধাৰণতে আপেক্ষিক, অৰ্থাৎ কপি কৰিলে সলনি হয়; পৰম উল্লেখ ডলাৰ চিহ্নৰে স্থিৰ কৰা হয়, যেনে $A$1, আৰু সেয়া নসলনি থাকে। এই পাৰ্থক্যই এই কাৰ্যসূচীৰ আটাইতকৈ বেছি সোধা কথা।

    চাৰ্টে সংখ্যাক ছবিলৈ ৰূপান্তৰ কৰে। কলাম চাৰ্টে মান তুলনা কৰে, লাইন চাৰ্টে সময়ৰ লগত প্ৰৱণতা দেখুৱায়, আৰু পাই চাৰ্টে গোটৰ অংশ দেখুৱায়, সেয়ে চাৰ্টৰ প্ৰকাৰ বাছনি এটা চিনাকি প্ৰশ্ন। ছৰ্টিঙে শাৰী সজায়, ফিল্টাৰিঙে চৰ্তৰ লগত নিমিলা শাৰী লুকুৱায়, আৰু অট' ফিল হেণ্ডলে আৰ্হি এটা স্তম্ভত তললৈ কপি কৰে।

    PowerPoint আৰু Access

    প্ৰজেণ্টেচন স্লাইডৰ সংগ্ৰহ। স্লাইড লে আউটে শিৰোনাম আৰু বিষয়বস্তুৰ ঠাই নিৰ্ণয় কৰে। ট্ৰেনজিচন এটা স্লাইডৰ পৰা আনটোলৈ যোৱাৰ প্ৰভাৱ, আনহাতে এনিমেচন স্লাইডৰ এটা বস্তুৰ ওপৰত লগোৱা প্ৰভাৱ। স্লাইড শ্ব' ভিউৱে প্ৰজেণ্টেচন পূৰ্ণ পৰ্দাত চলায়, আৰু প্ৰজেণ্টৰ ভিউৱে কেৱল বক্তাৰ পৰ্দাত টোকা দেখুৱায়। মাষ্টাৰ স্লাইডে একেলগে প্ৰতিটো স্লাইডৰ ডিজাইন নিয়ন্ত্ৰণ কৰে।

    Access ত চাৰিটা বস্তু। টেবুলে ডেটা সাঁচে, কুৱেৰিয়ে তাৰ ওপৰত প্ৰশ্ন সোধে, ফৰ্ম এটা সময়ত এটা অভিলেখ দিবলৈ বা চাবলৈ পৰ্দা, আৰু প্ৰতিবেদন ছপা হ'ব পৰা আউটপুট। প্ৰতিখন টেবুলত প্ৰাথমিক কি লাগে, আৰু টেবুলৰ মাজৰ সম্পৰ্ক সেই কিৰ ওপৰত হয়। এই অধ্যায়ৰ প্ৰশ্নত সাধাৰণতে সোধা হয় ছপাৰ বাবে কোন বস্তু, আৰু উত্তৰ প্ৰতিবেদন।

    সোধা চৰ্টকাটবোৰ

    Ctrl + C কপি, Ctrl + X কাট, Ctrl + V পে'ষ্ট, Ctrl + Z আনডু, Ctrl + Y ৰিডু, Ctrl + S সাঁচি ৰখা, Ctrl + P ছপা, Ctrl + A সকলো বাছনি, Ctrl + F বিচৰা, Ctrl + H সলনি কৰা, Ctrl + B বোল্ড আৰু Ctrl + U আণ্ডাৰলাইন। PowerPoint ত F5 এ স্লাইড শ্ব' আৰম্ভ কৰে আৰু Word ত ফিল্ড আপডেট কৰে, F7 এ বানান পৰীক্ষা কৰে, আৰু Ctrl + Home এ নথিৰ আৰম্ভণিলৈ যায়। যোৰ হিচাপে শিকা - কপি আৰু পে'ষ্ট, আনডু আৰু ৰিডু, বিচৰা আৰু সলনি - কাৰণ প্ৰশ্নই সাধাৰণতে যোৰটো দিয়ে।

    চুটিকৈ কৰা দুটা প্ৰশ্ন

    স্প্ৰেডশ্বীটৰ এক্সটেনচন কোনটো সোধা হ'ল। উত্তৰ .xlsx, পুৰণি ৰূপ .xls। .docx নথি আৰু .pptx প্ৰজেণ্টেচন। বিকল্পত তিনিওটা মিলাই দিলে কাৰ্যসূচীৰ নামৰ প্ৰথম আখৰেৰে ভাগ কৰা - Word, Excel, PowerPoint - যি এক্সটেনচনৰ প্ৰথম আখৰো।

    ৰেঞ্জৰ গড় উলিওৱা ফলন কোনটো সোধা হ'ল। উত্তৰ AVERAGE, আৰু ফান্দ সাধাৰণতে SUM ক হাতেৰে ভগা বা COUNT, যি গড় নহয় গণনা কৰে। প্ৰতিটো ফলনৰ লগত এটা ক্ৰিয়া জোৰা লগোৱা - যোগ, গড়, ডাঙৰ, সৰু, গণনা - তেতিয়া গোটেই পৰিয়াল ঠিক হয়।

    ক'ত নম্বৰ যায়

    কাৰ্যালয়ত Excel, আৰু পাঁচটা কথা

    ফ্ৰীজ পেনে শ্বীট স্ক্ৰল হ'লেও শিৰোনামৰ শাৰী দেখা কৰি ৰাখে, আৰু দীঘল তালিকা আৰামেৰে পঢ়াৰ উত্তৰ এইটোৱেই। কণ্ডিচনেল ফৰ্মেটিঙে নিয়ম অনুসৰি কোষৰ ৰং সলায়, সেয়ে কম মজুতৰ সংখ্যা নিজেই ৰঙা হয়। ডেটা ভেলিডেচনে কোষত কি টাইপ কৰিব পাৰি সেয়া সীমিত কৰে। পিভট টেবুলে দীঘল তালিকাক শ্ৰেণী অনুসৰি যোগফললৈ সাৰাংশ কৰে, আৰু সোনকালে সাৰাংশ বনোৱাৰ চিনাকি উত্তৰ এইটোৱেই। প্ৰিণ্ট এৰিয়া আৰু পেজ ব্ৰেক প্ৰিভিউৱে কাগজলৈ কি যাব সেয়া নিয়ন্ত্ৰণ কৰে।

    ভুলবোৰৰো নাম আছে। হেশ চিহ্নৰে ভৰা কোষ মানে স্তম্ভটো বৰ সৰু, সংখ্যা ভুল নহয়। #DIV/0! মানে শূন্য বা খালী কোষেৰে হৰণ। #REF! মানে উল্লেখ এটা মচি পেলোৱা কোষলৈ দেখুৱাইছে। এই তিনিওটা মিলোৱা প্ৰশ্ন হিচাপে আহে, আৰু প্ৰতিটো উত্তৰ এশাৰী।

    Word আৰু PowerPoint, প্ৰতিটোৰে আৰু তিনি

    Word ত ষ্টাইলে একেলগে গোটেই ফৰ্মেটিং প্ৰয়োগ কৰে, আৰু সেয়াই স্বয়ংক্ৰিয় বিষয়সূচী সম্ভৱ কৰে। ট্ৰেক চেঞ্জেছ এ পৰ্যালোচনাৰ বাবে সলনিবোৰ লিখি ৰাখে, আৰু কমেণ্টে লিখনী নসলোৱাকৈ এটা বাছনিত টোকা লগায়। PowerPoint ত স্লাইড ছৰ্টাৰ ভিউৱে সকলো স্লাইড সৰু ছবি হিচাপে দেখুৱাই ক্ৰম সজাব দিয়ে, নোটছ পেনে বক্তাই কি ক'ব সেয়া ধৰি ৰাখে, আৰু ৰিহাৰ্ছ টাইমিঙে প্ৰতিটো স্লাইডত কিমান সময় লাগে লিখি ৰাখে।

    কাৰ্যালয়ৰ ফাইল ভাগ কৰি লোৱা

    দৈনন্দিন কামত এটা নিয়ম সহায়ক: লিখনীৰ বাবে Word, গণনাৰ বাবে Excel, দেখুওৱাৰ বাবে PowerPoint, আৰু অভিলেখ ৰাখিবলৈ Access। প্ৰশ্নকাকতত কেতিয়াবা এটা কাম দি সোধা হয় কোন কাৰ্যসূচী ব্যৱহাৰ কৰিব - যেনে মাহৰ খৰচৰ যোগফল - তেতিয়া উত্তৰ Excel।

    তিনিটা ভুল বাৰে বাৰে আহে। ট্ৰেনজিচন আৰু এনিমেচন ওলোটাকৈ লোৱা হয়, সেয়ে স্লাইডৰ মাজৰ প্ৰভাৱক এনিমেচন বুলি কোৱা হয়। আপেক্ষিক উল্লেখক স্থিৰ বুলি কোৱা হয়, অথচ কেৱল ডলাৰ চিহ্নযুক্ত পৰম উল্লেখ স্থিৰ। আৰু ৱৰ্ড নথিৰ বাবে .pptx দিয়া হয়, যি বিকল্প সোনকালে পঢ়াৰ সাধাৰণ ভুল। আগতে কাৰ্যসূচীৰ নাম চোৱা, তাৰ পিছত উত্তৰ।

    • Word .docx, Excel .xlsx, PowerPoint .pptx, Access .accdb।
    • ৱাৰ্কবুকত ৱাৰ্কশ্বীট; কোষৰ ঠিকনা আগতে স্তম্ভ তাৰ পিছত শাৰী; ৰেঞ্জত ক'লন।
    • SUM, AVERAGE, MAX, MIN, COUNT, IF; সূত্ৰ সমান চিহ্নৰে আৰম্ভ হয়।
    • $A$1 পৰম আৰু নসলনি; A1 আপেক্ষিক আৰু কপি কৰিলে সলনি।
    • ট্ৰেনজিচন স্লাইডৰ মাজত, এনিমেচন বস্তুৰ ওপৰত; প্ৰতিবেদন ছপা হ'ব পৰা Access বস্তু।

    প্ৰিণ্ট আৰু পৃষ্ঠা সজ্জা

    প্ৰিণ্ট কৰাৰ আগতে সোধা হয় কোন ছেটিঙে কাগজৰ দিশ সলায় (লেণ্ডস্কেপ), কোনটোৱে মাৰ্জিন ঠিক কৰে (পেজ ছেটআপ), আৰু কোনটোৱে ছপা হোৱাৰ দৰে দেখুৱায় (প্ৰিণ্ট প্ৰিভিউ)। Word ত শিৰোনাম পৃষ্ঠাৰ পৰা আঁতৰাবলৈ Different First Page অপচন ব্যৱহাৰ হয়, আৰু পৃষ্ঠা নম্বৰ Insert মেনুৰ পৰা যোগ কৰা হয়।

    Excel ত ছপা কৰাৰ আগতে প্ৰিণ্ট এৰিয়া নিৰ্ধাৰণ কৰা হয়, যাতে গোটেই বিশাল শ্বীট নহয়, প্ৰয়োজনীয় অংশহে ছপা হয়। পৃষ্ঠা ভাঙি যোৱা ঠাই চাবলৈ পেজ ব্ৰেক প্ৰিভিউ ব্যৱহাৰ হয়। এই দুটা শব্দ প্ৰায় প্ৰতিবছৰে এটা প্ৰশ্নত আহে।

    ফাইল সাঁচি ৰখা আৰু পুনৰুদ্ধাৰ

    Save এ একেই ফাইলত সাঁচে, Save As এ নতুন নাম বা নতুন ঠাইত সাঁচে, আৰু AutoRecover এ দুৰ্ঘটনাজনিত বন্ধৰ পিছত কাম ঘূৰাই দিয়ে। PDF হিচাপে সাঁচিলে সজ্জা সলনি নহয়, সেয়ে প্ৰতিবেদন পঠিয়াবলৈ সেয়াই সুবিধাজনক। এই তিনিওটা এশাৰী প্ৰশ্নত কামত আহে।

    পৰীক্ষাৰ টিপ: চৰ্টকাটৰ যিকোনো প্ৰশ্নত আগতে কামটো মুখেৰে কোৱা - কপি, পে'ষ্ট, আনডু, ছপা - তেতিয়া কি-যোৰ নিজেই ওলায়। বেছিভাগ ক্ষেত্ৰত আখৰটো ইংৰাজী ক্ৰিয়াৰ প্ৰথম আখৰ।
