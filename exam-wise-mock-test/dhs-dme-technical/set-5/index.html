    Q18. Statement: Should zoos be closed? Argument I: No, zoos sell tickets. Argument II: No, children like seeing animals.
    বিবৃতি: চিৰিয়াখানাবোৰ বন্ধ কৰা উচিতনে? যুক্তি I: নহয়, চিৰিয়াখানাই টিকট বিক্ৰী কৰে। যুক্তি II: নহয়, শিশুৱে জন্তু চাবলৈ ভাল পায়।
    (A) Only argument I is strong কেৱল যুক্তি I সবল
    (B) Only argument II is strong কেৱল যুক্তি II সবল
    (C) Neither argument is strong কোনো যুক্তিয়েই সবল নহয়
    (D) Both arguments are strong দুয়োটা যুক্তিয়েই সবল
    Answer: Neither argument is strong
    কোনো যুক্তিয়েই সবল নহয়
    Explanation: The statement asks «Should zoos be closed?». Argument I answers «No, zoos sell tickets» and argument II answers «No, children like seeing animals».
