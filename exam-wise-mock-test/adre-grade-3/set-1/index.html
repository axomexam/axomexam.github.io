    নাৱৰ সোঁতৰ দিশৰ গতিৰ সৈতে বিপৰীত দিশৰ গতিৰ অনুপাত — (নাৱ 20 km/h, সোঁত 4 km/h)
    (A) 16 : 24 ১৬ : ২৪
    (B) 20 : 4 ২০ : ৪
    (C) 4 : 20 ৪ : ২০
    (D) 3 : 2 ৩ : ২
    Answer: 3 : 2
    ৩ : ২
    Explanation: Downstream : upstream = (boat + stream) : (boat - stream) = 24 : 16, which reduces to 3 : 2.
    সোঁতৰ দিশ : বিপৰীত = (নাৱ + সোঁত) : (নাৱ - সোঁত) = 24 : 16, যি 3 : 2 লৈ হ্ৰাস পায়।

    Q15. If P = Q Q <= R R <= S, which conclusion is definitely true?

    (B) P ≤ S
    (C) P > S
    (D) P = S

    Explanation: The chain P = Q Q <= R R <= S always gives P ≤ S, while the other relations are not forced.

    সঘনাই সোধা প্ৰশ্ন

    ADRE 3.0 গ্ৰেড III সম্পূৰ্ণ পত্ৰ ছেট ১ ত কি কি বিষয় আছে?

    ছেট ১ ত ADRE 3.0 গ্ৰেড III পাঠ্যক্ৰমৰ ৬৮ টা বিষয় আছে, ওপৰৰ "এই ছেটত সামৰি লোৱা বিষয়সমূহ" তালিকাত দেখুওৱা হৈছে। প্ৰতিটো বিষয়ে তাৰ সম্পূৰ্ণ প্ৰশ্ন-সংগ্ৰহলৈ লিংক কৰে, যাতে পত্ৰখন দিয়াৰ আগতে আপুনি তত্ত্ব পুনৰ পঢ়িব পাৰে।

    ADRE 3.0 গ্ৰেড III সম্পূৰ্ণ পত্ৰ ছেট ১ ত কিমান প্ৰশ্ন আছে?

    ১৫০ টা দ্বিভাষিক প্ৰশ্ন, প্ৰতিটোত চাৰিটা বিকল্প, পত্ৰৰ প্ৰতিটো বিষয় সামৰি।

    ADRE 3.0 গ্ৰেড III ছেট ১ সময়বদ্ধ নেকি?

    হয়। আৰম্ভ কৰাৰ মুহূৰ্তৰ পৰাই এটা সময়বদ্ধ ঘড়ীত ছেটটো চলে, সেয়ে ই প্ৰকৃত পৰীক্ষাৰ দৰেই কাম কৰে।

    উত্তৰ চাব পাৰিমনে?

    হয়। জমা দিয়াৰ পিছত প্ৰতিটো প্ৰশ্নত শুদ্ধ বিকল্প আৰু অসমীয়া আৰু ইংৰাজী দুয়ো ভাষাত চুটি ব্যাখ্যা দেখুওৱা হয়।

    এই ছেট পুনৰ চেষ্টা কৰিব পাৰিমনে?

    হয়। আটাইবোৰ ছেট বিনামূলীয়া আৰু সীমাহীন — আপুনি যিকোনো ছেট যিমানবাৰ বিচাৰে পুনৰ চেষ্টা কৰিব পাৰে।
