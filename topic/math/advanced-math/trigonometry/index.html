      Q23. In a right-angled triangle, sin θ = 3/5. Find the value of cos θ.
      এটা সমকোণী ত্ৰিভূজত, sin θ = 3/5। cos θ ৰ মান নিৰ্ণয় কৰা।
      Answer: Given sin θ = 3/5, so opposite = 3, hypotenuse = 5.,By Pythagoras, adjacent = √(5² − 3²) = √(16) = 4.,cos θ = 4/5,Answer: 4/5
      দিয়া আছে sin θ = 3/5, সেয়ে বিপৰীত বাহু = 3, অতিভুজ = 5।,পাইথাগোৰাছ মতে, সন্নিহিত বাহু = √(5² − 3²) = √(16) = 4।,cos θ = 4/5,উত্তৰ: 4/5
