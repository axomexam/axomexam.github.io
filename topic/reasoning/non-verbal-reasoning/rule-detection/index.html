    Rule Detection

    Rule detection questions for reasoning: a specific rule is given and the candidate must pick the option (letter-groups, numbers, words or figures) that obeys it. Bilingual practice set for Assam competitive exams.

    Q1. Which of the following letter-groups follows the rule: the letters are consecutive in the alphabet?
    তলৰ কোনটো আখৰ-গোটে নিয়মটো মানি চলে: আখৰকেইটা বৰ্ণমালাত ধাৰাবাহিকভাৱে আছে?
    Answer: A
    Explanation: Option A (DEF) has letters in consecutive alphabetical order (D, E, F). The other groups are not consecutive, so the correct answer is A.
    বিকল্প A (DEF) ত আখৰবোৰ বৰ্ণমালাত ধাৰাবাহিক (D, E, F)। বাকী গোটবোৰ ধাৰাবাহিক নহয়, সেয়ে শুদ্ধ উত্তৰ হ'ব A।

    Rule Detection: Types, Methods and Examples

    Rule detection is a non-verbal reasoning topic in which a definite rule is stated, such as a fixed gap between letters, a pattern in numbers, a condition on the letters of a word, or a property of a set of figures, and the candidate must pick from the options the group that obeys that rule. The rule is not discovered by the candidate; it is given in the question, and the task is to test each option against it.

    The topic is asked in APSC, ADRE, Assam Police, DHS, DME, SSC and Railway examinations because it tests careful reading, quick checking and the discipline of applying one fixed condition to every choice. Sometimes the rule concerns letters, sometimes digits, sometimes whole words and sometimes figures, but the method is always the same. This article gives a complete deep-study revision of rule detection: the basic terms, the core rules, the types of questions, the step-by-step method, the common mistakes and a practical preparation plan.

    Basic Terms

    • Rule: the fixed condition given in the question that the correct option must satisfy.
    • Letter-group: a set of letters, as in ABCD or ZXVT, on which the rule is tested.
    • Alphabet position: the serial number of a letter, A = 1, B = 2 and so on.
    • Constant gap: the same difference between the positions of consecutive letters or numbers.
    • Ascending order: arrangement from small to large or from A towards Z.
    • Descending order: arrangement from large to small or from Z towards A.
    • Alternate series: a series in which every second term follows a separate rule.
    • Word rule: a rule about the letters or vowels of a given word.
    • Figure rule: a rule about the shape, the number of sides or the rotation of figures.
    • Condition: a single requirement such as "the first and last letters are vowels".
    • Verification: checking each option against the rule one by one.
    • Elimination: rejecting an option as soon as one letter or number breaks the rule.
    • Counter-example: a single case that proves an option wrong.

    Core Concepts and Rules

    • The rule is given, so never search for a new pattern; simply test each option against the stated rule.
    • Read the rule very carefully, because one word such as "and", "or", "all" or "not" can change the answer.
    • Convert letters to their alphabet positions when the rule involves differences or sums.
    • Check every letter, not only the first two; most wrong options fail at the third or fourth place.
    • For number groups, check the difference, the ratio and the parity as the rule demands.
    • When the rule speaks of vowels and consonants, count both exactly as the rule requires.
    • In figure rules, check the number of sides, the number of lines, the symmetry and the direction of rotation.
    • An option must satisfy the rule completely; a partial match is not enough.
    • If more than one option seems to fit, re-read the rule and find the extra condition you may have missed.
    • Elimination is faster than confirmation: reject the options that clearly break the rule and test the rest.

    Types of Rule Detection Questions

    The first type gives a rule about letter-groups, such as consecutive letters or a constant gap. The second type gives a rule about a number group, such as increasing differences or a fixed sum. The third type states a condition on a word, such as the number of vowels or the position of a particular letter. The fourth type gives a rule about figures, such as every figure having the same number of sides or rotating by a fixed angle. The fifth type gives a mixed rule that combines letters and numbers, and the sixth type asks which option does not obey a given rule.

    Steps to Solve a Rule Detection Question

    First, read the rule twice and underline the key condition. Second, decide what has to be measured, such as alphabet positions, differences, vowels or the number of sides. Third, apply the rule to the first option and reject it at once if even one term fails. Fourth, move to the next option and repeat the same check. Fifth, stop as soon as exactly one option has passed and confirm it once more. Finally, mark the option that satisfies the rule fully, and do it quickly.

    Examination Trends

    In competitive examinations rule detection usually carries two to four marks. Most questions use letter-groups and number groups, and constant gap, ascending order and reverse order are the favourite rules. Word-based rules about vowels and repeated letters, and figure-based rules about the number of sides, also appear regularly. Since the rule is given, these questions are quick and scoring, and a candidate who reads carefully rarely makes a mistake.

    Common Mistakes to Avoid

    • Do not invent your own pattern; use only the rule given in the question.
    • Do not stop checking after the first two terms; the error is often later.
    • Do not miss small words such as "and", "or", "all" and "not" in the rule.
    • Do not mix ascending and descending order when the rule mentions only one.
    • Do not miscount vowels and consonants; say them aloud if needed.
    • Do not accept an option that fits partly; the rule must hold completely.

    How to Prepare This Topic

    Begin by writing the alphabet from A to Z with the position numbers below each letter, and practise finding differences quickly. Then take a set of letter-group rules and check four options against each rule in writing until the process becomes automatic. Next, practise number-group rules and word rules in the same way.

    A very useful habit is to underline the exact condition before looking at the options, so that the eye is not distracted by a tempting but wrong pattern. Another good method is to solve each question twice, once by checking the options and once by testing the rule on the answer, to confirm the result. Daily practice of fifteen to twenty questions for a few days makes the topic fast and accurate, and the same checking skill helps in series, analogy and classification questions.

    Quick Revision Tips

    • Read and underline the rule before looking at the options.
    • Convert letters to numbers whenever the rule speaks of gaps or sums.
    • Check every term, not just the first two.
    • Reject an option the moment one term breaks the rule.
    • Watch the words "and", "or", "all" and "not".
    • Confirm the answer by checking the whole rule once more.

    Final Revision Note

    In the final revision, solve ten letter-group and ten number-group rule questions and note which rule you misread. Re-read those rules slowly and test each option again. This habit of reading the rule with full attention is the real skill, and with regular practice rule detection becomes one of the quickest scoring topics in the paper.

    প্ৰথম প্ৰকাৰে আখৰ-গোটৰ ওপৰত এটা নিয়ম দিয়ে, যেনে ক্ৰমিক আখৰ বা স্থিৰ ব্যৱধান। দ্বিতীয় প্ৰকাৰে সংখ্যা-গোটৰ ওপৰত এটা নিয়ম দিয়ে, যেনে বাঢ়ি যোৱা পাৰ্থক্য বা স্থিৰ যোগফল। তৃতীয় প্ৰকাৰে এটা শব্দৰ ওপৰত চৰ্ত দিয়ে, যেনে স্বৰবৰ্ণৰ সংখ্যা বা এটা নিৰ্দিষ্ট আখৰৰ স্থান। চতুৰ্থ প্ৰকাৰে চিত্ৰৰ ওপৰত এটা নিয়ম দিয়ে, যেনে প্ৰতিটো চিত্ৰৰ বাহুৰ সংখ্যা সমান বা স্থিৰ কোণেৰে ঘূৰ্ণন। পঞ্চম প্ৰকাৰে আখৰ আৰু সংখ্যা মিলাই এটা মিশ্ৰ নিয়ম দিয়ে, আৰু ষষ্ঠ প্ৰকাৰে কোনটো বিকল্পই দিয়া নিয়ম মানি নচলে সোধে।

    নিয়ম চিনাক্তকৰণ প্ৰশ্ন সমাধানৰ খোজ

    প্ৰথমে নিয়মটো দুবাৰ পঢ়ি মূল চৰ্তটো তলত দাগ টানা। দ্বিতীয়তে কি জুখিব লাগে সেয়া নিৰ্ণয় কৰা, যেনে বৰ্ণমালাৰ স্থান, পাৰ্থক্য, স্বৰবৰ্ণ বা বাহুৰ সংখ্যা। তৃতীয়তে প্ৰথম বিকল্পত নিয়ম প্ৰয়োগ কৰা আৰু এটা পদো বিফল হলেই তৎক্ষণাত বাদ দিয়া। চতুৰ্থতে পিছৰ বিকল্পলৈ গৈ একেই পৰীক্ষা পুনৰাবৃত্তি কৰা। পঞ্চমতে ঠিক এটা বিকল্প পাছ হোৱাৰ লগে লগে ৰৈ সেয়া আকৌ এবাৰ নিশ্চিত কৰা। শেষত নিয়মটো সম্পূৰ্ণৰূপে মানি চলা বিকল্পটো দ্ৰুতকৈ চিহ্নিত কৰা।

    পৰীক্ষাৰ প্ৰৱণতা

    প্ৰতিযোগিতামূলক পৰীক্ষাত নিয়ম চিনাক্তকৰণ সাধাৰণতে দুটাৰপৰা চাৰিটা নম্বৰৰ হয়। বেছিভাগ প্ৰশ্নত আখৰ-গোট আৰু সংখ্যা-গোট ব্যৱহাৰ হয়, আৰু স্থিৰ ব্যৱধান, উৰ্ধক্ৰম আৰু বিপৰীত ক্ৰম আটাইতকৈ পছন্দৰ নিয়ম। স্বৰবৰ্ণ আৰু পুনৰাবৃত্ত আখৰৰ ওপৰত শব্দ-ভিত্তিক নিয়ম আৰু বাহুৰ সংখ্যাৰ ওপৰত চিত্ৰ-ভিত্তিক নিয়মও নিয়মীয়াকৈ ওলায়। নিয়ম দিয়া থাকে বাবে এই প্ৰশ্নবোৰ দ্ৰুত আৰু নম্বৰ-আহৰণকাৰী, আৰু সাৱধানে পঢ়া প্ৰাৰ্থীয়ে বিৰলহে ভুল কৰে।

    পৰিহাৰ কৰিবলগীয়া সাধাৰণ ভুল

    • নিজৰ আৰ্হি সৃষ্টি নকৰিবা; কেৱল প্ৰশ্নত দিয়া নিয়ম ব্যৱহাৰ কৰা।
    • প্ৰথম দুটা পদ পৰীক্ষা কৰিয়েই নৰ'বা; ভুল প্ৰায়ে পিছত থাকে।
    • নিয়মত থকা "আৰু", "বা", "আটাই", "নহয়" এনে সৰু শব্দ নাপাহৰিবা।
    • নিয়মে কেৱল এটা ক'লে উৰ্ধক্ৰম আৰু অধঃক্ৰম মিহলাই নিদিবা।
    • স্বৰবৰ্ণ আৰু ব্যঞ্জনবৰ্ণ ভুলকৈ নগণিবা; প্ৰয়োজন হ'লে উচ্চ স্বৰেৰে গুণি চোৱা।
    • আংশিক মিলা বিকল্প গ্ৰহণ নকৰিবা; নিয়মটো সম্পূৰ্ণৰূপে মানি চলিব লাগে।

    এই বিষয়টো কেনেকৈ প্ৰস্তুতি কৰিব

    Aৰপৰা Zলৈ বৰ্ণমালা লিখি প্ৰতিটো আখৰৰ তলত স্থান সংখ্যা লিখি আৰম্ভ কৰা, আৰু পাৰ্থক্য দ্ৰুতকৈ বিচৰাৰ অভ্যাস কৰা। তাৰ পিছত আখৰ-গোটৰ নিয়মৰ এটা সমষ্টি লৈ চাৰিটা বিকল্প প্ৰতিটো নিয়মৰ সৈতে লিখিতভাৱে পৰীক্ষা কৰা যেতিয়ালৈকে প্ৰক্ৰিয়াটো স্বাভাৱিক নহয়। ইয়াৰ পিছত সংখ্যা-গোটৰ নিয়ম আৰু শব্দৰ নিয়ম একেইধৰণে অভ্যাস কৰা।

    এটা অতি উপযোগী অভ্যাস হ'ল বিকল্প চোৱাৰ আগতে আচল চৰ্তটো তলত দাগ টনা, যাতে চকুৱে প্ৰলোভনজনক কিন্তু ভুল আৰ্হিৰ দ্বাৰা বিভ্ৰান্ত নহয়। আন এটা ভাল পদ্ধতি হ'ল প্ৰতিটো প্ৰশ্ন দুবাৰ সমাধান কৰা, এবাৰ বিকল্প পৰীক্ষা কৰি আৰু এবাৰ উত্তৰটোত নিয়ম পৰীক্ষা কৰি, ফলাফল নিশ্চিত কৰিবলৈ। কেইদিন দৈনিক পোন্ধৰৰপৰা বিশটা প্ৰশ্ন অভ্যাস কৰিলে এই বিষয়টো দ্ৰুত আৰু শুদ্ধ হয়, আৰু এই একে পৰীক্ষা কৰাৰ দক্ষতাই শ্ৰেণী, সাদৃশ্য আৰু বৰ্গীকৰণ প্ৰশ্নতো সহায় কৰে।

    দ্ৰুত পুনৰালোচনাৰ টিপছ

    • বিকল্প চোৱাৰ আগতে নিয়মটো পঢ়ি তলত দাগ টানা।
    • নিয়মে ব্যৱধান বা যোগফলৰ কথা ক'লে আখৰবোৰক সংখ্যালৈ ৰূপান্তৰ কৰা।
    • কেৱল প্ৰথম দুটাই নহয়, প্ৰতিটো পদ পৰীক্ষা কৰা।
    • এটা পদে নিয়ম ভাঙিলেই সেই বিকল্প বাদ দিয়া।
    • "আৰু", "বা", "আটাই", "নহয়" শব্দবোৰৰ প্ৰতি চকু ৰাখা।
    • নিয়মটো আকৌ এবাৰ পৰীক্ষা কৰি উত্তৰ নিশ্চিত কৰা।

    শেষ পুনৰালোচনাৰ টোকা

    শেষ পুনৰালোচনাত দহটা আখৰ-গোট আৰু দহটা সংখ্যা-গোট নিয়মৰ প্ৰশ্ন সমাধান কৰি কোনটো নিয়ম ভুলকৈ পঢ়িছিল টোকা কৰা। সেই নিয়মবোৰ লাহে লাহে পুনৰ পঢ়ি প্ৰতিটো বিকল্প আকৌ পৰীক্ষা কৰা। নিয়মটো সম্পূৰ্ণ মনোযোগেৰে পঢ়াৰ এই অভ্যাসেই প্ৰকৃত দক্ষতা, আৰু নিয়মীয়া অভ্যাসেৰে নিয়ম চিনাক্তকৰণ পত্ৰখনৰ আটাইতকৈ দ্ৰুত নম্বৰ-আহৰণকাৰী বিষয় হৈ পৰে।

    সঘনাই সোধা প্ৰশ্ন

    যুক্তিত নিয়ম চিনাক্তকৰণ কি?

    এয়া এনে এটা বিষয় য'ত এটা স্থিৰ নিয়ম দিয়া থাকে আৰু সেই নিয়মটো সম্পূৰ্ণৰূপে মানি চলা বিকল্পটো প্ৰাৰ্থীয়ে বাছি ল'ব লাগে।

    নিয়মটো নিজেই বিচাৰিব লাগেনে?

    নালাগে। নিয়মটো প্ৰশ্নতে দিয়া থাকে; আপুনি কেৱল প্ৰতিটো বিকল্প দিয়া নিয়মৰ সৈতে পৰীক্ষা কৰিব লাগে।

    আখৰ-গোটৰ নিয়ম দ্ৰুতকৈ কেনেকৈ পৰীক্ষা কৰিম?

    বৰ্ণমালা স্থান সংখ্যাৰ সৈতে লিখি প্ৰতিটো আখৰক তাৰ সংখ্যালৈ ৰূপান্তৰ কৰা, তেতিয়া ব্যৱধান আৰু যোগফল সহজে উলিয়াব পাৰি।

    এই প্ৰশ্নবোৰ সমাধানৰ আটাইতকৈ দ্ৰুত উপায় কি?

    যিবোৰ বিকল্প যি কোনো ঠাইত নিয়ম ভাঙে সেইবোৰ বাদ দিয়া আৰু এটাই বিকল্প ৰোৱাৰ লগে লগে ৰৈ এবাৰ নিশ্চিত কৰা।

    কোনবোৰ পৰীক্ষাত নিয়ম চিনাক্তকৰণৰ প্ৰশ্ন সোধে?

    APSC, ADRE, অসম আৰক্ষী, DHS, DME, SSC আৰু ৰে'লৱে পৰীক্ষাই যুক্তিৰ অংশত নিয়ম চিনাক্তকৰণৰ প্ৰশ্ন সোধে।
