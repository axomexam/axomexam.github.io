      Input-Output (Machine Input) Test: Types, Methods and Examples

      Input-output is a reasoning topic in which a set of numbers or words is passed through a machine that rearranges it step by step according to a hidden rule, and the candidate has to find the next step, a particular step, or the final arrangement. The first line is called the input and each following line is called a step, with the machine changing the order by moving one or two items at a time until the arrangement is complete. The candidate must discover the rule from the given steps and then apply it.

      The special feature of this topic is that it is a puzzle of patterns. The rule is never stated directly; it must be read from the way the items move from one step to the next. This article gives a complete deep-study revision of input-output. It explains the basic terms, the types of rearrangement, the method of detecting the rule, the useful shortcuts, the common mistakes and a practical preparation plan so that the topic becomes a dependable source of marks in APSC, ADRE, Assam Police, SSC and Railway examinations.

      Basic Terms

      • Input: the first line, which is the original arrangement before the machine acts.
      • Step: each line after the input, showing the arrangement after one action of the machine.
      • Final arrangement: the last step, where no further change is possible.
      • Rearrangement: the change in the order of items from one step to the next.
      • Rule: the hidden logic by which the machine moves the items.
      • Ascending order: arranging numbers from smallest to largest.
      • Descending order: arranging numbers from largest to smallest.
      • Alphabetical order: arranging words according to the dictionary.
      • Shift: moving an item to a new position without changing the others' relative order.
      • Machine number: the step number, such as step I or step II.

      Core Concepts and Shortcuts

      • Compare the input with the first step and note which item moved and where it went.
      • Check whether the machine is fixing the smallest or largest number at an end, or arranging in ascending or descending order.
      • For word inputs, check whether words are placed alphabetically or by length.
      • Notice whether two items change place at a time or only one item is picked and placed.
      • Once the rule is found, apply it to the input to write the required step directly.
      • Do not try to write every intermediate step if the question asks only for a later step; count the movements instead.
      • In "which step" questions, work forward step by step and count carefully.

      Types of Rearrangement

      The first type arranges numbers in ascending or descending order by fixing the smallest or largest number at one end in each step. The second type arranges a mix of numbers and words, putting numbers in one order and words in another. The third type shifts a particular item by a fixed number of places each time. The fourth type is based on the number of letters in words, and the fifth type changes the input by a rule such as adding or subtracting a fixed value. Recognising the type quickly is the key, because each type has its own short method.

      Method of Detecting the Rule

      Start with the input and the first step and ask which item has moved and from where to where. Then compare the first step with the second step and see whether the same kind of move is repeated. If the smallest number has come to the first place in step one and the next smallest in step two, the rule is ascending order from the left. If a word has gone to the last place by alphabetical order, the rule is reverse alphabetical fixing. Writing the position of one item in each step helps in seeing the pattern clearly.

      Steps to Solve an Input-Output Question

      First, read the input and all the given steps carefully. Second, compare consecutive steps and identify the movement of each item. Third, state the rule in one simple sentence, such as "the largest number is fixed at the right end in each step". Fourth, apply the rule to the input and write the step that is asked for. Finally, verify by checking that the following step given in the question matches the rule you have found.

      Examination Trends

      In competitive examinations, input-output questions usually give the input and four or five steps, and ask for a particular step, the final step, or the step number at which a given arrangement appears. Some papers ask which element is at a particular position in a particular step. Because the rule is hidden, these questions take a little more time than other reasoning questions, but a candidate who practises the common patterns can solve them quickly and accurately.

      Common Mistakes to Avoid

      • Do not assume the rule from the first step only; confirm it with the second and third steps.
      • Do not mix ascending and descending order while applying the rule.
      • Do not skip a step while counting; a single missed step changes the answer.
      • Do not apply the rule to the wrong end of the arrangement.
      • Do not ignore a mixed input where numbers and words follow different rules.

      How to Prepare This Topic

      Begin by practising the ascending and descending number arrangement, which is the most common pattern. Then study mixed number-word arrangements, followed by letter-count and shifting patterns. For each question, write the rule in one sentence before answering. Solve at least twenty questions so that the common patterns are recognised at first sight. Finally, attempt previous years' papers under timed conditions, since speed in detecting the rule is the main skill this topic demands.

      Frequently Asked Questions

      What is input-output in reasoning?

      Input-output is a reasoning puzzle in which a set of numbers or words is rearranged step by step by a machine according to a hidden rule, and the candidate must find a required step or the final arrangement.

      How do I find the hidden rule?

      Compare the input with the first step and then the first step with the second, and note which item moves where. If the same kind of move repeats, that is the rule.

      How do I solve a "which step" question?

      Work forward step by step from the input, applying the rule carefully, and count the steps until the required arrangement appears.

      What is a mixed arrangement?

      A mixed arrangement has both numbers and words. Usually the numbers are arranged in one order and the words in another, so the candidate must follow two rules at the same time.

      Why is this topic slower than other reasoning topics?

      Because the rule is not given and must be discovered from the steps. With practice, the common patterns are recognised quickly and the speed improves a lot.

      পুনঃসজ্জাৰ প্ৰকাৰ

      প্ৰথম প্ৰকাৰে প্ৰতিটো খোজত আটাইতকৈ সৰু বা ডাঙৰ সংখ্যা এটা মূৰত স্থিৰ কৰি সংখ্যাক ঊৰ্ধ্ব বা অধোংক্ৰমে সজায়। দ্বিতীয় প্ৰকাৰে সংখ্যা আৰু শব্দৰ মিশ্ৰণ সজায়, সংখ্যাক এটা ক্ৰমত আৰু শব্দক আন এটা ক্ৰমত ৰাখি। তৃতীয় প্ৰকাৰে প্ৰতিবাৰ এটা নিৰ্দিষ্ট বস্তু নিৰ্দিষ্ট সংখ্যক স্থান স্থানান্তৰ কৰে। চতুৰ্থ প্ৰকাৰ শব্দৰ আখৰ সংখ্যাৰ ওপৰত আধাৰিত, আৰু পঞ্চম প্ৰকাৰে স্থিৰ মান যোগ বা বিয়োগ কৰা দৰে নিয়মেৰে ইনপুট সলনি কৰে। প্ৰকাৰটো দ্ৰুতভাৱে চিনাক্ত কৰাটো মূল কথা, কাৰণ প্ৰতিটো প্ৰকাৰৰ নিজা চুটি পদ্ধতি আছে।

      নিয়ম ধৰা পেলোৱাৰ পদ্ধতি

      ইনপুট আৰু প্ৰথম খোজৰপৰা আৰম্ভ কৰি কোনটো বস্তু ক'ৰপৰা ক'লৈ গ'ল সোধা। তাৰ পিছত প্ৰথম খোজক দ্বিতীয় খোজৰ সৈতে তুলনা কৰি একে ধৰণৰ গতি পুনৰাবৃত্তি হৈছে নে নাই চোৱা। যদি প্ৰথম খোজত আটাইতকৈ সৰু সংখ্যাটো প্ৰথম স্থানলৈ আহিছে আৰু দ্বিতীয় খোজত পৰৱৰ্তী সৰুটো, তেন্তে নিয়মটো বাওঁফালৰপৰা ঊৰ্ধ্বক্ৰম। যদি এটা শব্দ বৰ্ণানুক্ৰমে শেষ স্থানলৈ গৈছে, তেন্তে নিয়মটো বিপৰীত বৰ্ণানুক্ৰম স্থিৰীকৰণ। প্ৰতিটো খোজত এটা বস্তুৰ অৱস্থান লিখিলে আৰ্হিটো স্পষ্টভাৱে দেখা যায়।

      ইনপুট-আউটপুট প্ৰশ্ন সমাধানৰ খোজ

      প্ৰথমে ইনপুট আৰু দিয়া আটাইবোৰ খোজ সাৱধানে পঢ়া। দ্বিতীয়তে ক্ৰমিক খোজবোৰ তুলনা কৰি প্ৰতিটো বস্তুৰ গতি চিনাক্ত কৰা। তৃতীয়তে নিয়মটো এটা সৰল বাক্যত কোৱা, যেনে "প্ৰতিটো খোজত আটাইতকৈ ডাঙৰ সংখ্যাটো সোঁ মূৰত স্থিৰ হয়"। চতুৰ্থতে ইনপুটত নিয়মটো প্ৰয়োগ কৰি সোধা খোজটো লিখা। শেষত প্ৰশ্নত দিয়া পৰৱৰ্তী খোজটো আপুনি পোৱা নিয়মৰ সৈতে মিলে নে নাই পৰীক্ষা কৰি সত্যাপন কৰা।

      পৰীক্ষাৰ প্ৰৱণতা

      প্ৰতিযোগিতামূলক পৰীক্ষাত ইনপুট-আউটপুট প্ৰশ্নই সাধাৰণতে ইনপুট আৰু চাৰি বা পাঁচটা খোজ দিয়ে, আৰু এটা নিৰ্দিষ্ট খোজ, চূড়ান্ত খোজ, নাইবা এটা দিয়া সজ্জা কোনটো খোজত দেখা যায় সেয়া সোধে। কিছুমান প্ৰশ্নকাকতত এটা নিৰ্দিষ্ট খোজত এটা নিৰ্দিষ্ট অৱস্থানত কোনটো উপাদান আছে সেয়া সোধে। নিয়ম লুকুৱা হোৱাৰ বাবে এই প্ৰশ্নবোৰ আন যুক্তি প্ৰশ্নতকৈ অলপ সময় লয়, কিন্তু সাধাৰণ আৰ্হিবোৰৰ অভ্যাস থকা প্ৰাৰ্থীয়ে সিহঁতক দ্ৰুত আৰু শুদ্ধভাৱে সমাধান কৰিব পাৰে।

      পৰিহাৰ কৰিবলগীয়া সাধাৰণ ভুল

      • কেৱল প্ৰথম খোজৰপৰা নিয়ম ধৰি নল'বা; দ্বিতীয় আৰু তৃতীয় খোজেৰে নিশ্চিত কৰা।
      • নিয়ম প্ৰয়োগ কৰাৰ সময়ত ঊৰ্ধ্ব আৰু অধোংক্ৰম মিশ্ৰিত নকৰিবা।
      • গণনা কৰাৰ সময়ত এটা খোজ বাদ নিদিবা; এটা বাদ পৰা খোজে উত্তৰ সলনি কৰে।
      • সজ্জাৰ ভুল মূৰত নিয়ম প্ৰয়োগ নকৰিবা।
      • সংখ্যা আৰু শব্দে বেলেগ নিয়ম অনুসৰণ কৰা মিশ্ৰ ইনপুট উপেক্ষা নকৰিবা।

      এই বিষয়টো কেনেকৈ প্ৰস্তুতি কৰিব

      আটাইতকৈ সাধাৰণ আৰ্হি ঊৰ্ধ্ব আৰু অধোংক্ৰম সংখ্যা সজ্জাৰ অভ্যাস কৰি আৰম্ভ কৰা। তাৰ পিছত মিশ্ৰ সংখ্যা-শব্দ সজ্জা, তাৰ পিছত আখৰ-গণনা আৰু স্থানান্তৰ আৰ্হি অধ্যয়ন কৰা। প্ৰতিটো প্ৰশ্নৰ বাবে উত্তৰ দিয়াৰ আগতে নিয়মটো এটা বাক্যত লিখা। অন্ততঃ বিশটা প্ৰশ্ন সমাধান কৰা যাতে সাধাৰণ আৰ্হিবোৰ প্ৰথম দৃষ্টিতেই চিনাক্ত হয়। শেষত সময়ৰ সীমাৰ ভিতৰত পূৰ্বৰ প্ৰশ্নকাকত চেষ্টা কৰা।

      ইনপুট-আউটপুট প্ৰশ্নত সময় বচোৱাৰ এটা সহজ উপায় হ'ল প্ৰথম দুটা খোজ তুলনা কৰি নিয়ম এটা বাক্যত লিখি লোৱা, আৰু সেই নিয়মেৰে প্ৰয়োজনীয় খোজটো পোনপটীয়াকৈ লিখা। প্ৰতিটো মধ্যৱৰ্তী খোজ নিলিখিও উত্তৰ দিব পাৰি, যদি নিয়ম নিশ্চিতভাৱে জনা যায়। কিন্তু নিয়ম নিশ্চিত নহ'লে এটা খোজও বাদ দিয়া উচিত নহয়, কাৰণ এটা বাদ পৰা খোজে গোটেই উত্তৰ সলনি কৰি দিয়ে। প্ৰাৰ্থীয়ে সদায় সংখ্যা সজ্জা, শব্দ সজ্জা আৰু মিশ্ৰ সজ্জা এই তিনিটা সাধাৰণ আৰ্হি ভালদৰে অভ্যাস কৰিলে পৰীক্ষাত এই প্ৰশ্ন কেইছেকেণ্ডতে সমাধান কৰিব পাৰিব। আৰু মনত ৰাখিব, আটাইতকৈ কম খোজত নিয়ম ধৰা পেলোৱাটোৱেই এই বিষয়ৰ আচল দক্ষতা। লগতে প্ৰতিটো খোজতে কোনটো উপাদান আটাইতকৈ সৰু বা ডাঙৰ সেয়া টোকা কৰিলে নিয়ম ধৰা পেলোৱা আৰু সহজ হয়।

      সঘনাই সোধা প্ৰশ্ন

      যুক্তিত ইনপুট-আউটপুট কি?

      ইনপুট-আউটপুট হৈছে এটা যুক্তি পাজল য'ত সংখ্যা বা শব্দৰ এটা গোট লুকুৱা নিয়ম অনুসৰি খোজে খোজে এটা মেচিনে পুনঃসজ্জিত কৰে, আৰু প্ৰাৰ্থীয়ে প্ৰয়োজনীয় খোজ বা চূড়ান্ত সজ্জা বিচাৰিব লাগে।

      লুকুৱা নিয়ম কেনেকৈ বিচাৰিম?

      ইনপুটক প্ৰথম খোজৰ সৈতে আৰু তাৰ পিছত প্ৰথম খোজক দ্বিতীয়ৰ সৈতে তুলনা কৰি কোনটো বস্তু ক'লৈ গ'ল টোকা কৰা। একে ধৰণৰ গতি পুনৰাবৃত্তি হ'লে সেয়াই নিয়ম।

      "কোনটো খোজ" প্ৰশ্ন কেনেকৈ সমাধান কৰিম?

      ইনপুটৰপৰা নিয়ম সাৱধানে প্ৰয়োগ কৰি খোজে খোজে আগবাঢ়া, আৰু প্ৰয়োজনীয় সজ্জা নোহোৱালৈকে খোজবোৰ গণনা কৰা।

      মিশ্ৰ সজ্জা কি?

      মিশ্ৰ সজ্জাত সংখ্যা আৰু শব্দ দুয়ো থাকে। সাধাৰণতে সংখ্যাক এটা ক্ৰমত আৰু শব্দক আন এটা ক্ৰমত সজোৱা হয়, গতিকে প্ৰাৰ্থীয়ে একে সময়তে দুটা নিয়ম অনুসৰণ কৰিব লাগে।

      এই বিষয়টো আন যুক্তি বিষয়তকৈ কিয় লেহেম?

      কাৰণ নিয়ম দিয়া নাথাকে আৰু খোজবোৰৰপৰা আৱিষ্কাৰ কৰিব লাগে। অভ্যাসৰ জৰিয়তে সাধাৰণ আৰ্হিবোৰ দ্ৰুতভাৱে চিনাক্ত হয় আৰু গতি বহু উন্নত হয়।
