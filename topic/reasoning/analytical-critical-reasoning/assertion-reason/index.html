    Assertion and Reason: Types, Methods and Examples

    Assertion and Reason is a reasoning topic in which two statements are given. The first statement, called the Assertion (A), states a fact or a claim. The second statement, called the Reason (R), gives a possible cause or explanation for that claim. The candidate must decide whether each statement is true and, more importantly, whether the Reason correctly explains the Assertion. The answer is marked from a fixed set of standard codes, so the topic tests general knowledge and logical judgement at the same time.

    This topic is popular in APSC, ADRE, Assam Police, DHS, DME, SSC and Railway examinations because a question can be asked from any subject, including history, geography, science, polity and current affairs. A candidate who understands the exact meaning of each code and the difference between "true but not the explanation" and "true and the correct explanation" can score full marks with confidence. This article gives a complete deep-study revision of assertion and reason. It explains the basic terms, the five standard codes, the types of questions, the method of solving, the common mistakes and a practical preparation plan.

    Basic Terms

    • Assertion (A): the first statement, which makes a claim or states a fact.
    • Reason (R): the second statement, which offers an explanation or a cause for the assertion.
    • True statement: a statement that is factually correct.
    • Explanation: a reason that directly and logically accounts for the assertion.
    • Standard codes: the five fixed options used to mark the answer.
    • Independent truth: the truth of a statement by itself, without reference to the other statement.
    • Cause and effect: a relation in which the reason produces or explains the assertion.
    • Correlation: two statements that are both true but not linked as cause and effect.
    • Verification: checking a statement against a known fact or a definition.
    • Elimination: removing the codes that do not satisfy the given conditions.

    The Five Standard Codes

    • Code (a): both A and R are true, and R is the correct explanation of A.
    • Code (b): both A and R are true, but R is not the correct explanation of A.
    • Code (c): A is true but R is false.
    • Code (d): A is false but R is true.
    • Code (e): both A and R are false.

    Core Concepts and Method

    • First test the assertion alone and decide whether it is true or false.
    • Then test the reason alone and decide whether it is true or false.
    • Only if both are true does the question of explanation arise; if either is false, the answer is decided at once.
    • The reason must explain the assertion as a cause explains an effect, and must not be merely another true fact.
    • A reason that is a consequence of the assertion, and not its cause, is not the correct explanation.
    • A reason that is too general or unrelated does not explain the assertion.
    • In mathematics and geometry, definitions and properties often make the reason a correct explanation.
    • In history, the reason must describe the actual cause of the event stated in the assertion.

    Types of Assertion and Reason Questions

    The first type is the factual type, in which the assertion and reason come from history, geography, polity or general science. The second type is the conceptual type, in which the assertion and reason are based on a definition or a scientific law, often from physics, chemistry, biology or mathematics. The third type is the causal type, in which the reason states a genuine cause of the event mentioned in the assertion. The fourth type pairs two true statements that are related but not as cause and effect, so the answer is the second code. The fifth type gives a false reason with a true assertion, or the reverse, and tests careful verification. Many papers combine assertion and reason with current events, so the candidate must also keep general awareness up to date.

    Steps to Solve an Assertion and Reason Question

    First, read the assertion carefully and decide on its truth by recalling the relevant fact, definition or event. Second, read the reason carefully and decide its truth in the same way. Third, if both are true, ask whether the reason directly and logically explains the assertion. Fourth, if the reason explains the assertion, mark the first code; if the reason is true but does not explain the assertion, mark the second code. Fifth, if the assertion is true and the reason false, use the third code; if the assertion is false and the reason true, use the fourth code; if both are false, use the fifth code. Finally, recheck the code that you selected, because most mistakes happen when a candidate knows that both statements are true but misjudges the explanation.

    Examination Trends

    In competitive examinations assertion and reason is a common topic and usually carries two to four marks. The factual type from history and science appears most often, followed by the conceptual type. The second code, in which both statements are true but not connected as cause and effect, is a favourite of examiners because it separates careful candidates from hasty ones. In the Assam examinations the assertion often refers to Assamese history, geography, culture or government schemes, so local general knowledge is very useful here.

    Common Mistakes to Avoid

    • Do not mark the first code merely because both statements are true.
    • Do not confuse the correct explanation with a related true statement.
    • Do not treat a reason that is an effect or a consequence as a cause.
    • Do not answer from memory without actually reading the reason.
    • Do not ignore the possibility that both statements may be false.
    • Do not change the statement while deciding its truth.

If the sentence "A is true because R" sounds natural and correct, the first code is likely; if the sentence sounds forced or wrong even though both statements are true, the second code is likely. This small test removes much of the confusion that the length of the statements creates.     প্ৰথমে দাবীটো সাৱধানে পঢ়ি প্ৰাসংগিক তথ্য, সংজ্ঞা বা ঘটনা মনত পেলাই ইয়াৰ সত্যতা নিৰ্ণয় কৰা। দ্বিতীয়তে কাৰণটো সাৱধানে পঢ়ি একে ধৰণে ইয়াৰ সত্যতা নিৰ্ণয় কৰা। তৃতীয়তে দুয়ো সত্য হ'লে কাৰণে দাবীক পোনপটীয়াকৈ আৰু যুক্তিসংগতভাৱে ব্যাখ্যা কৰেনে নকৰে সোধা। চতুৰ্থতে কাৰণে ব্যাখ্যা কৰিলে প্ৰথম ক'ড, আৰু কাৰণ সত্য কিন্তু ব্যাখ্যা নকৰিলে দ্বিতীয় ক'ড চিহ্নিত কৰা। পঞ্চমতে দাবী সত্য আৰু কাৰণ অসত্য হ'লে তৃতীয় ক'ড, দাবী অসত্য আৰু কাৰণ সত্য হ'লে চতুৰ্থ ক'ড, আৰু দুয়ো অসত্য হ'লে পঞ্চম ক'ড লোৱা। শেষত বাছনি কৰা ক'ডটো পুনৰ পৰীক্ষা কৰা, কাৰণ বেছিভাগ ভুল তেতিয়াহে হয় যেতিয়া প্ৰাৰ্থীয়ে দুয়ো বাক্য সত্য বুলি জানে কিন্তু ব্যাখ্যাটো ভুলকৈ বিচাৰ কৰে।

    পৰীক্ষাৰ প্ৰৱণতা

    প্ৰতিযোগিতামূলক পৰীক্ষাত দাবী আৰু কাৰণ এক সাধাৰণ বিষয় আৰু সাধাৰণতে দুৰপৰা চাৰিটা নম্বৰৰ হয়। ইতিহাস আৰু বিজ্ঞানৰ তথ্যভিত্তিক প্ৰকাৰ বেছি সোধা হয়, তাৰ পিছত ধাৰণাগত প্ৰকাৰ। দুয়ো বাক্য সত্য কিন্তু কাৰণ-ফল হিচাপে সংযুক্ত নোহোৱা দ্বিতীয় ক'ড পৰীক্ষকে বেছি ভাল পায়, কাৰণ ইয়ে সাৱধান প্ৰাৰ্থীক খৰধৰ কৰা প্ৰাৰ্থীৰপৰা পৃথক কৰে। অসমৰ পৰীক্ষাত দাবী প্ৰায়ে অসমৰ ইতিহাস, ভূগোল, সংস্কৃতি বা চৰকাৰী আঁচনিৰ ওপৰত আধাৰিত হয়, গতিকে স্থানীয় সাধাৰণ জ্ঞান ইয়াত বৰ উপযোগী।

    পৰিহাৰ কৰিবলগীয়া সাধাৰণ ভুল

    • দুয়ো বাক্য সত্য বুলিয়েই প্ৰথম ক'ড চিহ্নিত নকৰিবা।
    • সঠিক ব্যাখ্যাক সম্পৰ্কিত আন এটা সত্য বাক্যৰ সৈতে মিলাই নেপেলাবা।
    • ফল বা পৰিণতি হোৱা কাৰণক কাৰণ হিচাপে ধৰি নল'বা।
    • কাৰণটো নপঢ়াকৈ স্মৃতিৰপৰা উত্তৰ নিদিবা।
    • দুয়ো বাক্য অসত্য হ'ব পৰা সম্ভাৱনা উপেক্ষা নকৰিবা।
    • সত্যতা নিৰ্ণয় কৰোঁতে বাক্যৰ অৰ্থ সলনি নকৰিবা।

    এই বিষয়টো কেনেকৈ প্ৰস্তুতি কৰিব

    প্ৰথমে পাঁচটা মানক ক'ড আৰু সিহঁতৰ সঠিক ভাষা মনত ৰাখি আৰম্ভ কৰা। তাৰ পিছত সৰল কাৰণ-ফলৰ উদাহৰণেৰে ব্যাখ্যাৰ নিকা যুক্তি অভ্যাস কৰা, যাতে "সত্য আৰু সঠিক ব্যাখ্যা" আৰু "সত্য কিন্তু ব্যাখ্যা নহয়"ৰ পাৰ্থক্য স্পষ্ট হয়। ইয়াৰ পিছত যি বিষয়ৰপৰা এই প্ৰশ্ন সাধাৰণতে সোধা হয়, যেনে ভাৰতৰ ইতিহাস, অসমৰ ইতিহাস, ভূগোল, বিজ্ঞান, ৰাজনীতি আৰু গুৰুত্বপূৰ্ণ আঁচনি, সেইবোৰ পুনৰালোচনা কৰা। এই বিষয়ে যুক্তিৰ লগত সাধাৰণ জ্ঞান মিলে, গতিকে দৈনিক তথ্য পুনৰালোচনা আৰু ক'ডৰ নিয়মীয়া অভ্যাসেই শ্ৰেষ্ঠ প্ৰস্তুতি। যি প্ৰশ্নত দুয়ো বাক্য সত্য আছিল কিন্তু ভুলকৈ প্ৰথম ক'ড চিহ্নিত কৰিছিলা, তেনে প্ৰতিটো প্ৰশ্ন এখন টোকাবহিত লিখি ৰাখা, কাৰণ এই বিষয়ত এয়ে আটাইতকৈ সাধাৰণ ফান্দ।

    আন এটা উপযোগী অভ্যাস হ'ল ক'ড বাছনি কৰাৰ আগতে প্ৰতিটো দাবী-কাৰণ যোৰাক এটা সৰল "কাৰণ" বাক্যলৈ সলনি কৰা। যদি "A সত্য কাৰণ R" এই বাক্যটো স্বাভাৱিক আৰু শুদ্ধ লাগে, তেন্তে প্ৰথম ক'ডৰ সম্ভাৱনা বেছি; আনহাতে দুয়ো সত্য হ'লেও বাক্যটো জোৰকৈ বা ভুলভাৱে লাগিলে দ্বিতীয় ক'ডৰ সম্ভাৱনা বেছি। এই সৰু পৰীক্ষাই বাক্যৰ দৈৰ্ঘ্যই সৃষ্টি কৰা বহু বিভ্ৰান্তি আঁতৰায়। পৰীক্ষাত দাবী আৰু কাৰণৰ প্ৰশ্ন শান্ত মনেৰে কৰা, কাৰণ ইয়ে গতিতকৈ সাৱধান পঢ়াত বেছি নম্বৰ দিয়ে। পাঁচটা ক'ড আৰু তথ্যৰ নিয়মীয়া পুনৰালোচনা মনত থাকিলে এই বিষয়টো নম্বৰৰ এক নিৰ্ভৰযোগ্য উৎস হৈ পৰে।

    সঘনাই সোধা প্ৰশ্ন

    যুক্তিত দাবী আৰু কাৰণ কি?

    এয়া এনে এটা বিষয় য'ত এটা দাবী (A) আৰু এটা কাৰণ (R) দিয়া হয় আৰু প্ৰাৰ্থীয়ে পাঁচটা মানক ক'ড ব্যৱহাৰ কৰি দুয়ো সত্য হয়নে আৰু কাৰণে দাবীক সঠিকভাৱে ব্যাখ্যা কৰেনে নকৰে সেয়া নিৰ্ণয় কৰে।

    পাঁচটা মানক ক'ড কি কি?

    পাঁচটা ক'ড হ'ল: দুয়ো সত্য আৰু R এ A ক ব্যাখ্যা কৰে; দুয়ো সত্য কিন্তু R এ A ক ব্যাখ্যা নকৰে; A সত্য কিন্তু R অসত্য; A অসত্য কিন্তু R সত্য; আৰু দুয়ো অসত্য।

    প্ৰথম আৰু দ্বিতীয় ক'ডৰ মাজৰ পাৰ্থক্য কি?

    প্ৰথম ক'ডত কাৰণে দাবীক ফলৰ কাৰণ যেনেকৈ ব্যাখ্যা কৰে তেনেকৈ সঠিকভাৱে ব্যাখ্যা কৰে, আনহাতে দ্বিতীয় ক'ডত দুয়ো বাক্য সত্য কিন্তু কাৰণটো সঠিক ব্যাখ্যা নহয়।

    কাৰণে দাবীক ব্যাখ্যা কৰে নে নাই কেনেকৈ ঠিক কৰিম?

    যোৰাটো "কাৰণ" বাক্যলৈ সলনি কৰা। "A সত্য কাৰণ R" শুদ্ধ লাগিলে প্ৰথম ক'ড প্ৰযোজ্য; দুয়ো সত্য হ'লেও ভুল লাগিলে দ্বিতীয় ক'ড প্ৰযোজ্য।

    এই বিষয়টো কোনবোৰ পৰীক্ষাৰ বাবে উপযোগী?

    এয়া APSC, ADRE, অসম আৰক্ষী, DHS, DME, SSC আৰু ৰে'লৱে পৰীক্ষাৰ বাবে উপযোগী আৰু ইতিহাস, ভূগোল, বিজ্ঞান, ৰাজনীতি বা সাম্প্ৰতিক পৰিঘটনাৰপৰা সোধা হয়।
