    DBMS, Number Systems & Shortcuts: Concepts and Conversions

    This section tests three different skills together: the basic terms of a database, the conversion of numbers between the binary, octal, decimal and hexadecimal systems, and the common keyboard shortcuts of a computer. Each part is fact based, so short and clear revision secures almost full marks.

    This deep-study note covers the basic terms of a DBMS, the number systems and their conversions, the units of data and the keyboard shortcuts, the question patterns, a solving method, the traps examiners set and a preparation plan. After reading it, a candidate should be able to answer a database, conversion or shortcut question without hesitation.

    Basic Terms

    • Data: raw facts and figures that have little meaning on their own.
    • Database: an organised collection of related data stored so that it can be searched and updated easily.
    • DBMS: database management system, the software that creates and manages a database, such as MySQL or Oracle.
    • RDBMS: a relational database management system, which stores data in tables that are linked by keys.
    • Table: a set of rows and columns that stores data about one subject.
    • Record: one complete row of a table, describing one entity.
    • Field: one column of a table, holding one attribute of every record.
    • Primary key: a field that uniquely identifies each record of a table.
    • Foreign key: a field that links one table to the primary key of another.
    • SQL: structured query language, used to create, read, update and delete data.
    • Query: a request for data from a database.
    • Number system: a way of writing numbers by using a fixed set of digits, called its base.
    • Bit: a binary digit, either 0 or 1, the smallest unit of data.
    • Byte: a group of eight bits.

    Core Concepts and Rules

    • A DBMS is software, while a database is the organised collection of data that the DBMS manages.
    • A primary key is unique and cannot be empty, and a foreign key links two tables.
    • SQL statements include SELECT, INSERT, UPDATE, DELETE, CREATE and DROP.
    • The decimal system has base 10, binary base 2, octal base 8 and hexadecimal base 16.
    • To convert decimal to binary, divide again and again by two and read the remainders upwards.
    • To convert binary to decimal, add the place values where the digit is one.
    • Octal groups binary bits in threes and hexadecimal groups them in fours.
    • In hexadecimal the digits A to F stand for 10 to 15.
    • The table of data units is 8 bits = 1 byte, 1024 bytes = 1 KB, 1024 KB = 1 MB, 1024 MB = 1 GB and 1024 GB = 1 TB.
    • Ctrl+C copies, Ctrl+V pastes, Ctrl+Z undoes and Ctrl+S saves.

    Database Concepts

    A database stores related data in an organised way so that the same data need not be kept in many places. A DBMS is the software that creates the database and lets a user store, search, update and delete data, with examples such as MySQL, Oracle, SQL Server and MS Access. When the data is kept in tables that are linked by keys, the system is called a relational database management system. In a table each row is a record, each column is a field, and a primary key uniquely identifies every row, while a foreign key in one table points to the primary key of another and joins the two. Structured query language, SQL, is the standard language used to work with such tables, and its main statements are SELECT to read, INSERT to add, UPDATE to change and DELETE to remove data, along with CREATE and DROP to make or delete a table. Normalisation is the process of organising tables to reduce repetition and errors.

    Number Systems and Conversions

    A number system is named by its base, which is the number of different digits it uses. The decimal system uses ten digits from 0 to 9, the binary system uses two digits 0 and 1, the octal system uses eight digits from 0 to 7, and the hexadecimal system uses sixteen symbols, the digits 0 to 9 and the letters A to F for ten to fifteen. To convert a decimal number into binary, divide it by two again and again, write down each remainder and then read the remainders from the last to the first. To convert binary into decimal, multiply each bit by its place value, which doubles from right to left, and add the results. Octal and hexadecimal are useful because they are short forms of binary: three binary bits make one octal digit and four binary bits make one hexadecimal digit. The largest place value of a number is called the most significant digit and the smallest the least significant digit.

    Data Units and Keyboard Shortcuts

    The smallest unit of data is a bit, which is a single 0 or 1, and eight bits make one byte, which can store one character. The larger units rise in steps of 1024: 1024 bytes make one kilobyte, 1024 kilobytes one megabyte, 1024 megabytes one gigabyte, 1024 gigabytes one terabyte and 1024 terabytes one petabyte. A nibble is four bits, or half a byte. Keyboard shortcuts save time and are asked directly: Ctrl+C copies, Ctrl+X cuts, Ctrl+V pastes, Ctrl+Z undoes, Ctrl+Y redoes, Ctrl+A selects all, Ctrl+S saves, Ctrl+P prints, Ctrl+F finds, Ctrl+B makes text bold, Ctrl+I italics and Ctrl+U underline. Alt+F4 closes a window, Alt+Tab switches between open windows, and F5 refreshes a page or window.

    Types of Questions Asked

    The most common pattern asks for a conversion, such as the binary form of a decimal number. The second asks a definition, such as what a primary key is. The third asks a full form, such as DBMS, SQL or RDBMS. The fourth asks the number of bytes in a kilobyte or the bits in a byte. The fifth asks the shortcut for an action. Direct conversions and definitions take most of the marks.

    Steps to Solve a DBMS or Number Question

    First, read the question and see whether it asks for a database term, a conversion, a unit or a shortcut. Second, if it is a conversion, fix the bases involved and apply the divide or place-value rule. Third, if it is a definition, recall the exact one-line meaning and its key condition, such as unique for a primary key. Fourth, if it is a unit, remember the base of 1024 and the order of the units. Fifth, if it is a shortcut, picture the key and the action. Finally, check the result once, because a single wrong remainder or place value changes the whole answer.

    Common Mistakes to Avoid

    • Do not read the remainders in the wrong order; read the decimal-to-binary result from the last remainder to the first.
    • Do not confuse a primary key with a foreign key; only the primary key is unique.
    • Do not call a database and a DBMS the same; one is data and the other is software.
    • Do not use 1000 for the data units; computer memory uses 1024.
    • Do not forget that octal groups bits in threes and hexadecimal in fours.
    • Do not mix up the shortcut keys, such as Ctrl+Z for undo and Ctrl+Y for redo.

    Database এ সম্পৰ্কীয় তথ্য সুসংগঠিতভাৱে ৰাখে যাতে একেই তথ্য অনেক ঠাইত ৰাখিব নালাগে। DBMS হৈছে সেই software, যি database সৃষ্টি কৰি ব্যৱহাৰকাৰীক তথ্য ৰাখিব, বিচাৰিব, আপডেট আৰু মচিবলৈ দিয়ে, যেনে MySQL, Oracle, SQL Server আৰু MS Access। যেতিয়া তথ্য key ৰে সংযুক্ত table ত ৰখা হয়, তেতিয়া সেই system ক relational database management system বোলা হয়। Table ত প্ৰতিটো row এটা record, প্ৰতিটো column এটা field, আৰু primary key য়ে প্ৰতিটো row অদ্বিতীয়ভাৱে চিনাক্ত কৰে, আনহাতে এটা table ৰ foreign key য়ে আন এটাৰ primary key লৈ দেখুৱাই দুয়োটা জোৰা লগায়। Structured query language, SQL, এনে table ৰ লগত কাম কৰাৰ মানক ভাষা, আৰু ইয়াৰ মূল statement ক্ৰমে SELECT পঢ়িবলৈ, INSERT যোগ কৰিবলৈ, UPDATE সলাবলৈ আৰু DELETE মচিবলৈ, লগতে CREATE আৰু DROP table বনাব বা মচিবলৈ। Normalisation হৈছে পুনৰাবৃত্তি আৰু ভুল কমাবলৈ table সুসংগঠিত কৰাৰ প্ৰক্ৰিয়া।

    সংখ্যা পদ্ধতি আৰু ৰূপান্তৰ

    সংখ্যা পদ্ধতিৰ নাম তাৰ base ৰ পৰা হয়, যি ই ব্যৱহাৰ কৰা বেলেগ digit ৰ সংখ্যা। Decimal পদ্ধতিত 0 ৰ পৰা 9 লৈ দহটা digit, binary ত 0 আৰু 1 দুটা, octal ত 0 ৰ পৰা 7 লৈ আঠটা, আৰু hexadecimal ত ষোল্লটা চিহ্ন, অৰ্থাৎ 0 ৰ পৰা 9 লৈ digit আৰু দহৰ পৰা পোন্ধৰলৈ A ৰ পৰা F লৈ অক্ষৰ ব্যৱহৃত হয়। Decimal সংখ্যাক binary লৈ সলাবলৈ ইয়াক বাৰে বাৰে দুৰে ভাগ কৰি প্ৰতিটো ভাগশেষ লিখি শেষৰ পৰা প্ৰথমলৈ পঢ়ক। Binary ক decimal লৈ সলাবলৈ প্ৰতিটো bit ক তাৰ place value ৰে পূৰণ কৰক, যি সোঁফালৰ পৰা বাওঁফাললৈ দুগুণ হয়, আৰু ফলাফল যোগ কৰক। Octal আৰু hexadecimal উপকাৰী কাৰণ সিহঁত binary ৰ চুটি ৰূপ: তিনি bit এ এটা octal digit আৰু চাৰি bit এ এটা hexadecimal digit বনায়। সংখ্যা এটাৰ আটাইতকৈ ডাঙৰ place value ক most significant digit আৰু আটাইতকৈ সৰুটোক least significant digit বোলা হয়।

    তথ্যৰ একক আৰু Keyboard Shortcut

    তথ্যৰ আটাইতকৈ সৰু একক হৈছে bit, যি এটা 0 বা 1, আৰু আঠটা bit এ এটা byte বনায়, যি এটা character ৰাখিব পাৰে। ডাঙৰ এককবোৰ 1024 ৰ পৰ্যায়ত বাঢ়ে: 1024 byte = এটা kilobyte, 1024 kilobyte = এটা megabyte, 1024 megabyte = এটা gigabyte, 1024 gigabyte = এটা terabyte আৰু 1024 terabyte = এটা petabyte। Nibble হৈছে চাৰিটা bit, অৰ্থাৎ আধা byte। Keyboard shortcut এ সময় ৰাহি কৰে আৰু পোনপটীয়াকৈ সোধা হয়: Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo, Ctrl+Y redo, Ctrl+A আটাই বাছনি, Ctrl+S save, Ctrl+P print, Ctrl+F বিচাৰ, Ctrl+B bold, Ctrl+I italic আৰু Ctrl+U underline। Alt+F4 এ ৱিন্ডো বন্ধ কৰে, Alt+Tab এ খোলা ৱিন্ডোৰ মাজত সলনি কৰে, আৰু F5 এ পৃষ্ঠা বা ৱিন্ডো refresh কৰে।

    সোধা প্ৰশ্নৰ প্ৰকাৰ

    আটাইতকৈ বেছি অহা ধৰণ হ'ল এটা ৰূপান্তৰ, যেনে decimal সংখ্যা এটাৰ binary ৰূপ সোধা। দ্বিতীয়ত এটা সংজ্ঞা, যেনে primary key কি, সোধা হয়। তৃতীয়ত এটা full form, যেনে DBMS, SQL বা RDBMS, সোধা হয়। চতুৰ্থত এটা kilobyte ত কিমান byte বা এটা byte ত কিমান bit সোধা হয়। পঞ্চমত এটা কামৰ shortcut সোধা হয়। পোনপটীয়া ৰূপান্তৰ আৰু সংজ্ঞাই বেছি নম্বৰ লয়।

    DBMS বা সংখ্যাৰ প্ৰশ্ন সমাধানৰ স্তৰ

    প্ৰথমে প্ৰশ্ন পঢ়ি ই database ৰ শব্দ, ৰূপান্তৰ, একক নে shortcut বিচাৰে চাওক। দ্বিতীয়ে ৰূপান্তৰ হ'লে জড়িত base নিৰ্ণয় কৰি ভাগ বা place value ৰ নিয়ম প্ৰয়োগ কৰক। তৃতীয়ে সংজ্ঞা হ'লে সঠিক এশাৰী অৰ্থ আৰু তাৰ মূল চৰ্ত মনত পেলাওক, যেনে primary key ৰ অদ্বিতীয়তা। চতুৰ্থে একক হ'লে 1024 ৰ ভিত্তি আৰু এককৰ ক্ৰম মনত ৰাখক। পঞ্চমে shortcut হ'লে চাবি আৰু কাম কল্পনা কৰক। শেষত ফলাফল এবাৰ পৰীক্ষা কৰক, কাৰণ এটা ভুল ভাগশেষ বা place value য়ে গোটেই উত্তৰ সলনি কৰে।

    পৰীক্ষাৰ প্ৰৱণতা

    অসমৰ নিয়োগ পৰীক্ষাত decimal-ৰপৰা-binary ৰূপান্তৰ, তথ্য এককৰ তালিকা, primary key, foreign key আৰু DBMS ৰ সংজ্ঞা, SQL আৰু RDBMS ৰ full form আৰু সাধাৰণ keyboard shortcut আটাইতকৈ বেছি আহে, তাৰ পিছত octal আৰু hexadecimal ৰূপান্তৰ আৰু SQL statement। প্ৰশ্ন চুটি আৰু এটা তথ্যভিত্তিক, গতিকে নিয়মীয়া পুনৰালোচনেই যথেষ্ট। একেই ৰূপান্তৰ আৰু সংজ্ঞা সৰু সালসলনিৰে পুনৰ আহে, যাৰ ফলত এই অংশ দ্ৰুতভাৱে জনা যায়।

    সাধাৰণ ভুল

    • ভাগশেষ ভুল ক্ৰমত নপঢ়িব; decimal-ৰপৰা-binary ফলাফল শেষৰ ভাগশেষৰ পৰা প্ৰথমলৈ পঢ়ক।
    • Primary key আৰু foreign key মিলাই নিদিব; কেৱল primary key অদ্বিতীয়।
    • Database আৰু DBMS একে নুবুলিব; এটা তথ্য আৰু আনটো software।
    • তথ্য এককলৈ 1000 ব্যৱহাৰ নকৰিব; কম্পিউটাৰ মেমৰিত 1024 ব্যৱহাৰ হয়।
    • Octal য়ে bit তিনি তিনিকৈ আৰু hexadecimal য়ে চাৰি চাৰিকৈ গোট কৰে, নাপাহৰিব।
    • Shortcut চাবি মিলাই নিদিব, যেনে Ctrl+Z undo আৰু Ctrl+Y redo।

    প্ৰস্তুতি কেনেকৈ কৰিব

    সংখ্যা পদ্ধতি, সিহঁতৰ base আৰু digit লৈ তিনি স্তম্ভৰ তালিকা বনাই দিনে প্ৰতিটো দিশত দহটা ৰূপান্তৰ অভ্যাস কৰক। তাৰ পিছত bit ৰ পৰা petabyte লৈ, প্ৰতিটো খোজত 1024 মূল্য ৰাখি তথ্য এককৰ শ্ৰেণী লিখক। তাৰ পিছত table, record, field, primary key আৰু foreign key ৰ দৰে database ৰ শব্দ আৰু প্ৰতিটোৰ এশাৰী অৰ্থ লিখক। শেষত আটাইতকৈ বেছি অহা কুৰিটা keyboard shortcut আৰু সিহঁতৰ কাম লিখক।

    দিনে কুৰিটা প্ৰশ্ন কৰি ভুল হোৱা ৰূপান্তৰ, সংজ্ঞা আৰু shortcut ৰ এখন তালিকা ৰাখক, কাৰণ একেই বস্তু পুনৰ আহে। Decimal-ৰপৰা-binary ৰূপান্তৰ উচ্চস্বৰে অভ্যাস কৰি ভাগশেষ সঠিক ক্ৰমত পঢ়ক, কাৰণ ক্ৰমেই আটাইতকৈ সাধাৰণ ফান্দ। শেষ সপ্তাহত কেৱল তালিকা আৰু ৰেজিষ্টাৰ চাওক, তেতিয়া এই অংশ সাজু হ'ব।

    দ্ৰুত পুনৰালোচনাৰ টিপছ

    • Decimal base 10, binary base 2, octal base 8, hexadecimal base 16।
    • Decimal ৰপৰা binary: দুৰে ভাগ কৰি ভাগশেষ ওপৰলৈ পঢ়ক।
    • 8 bit = 1 byte, 1024 byte = 1 KB, 1024 KB = 1 MB।
    • Primary key অদ্বিতীয়; foreign key য়ে table সংযোগ কৰে।
    • Ctrl+Z undo, Ctrl+Y redo, Ctrl+S save, Ctrl+C copy।

    শেষ পুনৰালোচনা

    শেষ দিনা সংখ্যা পদ্ধতিৰ তালিকা, তথ্য এককৰ শ্ৰেণী, database ৰ শব্দ আৰু shortcut ৰ তালিকা পুনৰালোচনা কৰি কুৰিটা প্ৰশ্নৰ সময়বদ্ধ সংহতি কৰক। প্ৰতিটো ভুল উত্তৰৰ বাবে বাদ পৰা বস্তুটো লিখি ৰাখক। এই প্ৰশ্নই স্পষ্ট নিয়ম বিচাৰে, আৰু নিয়ম জনা প্ৰাৰ্থীয়ে দ্ৰুতভাৱে উত্তৰ দি সহজ নম্বৰ পায়।

    সঘনাই সোধা প্ৰশ্ন

    Primary key কি?

    Primary key হৈছে table ৰ প্ৰতিটো record অদ্বিতীয়ভাৱে চিনাক্ত কৰা field, যি খালী হ'ব নোৱাৰে।

    Decimal সংখ্যা 10 ৰ binary ৰূপ কি?

    Decimal সংখ্যা 10 ক binary ত 1010 বুলি লিখা হয়।

    এটা kilobyte ত কিমান byte থাকে?

    এটা kilobyte ত 1024 byte থাকে, কাৰণ কম্পিউটাৰ মেমৰি 1024 ৰ পৰ্যায়ত বাঢ়ে।

    SQL ৰ full form কি আৰু কাম কি?

    SQL ৰ full form structured query language, যি database ত তথ্য সৃষ্টি, পঢ়া, আপডেট আৰু মচিবলৈ ব্যৱহৃত হয়।

    কাম undo আৰু redo কৰিবলৈ কোন চাবি ব্যৱহৃত হয়?

    কাম undo কৰিবলৈ Ctrl+Z আৰু redo কৰিবলৈ Ctrl+Y ব্যৱহৃত হয়।
