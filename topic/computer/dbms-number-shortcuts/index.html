    DBMS, Number Systems and Keyboard Shortcuts

    This chapter bundles three separate skills that a single recruitment paper often tests together: the vocabulary of databases, conversions between the binary, octal, decimal and hexadecimal number systems, and the everyday keyboard shortcuts of a Windows computer. Each item is a single hard fact, so once the fact is fixed in memory the question takes only seconds. Below is the fact list, the conversion method I actually use under time pressure, and the places where candidates most often slip.

    Database Vocabulary You Must Know

    • Data: raw facts and figures that carry little meaning on their own.
    • Database: related data stored in an organised way so it can be searched and updated quickly.
    • DBMS: the software that creates and runs a database; MySQL, Oracle, SQL Server and MS Access are common examples.
    • RDBMS: a DBMS that keeps data in tables joined by keys.
    • Table: rows and columns holding data about one subject.
    • Record: one complete row, describing a single entity.
    • Field: one column, holding a single attribute of every record.
    • Primary key: the field that uniquely identifies a row; it can never be blank or repeated.
    • Foreign key: a field that points to the primary key of another table and joins the two.
    • SQL: structured query language, the standard language for creating, reading, updating and deleting data.
    • Query: a request for data from a database.
    • Normalisation: reorganising tables so that repetition and inconsistency are reduced.
    • Number system: a way of writing numbers using a fixed set of digits, called its base.
    • Bit: one binary digit, 0 or 1, the smallest unit of data.
    • Byte: a group of eight bits, enough to hold one character.

    Rules That Decide Most Answers

    • A database is the data; a DBMS is the software that manages it. Never treat the two as the same thing.
    • Only the primary key must be unique. A foreign key may repeat and may be empty.
    • SQL's working statements are SELECT to read, INSERT to add, UPDATE to change and DELETE to remove, with CREATE and DROP to make or delete a table.
    • The bases are 10 for decimal, 2 for binary, 8 for octal and 16 for hexadecimal.
    • Octal is a shorthand for binary in groups of three bits; hexadecimal groups four bits.
    • In hexadecimal the letters A to F stand for the values 10 to 15.
    • Computer memory climbs in powers of 1024, not 1000: 8 bits = 1 byte, 1024 bytes = 1 KB, 1024 KB = 1 MB, 1024 MB = 1 GB and 1024 GB = 1 TB.

    How the Four Number Systems Differ

    A number system takes its name from its base, the count of distinct digits it uses. Decimal runs 0 to 9 on ten digits. Binary uses only 0 and 1. Octal uses 0 to 7 on eight digits. Hexadecimal uses sixteen symbols: 0 to 9 followed by A, B, C, D, E and F for the values ten through fifteen. Because eight, sixteen and two are all powers of two, octal and hexadecimal are compact ways of writing long binary strings, which is why memory addresses are usually shown in hexadecimal. Within any number the leftmost digit carries the largest place value and is called the most significant digit; the rightmost is the least significant.

    Converting by Hand: Worked Examples

    Decimal to binary: divide by two, note each remainder, then read the remainders from bottom to top. Take 13. 13 divided by 2 is 6 remainder 1, 6 divided by 2 is 3 remainder 0, 3 divided by 2 is 1 remainder 1, and 1 divided by 2 is 0 remainder 1. Read upwards and 13 becomes 1101.

    Binary to decimal: add the place values wherever the digit is 1. The places, right to left, are 1, 2, 4, 8, 16 and so on. For 1101 that is 8 + 4 + 0 + 1, which is 13 and checks the first example.

    Binary to octal and hexadecimal: split the bits into groups. Grouping 1101 in threes from the right gives 1 and 101, so the octal form is 15. Grouping the same bits in fours gives 1101, so the hexadecimal form is D. A four-bit group is a nibble, half a byte.

    Memory Sizes and the 1024 Ladder

    A bit holds a single 0 or 1. Eight bits make a byte, which stores one character. From there every step multiplies by 1024: 1024 bytes make a kilobyte, 1024 KB a megabyte, 1024 MB a gigabyte, 1024 GB a terabyte and 1024 TB a petabyte. Questions usually ask how many bytes sit in a kilobyte or how many bits in a byte, and the answers are 1024 and 8.

    Shortcuts Worth Memorising

    Ctrl+C copies, Ctrl+X cuts, Ctrl+V pastes, Ctrl+Z undoes and Ctrl+Y redoes. Ctrl+A selects everything, Ctrl+S saves, Ctrl+P prints, Ctrl+F finds, and Ctrl+B, Ctrl+I and Ctrl+U apply bold, italics and underline. Alt+F4 closes the active window, Alt+Tab switches between open windows, and F5 refreshes the current page or window. A handy pairing: Z for undo sits just left of Y for redo.

    Where Candidates Lose Marks

    • Reading the decimal-to-binary remainders top to bottom instead of bottom to top.
    • Treating a foreign key as unique, when only the primary key is.
    • Writing 1000 for memory units; computer memory uses 1024.
    • Forgetting that octal groups bits in threes and hexadecimal in fours.
    • Swapping Ctrl+Z for undo and Ctrl+Y for redo.

    There are 1024 bytes in one kilobyte, because computer memory grows in steps of 1024 rather than 1000.

    What does SQL stand for and what is it used for?

    SQL stands for structured query language; it is used to create, read, update and delete data in a database.

    Binary ৰ পৰা octal আৰু hexadecimal: bit বোৰ গোটত ভাগ কৰক। 1101 ক সোঁফালৰ পৰা তিনি তিনি কৰি ভাগ কৰিলে 1 আৰু 101 পোৱা যায়, গতিকে octal ৰূপ 15। একেখিনি bit চাৰি চাৰিকৈ ভাগ কৰিলে 1101 পোৱা যায়, গতিকে hexadecimal ৰূপ D। চাৰি bit ৰ গোটক nibble বোলা হয়, যি আধা byte।

    মেমৰিৰ আকাৰ আৰু 1024 ৰ শ্ৰেণী

    এটা bit এ এটা 0 বা 1 ধৰি ৰাখে। আঠটা bit এ এটা byte বনায়, যি এটা character ৰাখে। তাৰ পৰা প্ৰতিটো খোজ 1024 ৰে পূৰণ হয়: 1024 byte = এটা kilobyte, 1024 KB = এটা megabyte, 1024 MB = এটা gigabyte, 1024 GB = এটা terabyte আৰু 1024 TB = এটা petabyte। প্ৰশ্নত সাধাৰণতে এটা kilobyte ত কিমান byte বা এটা byte ত কিমান bit সোধা হয়, আৰু উত্তৰ 1024 আৰু 8।

    মনত ৰখাৰ যোগ্য Shortcut

    Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo আৰু Ctrl+Y redo। Ctrl+A এ আটাই বাছনি, Ctrl+S save, Ctrl+P print, Ctrl+F find কৰে, আৰু Ctrl+B, Ctrl+I লগতে Ctrl+U এ bold, italic আৰু underline দিয়ে। Alt+F4 এ সক্ৰিয় ৱিন্ডো বন্ধ কৰে, Alt+Tab এ খোলা ৱিন্ডোৰ মাজত সলনি কৰে, আৰু F5 এ চলিত পৃষ্ঠা বা ৱিন্ডো refresh কৰে। এটা সহজ যোৰ: undo ৰ Z ঠিক redo ৰ Y ৰ বাওঁফালে থাকে।

    য'ত প্ৰাৰ্থীসকলে নম্বৰ হেৰুৱায়

    • Decimal-ৰপৰা-binary ৰ ভাগশেষ ওপৰৰ পৰা তললৈ পঢ়া, শেষৰ পৰা প্ৰথমলৈ পঢ়িবৰ সলনি।
    • Foreign key ক অদ্বিতীয় ভবা, য'ত কেৱল primary key অদ্বিতীয়।
    • মেমৰি এককলৈ 1000 লিখা; কম্পিউটাৰ মেমৰিত 1024 ব্যৱহৃত হয়।
    • Octal এ bit তিনি তিনি আৰু hexadecimal এ চাৰি চাৰিকৈ গোট কৰে, সেয়া পাহৰি যোৱা।
    • Ctrl+Z (undo) আৰু Ctrl+Y (redo) ওলোটাই দিয়া।

    দুই সপ্তাহৰ পুনৰালোচনাৰ পৰিকল্পনা

    চাৰিটা সংখ্যা পদ্ধতিৰ base আৰু digit লৈ এটা তালিকা আঁকক, আৰু bit ৰ পৰা petabyte লৈ প্ৰতিটো খোজত 1024 লিখি এটা শ্ৰেণী আঁকক। প্ৰথম সপ্তাহত দিনে দহটা decimal সংখ্যা binary লৈ আৰু উলটি decimal লৈ সলাওক, ভাগশেষ উচ্চস্বৰে পঢ়ি ক্ৰমটো স্বাভাৱিক কৰি তুলক। ভুল হোৱা প্ৰতিটো ৰূপান্তৰ, সংজ্ঞা বা shortcut ৰ এখন চলিত তালিকা ৰাখক আৰু প্ৰতি তৃতীয় দিনে সেই তালিকাতে নিজকে পৰীক্ষা কৰক। শেষ সপ্তাহত কেৱল দুয়োখন তালিকা আৰু ভুলৰ তালিকা পুনৰালোচনা কৰিলেই যথেষ্ট।

    সঘনাই সোধা প্ৰশ্ন

    Primary key কি?

    Primary key হৈছে table ৰ প্ৰতিটো record অদ্বিতীয়ভাৱে চিনাক্ত কৰা field, যি খালী ৰাখিব নোৱাৰি।

    Decimal সংখ্যা 10 ৰ binary ৰূপ কি?

    10 ক বাৰে বাৰে দুৰে ভাগ কৰিলে ভাগশেষ 0, 1, 0, 1 পোৱা যায়, গতিকে 10 ক binary ত 1010 বুলি লিখা হয়।

    এটা kilobyte ত কিমান byte থাকে?

    এটা kilobyte ত 1024 byte থাকে, কাৰণ কম্পিউটাৰ মেমৰি 1000 নহয় 1024 ৰ পৰ্যায়ত বাঢ়ে।

    SQL ৰ full form কি আৰু ইয়াৰ কাম কি?

    SQL ৰ full form structured query language; database ত তথ্য সৃষ্টি, পঢ়া, আপডেট আৰু মচিবলৈ ই ব্যৱহৃত হয়।

    কাম undo আৰু redo কৰিবলৈ কোন চাবি ব্যৱহৃত হয়?

    Ctrl+Z য়ে শেষ কাম undo কৰে আৰু Ctrl+Y য়ে redo কৰে।
