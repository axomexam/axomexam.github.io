    Computer Fundamentals & Hardware: Concepts, Devices and Methods

    Computer awareness tests how well a candidate knows the way a computer is built, the way it stores and processes data and the work done by each device. The questions are direct, fact based and repeated across years, so a candidate who learns the standard facts and a handful of definitions can score full marks in a short time.

    This deep-study note explains the basic terms, the generations of computers, the parts of a computer system, the memory and storage hierarchy, the question patterns, a step-by-step solving method, the traps examiners set and a preparation plan. After reading it, a candidate should be able to answer computer fundamentals and hardware questions quickly and with confidence.

    Basic Terms

    • Computer: an electronic device that accepts data, processes it according to instructions and gives useful information.
    • Data and information: raw, unorganised facts are data, while processed and meaningful output is information.
    • Hardware: the physical, touchable parts of a computer, such as the keyboard and the monitor.
    • Software: the set of programs and instructions that tell the hardware what to do.
    • Input device: a device used to enter data into a computer, such as a keyboard or a mouse.
    • Output device: a device that presents results to the user, such as a monitor or a printer.
    • CPU: the central processing unit, called the brain of the computer.
    • ALU: the arithmetic logic unit, which performs calculations and logical comparisons.
    • Control unit: the part that fetches, decodes and directs the execution of instructions.
    • Memory: the part of a computer that stores data and instructions.
    • Bit and byte: a bit is a single 0 or 1, and a byte is a group of eight bits.
    • Motherboard: the main circuit board that connects the CPU, memory and other components.

    Core Concepts and Rules

    • A computer follows the input, process, output and storage cycle, and no step can be skipped.
    • The CPU has three parts: the arithmetic logic unit, the control unit and the registers.
    • Primary memory is accessed directly by the CPU, while secondary memory is not.
    • RAM is volatile and loses its contents when the power goes off, while ROM is non-volatile and keeps them.
    • Speed order from fastest to slowest is registers, cache, RAM, solid state drive, hard disk, optical disk and magnetic tape.
    • One byte is eight bits, one kilobyte is 1024 bytes, one megabyte is 1024 kilobytes, one gigabyte is 1024 megabytes and one terabyte is 1024 gigabytes.
    • Input devices accept data, output devices present it and some devices, such as a touch screen, do both.
    • Storage devices are non-volatile, so they retain data even after the computer is switched off.
    • In the von Neumann architecture, both data and instructions are stored in the same memory.
    • The five generations of computers are named after the main electronic component used in each.

    Generations of Computers

    The first generation, from about 1940 to 1956, used vacuum tubes, was very large and produced much heat, and the ENIAC and UNIVAC belong to it. The second generation, from 1956 to 1963, replaced tubes with transistors, was smaller and used assembly language, as in the IBM 1401. The third generation, from 1964 to 1971, used integrated circuits and introduced keyboards, monitors and high-level languages, as in the IBM 360. The fourth generation, from 1971 onwards, used microprocessors and very large scale integration and brought personal computers and graphical user interfaces, as in the Intel 4004. The fifth generation, still developing, works with artificial intelligence, ultra large scale integration and parallel processing.

    Memory and Storage Hierarchy

    Memory is arranged in a hierarchy by speed and cost. Registers sit inside the CPU and are the fastest. Cache memory, in levels L1, L2 and L3, holds frequently used data close to the CPU. Primary memory follows and has two kinds: RAM, which is the working memory, and ROM, which holds the start-up instructions. RAM is of two types, static RAM, which is fast and needs no refreshing and is used for cache, and dynamic RAM, which is the main memory and needs constant refreshing. ROM is of the types PROM, EPROM and EEPROM. Secondary storage, such as hard disks, solid state drives, optical disks and flash drives, is slower but non-volatile and has a large capacity. Magnetic tapes are used mainly for backup.

    Types of Questions Asked

    The most common pattern asks a direct fact, such as who is called the father of the computer or what a full form means. The second asks the class of a device, that is whether it is an input, output or storage device. The third asks a unit conversion, such as how many kilobytes make a megabyte. The fourth gives a list and asks for the odd one out or a match. The fifth asks which generation introduced a given feature or component. Full forms of abbreviations form a regular part of the paper.

    Steps to Solve a Computer Awareness Question

    First, read the question and decide whether it asks for a definition, a device class, a number or a name. Second, recall the standard fact without guessing. Third, remove any option that belongs to a different category, such as an output device in a list of input devices. Fourth, for unit questions apply the 1024 multiples carefully and count the steps. Fifth, for device questions confirm the direction in which the data flows. Finally, check the full form letter by letter, because one wrong word often hides the correct option.

    Examination Trends

    In Assam recruitment papers the basic definitions, full forms, generations, memory units and input and output devices appear most often, followed by storage devices and the parts of the CPU. Questions are short and single fact based, so revision, not reasoning, wins marks. The same set of standard facts repeats with small changes, which makes the section one of the easiest to secure.

    Common Mistakes to Avoid

    • Do not confuse memory with storage, because memory is primary and often volatile.
    • Do not mix input and output devices, and always check the direction of data flow.
    • Do not guess a full form, and learn the standard expansion instead.
    • Do not forget that 1024, and not 1000, links the binary units.
    • Do not confuse a generation with the component it used.
    • Do not overlook small units such as a nibble, which is four bits.

    How to Prepare This Topic

    Make a one-page table of the five generations with their years, main component, language and example. Next make a list of input, output and storage devices and, beside each, note the flow of data. Then write the unit ladder from bit to terabyte on a card and revise it daily. In each practice set, underline every full form and learn the ones you did not know.

    Revise the hardware diagram of a computer system, showing the CPU, memory and input and output units, because many questions are drawn from it. Attempt twenty questions a day and keep a register of the facts you got wrong, since the same facts tend to recur. In the last week revise only that register and the one-page table, and the section will be ready.

    Final Revision Note

    On the last day, revise the generation table, the device list and the unit ladder and then attempt a timed set of twenty questions. For every wrong answer, write down the exact fact that was missed. Computer fundamentals and hardware reward clear, correct facts, and a candidate who has them answers without hesitation and gains easy marks.

    Frequently Asked Questions

    Who is called the father of the computer?

    Charles Babbage is called the father of the computer because he designed the Analytical Engine, the first mechanical general purpose computer.

    What is the difference between RAM and ROM?

    RAM is volatile working memory that loses its contents when the power goes off, while ROM is non-volatile and permanently stores the start-up instructions.

    How many bits are there in a byte?

    There are eight bits in one byte, and a nibble is half a byte, that is four bits.

    Which generation introduced microprocessors?

    The fourth generation, from 1971 onwards, introduced microprocessors and very large scale integration, leading to personal computers.

    Is a touch screen an input or an output device?

    A touch screen is both, because it displays output and also accepts input when the user touches it.

    প্ৰথম প্ৰজন্ম প্ৰায় 1940 ৰ পৰা 1956 লৈ vacuum tube ব্যৱহাৰ কৰিছিল, আকাৰত ডাঙৰ আছিল আৰু অধিক তাপ দিছিল; ENIAC আৰু UNIVAC ইয়াৰ উদাহৰণ। দ্বিতীয় প্ৰজন্মত 1956 ৰ পৰা 1963 লৈ vacuum tube ৰ ঠাইত transistor বহিছিল, সৰু আছিল আৰু assembly language ব্যৱহাৰ কৰিছিল, যেনে IBM 1401। তৃতীয় প্ৰজন্মত 1964 ৰ পৰা 1971 লৈ integrated circuit ব্যৱহাৰ কৰি কীবৰ্ড, মনিটৰ আৰু high-level language আনিছিল, যেনে IBM 360। চতুৰ্থ প্ৰজন্মত 1971 ৰ পৰা microprocessor আৰু VLSI আহিল, যাৰ ফলত personal computer আৰু graphical user interface ওলাইছিল, যেনে Intel 4004। পঞ্চম প্ৰজন্মত artificial intelligence, ULSI আৰু parallel processing ব্যৱহাৰ হয়।

    মেমৰি আৰু সংৰক্ষণৰ স্তৰবিন্যাস

    মেমৰি গতি আৰু খৰচ অনুসৰি স্তৰবিন্যাসত সজোৱা থাকে। Register CPU ৰ ভিতৰত থাকে আৰু আটাইতকৈ দ্ৰুত। Cache মেমৰি L1, L2 আৰু L3 স্তৰত সঘনাই ব্যৱহৃত তথ্য CPU ৰ ওচৰত ৰাখে। ইয়াৰ পিছত primary memory, যি দুই ধৰণৰ: RAM কাৰ্যক্ষম মেমৰি আৰু ROM ষ্টাৰ্ট-আপ নিৰ্দেশনা ৰখা মেমৰি। RAM ৰ দুই ধৰণ: static RAM দ্ৰুত আৰু refresh নালাগে, cache ত ব্যৱহাৰ হয়; dynamic RAM মূল মেমৰি, যাক সদায় refresh লগে। ROM ৰ PROM, EPROM আৰু EEPROM ধৰণ। Secondary storage, যেনে hard disk, SSD, optical disk আৰু flash drive, লেহেম কিন্তু non-volatile আৰু বেছি ধাৰণক্ষমতাৰ। Magnetic tape মূলত backup ৰ বাবে ব্যৱহাৰ হয়।

    সোধা প্ৰশ্নৰ প্ৰকাৰ

    আটাইতকৈ বেছি অহা ধৰণ হ'ল পোনপটীয়া তথ্য, যেনে কম্পিউটাৰৰ পিতৃ কাক কোৱা হয় বা এটা full form ৰ অৰ্থ কি। দ্বিতীয়ত যন্ত্ৰৰ শ্ৰেণী, অৰ্থাৎ ই input, output নে storage। তৃতীয়ত একক ৰূপান্তৰ, যেনে কিমান KB ত এক MB হয়। চতুৰ্থত তালিকা দি অমিলটো বা যোৰ বিচৰা হয়। পঞ্চমত কোন প্ৰজন্মই এটা বৈশিষ্ট্য বা উপাদান আনিছিল সোধা হয়। সংক্ষেপৰ full form নিয়মীয়াকৈ আহে।

    Computer Awareness প্ৰশ্ন সমাধানৰ স্তৰ

    প্ৰথমে প্ৰশ্ন পঢ়ি ই সংজ্ঞা, যন্ত্ৰৰ শ্ৰেণী, সংখ্যা নে নাম বিচাৰে নিৰ্ণয় কৰক। দ্বিতীয়ে অনুমান নকৰি মানক তথ্য মনত পেলাওক। তৃতীয়ে বেলেগ শ্ৰেণীৰ বিকল্প আতৰাওক, যেনে input যন্ত্ৰৰ তালিকাত এটা output যন্ত্ৰ। চতুৰ্থে এককৰ প্ৰশ্নত 1024 গুণক সাৱধানে ব্যৱহাৰ কৰি স্তৰ গণনা কৰক। পঞ্চমে যন্ত্ৰৰ প্ৰশ্নত তথ্যৰ দিশ নিশ্চিত কৰক। শেষত full form আখৰে আখৰে পৰীক্ষা কৰক, কাৰণ এটা ভুল শব্দই প্ৰায়ে শুদ্ধ বিকল্প লুকুৱায়।

    পৰীক্ষাৰ প্ৰৱণতা

    অসমৰ নিয়োগ পৰীক্ষাত মূল সংজ্ঞা, full form, প্ৰজন্ম, মেমৰি একক আৰু input-output যন্ত্ৰ আটাইতকৈ বেছি আহে, তাৰ পিছত storage যন্ত্ৰ আৰু CPU ৰ অংশ। প্ৰশ্ন চুটি আৰু এটা তথ্যভিত্তিক, গতিকে যুক্তি নহয়, পুনৰালোচনাই নম্বৰ আনে। একেই মানক তথ্য সৰু সালসলনিৰে পুনৰ আহে, যাৰ ফলত এই অংশ আটাইতকৈ সহজ হৈ পৰে।

    সাধাৰণ ভুল

    • মেমৰি আৰু storage এক কৰি নধৰিব; মেমৰি primary আৰু প্ৰায়ে volatile।
    • Input আৰু output যন্ত্ৰ মিলাই নিদিব; তথ্যৰ দিশ চাওক।
    • Full form অনুমান নকৰিব; মানক ৰূপ শিকক।
    • 1024, 1000 নহয়, যে binary একক সংযোগ কৰে নাপাহৰিব।
    • প্ৰজন্ম আৰু তাৰ উপাদান মিলাই নিদিব।
    • nibble ৰ দৰে সৰু একক নাপাহৰিব, যি চাৰিটা bit।

    প্ৰস্তুতি কেনেকৈ কৰিব

    পাঁচটা প্ৰজন্মৰ বছৰ, মূল উপাদান, ভাষা আৰু উদাহৰণ লৈ এখন পৃষ্ঠাৰ তালিকা বনাওক। তাৰ পিছত input, output আৰু storage যন্ত্ৰৰ তালিকা বনাই প্ৰতিটোৰ কাষত তথ্যৰ দিশ লিখক। তাৰ পিছত bit ৰ পৰা terabyte লৈ এককৰ শাৰী এখন কাৰ্ডত লিখি দৈনিক পুনৰালোচনা কৰক। প্ৰতিটো সংহতিত প্ৰতিটো full form ৰেখাংকন কৰি নজনাৰটো শিকি লওক।

    কম্পিউটাৰ চিষ্টেমৰ হাৰ্ডৱেৰ চিত্ৰ, যি CPU, মেমৰি আৰু input-output একক দেখুৱায়, পুনৰালোচনা কৰক, কাৰণ বহু প্ৰশ্ন ইয়াৰ পৰা আহে। দিনে কুৰিটা প্ৰশ্ন কৰি ভুল হোৱা তথ্যৰ এখন তালিকা ৰাখক; একেই তথ্য পুনৰ আহে। শেষ সপ্তাহত কেৱল সেই তালিকা আৰু এক পৃষ্ঠাৰ তালিকা চাওক, তেতিয়া এই অংশ সাজু হ'ব।

    দ্ৰুত পুনৰালোচনাৰ টিপছ

    • CPU ৰ ALU, control unit আৰু register থাকে।
    • RAM volatile, ROM non-volatile।
    • একক 1024 ৰে বাঢ়ে, আৰু আঠ bit ত এক byte।
    • প্ৰতিটো প্ৰজন্ম আৰু তাৰ মূল উপাদান জানক।
    • প্ৰতিটো যন্ত্ৰ input, output নে storage শ্ৰেণীবদ্ধ কৰক।

    শেষ পুনৰালোচনা

    শেষ দিনা প্ৰজন্মৰ তালিকা, যন্ত্ৰৰ তালিকা আৰু এককৰ শাৰী পুনৰালোচনা কৰি কুৰিটা প্ৰশ্নৰ সময়বদ্ধ সংহতি কৰক। প্ৰতিটো ভুল উত্তৰৰ বাবে বাদ পৰা তথ্যটো লিখি ৰাখক। Computer fundamentals আৰু hardware এ স্পষ্ট, শুদ্ধ তথ্য বিচাৰে; তথ্য থকা প্ৰাৰ্থীয়ে দ্বিধা নকৰি উত্তৰ দি সহজ নম্বৰ পায়।

    সঘনাই সোধা প্ৰশ্ন

    কম্পিউটাৰৰ পিতৃ কাক কোৱা হয়?

    Charles Babbage ক কম্পিউটাৰৰ পিতৃ কোৱা হয়, কাৰণ তেওঁ Analytical Engine সাজিছিল, যি প্ৰথম যান্ত্ৰিক সাধাৰণ উদ্দেশ্যৰ কম্পিউটাৰ।

    RAM আৰু ROM ৰ পাৰ্থক্য কি?

    RAM volatile কাৰ্যক্ষম মেমৰি, বিদ্যুৎ গ'লে তথ্য হেৰায়; ROM non-volatile আৰু ষ্টাৰ্ট-আপ নিৰ্দেশনা স্থায়ীভাৱে ৰাখে।

    এক byte ত কিমান bit থাকে?

    এক byte ত আঠটা bit থাকে, আৰু nibble হৈছে আধা byte, অৰ্থাৎ চাৰিটা bit।

    কোন প্ৰজন্মই microprocessor আনিছিল?

    চতুৰ্থ প্ৰজন্মই, 1971 ৰ পৰা, microprocessor আৰু VLSI আনিছিল, যাৰ ফলত personal computer ওলাইছিল।

    Touch screen input নে output যন্ত্ৰ?

    Touch screen দুয়োটা, কাৰণ ই output দেখুৱায় আৰু ব্যৱহাৰকাৰীয়ে চুই দিলে inputও লয়।
