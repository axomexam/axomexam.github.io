    Q1. Which of the following is system software?

    (B) MS Word MS Word
    (C) Tally Tally
    (D) Photoshop Photoshop

    Compiler এ সম্পূৰ্ণ high-level language program-ক চলোৱাৰ আগতে একেবাৰে machine code-লৈ ৰূপান্তৰ কৰে। ইয়াৰ বিপৰীতে interpreter লাইন-লাইনকৈ কাম কৰে।

    Software & Operating System: Types, Functions and Methods

    Software awareness tests whether a candidate can separate the programs that run a computer from the programs that a user runs, and whether the functions and types of an operating system are clear. The questions are fact based and repeat across years, so a candidate who learns the standard definitions and a few classifications can answer the whole set with confidence.

    This deep-study note covers the basic terms, the main kinds of software, the functions of an operating system, its common types, file systems, language processors, the question patterns, a solving method, the traps examiners set and a preparation plan. After reading it, a candidate should be able to classify any program and describe the work of an operating system without hesitation.

    Basic Terms

    • Software: a set of programs and instructions that directs the hardware of a computer.
    • System software: software that runs the computer itself, such as an operating system.
    • Application software: software that does a user's task, such as a word processor or a spreadsheet.
    • Operating system: the master program that manages hardware, software and files and gives the user an interface.
    • Kernel: the core of the operating system, which stays in memory and controls the most basic tasks.
    • Utility software: a small tool that maintains the system, such as an antivirus or a disk cleaner.
    • Device driver: a program that lets the operating system talk to a particular hardware device.
    • Firmware: software stored permanently in hardware, such as the BIOS.
    • BIOS: the basic input output system that starts a computer and hands control to the operating system.
    • Booting: the process of starting a computer and loading the operating system into memory.
    • File: a named collection of related data stored on a storage device.
    • File system: the method by which an operating system names, stores and retrieves files, such as NTFS or FAT.

    Core Concepts and Rules

    • Software is divided into system software and application software, and an operating system is system software.
    • An operating system is the interface between the user and the hardware.
    • The main functions of an operating system are process management, memory management, file management, device management and providing a user interface.
    • The kernel is loaded first and remains in memory throughout the session.
    • A command line interface uses typed commands, while a graphical user interface uses windows, icons and a mouse.
    • Types of operating systems include batch, multiprogramming, multitasking, multiprocessing, time sharing, real time, distributed, embedded and mobile.
    • A file system decides the naming rules, folders, permissions and the way space is allotted on a disk.
    • Language processors translate between human-readable code and machine code.
    • Booting is of two kinds, cold booting when the computer is switched on and warm booting when it is restarted.
    • Application software cannot run without an operating system, because it depends on the system services.

    Functions of an Operating System

    An operating system manages processes by deciding which program runs and for how long, and it manages memory by giving each program the space it needs and taking it back when the program ends. It manages files through directories and permissions, and it manages devices through drivers that carry data to and from the hardware. It also provides the user interface, whether a command line or a graphical shell, and it enforces security through user accounts and access rights. On a shared machine it schedules the processor so that each user seems to have the computer to himself.

    Types of Operating Systems

    A batch operating system collects jobs and runs them one after another without user interaction. A multiprogramming system keeps several jobs in memory and switches the processor among them to use idle time. A multitasking system lets one user run several tasks at once. A multiprocessing system works with two or more processors together. A time sharing system gives each user a small slice of processor time so that many users share the machine. A real time system must respond within a fixed time and is used in control and defence work. A distributed system spreads the work over several connected computers, an embedded system is built into a device, and a mobile operating system is designed for phones and tablets.

    Language Processors and File Systems

    A language processor converts a program written by a person into a form the machine understands. An assembler converts assembly language into machine language, and a compiler converts a high-level language into machine language all at once, while an interpreter converts and runs it line by line. A linker joins several object modules and library routines into one program, and a loader places that program into memory for execution. A file system, such as NTFS, FAT, ext or HFS, decides how files and folders are named, where they are stored on the disk and who may read or change them.

    Types of Questions Asked

    The most common pattern asks whether a named program is system software or application software. The second asks a function of the operating system. The third asks which type of operating system suits a given task. The fourth asks the meaning of a term such as kernel, BIOS or booting. The fifth asks about language processors or the full form of a file system or a device. Direct full forms and classifications take most of the marks.

    Steps to Solve a Software Question

    First, read the question and see whether it asks for a classification, a function, a type or a full form. Second, if it asks for a classification, decide whether the program runs the computer or serves the user, because that separates system from application software. Third, if it asks for a function, recall the five main jobs of an operating system. Fourth, if it asks for a type, match the description with the correct kind, such as real time for fixed-time response. Fifth, remove options that mix categories. Finally, check the full form word by word, since one wrong word hides the correct answer.

    Common Mistakes to Avoid

    • Do not call an application software a system software, and remember the operating system is system software.
    • Do not confuse the kernel with the whole operating system.
    • Do not confuse a compiler with an interpreter; a compiler translates the whole program first.
    • Do not mix BIOS with an operating system; BIOS is firmware.
    • Do not confuse multitasking with multiprogramming, which involves several users or jobs.
    • Do not overlook utility software, which maintains rather than runs the system.

    Frequently Asked Questions

    Is an operating system system software or application software?

    An operating system is system software, because it runs the computer and provides services to application software.

    What are the main functions of an operating system?

    Its main functions are process management, memory management, file management, device management and providing a user interface.

    What is the difference between a compiler and an interpreter?

    A compiler translates the whole program into machine code at once, while an interpreter translates and runs the program line by line.

    What is BIOS?

    BIOS, the basic input output system, is firmware that starts the computer and hands control to the operating system.

    What is the difference between multitasking and multiprogramming?

    Multitasking lets one user run several tasks at once, while multiprogramming keeps several jobs in memory so the processor is never idle.

    Language processor এ মানুহে লিখা কাৰ্যসূচীক মেচিনে বুজা ৰূপলৈ সলায়। Assembler এ assembly language ক machine language লৈ সলায়; compiler এ high-level language ক গোটেইখিনি একেবাৰে machine language লৈ সলায়, আনহাতে interpreter এ শাৰীে শাৰীে সলনি কৰি চলায়। Linker এ কেইবাটাও object module আৰু library routine যোগ কৰি এটা কাৰ্যসূচী বনায়, আৰু loader এ সেই কাৰ্যসূচী চলাবলৈ মেমৰিত ৰাখে। File system, যেনে NTFS, FAT, ext বা HFS, এ নিৰ্ণয় কৰে ফাইল আৰু folder কেনেকৈ নাম দিয়া, ডিস্কত ক'ত ৰখা আৰু কোনে পঢ়িব বা সলাব পাৰে।

    সোধা প্ৰশ্নৰ প্ৰকাৰ

    আটাইতকৈ বেছি অহা ধৰণ হ'ল দিয়া কাৰ্যসূচী এটা system software নে application software সোধা। দ্বিতীয়ত অপাৰেটিং ছিষ্টেমৰ কাৰ্য সোধা হয়। তৃতীয়ত কোনো নিৰ্দিষ্ট কামৰ বাবে কোন প্ৰকাৰৰ অপাৰেটিং ছিষ্টেম উপযুক্ত সোধা হয়। চতুৰ্থত kernel, BIOS বা booting ৰ দৰে শব্দৰ অৰ্থ সোধা হয়। পঞ্চমত language processor ৰ বা এটা file system বা device ৰ full form সোধা হয়। পোনপটীয়া full form আৰু শ্ৰেণীবিভাজনে বেছি নম্বৰ লয়।

    Software প্ৰশ্ন সমাধানৰ স্তৰ

    প্ৰথমে প্ৰশ্ন পঢ়ি ই শ্ৰেণীবিভাজন, কাৰ্য, প্ৰকাৰ নে full form বিচাৰে চাওক। দ্বিতীয়ে শ্ৰেণীবিভাজন হ'লে কাৰ্যসূচীটোৱে কম্পিউটাৰ চলায় নে ব্যৱহাৰকাৰীক সেৱা দিয়ে নিৰ্ণয় কৰক, কাৰণ ইয়েই system আৰু application ছফ্টৱেৰ পৃথক কৰে। তৃতীয়ে কাৰ্য হ'লে অপাৰেটিং ছিষ্টেমৰ পাঁচটা মূল কাম মনত পেলাওক। চতুৰ্থে প্ৰকাৰ হ'লে বৰ্ণনাৰ লগত সঠিক প্ৰকাৰ মিলাওক, যেনে নিৰ্দিষ্ট সময়ৰ উত্তৰৰ বাবে real time। পঞ্চমে শ্ৰেণী মিলা বিকল্প আতৰাওক। শেষত full form শব্দে শব্দে পৰীক্ষা কৰক, কাৰণ এটা ভুল শব্দই শুদ্ধ উত্তৰ লুকুৱায়।

    পৰীক্ষাৰ প্ৰৱণতা

    অসমৰ নিয়োগ পৰীক্ষাত ছফ্টৱেৰৰ শ্ৰেণীবিভাজন, অপাৰেটিং ছিষ্টেমৰ কাৰ্য, অপাৰেটিং ছিষ্টেমৰ প্ৰকাৰ আৰু kernel, BIOS, booting, file system ৰ দৰে শব্দ আটাইতকৈ বেছি আহে, তাৰ পিছত language processor আৰু utility software। প্ৰশ্ন চুটি আৰু এটা তথ্যভিত্তিক, গতিকে নিয়মীয়া পুনৰালোচনেই যথেষ্ট। একেই শব্দ সৰু সালসলনিৰে পুনৰ আহে, যাৰ ফলত এই অংশ দ্ৰুতভাৱে জনা যায়।

    সাধাৰণ ভুল

    • Application software ক system software নুবুলিব, আৰু অপাৰেটিং ছিষ্টেম যে system software মনত ৰাখক।
    • Kernel ক গোটেই অপাৰেটিং ছিষ্টেম বুলি নধৰিব।
    • Compiler আৰু interpreter মিলাই নিদিব; compiler এ আগতে গোটেই কাৰ্যসূচী সলায়।
    • BIOS ক অপাৰেটিং ছিষ্টেমৰ লগত নিমিলাব; BIOS হৈছে firmware।
    • Multitasking আৰু multiprogramming মিলাই নিদিব।
    • Utility software নাপাহৰিব, যি ছিষ্টেম চলোৱাৰ পৰিৱৰ্তে ৰক্ষা কৰে।

    প্ৰস্তুতি কেনেকৈ কৰিব

    System software আৰু application software ৰ দুটা স্তম্ভৰ তালিকা বনাই প্ৰতিটোত পাঁচটা উদাহৰণ দিয়ক। তাৰ পিছত অপাৰেটিং ছিষ্টেমৰ পাঁচটা মূল কাৰ্য লিখি প্ৰতিটোৰ কাষত এটা উদাহৰণ দিয়ক। তাৰ পিছত অপাৰেটিং ছিষ্টেমৰ প্ৰকাৰ আৰু কোনটো কোন পৰিস্থিতিত ব্যৱহাৰ হয় লৈ তালিকা বনাওক। শেষত language processor আৰু প্ৰতিটোৱে কি কৰে লিখি file system আৰু full form পুনৰালোচনা কৰক।

    দিনে কুৰিটা প্ৰশ্ন কৰি ভুল হোৱা শব্দৰ এখন তালিকা ৰাখক, কাৰণ একেই শব্দ পুনৰ আহে। Compiler আৰু interpreter ৰ, লগতে multitasking আৰু multiprogramming ৰ পাৰ্থক্য উচ্চস্বৰে পুনৰালোচনা কৰক, কাৰণ এয়াই আটাইতকৈ সাধাৰণ ফান্দ। শেষ সপ্তাহত কেৱল তালিকা আৰু ৰেজিষ্টাৰ চাওক, তেতিয়া এই অংশ সাজু হ'ব।

    দ্ৰুত পুনৰালোচনাৰ টিপছ

    • অপাৰেটিং ছিষ্টেম হৈছে system software আৰু user interface।
    • তাৰ পাঁচটা কাৰ্য: process, memory, file, device আৰু interface management।
    • Compiler এ একেবাৰে সলায়; interpreter এ শাৰীে শাৰীে সলায়।
    • BIOS firmware; kernel অপাৰেটিং ছিষ্টেমৰ মূল।
    • প্ৰতিটো অপাৰেটিং ছিষ্টেমৰ প্ৰকাৰ তাৰ ব্যৱহাৰৰ লগত মিলাওক।

    শেষ পুনৰালোচনা

    শেষ দিনা দুটা স্তম্ভৰ ছফ্টৱেৰ তালিকা, কাৰ্যৰ তালিকা আৰু অপাৰেটিং ছিষ্টেমৰ প্ৰকাৰ পুনৰালোচনা কৰি কুৰিটা প্ৰশ্নৰ সময়বদ্ধ সংহতি কৰক। প্ৰতিটো ভুল উত্তৰৰ বাবে বাদ পৰা শব্দটো লিখি ৰাখক। Software আৰু operating system ৰ প্ৰশ্নই স্পষ্ট শ্ৰেণীবিভাজন বিচাৰে, আৰু শ্ৰেণীবিভাজন জনা প্ৰাৰ্থীয়ে দ্ৰুতভাৱে উত্তৰ দি সহজ নম্বৰ পায়।

    সঘনাই সোধা প্ৰশ্ন

    অপাৰেটিং ছিষ্টেম system software নে application software?

    অপাৰেটিং ছিষ্টেম হৈছে system software, কাৰণ ই কম্পিউটাৰ চলায় আৰু application software ক সেৱা দিয়ে।

    অপাৰেটিং ছিষ্টেমৰ মূল কাৰ্য কি কি?

    তাৰ মূল কাৰ্য হৈছে process management, memory management, file management, device management আৰু user interface দিয়া।

    Compiler আৰু interpreter ৰ পাৰ্থক্য কি?

    Compiler এ গোটেই কাৰ্যসূচীক একেবাৰে machine code লৈ সলায়, আনহাতে interpreter এ শাৰীে শাৰীে সলনি কৰি চলায়।

    BIOS কি?

    BIOS, অৰ্থাৎ basic input output system, হৈছে firmware, যি কম্পিউটাৰ আৰম্ভ কৰি নিয়ন্ত্ৰণ অপাৰেটিং ছিষ্টেমক দিয়ে।

    Multitasking আৰু multiprogramming ৰ পাৰ্থক্য কি?

    Multitasking এ এজন ব্যৱহাৰকাৰীক একে সময়তে কেইবাটাও কাম চলাবলৈ দিয়ে, আনহাতে multiprogramming এ কেইবাটাও কাম মেমৰিত ৰাখি processor ক কেতিয়াও অলস নথয়।
