    MS Office Mock Test — Set 8

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which shortcut is used to find text in MS Word?
    MS Word-ত লিখনী বিচাৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + F Ctrl + F
    (B) Ctrl + H Ctrl + H
    (C) Ctrl + P Ctrl + P
    (D) Ctrl + D Ctrl + D
    Answer: Ctrl + F
    Ctrl + F
    Explanation: Ctrl + F opens the Find option in MS Word.
    Ctrl + F য়ে MS Word-ত Find বিকল্প খোলে।
    Q2. Which shortcut is used for Find and Replace in MS Word?
    MS Word-ত Find and Replace ৰ বাবে কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + T Ctrl + T
    (B) Ctrl + H Ctrl + H
    (C) Ctrl + F Ctrl + F
    (D) Ctrl + R Ctrl + R
    Answer: Ctrl + H
    Ctrl + H
    Explanation: Ctrl + H opens the Find and Replace dialog box.
    Ctrl + H য়ে Find and Replace ডায়লগ বক্স খোলে।
    Q3. Where does a footnote appear in a document?
    নথিপত্ৰত ফুটনোট ক'ত দেখা যায়?
    (A) In the header হেডাৰত
    (B) In the margin মাৰ্জিনত
    (C) At the bottom of the page পৃষ্ঠাৰ তলত
    (D) At the top of the page পৃষ্ঠাৰ ওপৰত
    Answer: At the bottom of the page
    পৃষ্ঠাৰ তলত
    Explanation: A footnote appears at the bottom of the page.
    ফুটনোট পৃষ্ঠাৰ তলত দেখা যায়।
    Q4. What does Ctrl + Enter insert in MS Word?
    MS Word-ত Ctrl + Enter য়ে কি সন্নিবেশ কৰে?
    (A) A line break শাৰী বিভাজন
    (B) A table এটা টেবুল
    (C) A picture এখন ছবি
    (D) A page break পৃষ্ঠা বিভাজন
    Answer: A page break
    পৃষ্ঠা বিভাজন
    Explanation: Ctrl + Enter inserts a page break in MS Word.
    Ctrl + Enter য়ে MS Word-ত পৃষ্ঠা বিভাজন সন্নিবেশ কৰে।
    Q5. Which view displays the headings and structure of a Word document?
    Word ডকুমেণ্টৰ শিৰোনামা আৰু গাঁথনি দেখুওৱা ভিউ কোনটো?
    (A) Outline view আউটলাইন ভিউ
    (B) Print Layout প্ৰিন্ট লে'আউট
    (C) Web Layout ৱেব লে'আউট
    (D) Full Screen Reading ফুল স্ক্ৰীন ৰিডিং
    Answer: Outline view
    আউটলাইন ভিউ
    Explanation: Outline view displays the headings and structure of a document.
    আউটলাইন ভিউয়ে নথিপত্ৰৰ শিৰোনামা আৰু গাঁথনি দেখুৱায়।
    Q6. Which function returns the largest value in Excel?
    Excel-ত সৰ্বোচ্চ মান ঘূৰাই দিয়া ফলন কোনটো?
    (A) LARGE LARGE
    (B) MAX MAX
    (C) MIN MIN
    (D) SUM SUM
    Answer: MAX
    MAX
    Explanation: The MAX function returns the largest value in a range.
    MAX ফলনে এটা পৰিসৰৰ সৰ্বোচ্চ মান ঘূৰাই দিয়ে।
    Q7. Which function is used for a logical test in Excel?
    Excel-ত তৰ্কমূলক পৰীক্ষাৰ বাবে কোন ফলন ব্যৱহাৰ হয়?
    (A) COUNT COUNT
    (B) NOW NOW
    (C) IF IF
    (D) SUM SUM
    Answer: IF
    IF
    Explanation: The IF function performs a logical test and returns one of two values.
    IF ফলনে তৰ্কমূলক পৰীক্ষা কৰি দুটা মানৰ এটা ঘূৰাই দিয়ে।
    Q8. An Excel file is called a?
    Excel ফাইলক কি বোলে?
    (A) Worksheet ৱৰ্কশ্বীট
    (B) Slide স্লাইড
    (C) Document ডকুমেণ্ট
    (D) Workbook ৱৰ্কবুক
    Answer: Workbook
    ৱৰ্কবুক
    Explanation: An Excel file is called a workbook, and it contains worksheets.
    Excel ফাইলক ৱৰ্কবুক বোলে, যি ৱৰ্কশ্বীটবোৰ ধৰি ৰাখে।
    Q9. Which shortcut inserts the current date in Excel?
    Excel-ত বৰ্তমান তাৰিখ সন্নিবেশ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + ; Ctrl + ;
    (B) Ctrl + : Ctrl + :
    (C) Ctrl + D Ctrl + D
    (D) Ctrl + T Ctrl + T
    Answer: Ctrl + ;
    Ctrl + ;
    Explanation: Ctrl + ; inserts the current date in Excel.
    Excel-ত Ctrl + ; য়ে বৰ্তমান তাৰিখ সন্নিবেশ কৰে।
    Q10. Which function looks up a value in the first column of a vertical table?
    উলম্ব টেবুলৰ প্ৰথম স্তম্ভত মান বিচাৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) MATCH MATCH
    (B) VLOOKUP VLOOKUP
    (C) HLOOKUP HLOOKUP
    (D) INDEX INDEX
    Answer: VLOOKUP
    VLOOKUP
    Explanation: VLOOKUP searches for a value in the first column of a vertical table.
    VLOOKUP য়ে উলম্ব টেবুলৰ প্ৰথম স্তম্ভত মান বিচাৰে।
    Q11. What does ##### in an Excel cell indicate?
    Excel চেলত ##### দেখুওৱাৰ অৰ্থ কি?
    (A) The cell is empty চেল খালী
    (B) The value is text মানটো লিখনী
    (C) The column is too narrow স্তম্ভ বহল নহয়
    (D) The formula is wrong সূত্ৰ ভুল
    Answer: The column is too narrow
    স্তম্ভ বহল নহয়
    Explanation: ##### appears when the column is too narrow to display the value.
    মানটো দেখুৱাবলৈ স্তম্ভ বহল নহ'লে ##### দেখা যায়।
    Q12. What is Conditional Formatting used for in Excel?
    Excel-ত Conditional Formatting কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Sorting the data তথ্য সজোৱা
    (B) Printing the sheet শ্বীট প্ৰিন্ট কৰা
    (C) Merging cells চেল মাৰ্জ কৰা
    (D) Formatting cells based on conditions চৰ্ত অনুসৰি চেল ফৰ্মেট কৰা
    Answer: Formatting cells based on conditions
    চৰ্ত অনুসৰি চেল ফৰ্মেট কৰা
    Explanation: Conditional Formatting changes the appearance of cells that meet specified conditions.
    Conditional Formatting য়ে নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা চেলৰ ৰূপ সলনি কৰে।
    Q13. Which shortcut duplicates the current slide in PowerPoint?
    PowerPoint-ত বৰ্তমান স্লাইডৰ প্ৰতিলিপি বনাবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + D Ctrl + D
    (B) Ctrl + M Ctrl + M
    (C) Ctrl + N Ctrl + N
    (D) Ctrl + C Ctrl + C
    Answer: Ctrl + D
    Ctrl + D
    Explanation: Ctrl + D duplicates the selected slide in PowerPoint.
    PowerPoint-ত Ctrl + D য়ে বাছনি কৰা স্লাইডৰ প্ৰতিলিপি বনায়।
    Q14. Which tab is used to apply a theme in PowerPoint?
    PowerPoint-ত থীম প্ৰয়োগ কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Transitions Transitions
    (B) Design Design
    (C) Home Home
    (D) Insert Insert
    Answer: Design
    Design
    Explanation: The Design tab is used to apply themes and variants in PowerPoint.
    PowerPoint-ত থীম আৰু ভেৰিয়েণ্ট প্ৰয়োগ কৰিবলৈ Design টেব ব্যৱহাৰ হয়।
    Q15. What does Presenter View show in PowerPoint?
    PowerPoint-ত Presenter View য়ে কি দেখুৱায়?
    (A) Only the slide thumbnails কেৱল স্লাইড থাম্বনেইল
    (B) Only the file name কেৱল ফাইলৰ নাম
    (C) Speaker notes and the next slide স্পীকাৰ নোট আৰু পৰৱৰ্তী স্লাইড
    (D) Only the current slide কেৱল বৰ্তমান স্লাইড
    Answer: Speaker notes and the next slide
    স্পীকাৰ নোট আৰু পৰৱৰ্তী স্লাইড
    Explanation: Presenter View shows speaker notes, the current slide and the next slide.
    Presenter View য়ে স্পীকাৰ নোট, বৰ্তমান স্লাইড আৰু পৰৱৰ্তী স্লাইড দেখুৱায়।
    Q16. What is a slide in PowerPoint?
    PowerPoint-ত এটা স্লাইড কি?
    (A) A type of chart এবিধ চাৰ্ট
    (B) A saved file সংৰক্ষিত ফাইল
    (C) A keyboard shortcut কীবৰ্ড চৰ্টকাট
    (D) A single page of a presentation প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠা
    Answer: A single page of a presentation
    প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠা
    Explanation: A slide is a single page of a presentation.
    স্লাইড হৈছে প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠা।
    Q17. Which shortcut starts a slide show from the current slide?
    বৰ্তমান স্লাইডৰপৰা স্লাইড শ্ব' আৰম্ভ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Shift + F5 Shift + F5
    (B) F5 F5
    (C) Ctrl + F5 Ctrl + F5
    (D) Alt + F5 Alt + F5
    Answer: Shift + F5
    Shift + F5
    Explanation: Shift + F5 starts the slide show from the current slide.
    Shift + F5 য়ে বৰ্তমান স্লাইডৰপৰা স্লাইড শ্ব' আৰম্ভ কৰে।
    Q18. MS Access is a?
    MS Access কি ধৰণৰ চফটৱেৰ?
    (A) Presentation software প্ৰেজেণ্টেচন চফটৱেৰ
    (B) Relational database management system ৰিলেচনেল ডেটাবেছ মেনেজমেণ্ট চিষ্টেম
    (C) Word processing software শব্দ প্ৰক্ৰিয়াকৰণ চফটৱেৰ
    (D) Spreadsheet software স্প্ৰেডশ্বীট চফটৱেৰ

    ৰিলেচনেল ডেটাবেছ মেনেজমেণ্ট চিষ্টেম
    Explanation: MS Access is a relational database management system.
    MS Access এটা ৰিলেচনেল ডেটাবেছ মেনেজমেণ্ট চিষ্টেম।
    Q19. Which Access data type automatically generates a unique number?
    কোন Access ডেটা টাইপে স্বয়ংক্ৰিয়ভাৱে অদ্বিতীয় সংখ্যা সৃষ্টি কৰে?
    (A) Number সংখ্যা
    (B) Date/Time তাৰিখ/সময়
    (C) AutoNumber অট'নাম্বাৰ
    (D) Short Text চুটি লিখনী
    Answer: AutoNumber
    অট'নাম্বাৰ
    Explanation: The AutoNumber data type automatically generates a unique number for each record.
    AutoNumber ডেটা টাইপে প্ৰতিটো ৰেকৰ্ডৰ বাবে স্বয়ংক্ৰিয়ভাৱে অদ্বিতীয় সংখ্যা সৃষ্টি কৰে।
    Q20. Which Access object is used to automate repetitive tasks?
    পুনৰাবৃত্তিমূলক কাম স্বয়ংক্ৰিয় কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) Table টেবুল
    (B) Query কুৱেৰী
    (C) Report ৰিপৰ্ট
    (D) Macro মেক্ৰ'
    Answer: Macro
    মেক্ৰ'
    Explanation: A macro is used to automate tasks in MS Access.
    MS Access-ত কাম স্বয়ংক্ৰিয় কৰিবলৈ মেক্ৰ' ব্যৱহাৰ হয়।
    Q21. What does CC mean in email?
    ইমেইলত CC ৰ অৰ্থ কি?
    (A) Carbon Copy Carbon Copy
    (B) Blind Carbon Copy Blind Carbon Copy
    (C) Computer Copy Computer Copy
    (D) Common Copy Common Copy
    Answer: Carbon Copy
    Carbon Copy
    Explanation: CC stands for Carbon Copy.
    CC ৰ সম্পূৰ্ণ ৰূপ হৈছে Carbon Copy।
    Q22. Which Outlook feature is used to schedule meetings and appointments?
    সভা আৰু অপয়ন্টমেণ্টৰ সময় নিৰ্ধাৰণ কৰিবলৈ Outlook-ৰ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Notes নোটছ
    (B) Calendar কেলেণ্ডাৰ
    (C) Contacts কণ্টেক্টছ
    (D) Tasks টাস্কছ
    Answer: Calendar
    কেলেণ্ডাৰ
    Explanation: The Calendar feature is used to schedule meetings and appointments.
    Calendar সুবিধা সভা আৰু অপয়ন্টমেণ্টৰ সময় নিৰ্ধাৰণ কৰিবলৈ ব্যৱহাৰ হয়।
    Q23. Which shortcut is used to copy the selected item in MS Office?
    MS Office-ত বাছনি কৰা বস্তু কপি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + V Ctrl + V
    (B) Ctrl + Z Ctrl + Z
    (C) Ctrl + C Ctrl + C
    (D) Ctrl + X Ctrl + X
    Answer: Ctrl + C
    Ctrl + C
    Explanation: Ctrl + C copies the selected item to the clipboard.
    Ctrl + C য়ে বাছনি কৰা বস্তু ক্লিপব'ৰ্ডলৈ কপি কৰে।
    Q24. What is a template in MS Office?
    MS Office-ত টেমপ্লেট কি?
    (A) A saved email সংৰক্ষিত ইমেইল
    (B) A type of chart এবিধ চাৰ্ট
    (C) A keyboard shortcut কীবৰ্ড চৰ্টকাট
    (D) A pre-designed document format পূৰ্ব-পৰিকল্পিত নথিপত্ৰৰ আৰ্হি
    Answer: A pre-designed document format
    পূৰ্ব-পৰিকল্পিত নথিপত্ৰৰ আৰ্হি
    Explanation: A template is a pre-designed format used as a starting point for new documents.
    টেমপ্লেট হৈছে নতুন নথিপত্ৰৰ আৰম্ভণি বিন্দু হিচাপে ব্যৱহৃত পূৰ্ব-পৰিকল্পিত আৰ্হি।
    Q25. Which key opens Help in MS Office?
    MS Office-ত সহায় (Help) পাবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) F1 F1
    (B) F2 F2
    (C) F5 F5
    (D) F7 F7
    Answer: F1
    F1
    Explanation: F1 opens the Help window in MS Office.
    F1 য়ে MS Office-ত সহায় উইণ্ডো খোলে।
