    MS Office Mock Test — Set 5

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which shortcut is used to insert a new worksheet?
    নতুন ৱৰ্কশ্বীট সন্নিবিষ্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Shift + F11 Shift + F11
    (B) Ctrl + F11 Ctrl + F11
    (C) Alt + F11 Alt + F11
    (D) F11 F11
    Answer: Shift + F11
    Shift + F11
    Explanation: Shift + F11 inserts a new worksheet in Excel.
    Shift + F11 য়ে Excel ত এটা নতুন কৰ্মপত্ৰ (worksheet) সন্নিবিষ্ট কৰে।
    Q2. Which shortcut is used to undo an action?
    এটা কাৰ্য আনডু কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + U Ctrl + U
    (B) Ctrl + B Ctrl + B
    (C) Ctrl + Z Ctrl + Z
    (D) Ctrl + Y Ctrl + Y
    Answer: Ctrl + Z
    Ctrl + Z
    Explanation: Ctrl + Z is used to undo an action.
    Ctrl + Z য়ে এটা কাৰ্য বাতিল (undo) কৰিবলৈ ব্যৱহাৰ হয়।
    Q3. A single page of a presentation is called?
    প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠাক কি বুলি কোৱা হয়?
    (A) Slide স্লাইড
    (B) Page পৃষ্ঠা
    (C) Frame ফ্ৰেম
    (D) Sheet শ্বীট
    Answer: Slide
    স্লাইড
    Explanation: A single page of a presentation is called a slide.
    প্ৰেজেণ্টেশ্যনৰ এটা পৃষ্ঠাক স্লাইড বোলা হয়।
    Q4. Which chart type shows trends over time?
    সময়ৰ লগত প্ৰৱণতা দেখুওৱা চাৰ্টৰ প্ৰকাৰ কোনটো?
    (A) Bar chart বাৰ চাৰ্ট
    (B) Doughnut chart ড'নাট চাৰ্ট
    (C) Line chart লাইন চাৰ্ট
    (D) Pie chart পাই চাৰ্ট
    Answer: Line chart
    লাইন চাৰ্ট
    Explanation: A line chart shows trends over time.
    Line chart য়ে সময়ৰ লগে লগে প্ৰৱণতা (trend) দেখুৱায়।
    Q5. Which shortcut opens the Print dialog box?
    প্ৰিন্ট ডায়লগ বক্স খুলিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + N Ctrl + N
    (B) Ctrl + P Ctrl + P
    (C) Ctrl + O Ctrl + O
    (D) Ctrl + S Ctrl + S
    Answer: Ctrl + P
    Ctrl + P
    Explanation: Ctrl + P opens the Print dialog box.
    Ctrl + P য়ে Print ডায়লগ বক্স খোলে।
    Q6. Which feature is used to quickly apply professional formatting to a document?
    ডকুমেণ্টত দ্ৰুতভাৱে পেছাদাৰী ফৰ্মেটিং প্ৰয়োগ কৰিবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Macro মেক্ৰ'
    (B) Comment কমেণ্ট
    (C) Footnote ফুটনোট
    (D) Styles ষ্টাইল
    Answer: Styles
    ষ্টাইল
    Explanation: Styles are used to quickly apply professional formatting to a document.
    Styles ব্যৱহাৰ কৰি নথিপত্ৰত দ্ৰুতভাৱে পেছাদাৰী ফৰ্মেটিং প্ৰয়োগ কৰা হয়।
    Q7. A file created in MS Office can be protected using?
    MS Office-ত সৃষ্টি কৰা ফাইল কিৰে সুৰক্ষিত কৰিব পাৰি?
    (A) Style ষ্টাইল
    (B) Macro মেক্ৰ'
    (C) Theme থীম
    (D) Password পাছৱৰ্ড
    Answer: Password
    পাছৱৰ্ড
    Explanation: An MS Office file can be protected using a password.
    MS Office ফাইল এটা পাছৱৰ্ড ব্যৱহাৰ কৰি সুৰক্ষিত কৰিব পাৰি।
    Q8. What does the Office Clipboard store after a cut or copy operation?
    কাট বা কপিৰ পিছত Office ক্লিপবৰ্ডে কি সংৰক্ষণ কৰে?
    (A) Printer settings প্ৰিণ্টাৰ ছেটিং
    (B) Only images কেৱল ছবি
    (C) Only text কেৱল লিখনী
    (D) Data ডেটা
    Answer: Data
    ডেটা
    Explanation: The Office Clipboard stores data after a cut or copy operation.
    Cut বা Copy কৰাৰ পিছত Office Clipboard য়ে ডেটা সংৰক্ষণ কৰে।
    Q9. Which shortcut is used to create a new document?
    নতুন ডকুমেণ্ট সৃষ্টি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + N Ctrl + N
    (B) Ctrl + M Ctrl + M
    (C) Ctrl + O Ctrl + O
    (D) Ctrl + D Ctrl + D
    Answer: Ctrl + N
    Ctrl + N
    Explanation: Ctrl + N is used to create a new document.
    Ctrl + N য়ে নতুন নথিপত্ৰ সৃষ্টি কৰিবলৈ ব্যৱহাৰ হয়।
    Q10. Which function finds the average of values?
    মানসমূহৰ গড় নিৰ্ণয় কৰা ফলন কোনটো?
    (A) MIN MIN
    (B) AVERAGE AVERAGE
    (C) SUM SUM
    (D) MAX MAX
    Answer: AVERAGE
    AVERAGE
    Explanation: The AVERAGE function finds the average of values.
    AVERAGE ফলনে মানসমূহৰ গড় নিৰ্ণয় কৰে।
    Q11. MS PowerPoint is used to create?
    MS PowerPoint কি সৃষ্টি কৰিবলৈ ব্যৱহাৰ হয়?
    (A) Databases ডেটাবেছ
    (B) Spreadsheets স্প্ৰেডশ্বীট
    (C) Documents ডকুমেণ্ট
    (D) Presentations প্ৰেজেণ্টেচন
    Answer: Presentations
    প্ৰেজেণ্টেচন
    Explanation: MS PowerPoint is used to create presentations.
    MS PowerPoint প্ৰেজেণ্টেশ্যন সৃষ্টি কৰিবলৈ ব্যৱহাৰ কৰা হয়।
    Q12. What is the maximum font size available in MS Word?
    MS Word-ত উপলব্ধ সৰ্বাধিক ফণ্ট ছাইজ কি?
    (A) 1638 1638
    (B) 72 72
    (C) 100 100
    (D) 500 500
    Answer: 1638
    1638
    Explanation: The maximum font size available in MS Word is 1638.
    MS Word ত উপলব্ধ সৰ্বাধিক ফণ্ট ছাইজ হৈছে ১৬৩৮।
    Q13. A group of selected cells is called?
    নিৰ্বাচিত চেলৰ সমষ্টিক কি বুলি কোৱা হয়?
    (A) Cell চেল
    (B) Range ৰেঞ্জ
    (C) Table টেবুল
    (D) Chart চাৰ্ট
    Answer: Range
    ৰেঞ্জ
    Explanation: A group of selected cells is called a range.
    নিৰ্বাচিত কোষসমূহৰ এটা গোটক Range বোলা হয়।
    Q14. Which file format is widely used and keeps basic formatting across applications?
    কোনটো ফাইল ফৰ্মেট বহুলভাৱে ব্যৱহৃত আৰু এপ্লিকেচনৰ মাজত মৌলিক ফৰ্মেটিং ৰাখে?
    (A) XLSX XLSX
    (B) PPTX PPTX
    (C) PDF PDF
    (D) DOCX DOCX
    Answer: PDF
    PDF
    Explanation: PDF is widely used and keeps basic formatting across applications.
    PDF বহুলভাৱে ব্যৱহৃত হয় আৰু বিভিন্ন এপ্লিকেশ্যনত মৌলিক ফৰ্মেটিং অটল ৰাখে।
    Q15. A predefined set of colors, fonts and effects is called?
    পূৰ্বনিৰ্ধাৰিত ৰং, ফণ্ট আৰু প্ৰভাৱৰ সংগ্ৰহক কি বুলি কোৱা হয়?
    (A) Scheme স্কীম
    (B) Theme থীম
    (C) Layout লে'আউট
    (D) Template টেমপ্লেট
    Answer: Theme
    থীম
    Explanation: A predefined set of colors, fonts and effects is called a theme.
    ৰং, ফণ্ট আৰু ইফেক্টৰ এটা পূৰ্বনিৰ্ধাৰিত সংহতিকে Theme বোলা হয়।
    Q16. Which key combination selects all text?
    সকলো লিখনী নিৰ্বাচন কৰিবলৈ কোন কি সংমিশ্ৰণ ব্যৱহাৰ হয়?

    (D) Ctrl + Q Ctrl + Q
    Answer: Ctrl + A
    Ctrl + A
    Explanation: Ctrl + A selects all the text.
    Ctrl + A য়ে সকলো লিখনি নিৰ্বাচন কৰে।
    Q17. Which shortcut is used to center-align text?
    লিখনী কেন্দ্ৰত সজাবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    (D) Ctrl + V Ctrl + V

    Q18. The header of a document appears at the?
    ডকুমেণ্টৰ হেডাৰ ক'ত দেখুৱা হয়?
    (A) Bottom of the page পৃষ্ঠাৰ তলত
    (B) Center of the page পৃষ্ঠাৰ মাজত

    Answer: Top of the page
    পৃষ্ঠাৰ ওপৰত
    Explanation: The header of a document appears at the top of the page.
    নথিপত্ৰৰ header পৃষ্ঠাৰ ওপৰত দেখা যায়।
    Q19. Which key combination inserts a page break?
    পেজ ব্ৰেক সন্নিবিষ্ট কৰিবলৈ কোন কি সংমিশ্ৰণ ব্যৱহাৰ হয়?

    Ctrl + Enter
    Explanation: Ctrl + Enter inserts a page break.
    Ctrl + Enter য়ে পেজ ব্ৰেক সন্নিবিষ্ট কৰে।
    Q20. Which shortcut inserts the current date in MS Word?
    MS Word-ত বৰ্তমান তাৰিখ সন্নিবিষ্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    Word টেমপ্লেটৰ বাবে কোন ফাইল এক্সটেনচন ব্যৱহাৰ হয়?

    (C) .rtf .rtf
    (D) .dotx .dotx

    .dotx
    Explanation: .dotx is the file extension used for a Word template.
    .dotx হৈছে Word টেমপ্লেটৰ বাবে ব্যৱহৃত ফাইল এক্সটেনচন।
    Q22. Which object is used to enter text on a slide?
    স্লাইডত লিখনী লিখিবলৈ কোন বস্তু ব্যৱহাৰ হয়?

    (C) Picture ছবি

    টেক্সট বক্স
    Explanation: A text box is used to enter text on a slide.
    স্লাইডত লিখনি লিখিবলৈ Text Box ব্যৱহাৰ কৰা হয়।
    Q23. Ctrl + P is used for?
    Ctrl + P কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Print প্ৰিন্ট
    (B) Preview প্ৰিৱিউ

    (D) Paste পেইষ্ট

    প্ৰিন্ট

    Q24. Ctrl + E is used for which alignment?
    Ctrl + E কোন এলাইনমেণ্টৰ বাবে ব্যৱহাৰ হয়?
    (A) Center কেন্দ্ৰত
    (B) Justify জাষ্টিফাই
    (C) Left বাওঁফালে
    (D) Right সোঁফালে
    Answer: Center
    কেন্দ্ৰত
    Explanation: Ctrl + E is used for center alignment.
    Ctrl + E কেন্দ্ৰ সংৰেখন (center alignment) ৰ বাবে ব্যৱহাৰ কৰা হয়।
    Q25. Which view is used to rearrange the order of slides?
    স্লাইডৰ ক্ৰম সলনি কৰিবলৈ কোন ভিউ ব্যৱহাৰ হয়?
    (A) Normal নৰ্মাল
    (B) Slide Show স্লাইড শ্ব'
    (C) Slide Sorter স্লাইড চৰ্টাৰ
    (D) Outline আউটলাইন
    Answer: Slide Sorter
    স্লাইড চৰ্টাৰ
    Explanation: Slide Sorter view is used to rearrange the order of slides.
    Slide Sorter দৃশ্য স্লাইডৰ ক্ৰম পুনৰ সজ্জিত কৰিবলৈ ব্যৱহাৰ কৰা হয়।
