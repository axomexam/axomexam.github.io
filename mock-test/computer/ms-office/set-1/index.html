    MS Office Mock Test — Set 1

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Ctrl + Z is used for?
    Ctrl + Z কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Redo ৰিডু
    (B) Undo আনডু
    (C) Zoom জুম
    (D) Close ক্ল'জ
    Answer: Undo
    আনডু
    Explanation: Ctrl + Z is used to undo the last action.
    Ctrl + Z শেহতীয়া কাৰ্য বাতিল (undo) কৰিবলৈ ব্যৱহাৰ হয়।
    Q2. What is the default slide orientation in PowerPoint?
    PowerPoint-ত স্লাইডৰ ডিফল্ট অভিমুখ কি?
    (A) Square বৰ্গ
    (B) Custom কাষ্টম
    (C) Portrait পৰ্ট্ৰেট
    (D) Landscape লেণ্ডস্কেপ
    Answer: Landscape
    লেণ্ডস্কেপ
    Explanation: The default slide orientation in PowerPoint is Landscape.
    PowerPoint ত স্লাইডৰ ডিফ'ল্ট অভিমুখ হৈছে Landscape (অনুভূমিক)।
    Q3. Which shortcut opens the Font dialog box in PowerPoint?
    PowerPoint-ত ফণ্ট ডায়লগ বক্স খুলিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + B Ctrl + B
    (B) Ctrl + T Ctrl + T
    (C) Ctrl + F Ctrl + F
    (D) Ctrl + P Ctrl + P
    Answer: Ctrl + T
    Ctrl + T
    Explanation: Ctrl + T opens the Font dialog box in PowerPoint.
    PowerPoint ত Ctrl + T য়ে Font ডায়লগ বক্স খোলে।
    Q4. Which effect makes text appear one line at a time?
    লিখনী এটা এটা শাৰীকৈ দেখা দিয়াকৈ কৰা প্ৰভাৱ কোনটো?
    (A) Zoom জুম
    (B) Crop ক্ৰপ
    (C) Animation এনিমেচন
    (D) Transition ট্ৰানজিচন
    Answer: Animation
    এনিমেচন
    Explanation: Animation is used to make text appear one line at a time during a slide show.
    Animation ব্যৱহাৰ কৰি স্লাইড শ্ব'ত লিখা এটা এটা শাৰী কৰি দেখুওৱা হয়।
    Q5. Which shortcut is used to edit the active cell?
    সক্ৰিয় চেল সম্পাদনা কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) F7 F7
    (B) F1 F1
    (C) F5 F5
    (D) F2 F2
    Answer: F2
    F2
    Explanation: F2 is used to edit the active cell in MS Excel.
    MS Excel ত F2 কীয়ে সক্ৰিয় চেল সম্পাদনা কৰিবলৈ ব্যৱহাৰ হয়।
    Q6. Which of the following is a word processing software?
    তলৰ কোনটো ৱৰ্ড প্ৰচেছিং ছফটৱেৰ?
    (A) MS Word MS Word
    (B) MS PowerPoint MS PowerPoint
    (C) MS Access MS Access
    (D) MS Excel MS Excel
    Answer: MS Word
    MS Word
    Explanation: MS Word is a word processing software used to create and edit text documents.
    MS Word এটা ৱৰ্ড প্ৰচেছিং চফটৱেৰ যি লিখিত নথিপত্ৰ সৃষ্টি আৰু সম্পাদনা কৰিবলৈ ব্যৱহাৰ হয়।
    Q7. Which function is used for a logical test?
    যুক্তি পৰীক্ষাৰ বাবে কোন ফলন ব্যৱহাৰ হয়?
    (A) SUM SUM
    (B) COUNT COUNT
    (C) NOW NOW
    (D) IF IF
    Answer: IF
    IF
    Explanation: The IF function is used for a logical test and returns one value if true and another if false.
    IF ফাংচন তৰ্কমূলক পৰীক্ষাৰ বাবে ব্যৱহাৰ হয়; সত্য হ'লে এটা মান আৰু মিছা হ'লে আন এটা মান ঘূৰাই দিয়ে।
    Q8. Which feature adds a note at the bottom of the page?
    পৃষ্ঠাৰ তলত টোকা যোগ কৰা সুবিধা কোনটো?
    (A) Footnote ফুটনোট
    (B) Comment কমেণ্ট
    (C) Hyperlink হাইপাৰলিংক
    (D) Endnote ইণ্ডনোট
    Answer: Footnote
    ফুটনোট
    Explanation: A footnote adds a note at the bottom of the page.
    ফুটন'টে পৃষ্ঠাৰ তলত এটা টীকা যোগ কৰে।
    Q9. Which shortcut is common to save a file in all MS Office applications?
    সকলো MS Office এপ্লিকেচনত ফাইল চেভ কৰিবলৈ সাধাৰণতে কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + P Ctrl + P
    (B) Ctrl + S Ctrl + S
    (C) Ctrl + X Ctrl + X
    (D) Ctrl + O Ctrl + O
    Answer: Ctrl + S
    Ctrl + S
    Explanation: Ctrl + S is the common shortcut to save a file in all MS Office applications.
    সকলো MS Office এপ্লিকেশ্যনত ফাইল সংৰক্ষণ কৰাৰ সাধাৰণ শৰ্টকাট হৈছে Ctrl + S।
    Q10. Which key ends a running slide show?
    চলি থকা স্লাইড শ্ব' কোন কিৰে শেষ কৰা হয়?
    (A) Tab Tab
    (B) Enter Enter
    (C) Esc Esc
    (D) Spacebar স্পেচবাৰ
    Answer: Esc
    Esc
    Explanation: The Esc key ends a running slide show in PowerPoint.
    PowerPoint ত চলি থকা স্লাইড শ্ব' বন্ধ কৰিবলৈ Esc কী ব্যৱহাৰ হয়।
    Q11. Which feature shows only the rows that meet a condition?
    কেৱল চৰ্ত পূৰণ কৰা শাৰী দেখুওৱা সুবিধা কোনটো?
    (A) Sort চৰ্ট
    (B) Format ফৰ্মেট
    (C) Merge মাৰ্জ
    (D) Filter ফিল্টাৰ
    Answer: Filter
    ফিল্টাৰ
    Explanation: Filter shows only the rows that meet a given condition.
    Filter য়ে কেৱল নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা শাৰীবোৰ দেখুৱায়।
    Q12. The ruler in MS Word is used for?
    MS Word-ৰ ৰুলাৰ কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Setting margins and indents মাৰ্জিন আৰু ইণ্ডেণ্ট নিৰ্ধাৰণ
    (B) Printing প্ৰিন্ট কৰা
    (C) Zooming জুম কৰা
    (D) Saving the file ফাইল চেভ কৰা
    Answer: Setting margins and indents
    মাৰ্জিন আৰু ইণ্ডেণ্ট নিৰ্ধাৰণ
    Explanation: The ruler in MS Word is used for setting margins and indents.
    MS Word ৰ ৰুলাৰ মাৰ্জিন আৰু ইণ্ডেণ্ট নিৰ্ধাৰণ কৰিবলৈ ব্যৱহাৰ হয়।
    Q13. Which feature records the changes made to a document?
    ডকুমেণ্টত কৰা পৰিৱৰ্তন ৰেকৰ্ড কৰা সুবিধা কোনটো?
    (A) Protect সুৰক্ষা
    (B) Word Count ৱৰ্ড কাউণ্ট
    (C) Track Changes ট্ৰেক চেঞ্জেছ
    (D) Compare তুলনা
    Answer: Track Changes
    ট্ৰেক চেঞ্জেছ
    Explanation: Track Changes records the changes made to a document so they can be reviewed.
    Track Changes য়ে নথিপত্ৰত কৰা পৰিবৰ্তন লিপিবদ্ধ কৰে, যাতে পৰ্যালোচনা কৰিব পাৰি।
    Q14. Which tab is used to add a new slide in PowerPoint?
    PowerPoint-ত নতুন স্লাইড যোগ কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Home Home
    (B) View View
    (C) Design ডিজাইন
    (D) Slide Show স্লাইড শ্ব'
    Answer: Home
    Home
    Explanation: The Home tab is used to add a new slide in PowerPoint.
    PowerPoint ত নতুন স্লাইড যোগ কৰিবলৈ Home টেব ব্যৱহাৰ কৰা হয়।
    Q15. The process of combining a main document with a data source is called?
    মূল ডকুমেণ্টৰ সৈতে ডেটা উৎস সংযুক্ত কৰা প্ৰক্ৰিয়াক কি বুলি কোৱা হয়?
    (A) Merge Cells মাৰ্জ চেল
    (B) Data Sort ডেটা চৰ্ট
    (C) Mail Merge মেইল মাৰ্জ
    (D) Filter ফিল্টাৰ
    Answer: Mail Merge
    মেইল মাৰ্জ
    Explanation: Mail Merge is the process of combining a main document with a data source to create personalised letters.
    Mail Merge হৈছে মূল নথিপত্ৰক এটা তথ্য উৎসৰ সৈতে সংযুক্ত কৰি ব্যক্তিগতকৃত পত্ৰ সৃষ্টি কৰাৰ প্ৰক্ৰিয়া।
    Q16. Which function returns only the current date?
    কেৱল বৰ্তমান তাৰিখ ঘূৰাই দিয়া ফলন কোনটো?
    (A) DATEVALUE DATEVALUE
    (B) TODAY() TODAY()
    (C) DAY DAY
    (D) NOW() NOW()
    Answer: TODAY()
    TODAY()
    Explanation: TODAY() returns only the current date.
    TODAY() য়ে কেৱল বৰ্তমান তাৰিখ ঘূৰাই দিয়ে।
    Q17. Which key is used to move to the next cell to the right?
    সোঁফালৰ পৰৱৰ্তী চেললৈ যাবলৈ কোন কি ব্যৱহাৰ হয়?
    (A) Enter Enter
    (B) Shift Shift
    (C) Esc Esc
    (D) Tab Tab
    Answer: Tab
    Tab
    Explanation: The Tab key is used to move to the next cell to the right in a spreadsheet.
    স্প্ৰেডশ্বীটত Tab কীয়ে সোঁফালৰ পৰৱৰ্তী চেললৈ যাবলৈ ব্যৱহাৰ হয়।
    Q18. Which of the following is a spreadsheet application?
    তলৰ কোনটো স্প্ৰেডশ্বীট এপ্লিকেচন?
    (A) MS Word MS Word
    (B) MS PowerPoint MS PowerPoint
    (C) MS Outlook MS Outlook
    (D) MS Excel MS Excel
    Answer: MS Excel
    MS Excel
    Explanation: MS Excel is a spreadsheet application used for calculations and data analysis.
    MS Excel এটা স্প্ৰেডশ্বীট এপ্লিকেশ্যন যি গণনা আৰু তথ্য বিশ্লেষণৰ বাবে ব্যৱহাৰ হয়।
    Q19. Which tab contains the Slide Show options?
    স্লাইড শ্ব' বিকল্প কোন টেবত আছে?
    (A) View View
    (B) Slide Show স্লাইড শ্ব'
    (C) Home Home
    (D) Insert Insert
    Answer: Slide Show
    স্লাইড শ্ব'
    Explanation: The Slide Show tab contains the slide show options in PowerPoint.
    PowerPoint ত Slide Show টেবত স্লাইড শ্ব'ৰ বিকল্প থাকে।
    Q20. Which function returns the current date and time?
    বৰ্তমান তাৰিখ আৰু সময় ঘূৰাই দিয়া ফলন কোনটো?
    (A) TIME() TIME()
    (B) TODAY() TODAY()
    (C) NOW() NOW()
    (D) DATE() DATE()
    Answer: NOW()
    NOW()
    Explanation: NOW() returns the current date and time.
    NOW() য়ে বৰ্তমান তাৰিখ আৰু সময় ঘূৰাই দিয়ে।
    Q21. Which function returns the smallest value?
    সৰ্বনিম্ন মান ঘূৰাই দিয়া ফলন কোনটো?
    (A) MAX MAX
    (B) MIN MIN
    (C) SMALL SMALL
    (D) AVERAGE AVERAGE
    Answer: MIN
    MIN
    Explanation: The MIN function returns the smallest value from a range of numbers.
    MIN ফাংচনে সংখ্যাৰ পৰিসৰৰ পৰা আটাইতকৈ সৰু মান ঘূৰাই দিয়ে।
    Q22. Which shortcut key is used to save a document?
    ডকুমেণ্ট চেভ কৰিবলৈ কোন চৰ্টকাট কি ব্যৱহাৰ হয়?
    (A) Ctrl + S Ctrl + S
    (B) Ctrl + O Ctrl + O
    (C) Ctrl + N Ctrl + N
    (D) Ctrl + P Ctrl + P
    Answer: Ctrl + S
    Ctrl + S
    Explanation: Ctrl + S is used to save a document.
    নথিপত্ৰ সংৰক্ষণ (save) কৰিবলৈ Ctrl + S ব্যৱহাৰ হয়।
    Q23. Which chart is best for showing parts of a whole?
    সম্পূৰ্ণৰ অংশ দেখুওৱাৰ বাবে কোন চাৰ্ট উত্তম?
    (A) Pie chart পাই চাৰ্ট
    (B) Scatter chart স্কেটাৰ চাৰ্ট
    (C) Area chart এৰিয়া চাৰ্ট
    (D) Line chart লাইন চাৰ্ট
    Answer: Pie chart
    পাই চাৰ্ট
    Explanation: A pie chart is best for showing parts of a whole.
    সম্পূৰ্ণৰ অংশ দেখুওৱাৰ বাবে পাই চাৰ্ট (Pie chart) আটাইতকৈ উপযুক্ত।
    Q24. Which shortcut starts a slide show from the beginning?
    আৰম্ভণিৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) F5 F5
    (B) F2 F2
    (C) F7 F7
    (D) F12 F12
    Answer: F5
    F5
    Explanation: F5 starts a slide show from the beginning in PowerPoint.
    PowerPoint ত F5 য়ে আৰম্ভণিৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰে।
    Q25. Which key deletes the character to the right of the cursor?
    কাৰ্ছৰৰ সোঁফালৰ আখৰ মচিবলৈ কোন কি ব্যৱহাৰ হয়?
    (A) Insert Insert
    (B) Escape Escape
    (C) Delete Delete
    (D) Backspace Backspace
    Answer: Delete
    Delete
    Explanation: The Delete key deletes the character to the right of the cursor.
    Delete কীয়ে কাৰ্ছৰৰ সোঁফালে থকা আখৰটো মচে।
