    MS Office Mock Test — Set 3

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which shortcut is used to duplicate a slide quickly?
    এটা স্লাইড দ্ৰুতভাৱে নকল কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + D Ctrl + D
    (B) Ctrl + C Ctrl + C
    (C) Ctrl + V Ctrl + V
    (D) Ctrl + M Ctrl + M
    Answer: Ctrl + D
    Ctrl + D
    Explanation: Ctrl + D is used to duplicate the selected slide quickly.
    বাছনি কৰা স্লাইড দ্ৰুতভাৱে নকল (duplicate) কৰিবলৈ Ctrl + D ব্যৱহাৰ হয়।
    Q2. Bullets and Numbering are found under which tab?
    বুলেট আৰু নাম্বাৰিং কোন টেবৰ অধীনত থাকে?
    (A) Home Home
    (B) Insert Insert
    (C) Layout Layout
    (D) Design Design
    Answer: Home
    Home
    Explanation: Bullets and Numbering options are found under the Home tab.
    Bullets আৰু Numbering বিকল্প Home টেবত পোৱা যায়।
    Q3. Which tab is used to insert headers and footers?
    হেডাৰ আৰু ফুটৰ সন্নিবিষ্ট কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Home Home
    (B) Layout Layout
    (C) Review Review
    (D) Insert Insert
    Answer: Insert
    Insert
    Explanation: The Insert tab is used to insert headers and footers.
    হেডাৰ আৰু ফুটাৰ যোগ কৰিবলৈ Insert টেব ব্যৱহাৰ হয়।
    Q4. Which function is used to join text strings?
    লিখনীৰ শৃংখলা সংযোগ কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) CONCATENATE CONCATENATE
    (B) SUM SUM
    (C) JOIN JOIN
    (D) MERGE MERGE
    Answer: CONCATENATE
    CONCATENATE
    Explanation: CONCATENATE function is used to join text strings together.
    CONCATENATE ফাংচনে একাধিক লিখা অংশ সংযোগ কৰিবলৈ ব্যৱহাৰ হয়।
    Q5. Which shortcut is used to select all content?
    সকলো সমল নিৰ্বাচন কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + A Ctrl + A
    (B) Ctrl + E Ctrl + E
    (C) Ctrl + Q Ctrl + Q
    (D) Ctrl + S Ctrl + S
    Answer: Ctrl + A
    Ctrl + A
    Explanation: Ctrl + A is used to select all content.
    সকলো সমল বাছনি কৰিবলৈ Ctrl + A ব্যৱহাৰ হয়।
    Q6. Which feature is used to arrange data in a particular order?
    ডেটা এটা নিৰ্দিষ্ট ক্ৰমত সজাবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Filter ফিল্টাৰ
    (B) Format ফৰ্মেট
    (C) Sort চৰ্ট
    (D) Find ফাইণ্ড
    Answer: Sort
    চৰ্ট
    Explanation: Sort feature is used to arrange data in a particular order.
    Sort সুবিধা ব্যৱহাৰ কৰি তথ্য নিৰ্দিষ্ট ক্ৰমত সজোৱা হয়।
    Q7. The Font group is found under which tab?
    ফণ্ট গ্ৰুপ কোন টেবৰ অধীনত থাকে?
    (A) Home Home
    (B) Review Review
    (C) Insert Insert
    (D) View View
    Answer: Home
    Home
    Explanation: The Font group is found under the Home tab.
    Font গ্ৰুপ Home টেবত পোৱা যায়।
    Q8. Which function returns the largest value?
    সৰ্বাধিক মান ঘূৰাই দিয়া ফলন কোনটো?
    (A) MAX MAX
    (B) MIN MIN
    (C) SUM SUM
    (D) LARGE LARGE
    Answer: MAX
    MAX
    Explanation: The MAX function returns the largest value from a range.
    MAX ফাংচনে এটা পৰিসৰৰ পৰা আটাইতকৈ ডাঙৰ মান ঘূৰাই দিয়ে।
    Q9. Which application is best for making a slide presentation?
    স্লাইড প্ৰেজেণ্টেচন বনোৱাৰ বাবে কোন এপ্লিকেচন উত্তম?
    (A) MS Excel MS Excel
    (B) MS PowerPoint MS PowerPoint
    (C) MS Access MS Access
    (D) MS Word MS Word
    Answer: MS PowerPoint
    MS PowerPoint
    Explanation: MS PowerPoint is best for making slide presentations.
    স্লাইড উপস্থাপন সাজিবলৈ MS PowerPoint আটাইতকৈ উপযুক্ত।
    Q10. The arrangement of placeholders on a slide is called?
    স্লাইডত placeholders ৰ বিন্যাসক কি বুলি কোৱা হয়?
    (A) Theme থীম
    (B) Slide Design স্লাইড ডিজাইন
    (C) Slide Master স্লাইড মাষ্টাৰ
    (D) Slide Layout স্লাইড লে'আউট
    Answer: Slide Layout
    স্লাইড লে'আউট
    Explanation: The arrangement of placeholders on a slide is called Slide Layout.
    স্লাইডত প্লে'ছহ'ল্ডাৰৰ বিন্যাসক Slide Layout বোলা হয়।
    Q11. Which application is used to send and receive emails?
    ইমেইল পঠোৱা আৰু গ্ৰহণ কৰিবলৈ কোন এপ্লিকেচন ব্যৱহাৰ হয়?
    (A) MS Outlook MS Outlook
    (B) MS Word MS Word
    (C) MS Excel MS Excel
    (D) MS Access MS Access
    Answer: MS Outlook
    MS Outlook
    Explanation: MS Outlook is used to send and receive emails.
    MS Outlook ইমেইল পঠিওৱা আৰু লোৱাৰ বাবে ব্যৱহাৰ হয়।
    Q12. The footer of a document appears at the?
    ডকুমেণ্টৰ ফুটৰ ক'ত দেখুৱা হয়?
    (A) Left side বাওঁফালে
    (B) Bottom of the page পৃষ্ঠাৰ তলত
    (C) Top of the page পৃষ্ঠাৰ ওপৰত
    (D) Center of the page পৃষ্ঠাৰ মাজত
    Answer: Bottom of the page
    পৃষ্ঠাৰ তলত
    Explanation: The footer of a document appears at the bottom of the page.
    নথিপত্ৰৰ ফুটাৰ পৃষ্ঠাৰ তলত দেখা যায়।
    Q13. In MS Excel, a file is known as a?
    MS Excel-ত এটা ফাইলক কি বুলি কোৱা হয়?
    (A) Database ডেটাবেছ
    (B) Document ডকুমেণ্ট
    (C) Workbook ৱৰ্কবুক
    (D) Presentation প্ৰেজেণ্টেচন
    Answer: Workbook
    ৱৰ্কবুক
    Explanation: In MS Excel, a file is known as a workbook.
    MS Excel ত এটা ফাইলক ৱৰ্কবুক বোলা হয়।
    Q14. Which application is used to create and manage databases?
    ডেটাবেছ সৃষ্টি আৰু পৰিচালনা কৰিবলৈ কোন এপ্লিকেচন ব্যৱহাৰ হয়?

    (B) MS Access MS Access
    (C) MS Word MS Word
    (D) MS Excel MS Excel
    Answer: MS Access
    MS Access
    Explanation: MS Access is used to create and manage databases.
    MS Access ডেটাবেছ সৃষ্টি আৰু পৰিচালনা কৰিবলৈ ব্যৱহাৰ হয়।
    Q15. Which symbol begins every formula in Excel?
    Excel-ত প্ৰতিটো ফৰ্মুলা কোন চিহ্নৰে আৰম্ভ হয়?
    (A) @ @
    (B) + +
    (C) - -
    (D) = =
    Answer: =
    =
    Explanation: Every formula in Excel begins with the = symbol.
    Excel ত প্ৰতিটো ফৰ্মুলা = চিহ্নৰ পৰা আৰম্ভ হয়।
    Q16. Ctrl + U is used for?
    Ctrl + U কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Uppercase আপাৰকেছ
    (B) Update আপডেট
    (C) Underline আণ্ডাৰলাইন
    (D) Undo আনডু
    Answer: Underline
    আণ্ডাৰলাইন
    Explanation: Ctrl + U is used to underline the selected text.
    বাছনি কৰা লিখাৰ তলত ৰেখা (underline) দিবলৈ Ctrl + U ব্যৱহাৰ হয়।
    Q17. Which shortcut is used to paste copied content?
    কপি কৰা সমল পেইষ্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    (B) Ctrl + V Ctrl + V
    (C) Ctrl + C Ctrl + C
    (D) Ctrl + X Ctrl + X

    Ctrl + V
    Explanation: Ctrl + V is used to paste copied content.

    Q18. The Word Count option is available under which tab?

    Q19. Which shortcut moves the cursor to the beginning of the document?
    কাৰ্ছৰক ডকুমেণ্টৰ আৰম্ভণিলৈ নিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    (B) Alt + Home Alt + Home
    (C) Ctrl + Home Ctrl + Home
    (D) Ctrl + End Ctrl + End
    Answer: Ctrl + Home
    Ctrl + Home
    Explanation: Ctrl + Home moves the cursor to the beginning of the document.
    Ctrl + Home য়ে কাৰ্ছৰক নথিপত্ৰৰ আৰম্ভণিলৈ লৈ যায়।
    Q20. Which shortcut is used to redo an action?
    এটা কাৰ্য পুনৰ কৰিবলৈ (redo) কোন চৰ্টকাট ব্যৱহাৰ হয়?

    (B) Ctrl + Y Ctrl + Y
    (C) Ctrl + R Ctrl + R
    (D) Ctrl + Z Ctrl + Z
    Answer: Ctrl + Y
    Ctrl + Y
    Explanation: Ctrl + Y is used to redo an action that was undone.
    বাতিল কৰা কাৰ্য পুনৰ কৰিবলৈ (redo) Ctrl + Y ব্যৱহাৰ হয়।
    Q21. Which shortcut starts a slide show from the current slide?
    বৰ্তমান স্লাইডৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Alt + F5 Alt + F5
    (B) F6 F6
    (C) Shift + F5 Shift + F5
    (D) Ctrl + F5 Ctrl + F5
    Answer: Shift + F5
    Shift + F5
    Explanation: Shift + F5 starts a slide show from the current slide.
    Shift + F5 য়ে বৰ্তমান স্লাইডৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰে।
    Q22. Ctrl + J is used for which alignment?
    Ctrl + J কোন এলাইনমেণ্টৰ বাবে ব্যৱহাৰ হয়?
    (A) Join জয়েন
    (B) Junk জাংক
    (C) Justify জাষ্টিফাই
    (D) Jump জাম্প
    Answer: Justify
    জাষ্টিফাই
    Explanation: Ctrl + J is used for Justify alignment, which aligns text evenly on both sides.
    Ctrl + J য়ে Justify alignment ৰ বাবে ব্যৱহাৰ হয়, যি লিখাক দুয়োফালে সমানভাৱে সজায়।
    Q23. The intersection of a row and a column is called?
    শাৰী আৰু স্তম্ভৰ ছেদবিন্দুক কি বুলি কোৱা হয়?
    (A) Box বক্স
    (B) Cell চেল
    (C) Range ৰেঞ্জ
    (D) Sheet শ্বীট
    Answer: Cell
    চেল
    Explanation: The intersection of a row and a column is called a cell.
    শাৰী আৰু স্তম্ভৰ সংযোগস্থলক চেল (cell) বোলা হয়।
    Q24. The cell reference that does not change when copied is called?
    কপি কৰিলে নসলনি হোৱা চেল ৰেফাৰেন্সক কি বুলি কোৱা হয়?
    (A) Circular reference বৃত্তাকাৰ ৰেফাৰেন্স
    (B) Relative reference আপেক্ষিক ৰেফাৰেন্স
    (C) Mixed reference মিশ্ৰ ৰেফাৰেন্স
    (D) Absolute reference পৰম ৰেফাৰেন্স
    Answer: Absolute reference
    পৰম ৰেফাৰেন্স
    Explanation: The cell reference that does not change when copied is called an absolute reference.
    কপি কৰিলে যি চেল ৰেফাৰেন্স সলনি নহয় তাক absolute reference বোলা হয়।
    Q25. Which shortcut is used for Find and Replace?
    ফাইণ্ড এণ্ড ৰিপ্লেইচ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + G Ctrl + G
    (B) Ctrl + R Ctrl + R
    (C) Ctrl + F Ctrl + F
    (D) Ctrl + H Ctrl + H
    Answer: Ctrl + H
    Ctrl + H
    Explanation: Ctrl + H is used for Find and Replace.
    Find and Replace ৰ বাবে Ctrl + H ব্যৱহাৰ হয়।
