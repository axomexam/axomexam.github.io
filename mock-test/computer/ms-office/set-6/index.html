    MS Office Mock Test — Set 6

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. What is the default file extension of a Microsoft Word document?
    Microsoft Word ডকুমেণ্টৰ ডিফল্ট ফাইল এক্সটেনশ্যন কি?
    (A) .docx .docx
    (B) .doc .doc
    (C) .txt .txt
    (D) .rtf .rtf
    Answer: .docx
    .docx
    Explanation: The default extension of a Word document is .docx.
    Word ডকুমেণ্টৰ ডিফল্ট এক্সটেনশ্যন হৈছে .docx।
    Q2. Which shortcut selects all the text in a Word document?
    Word ডকুমেণ্টৰ সকলো লিখনী বাছনি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + C Ctrl + C
    (B) Ctrl + A Ctrl + A
    (C) Ctrl + S Ctrl + S
    (D) Ctrl + P Ctrl + P
    Answer: Ctrl + A
    Ctrl + A
    Explanation: Ctrl + A selects all the text in a document.
    Ctrl + A য়ে ডকুমেণ্টৰ সকলো লিখনী বাছনি কৰে।
    Q3. Which feature is used to send the same letter to many people with different names and addresses?
    একে এখন পত্ৰ বহু লোকলৈ বেলেগ নাম আৰু ঠিকনাৰে পঠিয়াবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Word Count ৱৰ্ড কাউণ্ট
    (B) Format Painter ফৰ্মেট পেইণ্টাৰ
    (C) Mail Merge মেইল মাৰ্জ
    (D) Track Changes ট্ৰেক চেঞ্জেছ
    Answer: Mail Merge
    মেইল মাৰ্জ
    Explanation: Mail Merge combines a main document with a data source to create personalised letters.
    Mail Merge য়ে মূল ডকুমেণ্টক তথ্য উৎসৰ সৈতে সংযুক্ত কৰি ব্যক্তিগতকৃত পত্ৰ তৈয়াৰ কৰে।
    Q4. Which view shows a Word document exactly as it will appear when printed?
    Word ডকুমেণ্ট ছপা হোৱাৰ দৰে দেখুওৱা ভিউ কোনটো?
    (A) Web Layout ৱেব লে'আউট
    (B) Outline আউটলাইন
    (C) Draft ড্ৰাফ্ট
    (D) Print Layout প্ৰিন্ট লে'আউট
    Answer: Print Layout
    প্ৰিন্ট লে'আউট
    Explanation: Print Layout view shows the document as it will look when printed.
    Print Layout ভিউত নথিপত্ৰ ছপা হোৱাৰ দৰে দেখা যায়।
    Q5. What does Ctrl + E do in MS Word?
    MS Word-ত Ctrl + E য়ে কি কৰে?
    (A) Center align কেন্দ্ৰত সংযুক্ত কৰা
    (B) Bold বোল্ড কৰা
    (C) Find বিচৰা
    (D) Print প্ৰিন্ট কৰা
    Answer: Center align
    কেন্দ্ৰত সংযুক্ত কৰা
    Explanation: Ctrl + E is used to centre-align the selected text.
    Ctrl + E য়ে বাছনি কৰা লিখনীক কেন্দ্ৰত সংযুক্ত কৰে।
    Q6. What is the default file extension of an Excel workbook?
    Excel ৱৰ্কবুকৰ ডিফল্ট ফাইল এক্সটেনশ্যন কি?
    (A) .accdb .accdb
    (B) .xlsx .xlsx
    (C) .docx .docx
    (D) .pptx .pptx
    Answer: .xlsx
    .xlsx
    Explanation: The default extension of an Excel workbook is .xlsx.
    Excel ৱৰ্কবুকৰ ডিফল্ট এক্সটেনশ্যন হৈছে .xlsx।
    Q7. Which Excel function is used to add numbers?
    সংখ্যা যোগ কৰিবলৈ Excel-ৰ কোন ফলন ব্যৱহাৰ হয়?
    (A) COUNT COUNT
    (B) MAX MAX
    (C) SUM SUM
    (D) AVERAGE AVERAGE
    Answer: SUM
    SUM
    Explanation: The SUM function adds all the numbers in a range.
    SUM ফলনে এটা পৰিসৰৰ সকলো সংখ্যা যোগ কৰে।
    Q8. Which function returns only the current date?
    কেৱল বৰ্তমান তাৰিখ ঘূৰাই দিয়া ফলন কোনটো?
    (A) NOW() NOW()
    (B) DATE() DATE()
    (C) TIME() TIME()
    (D) TODAY() TODAY()
    Answer: TODAY()
    TODAY()
    Explanation: TODAY() returns only the current date.
    TODAY() য়ে কেৱল বৰ্তমান তাৰিখ ঘূৰাই দিয়ে।
    Q9. Which symbol is used to make an absolute cell reference?
    পূৰ্ণ (absolute) চেল ৰেফাৰেন্স বনাবলৈ কোন চিহ্ন ব্যৱহাৰ হয়?
    (A) $ $
    (B) % %
    (C) # #
    (D) & &
    Answer: $
    $
    Explanation: The $ symbol makes a cell reference absolute, as in $A$1.
    $ চিহ্নই চেল ৰেফাৰেন্স পূৰ্ণ কৰে, যেনে $A$1।
    Q10. Which key is used to edit the active cell in Excel?
    Excel-ত সক্ৰিয় চেল সম্পাদনা কৰিবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) F9 F9
    (B) F2 F2
    (C) F5 F5
    (D) F7 F7
    Answer: F2
    F2
    Explanation: F2 puts the active cell into edit mode.
    F2 য়ে সক্ৰিয় চেলক সম্পাদনা ম'ডত ৰাখে।
    Q11. Which chart is best for showing parts of a whole?
    সম্পূৰ্ণৰ অংশ দেখুওৱাৰ বাবে কোন চাৰ্ট উত্তম?
    (A) Scatter chart স্কেটাৰ চাৰ্ট
    (B) Column chart কলাম চাৰ্ট
    (C) Pie chart পাই চাৰ্ট
    (D) Line chart লাইন চাৰ্ট
    Answer: Pie chart
    পাই চাৰ্ট
    Explanation: A pie chart is best for showing parts of a whole.
    সম্পূৰ্ণৰ অংশ দেখুওৱাৰ বাবে পাই চাৰ্ট আটাইতকৈ উপযুক্ত।
    Q12. What does the #DIV/0! error mean in Excel?
    Excel-ত #DIV/0! ত্ৰুটিয়ে কি বুজায়?
    (A) Text too long লিখনী অতি দীঘল
    (B) Column too narrow স্তম্ভ বহল নহয়
    (C) Invalid name অবৈধ নাম
    (D) Division by zero শূন্যৰে ভাগ কৰা
    Answer: Division by zero
    শূন্যৰে ভাগ কৰা
    Explanation: The #DIV/0! error appears when a formula tries to divide by zero.
    #DIV/0! ত্ৰুটি তেতিয়া দেখুৱায় যেতিয়া এটা সূত্ৰই শূন্যৰে ভাগ কৰিবলৈ চেষ্টা কৰে।
    Q13. What is the default file extension of a PowerPoint presentation?
    PowerPoint প্ৰেজেণ্টেচনৰ ডিফল্ট ফাইল এক্সটেনশ্যন কি?
    (A) .pptx .pptx
    (B) .docx .docx
    (C) .xlsx .xlsx
    (D) .ppsx .ppsx
    Answer: .pptx
    .pptx
    Explanation: The default extension of a PowerPoint presentation is .pptx.
    PowerPoint প্ৰেজেণ্টেচনৰ ডিফল্ট এক্সটেনশ্যন হৈছে .pptx।
    Q14. What is the default slide orientation in PowerPoint?
    PowerPoint-ত স্লাইডৰ ডিফল্ট অভিমুখ কি?
    (A) Custom কাষ্টম
    (B) Landscape লেণ্ডস্কেপ
    (C) Portrait পৰ্ট্ৰেট
    (D) Square বৰ্গ
    Answer: Landscape
    লেণ্ডস্কেপ
    Explanation: The default slide orientation in PowerPoint is Landscape.
    PowerPoint-ত স্লাইডৰ ডিফল্ট অভিমুখ হৈছে Landscape।
    Q15. Which key starts a slide show from the beginning?
    আৰম্ভণিৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰিবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) F1 F1
    (B) F2 F2
    (C) F5 F5
    (D) Esc Esc
    Answer: F5
    F5
    Explanation: F5 starts a slide show from the beginning in PowerPoint.
    PowerPoint-ত F5 য়ে আৰম্ভণিৰ পৰা স্লাইড শ্ব' আৰম্ভ কৰে।
    Q16. Which feature is used to apply effects to text or objects on a slide?
    স্লাইডত লিখনী বা বস্তুত প্ৰভাৱ প্ৰয়োগ কৰিবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Transition ট্ৰানজিচন
    (B) Slide Master স্লাইড মাষ্টাৰ
    (C) Rehearse Timings ৰিহাৰ্ছ টাইমিংছ
    (D) Animation এনিমেচন
    Answer: Animation
    এনিমেচন
    Explanation: Animation applies effects to text or objects within a slide.
    Animation য়ে এটা স্লাইডৰ ভিতৰত লিখনী বা বস্তুত প্ৰভাৱ প্ৰয়োগ কৰে।
    Q17. What is the main purpose of the Slide Master?
    Slide Master ৰ মূল উদ্দেশ্য কি?
    (A) Apply a consistent design to all slides সকলো স্লাইডত একে ডিজাইন প্ৰয়োগ কৰা
    (B) Print the slides স্লাইডবোৰ প্ৰিন্ট কৰা
    (C) Delete the slides স্লাইডবোৰ মচা
    (D) Record narration ধ্বনি ৰেকৰ্ড কৰা
    Answer: Apply a consistent design to all slides
    সকলো স্লাইডত একে ডিজাইন প্ৰয়োগ কৰা
    Explanation: The Slide Master controls the design and layout of all slides in a presentation.
    Slide Master য়ে প্ৰেজেণ্টেচনৰ সকলো স্লাইডৰ ডিজাইন আৰু বিন্যাস নিয়ন্ত্ৰণ কৰে।
    Q18. What is the default file extension of an MS Access database?

    Q19. Which Access object is used to store data?
    তথ্য সংৰক্ষণ কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) Form ফৰ্ম
    (B) Report ৰিপৰ্ট
    (C) Table টেবুল
    (D) Query কুৱেৰী
    Answer: Table
    টেবুল
    Explanation: A table stores the actual data in an Access database.
    Access ডেটাবেছত টেবুলে প্ৰকৃত তথ্য সংৰক্ষণ কৰে।
    Q20. What is the purpose of a primary key in an Access table?
    Access টেবুলত প্ৰাইমেৰী কী ৰ উদ্দেশ্য কি?
    (A) Sort the records ৰেকৰ্ডবোৰ ক্ৰমবদ্ধ কৰা
    (B) Print the records ৰেকৰ্ডবোৰ প্ৰিন্ট কৰা
    (C) Delete duplicate records পুনৰাবৃত্ত ৰেকৰ্ড মচা
    (D) Uniquely identify each record প্ৰতিটো ৰেকৰ্ড অদ্বিতীয়ভাৱে চিনাক্ত কৰা
    Answer: Uniquely identify each record
    প্ৰতিটো ৰেকৰ্ড অদ্বিতীয়ভাৱে চিনাক্ত কৰা
    Explanation: A primary key uniquely identifies each record in a table.
    প্ৰাইমেৰী কী য়ে টেবুলৰ প্ৰতিটো ৰেকৰ্ড অদ্বিতীয়ভাৱে চিনাক্ত কৰে।
    Q21. MS Outlook is mainly used for?
    MS Outlook মূলতঃ কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Sending and receiving emails ইমেইল পঠিওৱা আৰু লোৱা
    (B) Making spreadsheets স্প্ৰেডশ্বীট তৈয়াৰ কৰা
    (C) Editing photos ফটো সম্পাদনা কৰা
    (D) Designing slides স্লাইড ডিজাইন কৰা
    Answer: Sending and receiving emails
    ইমেইল পঠিওৱা আৰু লোৱা
    Explanation: MS Outlook is mainly an email client used to send and receive emails.
    MS Outlook মূলতঃ এটা ইমেইল ক্লায়েণ্ট, যি ইমেইল পঠিওৱা আৰু ল'বলৈ ব্যৱহাৰ হয়।

    Q23. Which shortcut is used to save a file in MS Office?
    MS Office-ত ফাইল চেভ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    (C) Ctrl + S Ctrl + S
    (D) Ctrl + P Ctrl + P

    Ctrl + S
    Explanation: Ctrl + S is the common shortcut to save a file in MS Office.
    MS Office-ত ফাইল চেভ কৰাৰ সাধাৰণ চৰ্টকাট হৈছে Ctrl + S।
    Q24. What is opened when you click the File tab in MS Office?
    MS Office-ত File টেবত ক্লিক কৰিলে কি খোলে?
    (A) Home tab Home টেব
    (B) Developer tab Developer টেব
    (C) Quick Access Toolbar কুইক এক্সেছ টুলবাৰ
    (D) Backstage view বেকষ্টেজ ভিউ
    Answer: Backstage view
    বেকষ্টেজ ভিউ
    Explanation: Clicking the File tab opens the Backstage view.
    File টেবত ক্লিক কৰিলে Backstage view খোলে।
    Q25. Which MS Office application is used for presentations?
    কোন MS Office এপ্লিকেচন প্ৰেজেণ্টেচনৰ বাবে ব্যৱহাৰ হয়?
    (A) PowerPoint PowerPoint
    (B) Word Word
    (C) Excel Excel
    (D) Access Access
    Answer: PowerPoint
    PowerPoint
    Explanation: PowerPoint is the MS Office application used for presentations.
    PowerPoint হৈছে প্ৰেজেণ্টেচনৰ বাবে ব্যৱহৃত MS Office এপ্লিকেচন।
