    MS Office Mock Test — Set 7

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which shortcut is used to print a document in MS Word?
    MS Word-ত নথিপত্ৰ প্ৰিন্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + P Ctrl + P
    (B) Ctrl + S Ctrl + S
    (C) Ctrl + O Ctrl + O
    (D) Ctrl + N Ctrl + N
    Answer: Ctrl + P
    Ctrl + P
    Explanation: Ctrl + P opens the print options in MS Word.
    Ctrl + P য়ে MS Word-ত প্ৰিন্টৰ বিকল্প খোলে।
    Q2. Which key is used to check spelling and grammar in MS Word?
    MS Word-ত বানান আৰু ব্যাকৰণ পৰীক্ষা কৰিবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) F9 F9
    (B) F7 F7
    (C) F1 F1
    (D) F5 F5
    Answer: F7
    F7
    Explanation: F7 starts the spelling and grammar check in MS Word.
    F7 য়ে MS Word-ত বানান আৰু ব্যাকৰণ পৰীক্ষা আৰম্ভ কৰে।
    Q3. Where does a header appear in a Word document?
    Word ডকুমেণ্টত হেডাৰ ক'ত দেখা যায়?
    (A) In the middle of the page পৃষ্ঠাৰ মাজত
    (B) Only on the last page কেৱল শেষ পৃষ্ঠাত
    (C) At the top of the page পৃষ্ঠাৰ ওপৰত
    (D) At the bottom of the page পৃষ্ঠাৰ তলত
    Answer: At the top of the page
    পৃষ্ঠাৰ ওপৰত
    Explanation: A header appears at the top of every page.
    হেডাৰ প্ৰতিটো পৃষ্ঠাৰ ওপৰত দেখা যায়।
    Q4. What is the Track Changes feature used for in Word?
    Word-ত Track Changes সুবিধা কিৰ বাবে ব্যৱহাৰ হয়?
    (A) To print the document নথিপত্ৰ প্ৰিন্ট কৰা
    (B) To count the words শব্দ গণনা কৰা
    (C) To change the font ফণ্ট সলনি কৰা
    (D) To record edits made to a document নথিপত্ৰত কৰা পৰিৱৰ্তন লিপিবদ্ধ কৰা
    Answer: To record edits made to a document
    নথিপত্ৰত কৰা পৰিৱৰ্তন লিপিবদ্ধ কৰা
    Explanation: Track Changes records all edits so that they can be reviewed.
    Track Changes য়ে সকলো পৰিৱৰ্তন লিপিবদ্ধ কৰে, যাতে পৰ্যালোচনা কৰিব পাৰি।
    Q5. What is the file extension of a Word template?
    Word টেমপ্লেট ফাইলৰ এক্সটেনশ্যন কি?
    (A) .dotx .dotx
    (B) .docx .docx
    (C) .docm .docm
    (D) .pdf .pdf
    Answer: .dotx
    .dotx
    Explanation: A Word template uses the .dotx extension.
    Word টেমপ্লেটে .dotx এক্সটেনশ্যন ব্যৱহাৰ কৰে।
    Q6. Which function is used to find the average of numbers in Excel?
    Excel-ত সংখ্যাৰ গড় নিৰ্ণয় কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) MAX MAX
    (B) AVERAGE AVERAGE
    (C) SUM SUM
    (D) COUNT COUNT
    Answer: AVERAGE
    AVERAGE
    Explanation: The AVERAGE function returns the arithmetic mean of a range.
    AVERAGE ফলনে এটা পৰিসৰৰ গাণিতিক গড় ঘূৰাই দিয়ে।
    Q7. Which shortcut is used for AutoSum in Excel?
    Excel-ত AutoSum ৰ বাবে কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Alt + S Alt + S
    (B) Ctrl + S Ctrl + S
    (C) Alt + = Alt + =
    (D) Ctrl + = Ctrl + =
    Answer: Alt + =
    Alt + =
    Explanation: Alt + = inserts the AutoSum formula in Excel.
    Excel-ত Alt + = য়ে AutoSum সূত্ৰ সন্নিবেশ কৰে।
    Q8. Which function counts the cells that meet a condition?
    চৰ্ত পূৰণ কৰা চেলৰ সংখ্যা গণনা কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) COUNT COUNT
    (B) SUMIF SUMIF
    (C) IF IF
    (D) COUNTIF COUNTIF
    Answer: COUNTIF
    COUNTIF
    Explanation: COUNTIF counts cells that satisfy a given condition.
    COUNTIF য়ে নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা চেলবোৰ গণনা কৰে।
    Q9. What is the purpose of Freeze Panes in Excel?
    Excel-ত Freeze Panes ৰ উদ্দেশ্য কি?
    (A) Keep rows or columns visible while scrolling স্ক্ৰল কৰাৰ সময়তো শাৰী বা স্তম্ভ দেখা ৰখা
    (B) Hide the selected rows বাছনি কৰা শাৰীবোৰ লুকুৱা
    (C) Delete empty rows খালী শাৰীবোৰ মচা
    (D) Change the chart type চাৰ্টৰ প্ৰকাৰ সলনি কৰা
    Answer: Keep rows or columns visible while scrolling
    স্ক্ৰল কৰাৰ সময়তো শাৰী বা স্তম্ভ দেখা ৰখা
    Explanation: Freeze Panes keeps selected rows or columns visible while scrolling.
    Freeze Panes য়ে স্ক্ৰল কৰাৰ সময়তো বাছনি কৰা শাৰী বা স্তম্ভ দেখা ৰাখে।
    Q10. Which function returns the number of characters in a text string?
    এটা লিখনীৰ আখৰৰ সংখ্যা ঘূৰাই দিয়া ফলন কোনটো?
    (A) TRIM TRIM
    (B) LEN LEN
    (C) LEFT LEFT
    (D) MID MID
    Answer: LEN
    LEN
    Explanation: The LEN function returns the number of characters in a text string.
    LEN ফলনে এটা লিখনীৰ আখৰৰ সংখ্যা ঘূৰাই দিয়ে।
    Q11. What is the Filter feature used for in Excel?
    Excel-ত Filter সুবিধা কিৰ বাবে ব্যৱহাৰ হয়?
    (A) To merge the cells চেলবোৰ মাৰ্জ কৰা
    (B) To change the font colour ফণ্টৰ ৰং সলনি কৰা
    (C) To show only rows that meet a condition কেৱল চৰ্ত পূৰণ কৰা শাৰী দেখুওৱা
    (D) To sort the data alphabetically তথ্য বৰ্ণানুক্ৰমে সজোৱা
    Answer: To show only rows that meet a condition
    কেৱল চৰ্ত পূৰণ কৰা শাৰী দেখুওৱা
    Explanation: Filter displays only the rows that meet a specified condition.
    Filter য়ে কেৱল নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা শাৰীবোৰ দেখুৱায়।
    Q12. Which tab is used to insert a PivotTable in Excel?
    Excel-ত PivotTable সন্নিবেশ কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Home Home
    (B) View View
    (C) Formulas Formulas
    (D) Insert Insert
    Answer: Insert
    Insert
    Explanation: A PivotTable is inserted from the Insert tab in Excel.
    Excel-ত PivotTable Insert টেবৰপৰা সন্নিবেশ কৰা হয়।
    Q13. Which shortcut adds a new slide in PowerPoint?
    PowerPoint-ত নতুন স্লাইড যোগ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + M Ctrl + M
    (B) Ctrl + N Ctrl + N
    (C) Ctrl + S Ctrl + S
    (D) Ctrl + P Ctrl + P
    Answer: Ctrl + M
    Ctrl + M
    Explanation: Ctrl + M adds a new slide in PowerPoint.
    PowerPoint-ত Ctrl + M য়ে নতুন স্লাইড যোগ কৰে।
    Q14. Which key ends a running slide show?
    চলি থকা স্লাইড শ্ব' শেষ কৰিবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) Spacebar স্পেচবাৰ
    (B) Esc Esc
    (C) Enter Enter
    (D) Tab Tab
    Answer: Esc
    Esc
    Explanation: The Esc key ends a running slide show in PowerPoint.
    PowerPoint-ত চলি থকা স্লাইড শ্ব' শেষ কৰিবলৈ Esc কী ব্যৱহাৰ হয়।
    Q15. A transition is applied between?
    Transition কিমানৰ মাজত প্ৰয়োগ কৰা হয়?
    (A) Two fonts দুটা ফণ্টৰ মাজত
    (B) Two tabs দুটা টেবৰ মাজত
    (C) Two slides দুটা স্লাইডৰ মাজত
    (D) Two objects on a slide স্লাইডৰ দুটা বস্তুৰ মাজত
    Answer: Two slides
    দুটা স্লাইডৰ মাজত
    Explanation: A transition is the effect that occurs between two slides.
    Transition হৈছে দুটা স্লাইডৰ মাজত ঘটা প্ৰভাৱ।
    Q16. Which view arranges the slides as thumbnails?
    স্লাইডবোৰ সৰু থাম্বনেইল হিচাপে দেখুওৱা ভিউ কোনটো?
    (A) Normal view Normal ভিউ
    (B) Reading view Reading ভিউ
    (C) Outline view Outline ভিউ
    (D) Slide Sorter view Slide Sorter ভিউ
    Answer: Slide Sorter view
    Slide Sorter ভিউ
    Explanation: Slide Sorter view shows all slides as thumbnails so they can be rearranged.
    Slide Sorter ভিউত সকলো স্লাইড থাম্বনেইল হিচাপে দেখা যায়, যাতে সজাই পৰিবৰ্তন কৰিব পাৰি।
    Q17. Which PowerPoint file opens directly as a slide show?
    পোনপটীয়াকৈ স্লাইড শ্ব' হিচাপে খোলা PowerPoint ফাইল কোনটো?
    (A) .ppsx .ppsx
    (B) .pptx .pptx
    (C) .potx .potx
    (D) .docx .docx
    Answer: .ppsx
    .ppsx
    Explanation: A .ppsx file opens directly in slide show mode.
    .ppsx ফাইল পোনপটীয়াকৈ স্লাইড শ্ব' ম'ডত খোলে।
    Q18. Which Access object provides an easy screen for entering data?
    তথ্য প্ৰৱেশ কৰিবলৈ সহজ স্ক্ৰীন প্ৰদান কৰা Access বস্তু কোনটো?
    (A) Macro মেক্ৰ'
    (B) Form ফৰ্ম
    (C) Table টেবুল
    (D) Report ৰিপৰ্ট
    Answer: Form
    ফৰ্ম
    Explanation: A form provides a user-friendly screen for entering and editing data.
    ফৰ্মে তথ্য প্ৰৱেশ আৰু সম্পাদনাৰ বাবে ব্যৱহাৰকাৰী-বান্ধৱ স্ক্ৰীন প্ৰদান কৰে।
    Q19. Which Access object is used to produce printable output?
    ছপা কৰিব পৰা আউটপুট তৈয়াৰ কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) Query কুৱেৰী
    (B) Table টেবুল
    (C) Report ৰিপৰ্ট
    (D) Form ফৰ্ম
    Answer: Report
    ৰিপৰ্ট
    Explanation: A report is used to present data in a printable format.
    ৰিপৰ্টে তথ্য ছপা কৰিব পৰা ৰূপত উপস্থাপন কৰে।
    Q20. Which Access object is used to retrieve or filter data?
    তথ্য উদ্ধাৰ বা ফিল্টাৰ কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) Table টেবুল
    (B) Form ফৰ্ম
    (C) Report ৰিপৰ্ট
    (D) Query কুৱেৰী
    Answer: Query
    কুৱেৰী
    Explanation: A query is used to retrieve, filter and sort data from tables.
    কুৱেৰীয়ে টেবুলৰপৰা তথ্য উদ্ধাৰ, ফিল্টাৰ আৰু সজোৱাৰ বাবে ব্যৱহাৰ হয়।
    Q21. Which Outlook folder contains received emails?
    Outlook-ত লোৱা ইমেইলবোৰ কোন ফোল্ডাৰত থাকে?
    (A) Inbox ইনবক্স
    (B) Sent Items প্ৰেৰিত আইটেম
    (C) Drafts ড্ৰাফ্ট
    (D) Outbox আউটবক্স

    ইনবক্স
    Explanation: Received emails are stored in the Inbox.
    লোৱা ইমেইলবোৰ Inbox ত সংৰক্ষিত থাকে।

    Outlook-ত প্ৰাপ্ত ইমেইলৰ উত্তৰ দিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    MS Office-ত শেষ কাৰ্য বাতিল কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    Q24. What does the ribbon in MS Office contain?

    (A) Only fonts কেৱল ফণ্ট
    (B) Saved files সংৰক্ষিত ফাইল
    (C) Email messages ইমেইল বাৰ্তা

    Q25. Which MS Office application is a spreadsheet program?

    Excel
    Explanation: Excel is the spreadsheet program in MS Office.
    Excel হৈছে MS Office ৰ স্প্ৰেডশ্বীট প্ৰগ্ৰাম।
