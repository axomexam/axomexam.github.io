    MS Office Mock Test — Set 4

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which view shows how the document will look when printed?
    প্ৰিন্ট কৰাৰ পিছত ডকুমেণ্ট কেনে দেখা যাব, তাক কোন ভিউৱে দেখুৱায়?
    (A) Outline আউটলাইন
    (B) Web Layout ৱেব লে'আউট
    (C) Read Mode ৰিড ম'ড
    (D) Print Layout প্ৰিন্ট লে'আউট
    Answer: Print Layout
    প্ৰিন্ট লে'আউট
    Explanation: Print Layout view shows the document exactly as it will appear when printed.
    Print Layout দৃশ্যই নথিপত্ৰখন কাগজত ছপা হ'লে যেনেকৈ দেখা যাব, তেনেকৈ দেখুৱায়।
    Q2. Which tool copies formatting from one part of text to another?
    এটা লিখনীৰ পৰা আন এটালৈ ফৰ্মেটিং কপি কৰা সঁজুলি কোনটো?
    (A) Clipboard ক্লিপবৰ্ড
    (B) Painter পেইণ্টাৰ
    (C) Copy Style কপি ষ্টাইল
    (D) Format Painter ফৰ্মেট পেইণ্টাৰ
    Answer: Format Painter
    ফৰ্মেট পেইণ্টাৰ
    Explanation: Format Painter copies formatting from one part of text to another.
    Format Painter য়ে এটা ঠাইৰ লিখনিৰ পৰা আন ঠাইলৈ ফৰ্মেটিং কপি কৰে।
    Q3. Which shortcut is used to remove all formatting from selected text?
    নিৰ্বাচিত লিখনীৰ পৰা সকলো ফৰ্মেটিং আঁতৰাবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + R Ctrl + R
    (B) Ctrl + Shift + N Ctrl + Shift + N
    (C) Ctrl + Space Ctrl + Space
    (D) Ctrl + Del Ctrl + Del
    Answer: Ctrl + Space
    Ctrl + Space
    Explanation: Ctrl + Space removes all character formatting from the selected text.
    Ctrl + Space য়ে নিৰ্বাচিত লিখনিৰ পৰা সকলো কেৰেক্টাৰ ফৰ্মেটিং আঁতৰায়।
    Q4. Which feature is used to check spelling and grammar?
    বানান আৰু ব্যাকৰণ পৰীক্ষা কৰিবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Translate অনুবাদ
    (B) Spelling & Grammar স্পেলিং এণ্ড গ্ৰেমাৰ
    (C) Thesaurus থেছ'ৰাছ
    (D) Word Count ৱৰ্ড কাউণ্ট
    Answer: Spelling & Grammar
    স্পেলিং এণ্ড গ্ৰেমাৰ
    Explanation: The Spelling & Grammar feature checks spelling and grammar mistakes.
    Spelling & Grammar সুবিধাই বানান আৰু ব্যাকৰণৰ ভুল পৰীক্ষা কৰে।
    Q5. Which shortcut is used to insert a comment?
    কমেণ্ট সন্নিবিষ্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + Alt + M Ctrl + Alt + M
    (B) Ctrl + Alt + C Ctrl + Alt + C
    (C) Ctrl + M Ctrl + M
    (D) Alt + M Alt + M
    Answer: Ctrl + Alt + M
    Ctrl + Alt + M
    Explanation: Ctrl + Alt + M inserts a comment in MS Word.
    Ctrl + Alt + M য়ে MS Word ত এটা মন্তব্য (comment) সন্নিবিষ্ট কৰে।
    Q6. Which key opens the Help window in MS Office?
    MS Office-ত Help উইণ্ড' খুলিবলৈ কোন কি ব্যৱহাৰ হয়?
    (A) F2 F2
    (B) F5 F5
    (C) F1 F1
    (D) F10 F10
    Answer: F1
    F1
    Explanation: F1 opens the Help window in MS Office.
    F1 য়ে MS Office ত Help উইণ্ড' খোলে।
    Q7. Which feature is used to create a standard document from a ready-made design?
    সাজু ডিজাইনৰ পৰা মানক ডকুমেণ্ট সৃষ্টি কৰিবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Theme থীম
    (B) Style ষ্টাইল
    (C) Format ফৰ্মেট
    (D) Template টেমপ্লেট
    Answer: Template
    টেমপ্লেট
    Explanation: A template is a ready-made design used to create a standard document.
    Template হৈছে এক ৰেডিমেড ডিজাইন, যাৰ দ্বাৰা আদৰ্শ নথিপত্ৰ সৃষ্টি কৰা হয়।
    Q8. Office Clipboard can store up to how many items?
    Office ক্লিপবৰ্ডে সৰ্বাধিক কিমানটা বস্তু সংৰক্ষণ কৰিব পাৰে?
    (A) 24 24
    (B) 100 100
    (C) 10 10
    (D) 12 12
    Answer: 24
    24
    Explanation: The Office Clipboard can store up to 24 items.
    Office Clipboard য়ে সৰ্বাধিক ২৪ টা আইটেম সংৰক্ষণ কৰিব পাৰে।
    Q9. The Quick Access Toolbar is located at the?
    Quick Access Toolbar ক'ত অৱস্থিত?
    (A) Center মাজত
    (B) Bottom তলত
    (C) Top-left corner ওপৰ বাওঁ কোণত
    (D) Right side সোঁফালে
    Answer: Top-left corner
    ওপৰ বাওঁ কোণত
    Explanation: The Quick Access Toolbar is located at the top-left corner of the Office window.
    Quick Access Toolbar Office উইণ্ড'ৰ ওপৰ-বাওঁ কোণত অৱস্থিত।
    Q10. Mail Merge is used to?
    মেইল মাৰ্জ কিৰ বাবে ব্যৱহাৰ হয়?
    (A) Send the same letter to many people এটা চিঠি বহু লোকলৈ পঠোৱা
    (B) Insert images ছবি সন্নিবিষ্ট কৰা
    (C) Calculate totals যোগফল গণনা
    (D) Create charts চাৰ্ট সৃষ্টি
    Answer: Send the same letter to many people
    এটা চিঠি বহু লোকলৈ পঠোৱা
    Explanation: Mail Merge is used to send the same letter to many people.
    Mail Merge য়ে একেই এখন চিঠি বহু লোকলৈ পঠিয়াবলৈ ব্যৱহাৰ হয়।
    Q11. Which file extension represents a PowerPoint template?
    PowerPoint টেমপ্লেটৰ এক্সটেনচন কোনটো?
    (A) .potx .potx
    (B) .pptx .pptx
    (C) .ppsx .ppsx
    (D) .docx .docx
    Answer: .potx
    .potx
    Explanation: .potx is the file extension that represents a PowerPoint template.
    .potx হৈছে PowerPoint টেমপ্লেটৰ ফাইল এক্সটেনচন।
    Q12. Which feature automatically corrects common typing errors?
    সাধাৰণ টাইপিং ভুল স্বয়ংক্ৰিয়ভাৱে সংশোধন কৰা সুবিধা কোনটো?
    (A) AutoFormat অটোফৰ্মেট
    (B) AutoCorrect অটো কৰেক্ট
    (C) AutoText অটোটেক্সট
    (D) AutoSave অটোচেভ
    Answer: AutoCorrect
    অটো কৰেক্ট
    Explanation: AutoCorrect automatically corrects common typing errors.
    AutoCorrect য়ে সাধাৰণ টাইপিং ভুল স্বয়ংক্ৰিয়ভাৱে শুধৰায়।
    Q13. Which shortcut displays the Open dialog box?
    Open ডায়লগ বক্স দেখুওৱাবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    Q15. Who developed MS Word?
    MS Word কোনে সৃষ্টি কৰিছে?

    (B) CPU CPU

    Q17. Which feature is used to search for commands in newer MS Office versions?
    নতুন MS Office সংস্কৰণত আদেশ বিচাৰিবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Tell Me Tell Me
    (B) Cortana কৰ্টানা

    Tell Me
    Explanation: The Tell Me feature is used to search for commands in newer MS Office versions.
    Tell Me সুবিধাই নতুন MS Office সংস্কৰণত কমান্ড সন্ধান কৰিবলৈ ব্যৱহাৰ হয়।
    Q18. Which function counts the number of numeric cells?
    সংখ্যামূলক চেলৰ সংখ্যা গণনা কৰা ফলন কোনটো?

    (B) NUMBER NUMBER
    (C) COUNT COUNT
    (D) COUNTA COUNTA

    COUNT
    Explanation: The COUNT function counts the number of numeric cells.
    COUNT ফলনে সংখ্যামূলক কোষৰ সংখ্যা গণনা কৰে।

    MS Office-ত বৰ্তমান ভিউ বা ফিল্ড ৰিফ্ৰেশ কৰিবলৈ কোন কি ব্যৱহাৰ হয়?

    F5
    Explanation: F5 refreshes the current view or field in MS Office.

    Q20. Which function is used to add numbers in Excel?
    Excel-ত সংখ্যা যোগ কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?

    (B) SUM SUM

    খোলা Office উইণ্ড'বোৰৰ মাজত সলনি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    Alt + Tab
    Explanation: Alt + Tab switches between open Office windows.
    Alt + Tab য়ে খোলা Office উইণ্ড'সমূহৰ মাজত সলনি কৰে।
    Q22. Which feature is used to add speaker notes?
    বক্তাৰ টোকা যোগ কৰিবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Comment কমেণ্ট

    নোটছ পেইন
    Explanation: The Notes pane is used to add speaker notes.
    Notes pane ব্যৱহাৰ কৰি স্পীকাৰ নোট যোগ কৰা হয়।
    Q23. The effect that occurs when moving from one slide to another is called?
    এটা স্লাইডৰ পৰা আন এটালৈ যাওঁতে হোৱা প্ৰভাৱক কি বুলি কোৱা হয়?
    (A) Motion মোচন
    (B) Action একচন
    (C) Transition ট্ৰানজিচন
    (D) Animation এনিমেচন
    Answer: Transition
    ট্ৰানজিচন
    Explanation: A transition is the effect that occurs when moving from one slide to another.
    এটা স্লাইডৰ পৰা আন এটালৈ যাওঁতে হোৱা প্ৰভাৱক Transition বোলা হয়।
    Q24. A saved slide show that opens directly in show mode has the extension?
    পোনপটীয়াকৈ শ্ব' ম'ডত খোলা সংৰক্ষিত স্লাইড শ্ব'ৰ এক্সটেনচন কি?
    (A) .potx .potx
    (B) .ppt .ppt
    (C) .pptx .pptx
    (D) .ppsx .ppsx
    Answer: .ppsx
    .ppsx
    Explanation: .ppsx is a saved slide show that opens directly in show mode.
    .ppsx হৈছে এনে এটা সংৰক্ষিত স্লাইড শ্ব' যি পোনপটীয়াকৈ শ্ব' ম'ডত খোলেগৈ।

    MS Word-ত হাইপাৰলিংক সন্নিবিষ্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    (B) Ctrl + K Ctrl + K
    (C) Ctrl + L Ctrl + L
    (D) Ctrl + M Ctrl + M

    Ctrl + K
    Explanation: Ctrl + K is used to insert a hyperlink in MS Word.
    Ctrl + K য়ে MS Word ত হাইপাৰলিংক সন্নিবিষ্ট কৰে।
