    MS Office Mock Test — Set 2

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which pane shows thumbnails of all slides?
    সকলো স্লাইডৰ থাম্বনেইল দেখুওৱা পেইন কোনটো?
    (A) Status bar ষ্টেটাছ বাৰ
    (B) Notes pane নোটছ পেইন
    (C) Task pane টাস্ক পেইন
    (D) Slide pane স্লাইড পেইন
    Answer: Slide pane
    স্লাইড পেইন
    Explanation: The Slide pane shows thumbnails of all slides, allowing quick navigation and reordering.
    Slide পেনে সকলো স্লাইডৰ থাম্বনেইল দেখুৱায়, যাৰ দ্বাৰা দ্ৰুতভাৱে বিচৰণ আৰু পুনৰ্বিন্যাস কৰিব পাৰি।
    Q2. Which shortcut makes the selected text bold?
    নিৰ্বাচিত লিখনী বোল্ড কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + D Ctrl + D
    (B) Ctrl + B Ctrl + B
    (C) Ctrl + I Ctrl + I
    (D) Ctrl + U Ctrl + U
    Answer: Ctrl + B
    Ctrl + B
    Explanation: Ctrl + B makes the selected text bold.
    Ctrl + B য়ে বাছনি কৰা লিখাক বোল্ড (গাঢ়) কৰে।
    Q3. What is the default file extension of an MS Word document?
    MS Word ডকুমেণ্টৰ ডিফল্ট ফাইল এক্সটেনচন কি?
    (A) .xlsx .xlsx
    (B) .pptx .pptx
    (C) .docx .docx
    (D) .txt .txt
    Answer: .docx
    .docx
    Explanation: The default file extension of an MS Word document is .docx.
    MS Word নথিপত্ৰৰ ডিফ'ল্ট ফাইল এক্সটেনশ্যন হৈছে .docx।
    Q4. Which shortcut is used to create a new slide?
    নতুন স্লাইড সৃষ্টি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + S Ctrl + S
    (B) Ctrl + K Ctrl + K
    (C) Ctrl + N Ctrl + N
    (D) Ctrl + M Ctrl + M
    Answer: Ctrl + M
    Ctrl + M
    Explanation: Ctrl + M is used to create a new slide in PowerPoint.
    PowerPoint ত নতুন স্লাইড সৃষ্টি কৰিবলৈ Ctrl + M ব্যৱহাৰ হয়।
    Q5. In Excel, columns are labelled with?
    Excel-ত স্তম্ভবোৰ কিৰে লেবেল কৰা হয়?
    (A) Colors ৰং
    (B) Numbers সংখ্যা
    (C) Letters আখৰ
    (D) Symbols চিহ্ন
    Answer: Letters
    আখৰ
    Explanation: In Excel, columns are labelled with letters (A, B, C ...).
    Excel ত স্তম্ভবোৰ (columns) আখৰেৰে (A, B, C ...) লেবেল কৰা হয়।
    Q6. Which tab contains the Table option?
    টেবুল বিকল্প কোন টেবত আছে?
    (A) View View
    (B) Insert Insert
    (C) Design Design
    (D) Home Home
    Answer: Insert
    Insert
    Explanation: The Insert tab contains the Table option.
    Table বিকল্প Insert টেবত আছে।
    Q7. Which view allows editing of the overall design of all slides?
    সকলো স্লাইডৰ সামগ্ৰিক ডিজাইন সম্পাদনা কৰিবলৈ কোন ভিউৱে অনুমতি দিয়ে?
    (A) Normal নৰ্মাল
    (B) Reading ৰিডিং
    (C) Slide Sorter স্লাইড চৰ্টাৰ
    (D) Slide Master স্লাইড মাষ্টাৰ
    Answer: Slide Master
    স্লাইড মাষ্টাৰ
    Explanation: Slide Master view allows editing the overall design of all slides at once.
    Slide Master দৃশ্যই সকলো স্লাইডৰ সামগ্ৰিক ডিজাইন একেলগে সম্পাদনা কৰিবলৈ দিয়ে।
    Q8. The formula bar displays the contents of?
    ফৰ্মুলা বাৰে কিৰ সমল দেখুৱায়?
    (A) The active cell সক্ৰিয় চেল
    (B) The toolbar টুলবাৰ
    (C) The status bar ষ্টেটাছ বাৰ
    (D) The whole sheet সমগ্ৰ শ্বীট
    Answer: The active cell
    সক্ৰিয় চেল
    Explanation: The formula bar displays the contents of the active cell.
    ফৰ্মুলা বাৰে সক্ৰিয় চেলৰ সমল দেখুৱায়।
    Q9. Which shortcut is used to cut the selected content?
    নিৰ্বাচিত সমল কাট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + V Ctrl + V
    (B) Ctrl + X Ctrl + X
    (C) Ctrl + Z Ctrl + Z
    (D) Ctrl + C Ctrl + C
    Answer: Ctrl + X
    Ctrl + X
    Explanation: Ctrl + X is used to cut the selected content.
    বাছনি কৰা সমল কাট কৰিবলৈ Ctrl + X ব্যৱহাৰ হয়।
    Q10. Which key advances to the next slide during a show?
    শ্ব' চলোঁতে পৰৱৰ্তী স্লাইডলৈ যাবলৈ কোন কি ব্যৱহাৰ হয়?
    (A) Backspace Backspace
    (B) Spacebar স্পেচবাৰ
    (C) Tab Tab
    (D) Esc Esc
    Answer: Spacebar
    স্পেচবাৰ
    Explanation: The Spacebar advances to the next slide during a slide show.
    স্লাইড শ্ব'ৰ সময়ত Spacebar য়ে পৰৱৰ্তী স্লাইডলৈ যায়।
    Q11. Which key combination is used to close the active window?
    সক্ৰিয় উইণ্ড' বন্ধ কৰিবলৈ কোন কি সংমিশ্ৰণ ব্যৱহাৰ হয়?
    (A) Ctrl + W Ctrl + W
    (B) Ctrl + F4 Ctrl + F4
    (C) Alt + F4 Alt + F4
    (D) Shift + F4 Shift + F4
    Answer: Alt + F4
    Alt + F4
    Explanation: Alt + F4 is used to close the active window.
    সক্ৰিয় উইণ্ড' বন্ধ কৰিবলৈ Alt + F4 ব্যৱহাৰ হয়।
    Q12. A saved collection of formatting settings with a name is called?
    নামসহ সংৰক্ষিত ফৰ্মেটিং ছেটিংছৰ সংগ্ৰহক কি বুলি কোৱা হয়?
    (A) Style ষ্টাইল
    (B) Macro মেক্ৰ'
    (C) Theme থীম
    (D) Template টেমপ্লেট
    Answer: Style
    ষ্টাইল
    Explanation: A style is a saved collection of formatting settings with a name.
    ষ্টাইল হৈছে এটা নামেৰে সংৰক্ষিত ফৰ্মেটিং ছেটিংছৰ সংগ্ৰহ।
    Q13. Which of the following is an MS Office application?
    তলৰ কোনটো MS Office এপ্লিকেচন?
    (A) Google Chrome গুগল ক্ৰ'ম
    (B) VLC Media Player VLC মিডিয়া প্লেয়াৰ
    (C) MS Excel MS Excel
    (D) Adobe Photoshop এড'বি ফট'শ্বপ
    Answer: MS Excel
    MS Excel
    Explanation: MS Excel is an MS Office application used for spreadsheets.
    MS Excel এটা MS Office এপ্লিকেশ্যন যি স্প্ৰেডশ্বীটৰ বাবে ব্যৱহাৰ হয়।
    Q14. Which of the following is a standard paper size in MS Word?

    Q16. Which shortcut moves the cursor to the end of the document?
    কাৰ্ছৰক ডকুমেণ্টৰ শেষলৈ নিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + End Ctrl + End
    (B) End End
    (C) Alt + End Alt + End
    (D) Ctrl + Home Ctrl + Home
    Answer: Ctrl + End
    Ctrl + End
    Explanation: Ctrl + End moves the cursor to the end of the document.
    Ctrl + End য়ে কাৰ্ছৰক নথিপত্ৰৰ শেষলৈ লৈ যায়।
    Q17. The status bar is generally located at the?
    ষ্টেটাছ বাৰ সাধাৰণতে ক'ত অৱস্থিত?
    (A) Left side বাওঁফালে

    লিখনী ইটালিক কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    Q19. Which feature adds movement to objects on a slide?
    স্লাইডৰ বস্তুত গতি যোগ কৰা সুবিধা কোনটো?
    (A) Transition ট্ৰানজিচন

    এনিমেচন
    Explanation: Animation adds movement to objects on a slide.
    এনিমেশ্যনে স্লাইডৰ বস্তুত গতি যোগ কৰে।
    Q20. What is the default file extension of a PowerPoint presentation?
    PowerPoint প্ৰেজেণ্টেচনৰ ডিফল্ট ফাইল এক্সটেনচন কি?

    Q21. The symbol $ in a cell reference indicates?
    চেল ৰেফাৰেন্সত $ চিহ্নে কি সূচাই?
    (A) Text লিখনী
    (B) Absolute reference পৰম ৰেফাৰেন্স
    (C) Relative reference আপেক্ষিক ৰেফাৰেন্স
    (D) Currency মুদ্ৰা
    Answer: Absolute reference
    পৰম ৰেফাৰেন্স
    Explanation: The $ symbol in a cell reference indicates an absolute reference.
    চেল ৰেফাৰেন্সত $ চিহ্নই পৰম (absolute) ৰেফাৰেন্স সূচায়।
    Q22. The ribbon in MS Office is organised into a set of?
    MS Office-ৰ ৰিবন কেতবোৰ কিৰ সংগ্ৰহত সজ্জিত?
    (A) Sections অংশ
    (B) Sheets শ্বীট
    (C) Tabs টেব
    (D) Pages পৃষ্ঠা
    Answer: Tabs
    টেব
    Explanation: The ribbon in MS Office is organised into a set of tabs.
    MS Office ৰ ৰিবন কেইবাটাও টেবত সংগঠিত।
    Q23. Which shortcut is used to print the active file?
    সক্ৰিয় ফাইল প্ৰিন্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?

    Q24. Which feature is used to arrange text in a newspaper-like layout?
    বাতৰি কাকতৰ দৰে বিন্যাসত লিখনী সজাবলৈ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) Columns কলাম
    (B) Borders বৰ্ডাৰ
    (C) Shading শ্বেডিং
    (D) Styles ষ্টাইল
    Answer: Columns
    কলাম
    Explanation: Columns feature is used to arrange text in a newspaper-like layout.
    Columns সুবিধা ব্যৱহাৰ কৰি সংবাদপত্ৰৰ দৰে বিন্যাসত লিখা সজোৱা হয়।
    Q25. In Excel, rows are labelled with?
    Excel-ত শাৰীবোৰ কিৰে লেবেল কৰা হয়?
    (A) Colors ৰং
    (B) Letters আখৰ
    (C) Symbols চিহ্ন
    (D) Numbers সংখ্যা
    Answer: Numbers
    সংখ্যা
    Explanation: In Excel, rows are labelled with numbers (1, 2, 3 ...).
    Excel ত শাৰীবোৰ (rows) সংখ্যাৰে (1, 2, 3 ...) লেবেল কৰা হয়।
