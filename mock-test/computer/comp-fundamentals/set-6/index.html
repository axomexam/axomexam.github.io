    Q1. The full form of BIOS is?
    BIOS-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) Basic Input Output System বেচিক ইনপুট আউটপুট চিষ্টেম

    (D) Basic Input Output Software বেচিক ইনপুট আউটপুট ছফটৱেৰ

    বেচিক ইনপুট আউটপুট চিষ্টেম
    Explanation: BIOS stands for Basic Input Output System. It starts the computer and checks the hardware during booting.
    BIOS ৰ সম্পূৰ্ণ ৰূপ Basic Input Output System। ই কম্পিউটাৰ আৰম্ভ কৰে আৰু বুটিং সময়ত হাৰ্ডৱেৰ পৰীক্ষা কৰে।
    Q2. Which part of the CPU performs arithmetic and logical operations?
    CPU-ৰ কোন অংশই গাণিতিক আৰু যুক্তিমূলক কাৰ্য সম্পাদন কৰে?

    (C) Memory Unit মেমেৰী ইউনিট
    (D) Register ৰেজিষ্টাৰ
    Answer: Arithmetic Logic Unit
    এৰিথমেটিক লজিক ইউনিট
    Explanation: The Arithmetic Logic Unit (ALU) performs all arithmetic and logical operations inside the CPU.
    ALU (Arithmetic Logic Unit) য়ে CPU ৰ ভিতৰত সকলো গাণিতিক আৰু যুক্তিমূলক কাৰ্য সম্পাদন কৰে।

    টাচ স্ক্ৰীনে স্পৰ্শৰে ইনপুট লয় আৰু আউটপুটও দেখুৱায়; সেয়ে ই দুয়োটা হিচাপে কাম কৰে।

    Q8. Which of the following is a non-volatile memory?

    ROM অপৰিৱৰ্তনশীল স্মৃতি; বিদ্যুৎ বন্ধ হ'লেও ইয়াৰ তথ্য থাকে।
