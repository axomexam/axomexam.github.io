    Q1. Cache memory is usually made of which type of memory?
    কেশ্ব স্মৃতি সাধাৰণতে কোন ধৰণৰ স্মৃতিৰে তৈয়াৰ কৰা হয়?
    (A) SRAM
    (B) DRAM
    (C) ROM
    (D) Hard disk হাৰ্ড ডিস্ক
    Answer: SRAM
    Explanation: Cache memory is usually built with SRAM because it is faster than DRAM.
    কেশ্ব স্মৃতি সাধাৰণতে SRAM ৰে তৈয়াৰ কৰা হয়, কাৰণ ই DRAM তকৈ দ্ৰুত।
    Q2. Which memory stores the BIOS and firmware?
    কোন স্মৃতিয়ে BIOS আৰু ফাৰ্মৱেৰ সংৰক্ষণ কৰে?
    (A) RAM
    (B) ROM
    (C) Cache কেশ্ব
    (D) Register ৰেজিষ্টাৰ
    Answer: ROM
    Explanation: ROM stores the BIOS and firmware, which are needed when the computer starts.
    ROM য়ে BIOS আৰু ফাৰ্মৱেৰ সংৰক্ষণ কৰে, যি কম্পিউটাৰ আৰম্ভ হ'বলৈ প্ৰয়োজন।
    Q3. Which of the following is a secondary storage device?

    (B) Cache কেশ্ব
    (C) DVD
    (D) Register ৰেজিষ্টাৰ

    Explanation: A DVD is secondary storage used to store data permanently for later use.
    DVD গৌণ সংৰক্ষণ, যি তথ্য পিছত ব্যৱহাৰৰ বাবে স্থায়ীভাৱে ৰাখে।
    Q4. 1 MB is equal to?
    ১ MB কিমানৰ সমান?
    (A) 1000 KB ১০০০ KB
    (B) 1024 KB ১০২৪ KB
    (C) 512 KB ৫১২ KB
    (D) 2048 KB ২০৪৮ KB
    Answer: 1024 KB
    ১০২৪ KB
    Explanation: 1 MB (megabyte) is equal to 1024 KB (kilobytes).
    ১ MB (মেগাবাইট) = ১০২৪ KB (কিলোবাইট)।
    Q5. The full form of ASCII is?
    ASCII-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) American National Standard Code আমেৰিকান নেশ্যনেল ষ্টেণ্ডাৰ্ড কোড
    (B) American Standard Code for Information Exchange আমেৰিকান ষ্টেণ্ডাৰ্ড কোড ফৰ ইনফৰ্মেশ্যন এক্সচেঞ্জ
    (C) American System Code for Information Interchange আমেৰিকান চিষ্টেম কোড ফৰ ইনফৰ্মেশ্যন ইন্টাৰচেঞ্জ
    (D) American Standard Code for Information Interchange আমেৰিকান ষ্টেণ্ডাৰ্ড কোড ফৰ ইনফৰ্মেশ্যন ইন্টাৰচেঞ্জ
    Answer: American Standard Code for Information Interchange
    আমেৰিকান ষ্টেণ্ডাৰ্ড কোড ফৰ ইনফৰ্মেশ্যন ইন্টাৰচেঞ্জ
    Explanation: ASCII stands for American Standard Code for Information Interchange, a character encoding standard.
    ASCII ৰ সম্পূৰ্ণ ৰূপ American Standard Code for Information Interchange; ই আখৰ এনকোডিংৰ মান।
    Q6. How many bits are there in a nibble?
    এটা নিবলত কিমান বিট থাকে?
    (A) 4 bits ৪ বিট
    (B) 8 bits ৮ বিট
    (C) 2 bits ২ বিট
    (D) 16 bits ১৬ বিট
    Answer: 4 bits
    ৪ বিট
    Explanation: A nibble contains 4 bits, while a byte contains 8 bits.
    এটা নিবলত ৪ বিট থাকে, আনহাতে এটা বাইটত ৮ বিট থাকে।

    (B) Plotter প্লটাৰ
    (C) Monitor মনিটৰ
    (D) Speaker স্পীকাৰ
    Answer: Plotter
    প্লটাৰ
    Explanation: A plotter is an output device used to print large drawings, maps and designs.
    প্লটাৰ এটা আউটপুট সঁজুলি, যি ডাঙৰ অংকন, মানচিত্ৰ আৰু ডিজাইন ছপাবলৈ ব্যৱহাৰ হয়।

    (A) Mouse মাউছ

    (D) Joystick জয়ষ্টিক
    Answer: Scanner
    স্কেনাৰ
    Explanation: A scanner converts printed documents and images into digital form.
    স্কেনাৰে ছপা নথিপত্ৰ আৰু ছবি ডিজিটেল ৰূপলৈ ৰূপান্তৰ কৰে।

    Python এটা উচ্চস্তৰীয় প্ৰগ্ৰামিং ভাষা, যি কম্পিউটাৰ প্ৰগ্ৰাম লিখিবলৈ ব্যৱহাৰ হয়।
    Q11. Which translator converts a program line by line?
    কোন অনুবাদকে প্ৰগ্ৰাম শাৰী শাৰীকৈ ৰূপান্তৰ কৰে?

    (B) Interpreter ইণ্টাৰপ্ৰেটাৰ
    (C) Assembler এচেম্বলাৰ

    Answer: Interpreter
    ইণ্টাৰপ্ৰেটাৰ
    Explanation: An interpreter translates and executes a program one line at a time.
    ইণ্টাৰপ্ৰেটাৰে প্ৰগ্ৰাম এটা এটা শাৰীকৈ অনুবাদ আৰু সম্পাদন কৰে।

    (A) Interpreter ইণ্টাৰপ্ৰেটাৰ
    (B) Assembler এচেম্বলাৰ
    (C) Compiler ক’ম্পাইলাৰ
    (D) Loader লোডাৰ
    Answer: Compiler
    ক’ম্পাইলাৰ
