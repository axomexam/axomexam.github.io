    (B) Is an input device এটা ইনপুট ডিভাইচ
    (C) Stores only ROM কেৱল ROM সংৰক্ষণ কৰে
    (D) Translates and executes code line by line ক’ড শাৰী শাৰীকৈ অনুবাদ আৰু চলায়
    Answer: Translates and executes code line by line
    ক’ড শাৰী শাৰীকৈ অনুবাদ আৰু চলায়
    Explanation: An interpreter translates and executes a program line by line.
    ইণ্টাৰপ্ৰিটাৰে প্ৰগ্ৰাম শাৰী শাৰী কৰি ৰূপান্তৰ কৰি চলায়।
