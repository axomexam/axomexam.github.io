    Answer: Print
    প্ৰিণ্ট
    Explanation: Ctrl + P is commonly used to print the current document or page.

    Q24. F1 key is commonly used for?
    F1 কি সাধাৰণতে কিৰ বাবে?
    (A) Refresh ৰিফ্ৰেছ
    (B) Rename ৰিনেম
    (C) Full screen ফুল স্ক্ৰীন
    (D) Help সহায়
    Answer: Help
    সহায়
    Explanation: The F1 key is commonly used to open help in most programs.
    F1 কীয়ে বেছিভাগ প্ৰগ্ৰামত সহায় (help) খুলিবলৈ ব্যৱহাৰ হয়।
    Q25. To refresh a Windows desktop or folder, a common shortcut is?
    Windows ডেস্কটপ বা ফ’ল্ডাৰ ৰিফ্ৰেছ কৰিবলৈ সাধাৰণ শ্বৰ্টকাট কি?
    (A) F2 F2
    (B) F1 F1
    (C) F12 F12
    (D) F5 F5
    Answer: F5
    F5
    Explanation: F5 is a common shortcut to refresh a Windows desktop, folder or web page.
    F5 Windows ডেস্কটপ, ফ'ল্ডাৰ বা ৱেবপৃষ্ঠা সতেজ (refresh) কৰাৰ সাধাৰণ শৰ্টকাট।
