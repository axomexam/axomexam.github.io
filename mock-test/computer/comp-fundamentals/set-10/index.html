    Fundamentals Mock Test — Set 10

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. Which is the smallest unit of data in a computer?
    কম্পিউটাৰত তথ্যৰ আটাইতকৈ সৰু একক কোনটো?
    (A) Byte বাইট
    (B) Bit বিট
    (C) Nibble নিবল
    (D) Kilobyte কিলোবাইট
    Answer: Bit
    বিট
    Explanation: A bit is the smallest unit of data and can have a value of either 0 or 1.
    বিট হৈছে তথ্যৰ আটাইতকৈ সৰু একক, যাৰ মান ০ বা ১ হ'ব পাৰে।
    Q2. 1 KB is equal to how many bytes?
    ১ KB কিমান বাইটৰ সমান?
    (A) 1000 bytes ১০০০ বাইট
    (B) 1024 bytes ১০২৪ বাইট
    (C) 512 bytes ৫১২ বাইট
    (D) 2048 bytes ২০৪৮ বাইট
    Answer: 1024 bytes
    ১০২৪ বাইট
    Explanation: 1 KB (kilobyte) is equal to 1024 bytes.
    ১ KB (কিলোবাইট) = ১০২৪ বাইট।
    Q3. Which of the following is the fastest type of memory?
    তলৰ কোনটো আটাইতকৈ দ্ৰুত স্মৃতি?
    (A) Hard disk হাৰ্ড ডিস্ক
    (B) RAM RAM
    (C) Register ৰেজিষ্টাৰ
    (D) Cache কেশ্ব
    Answer: Register
    ৰেজিষ্টাৰ
    Explanation: Registers are located inside the CPU and are the fastest type of memory.
    ৰেজিষ্টাৰ CPU-ৰ ভিতৰত থাকে আৰু আটাইতকৈ দ্ৰুত স্মৃতি।
    Q4. The full form of CPU is?
    CPU-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) Central Process Unit চেণ্ট্ৰেল প্ৰচেছ ইউনিট
    (B) Central Processing Unit চেণ্ট্ৰেল প্ৰচেছিং ইউনিট
    (C) Computer Processing Unit কম্পিউটাৰ প্ৰচেছিং ইউনিট
    (D) Central Program Unit চেণ্ট্ৰেল প্ৰগ্ৰাম ইউনিট
    Answer: Central Processing Unit
    চেণ্ট্ৰেল প্ৰচেছিং ইউনিট
    Explanation: CPU stands for Central Processing Unit, which executes instructions and processes data.
    CPU ৰ সম্পূৰ্ণ ৰূপ Central Processing Unit, যি নিৰ্দেশনা সম্পাদন আৰু তথ্য প্ৰক্ৰিয়া কৰে।
    Q5. The full form of RAM is?
    RAM-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) Rapid Access Memory ৰেপিড এক্সেছ মেম’ৰী
    (B) Read Access Memory ৰিড এক্সেছ মেম’ৰী
    (C) Random Access Memory ৰেনডম এক্সেছ মেম’ৰী
    (D) Random Available Memory ৰেনডম এভেইলেবল মেম’ৰী
    Answer: Random Access Memory
    ৰেনডম এক্সেছ মেম’ৰী
    Explanation: RAM stands for Random Access Memory, where data can be read and written randomly.
    RAM ৰ সম্পূৰ্ণ ৰূপ Random Access Memory, য'ত তথ্য যিকোনো ক্ৰমত পঢ়া আৰু লিখা যায়।
    Q6. BIOS settings are stored in which chip?
    BIOS ছেটিং কোন চিপত সংৰক্ষিত হয়?
    (A) CMOS CMOS
    (B) RAM RAM
    (C) ROM ROM
    (D) Cache কেশ্ব
    Answer: CMOS
    CMOS
    Explanation: BIOS settings are stored in the CMOS chip, which is backed up by a small battery.
    BIOS ছেটিং CMOS চিপত সংৰক্ষিত হয়, যি এটা সৰু বেটাৰীৰ দ্বাৰা সমৰ্থিত।
    Q7. Which device is used to produce a hard copy of a document?
    নথিৰ হাৰ্ড কপি তৈয়াৰ কৰিবলৈ কোন সঁজুলি ব্যৱহাৰ হয়?
    (A) Monitor মনিটৰ
    (B) Speaker স্পীকাৰ
    (C) Projector প্ৰজেক্টৰ
    (D) Printer প্ৰিণ্টাৰ
    Answer: Printer
    প্ৰিণ্টাৰ
    Explanation: A printer produces a hard copy of digital documents on paper.
    প্ৰিণ্টাৰে ডিজিটেল নথিৰ কাগজত হাৰ্ড কপি উৎপন্ন কৰে।
    Q8. The full form of WWW is?
    WWW-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) World Web Wide ৱৰ্ল্ড ৱেব ৱাইড
    (B) Wide World Web ৱাইড ৱৰ্ল্ড ৱেব
    (C) World Wide Web ৱৰ্ল্ড ৱাইড ৱেব
    (D) Web World Wide ৱেব ৱৰ্ল্ড ৱাইড
    Answer: World Wide Web
    ৱৰ্ল্ড ৱাইড ৱেব
    Explanation: WWW stands for World Wide Web, a system of linked documents on the internet.
    WWW ৰ সম্পূৰ্ণ ৰূপ World Wide Web; ই ইন্টাৰনেটত সংযুক্ত নথিৰ ব্যৱস্থা।
    Q9. The full form of HTTP is?
    HTTP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) HyperText Transfer Protocol হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল
    (B) HyperText Transmission Protocol হাইপাৰটেক্সট ট্ৰান্সমিশ্যন প্ৰ’ট’কল
    (C) High Transfer Text Protocol হাই ট্ৰান্সফাৰ টেক্সট প্ৰ’ট’কল
    (D) Hyper Transfer Text Protocol হাইপাৰ ট্ৰান্সফাৰ টেক্সট প্ৰ’ট’কল
    Answer: HyperText Transfer Protocol
    হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল
    Explanation: HTTP stands for HyperText Transfer Protocol, used to transfer web pages over the internet.
    HTTP ৰ সম্পূৰ্ণ ৰূপ HyperText Transfer Protocol, যি ইন্টাৰনেটত ৱেব পৃষ্ঠা প্ৰেৰণ কৰিবলৈ ব্যৱহৃত হয়।
    Q10. The full form of HTTPS is?
    HTTPS-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) HyperText Transfer Protocol System হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল চিষ্টেম
    (B) HyperText Transfer Protocol Server হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ছাৰ্ভাৰ
    (C) HyperText Transfer Protocol Standard হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ষ্টেণ্ডাৰ্ড
    (D) HyperText Transfer Protocol Secure হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ছিকিউৰ
    Answer: HyperText Transfer Protocol Secure
    হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ছিকিউৰ
    Explanation: HTTPS stands for HyperText Transfer Protocol Secure, which encrypts data between the browser and server.
    HTTPS ৰ সম্পূৰ্ণ ৰূপ HyperText Transfer Protocol Secure, যি ব্ৰাউজাৰ আৰু ছাৰ্ভাৰৰ মাজত তথ্য এনক্ৰিপ্ট কৰে।
    Q11. The full form of IP is?
    IP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) Internet Program ইণ্টাৰনেট প্ৰগ্ৰাম
    (B) Internet Protocol ইণ্টাৰনেট প্ৰ’ট’কল
    (C) Internal Protocol ইণ্টাৰনেল প্ৰ’ট’কল
    (D) Internet Provider ইণ্টাৰনেট প্ৰ’ভাইডাৰ
    Answer: Internet Protocol
    ইণ্টাৰনেট প্ৰ’ট’কল
    Explanation: IP stands for Internet Protocol, which identifies devices and routes data on a network.
    IP ৰ সম্পূৰ্ণ ৰূপ Internet Protocol, যি নেটৱৰ্কত সঁজুলি চিনাক্ত কৰে আৰু তথ্য পথ প্ৰদৰ্শন কৰে।
    Q12. The full form of WiFi is?
    WiFi-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) Wireless Finder ৱায়াৰলেছ ফাইণ্ডাৰ
    (B) Wire Fidelity ৱায়াৰ ফিডেলিটি
    (C) Wireless Fidelity ৱায়াৰলেছ ফিডেলিটি
    (D) Wide Fidelity ৱাইড ফিডেলিটি
    Answer: Wireless Fidelity
    ৱায়াৰলেছ ফিডেলিটি
    Explanation: WiFi stands for Wireless Fidelity, a technology used for wireless network connections.
    WiFi ৰ সম্পূৰ্ণ ৰূপ Wireless Fidelity, যি তাৰবিহীন নেটৱৰ্ক সংযোগৰ বাবে ব্যৱহৃত প্ৰযুক্তি।
    Q13. Which symbol is present in every email address?
    প্ৰতিটো ইমেইল ঠিকনাত কোন চিহ্ন থাকে?
    (A) @ @
    (B) # #
    (C) $ $
    (D) % %
    Answer: @
    @
    Explanation: Every email address contains the @ symbol, which separates the user name from the domain name.
    প্ৰতিটো ইমেইল ঠিকনাত @ চিহ্ন থাকে, যি ব্যৱহাৰকাৰী নাম আৰু ডমেইন নাম পৃথক কৰে।
    Q14. Which function key is used to refresh a web page?
    ৱেব পৃষ্ঠা ৰিফ্ৰেশ কৰিবলৈ কোন ফাংচন কী ব্যৱহাৰ হয়?
    (A) F1 F1
    (B) F2 F2
    (C) F3 F3
    (D) F5 F5
    Answer: F5
    F5
    Explanation: F5 is commonly used to refresh or reload a web page in most browsers.
    অধিকাংশ ব্ৰাউজাৰত ৱেব পৃষ্ঠা ৰিফ্ৰেশ বা পুনৰ লোড কৰিবলৈ F5 ব্যৱহাৰ হয়।
    Q15. Which function key is used to rename a selected file?
    বাছনি কৰা ফাইলৰ নাম সলনি কৰিবলৈ কোন ফাংচন কী ব্যৱহাৰ হয়?
    (A) F1 F1
    (B) F2 F2
    (C) F3 F3
    (D) F5 F5
    Answer: F2
    F2
    Explanation: Pressing F2 on a selected file allows you to rename it in Windows.
    Windows-ত বাছনি কৰা ফাইলত F2 টিপিলে ইয়াৰ নাম সলনি কৰিব পাৰি।
    Q16. Ctrl + Alt + Delete is commonly used to open?
    Ctrl + Alt + Delete সাধাৰণতে কি খুলিবলৈ ব্যৱহাৰ হয়?

    (B) Control Panel Control Panel
    (C) Task Manager Task Manager
    (D) My Computer My Computer
    Answer: Task Manager
    Task Manager
    Explanation: Ctrl + Alt + Delete opens the security screen from which Task Manager can be opened.
    Ctrl + Alt + Delete এ ছিকিউৰিটি স্ক্ৰীন খোলে, যাৰ পৰা Task Manager খুলিব পাৰি।
    Q17. Which key is used to cancel an operation?
    কোন কী ব্যৱহাৰ কৰি কোনো কাৰ্য বাতিল কৰা হয়?
    (A) Esc Esc
    (B) Enter Enter
    (C) Tab Tab
    (D) Shift Shift
    Answer: Esc
    Esc
    Explanation: The Esc (Escape) key is generally used to cancel or exit an operation.
    Esc (Escape) কী সাধাৰণতে কোনো কাৰ্য বাতিল বা ওলাই যাবলৈ ব্যৱহাৰ হয়।
    Q18. Which key moves the cursor to the end of a line?
    কোন কীএ কাৰ্চৰক শাৰীৰ শেষলৈ লৈ যায়?
    (A) Home Home
    (B) Insert Insert
    (C) End End
    (D) Page Up Page Up
    Answer: End
    End
    Explanation: The End key moves the cursor to the end of the current line.
    End কীএ কাৰ্চৰক বৰ্তমান শাৰীৰ শেষলৈ লৈ যায়।
    Q19. Which key deletes the character to the left of the cursor?
    কোন কীএ কাৰ্চৰৰ বাওঁফালৰ আখৰ মচি পেলায়?
    (A) Delete Delete
    (B) Backspace Backspace
    (C) Enter Enter
    (D) Tab Tab
    Answer: Backspace
    Backspace
    Explanation: The Backspace key deletes the character immediately to the left of the cursor.
    Backspace কীএ কাৰ্চৰৰ ঠিক বাওঁফালে থকা আখৰ মচি পেলায়।
    Q20. Which software is used to create presentations?
    উপস্থাপন তৈয়াৰ কৰিবলৈ কোন ছফ্টৱেৰ ব্যৱহাৰ হয়?

    Q21. Which software is mainly used for editing images?
    ছবি সম্পাদনা কৰিবলৈ মূলতঃ কোন ছফ্টৱেৰ ব্যৱহাৰ হয়?

    Q23. Which of the following is a markup language used to create web pages?
    ৱেব পৃষ্ঠা তৈয়াৰ কৰিবলৈ তলৰ কোনটো মাৰ্কআপ ভাষা ব্যৱহাৰ হয়?

    HTML

    Q24. Which language is used for styling web pages?

    CSS

    CSS (Cascading Style Sheets) ব্যৱহাৰ কৰি ৱেব পৃষ্ঠাৰ বিন্যাস আৰু ৰূপ নিয়ন্ত্ৰণ কৰা হয়।
    Q25. Which language is used to add interactivity to web pages?
