    (D) Internet of Things ইণ্টাৰনেট অৱ থিংছ
    Answer: Internet of Things
    ইণ্টাৰনেট অৱ থিংছ
    Explanation: IoT stands for Internet of Things, which means connecting everyday devices to the internet.
    IoT ৰ সম্পূৰ্ণ ৰূপ Internet of Things, অৰ্থাৎ দৈনন্দিন সঁজুলিক ইণ্টাৰনেটৰ সৈতে সংযোগ কৰা।
    Q25. Which of the following is an example of application software?
    তলৰ কোনটো এপ্লিকেচন ছফটৱেৰৰ উদাহৰণ?
    (A) Windows kernel only কেৱল Windows কাৰ্নেল
    (B) BIOS chip BIOS চিপ
    (C) ALU circuit ALU চাৰ্কিট
    (D) MS Word MS Word
    Answer: MS Word
    MS Word
    Explanation: MS Word is application software, used for creating and editing text documents.
    MS Word এপ্লিকেশ্যন চফটৱেৰ, যি লিখিত নথিপত্ৰ সৃষ্টি আৰু সম্পাদনা কৰিবলৈ ব্যৱহাৰ হয়।
