    Advanced Math Mock Test — Set 6

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. If x + 1/x = 4, then the value of x² + 1/x² is:
    যদি x + 1/x = 4 হয়, তেন্তে x² + 1/x² ৰ মান কি?
    (A) 14 14
    (B) 16 16
    (C) 12 12
    (D) 18 18
    Answer: 14
    14
    Explanation: x² + 1/x² = (x + 1/x)² − 2 = 4² − 2 = 14.
    x² + 1/x² = (x + 1/x)² − 2 = 4² − 2 = 14।
    Q2. If x − 1/x = 5, then the value of x² + 1/x² is:
    যদি x − 1/x = 5 হয়, তেন্তে x² + 1/x² ৰ মান কি?
    (A) 23 23
    (B) 25 25
    (C) 27 27
    (D) 29 29
    Answer: 27
    27
    Explanation: x² + 1/x² = (x − 1/x)² + 2 = 5² + 2 = 27.
    x² + 1/x² = (x − 1/x)² + 2 = 5² + 2 = 27।
    Q3. The factorization of x² + 5x + 6 is:
    x² + 5x + 6 ৰ উৎপাদক বিশ্লেষণ কি?
    (A) (x + 1)(x + 6) (x + 1)(x + 6)
    (B) (x + 2)(x + 3) (x + 2)(x + 3)
    (C) (x − 2)(x − 3) (x − 2)(x − 3)
    (D) (x + 5)(x + 1) (x + 5)(x + 1)
    Answer: (x + 2)(x + 3)
    (x + 2)(x + 3)
    Explanation: x² + 5x + 6 = (x + 2)(x + 3), since 2 + 3 = 5 and 2 × 3 = 6.
    x² + 5x + 6 = (x + 2)(x + 3), কাৰণ 2 + 3 = 5 আৰু 2 × 3 = 6।
    Q4. If a + b = 5 and a − b = 3, then the value of ab is:
    যদি a + b = 5 আৰু a − b = 3 হয়, তেন্তে ab ৰ মান কি?
    (A) 4 4
    (B) 5 5
    (C) 3 3
    (D) 2 2
    Answer: 4
    4
    Explanation: Solving, a = 4 and b = 1, so ab = 4.
    সমাধান কৰি a = 4 আৰু b = 1, গতিকে ab = 4।
    Q5. The value of (102)² using an identity is:
    অভেদ ব্যৱহাৰ কৰি (102)² ৰ মান কি?
    (A) 10404 10404
    (B) 10204 10204
    (C) 10004 10004
    (D) 10440 10440
    Answer: 10404
    10404
    Explanation: (100 + 2)² = 100² + 2 × 100 × 2 + 2² = 10000 + 400 + 4 = 10404.
    (100 + 2)² = 100² + 2 × 100 × 2 + 2² = 10000 + 400 + 4 = 10404।
    Q6. If a + b + c = 9 and ab + bc + ca = 26, then a² + b² + c² is:
    যদি a + b + c = 9 আৰু ab + bc + ca = 26 হয়, তেন্তে a² + b² + c² ৰ মান কি?
    (A) 29 29
    (B) 31 31
    (C) 27 27
    (D) 25 25
    Answer: 29
    29
    Explanation: a² + b² + c² = (a + b + c)² − 2(ab + bc + ca) = 81 − 52 = 29.
    a² + b² + c² = (a + b + c)² − 2(ab + bc + ca) = 81 − 52 = 29।
    Q7. The factorization of x³ − 8 is:
    x³ − 8 ৰ উৎপাদক বিশ্লেষণ কি?
    (A) (x − 2)(x² + 2x + 4) (x − 2)(x² + 2x + 4)
    (B) (x − 2)(x² − 2x + 4) (x − 2)(x² − 2x + 4)
    (C) (x + 2)(x² − 2x + 4) (x + 2)(x² − 2x + 4)
    (D) (x − 2)³ (x − 2)³
    Answer: (x − 2)(x² + 2x + 4)
    (x − 2)(x² + 2x + 4)
    Explanation: Using a³ − b³ = (a − b)(a² + ab + b²), x³ − 8 = (x − 2)(x² + 2x + 4).
    a³ − b³ = (a − b)(a² + ab + b²) সূত্ৰৰপৰা x³ − 8 = (x − 2)(x² + 2x + 4)।
    Q8. If x + 1/x = 2, then x³ + 1/x³ is:
    যদি x + 1/x = 2 হয়, তেন্তে x³ + 1/x³ ৰ মান কি?
    (A) 6 6
    (B) 8 8
    (C) 2 2
    (D) 4 4
    Answer: 2
    2
    Explanation: x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 8 − 6 = 2.
    x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 8 − 6 = 2।
    Q9. The remainder when x³ + 3x² + 3x + 1 is divided by (x + 1) is:
    x³ + 3x² + 3x + 1 ক (x + 1) ৰে ভাগ কৰিলে অৱশেষ কিমান?
    (A) 0 0
    (B) 1 1
    (C) −1 −1
    (D) 2 2
    Answer: 0
    0
    Explanation: Put x = −1: −1 + 3 − 3 + 1 = 0, so the remainder is 0.
    x = −1 বহুৱাই: −1 + 3 − 3 + 1 = 0, গতিকে অৱশেষ 0।
    Q10. If x = √5 + 2, then the value of x − 1/x is:
    যদি x = √5 + 2 হয়, তেন্তে x − 1/x ৰ মান কি?
    (A) 4 4
    (B) 2√5 2√5
    (C) 2 2
    (D) √5 √5
    Answer: 4
    4
    Explanation: 1/x = √5 − 2, so x − 1/x = (√5 + 2) − (√5 − 2) = 4.
    1/x = √5 − 2, গতিকে x − 1/x = (√5 + 2) − (√5 − 2) = 4।
    Q11. The value of √(6 + √(6 + √(6 + …))) is:
    √(6 + √(6 + √(6 + …))) ৰ মান কি?
    (A) 3 3
    (B) 2 2
    (C) 6 6
    (D) 4 4
    Answer: 3
    3
    Explanation: Let x = √(6 + x), then x² = 6 + x, giving x = 3 (positive root).
    x = √(6 + x) ধৰি, x² = 6 + x, যাৰপৰা x = 3 (ধনাত্মক মূল)।
    Q12. If a + b = 3 and ab = 2, then a³ + b³ is:
    যদি a + b = 3 আৰু ab = 2 হয়, তেন্তে a³ + b³ ৰ মান কি?
    (A) 9 9
    (B) 7 7
    (C) 11 11
    (D) 15 15
    Answer: 9
    9
    Explanation: a³ + b³ = (a + b)³ − 3ab(a + b) = 27 − 18 = 9.
    a³ + b³ = (a + b)³ − 3ab(a + b) = 27 − 18 = 9।
    Q13. Simplify: (a + b)³ − (a − b)³.
    সৰল কৰা: (a + b)³ − (a − b)³।
    (A) 2b(3a² + b²) 2b(3a² + b²)
    (B) 2a(3b² + a²) 2a(3b² + a²)
    (C) 6ab(a + b) 6ab(a + b)
    (D) 2b²(3a + b) 2b²(3a + b)
    Answer: 2b(3a² + b²)
    2b(3a² + b²)
    Explanation: (a + b)³ − (a − b)³ = 6a²b + 2b³ = 2b(3a² + b²).
    (a + b)³ − (a − b)³ = 6a²b + 2b³ = 2b(3a² + b²)।
    Q14. If x² + 1/x² = 7, then x − 1/x is:
    যদি x² + 1/x² = 7 হয়, তেন্তে x − 1/x ৰ মান কি?
    (A) √5 √5
    (B) √7 √7
    (C) 5 5
    (D) 3 3
    Answer: √5
    √5
    Explanation: (x − 1/x)² = x² + 1/x² − 2 = 7 − 2 = 5, so x − 1/x = √5.
    (x − 1/x)² = x² + 1/x² − 2 = 7 − 2 = 5, গতিকে x − 1/x = √5।
    Q15. The HCF of x² − 1 and x² − 2x + 1 is:
    x² − 1 আৰু x² − 2x + 1 ৰ গৰিষ্ঠ সাধাৰণ উৎপাদক কি?
    (A) x − 1 x − 1
    (B) x + 1 x + 1
    (C) (x − 1)² (x − 1)²
    (D) x² − 1 x² − 1
    Answer: x − 1
    x − 1
    Explanation: x² − 1 = (x − 1)(x + 1) and x² − 2x + 1 = (x − 1)², so HCF = x − 1.
    x² − 1 = (x − 1)(x + 1) আৰু x² − 2x + 1 = (x − 1)², গতিকে HCF = x − 1।
    Q16. If a/3 = b/4 = c/5, then (a + b + c)/c is:
    যদি a/3 = b/4 = c/5 হয়, তেন্তে (a + b + c)/c ৰ মান কি?
    (A) 12/5 12/5
    (B) 5/12 5/12
    (C) 3/5 3/5
    (D) 7/5 7/5
    Answer: 12/5
    12/5
    Explanation: Let a = 3k, b = 4k, c = 5k; then (a + b + c)/c = 12k/5k = 12/5.
    a = 3k, b = 4k, c = 5k ধৰি (a + b + c)/c = 12k/5k = 12/5।
    Q17. The value of 999 × 1001 is:
    999 × 1001 ৰ মান কি?
    (A) 999999 999999
    (B) 999899 999899
    (C) 999099 999099
    (D) 998999 998999
    Answer: 999999
    999999
    Explanation: 999 × 1001 = (1000 − 1)(1000 + 1) = 1000² − 1² = 999999.
    999 × 1001 = (1000 − 1)(1000 + 1) = 1000² − 1² = 999999।
    Q18. If x + y = 5 and x² + y² = 13, then xy is:
    যদি x + y = 5 আৰু x² + y² = 13 হয়, তেন্তে xy ৰ মান কি?
    (A) 6 6
    (B) 5 5
    (C) 12 12
    (D) 4 4
    Answer: 6
    6
    Explanation: xy = ((x + y)² − (x² + y²))/2 = (25 − 13)/2 = 6.
    xy = ((x + y)² − (x² + y²))/2 = (25 − 13)/2 = 6।
    Q19. The factors of a³ + b³ are:
    a³ + b³ ৰ উৎপাদক কি?
    (A) (a + b)(a² − ab + b²) (a + b)(a² − ab + b²)
    (B) (a + b)(a² + ab + b²) (a + b)(a² + ab + b²)
    (C) (a − b)(a² + ab + b²) (a − b)(a² + ab + b²)
    (D) (a + b)³ (a + b)³
    Answer: (a + b)(a² − ab + b²)
    (a + b)(a² − ab + b²)
    Explanation: a³ + b³ = (a + b)(a² − ab + b²).
    a³ + b³ = (a + b)(a² − ab + b²)।
    Q20. If p(x) = x² − 3x + 2, then p(2) is:
    যদি p(x) = x² − 3x + 2 হয়, তেন্তে p(2) ৰ মান কি?
    (A) 0 0
    (B) 2 2
    (C) 4 4
    (D) −2 −2
    Answer: 0
    0
    Explanation: p(2) = 4 − 6 + 2 = 0.
    p(2) = 4 − 6 + 2 = 0।
    Q21. The value of (2 + √3)(2 − √3) is:
    (2 + √3)(2 − √3) ৰ মান কি?
    (A) 1 1
    (B) 7 7
    (C) 4 4
    (D) −1 −1
    Answer: 1
    1
    Explanation: (2 + √3)(2 − √3) = 2² − (√3)² = 4 − 3 = 1.
    (2 + √3)(2 − √3) = 2² − (√3)² = 4 − 3 = 1।
    Q22. If 5ˣ = 625, then x is:
    যদি 5ˣ = 625 হয়, তেন্তে x ৰ মান কি?
    (A) 4 4
    (B) 3 3
    (C) 5 5
    (D) 6 6
    Answer: 4
    4
    Explanation: 625 = 5⁴, so x = 4.
    625 = 5⁴, গতিকে x = 4।
    Q23. If x − 1/x = 3, then x³ − 1/x³ is:
    যদি x − 1/x = 3 হয়, তেন্তে x³ − 1/x³ ৰ মান কি?
    (A) 36 36
    (B) 27 27
    (C) 18 18
    (D) 30 30
    Answer: 36
    36
    Explanation: x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x) = 27 + 9 = 36.
    x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x) = 27 + 9 = 36।
    Q24. The number of terms in the expansion of (a + b)⁴ is:
    (a + b)⁴ ৰ সম্প্ৰসাৰণত কিমানটা পদ থাকে?
    (A) 5 5
    (B) 4 4
    (C) 6 6
    (D) 3 3
    Answer: 5
    5
    Explanation: The expansion of (a + b)ⁿ has n + 1 terms, so here 4 + 1 = 5.
    (a + b)ⁿ ৰ সম্প্ৰসাৰণত n + 1 টা পদ থাকে, গতিকে ইয়াত 4 + 1 = 5।
    Q25. If a + b + c = 0 and a² + b² + c² = 16, then ab + bc + ca is:
    যদি a + b + c = 0 আৰু a² + b² + c² = 16 হয়, তেন্তে ab + bc + ca ৰ মান কি?
    (A) −8 −8
    (B) 8 8
    (C) −16 −16
    (D) 16 16
    Answer: −8
    −8
    Explanation: ab + bc + ca = ((a + b + c)² − (a² + b² + c²))/2 = (0 − 16)/2 = −8.
    ab + bc + ca = ((a + b + c)² − (a² + b² + c²))/2 = (0 − 16)/2 = −8।
