    Advanced Math Mock Test — Set 3

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. The value of sin 90° is:
    sin 90° ৰ মান কি?
    (A) 0
    (B) 1
    (C) 1/2
    (D) √3/2
    Answer: 1
    Explanation: sin 90° = 1.
    sin 90° = 1।
    Q2. The value of cos 0° is:
    cos 0° ৰ মান কি?
    (A) 0
    (B) 1/2
    (C) 1
    (D) √3/2
    Answer: 1
    Explanation: cos 0° = 1.
    cos 0° = 1।
    Q3. The value of tan 45° is:
    tan 45° ৰ মান কি?
    (A) 0
    (B) √3
    (C) 1/√3
    (D) 1
    Answer: 1
    Explanation: tan 45° = 1.
    tan 45° = 1।
    Q4. sin²θ + cos²θ is equal to:
    sin²θ + cos²θ ৰ মান কি?
    (A) 0
    (B) 1
    (C) 2
    (D) sin 2θ
    Answer: 1
    Explanation: sin²θ + cos²θ = 1, the fundamental trigonometric identity.
    sin²θ + cos²θ = 1, এয়া মূল ত্ৰিকোণমিতিক অভেদ।
    Q5. The value of sin 30° is:
    sin 30° ৰ মান কি?
    (A) 1/2
    (B) √3/2
    (C) 1
    (D) 0
    Answer: 1/2
    Explanation: sin 30° = 1/2.
    sin 30° = 1/2।
    Q6. The value of cos 60° is:
    cos 60° ৰ মান কি?
    (A) √3/2
    (B) 1
    (C) 1/2
    (D) 0
    Answer: 1/2
    Explanation: cos 60° = 1/2.
    cos 60° = 1/2।
    Q7. 1 + tan²θ is equal to:
    1 + tan²θ ৰ মান কি?
    (A) sin²θ
    (B) sec²θ
    (C) cos²θ
    (D) cot²θ
    Answer: sec²θ
    Explanation: 1 + tan²θ = sec²θ.
    1 + tan²θ = sec²θ।
    Q8. The value of tan 60° is:
    tan 60° ৰ মান কি?
    (A) 1
    (B) 1/√3
    (C) √3
    (D) 0
    Answer: √3
    Explanation: tan 60° = √3.
    tan 60° = √3।
    Q9. sin(90° − θ) is equal to:
    sin(90° − θ) ৰ মান কি?
    (A) sin θ
    (B) cos θ
    (C) tan θ
    (D) cot θ
    Answer: cos θ
    Explanation: sin(90° − θ) = cos θ.
    sin(90° − θ) = cos θ।
    Q10. The value of cot 45° is:
    cot 45° ৰ মান কি?
    (A) 0
    (B) √3
    (C) 1
    (D) 1/√3
    Answer: 1
    Explanation: cot 45° = 1.
    cot 45° = 1।
    Q11. If sin θ = 3/5, then cos θ is: (θ is acute)
    যদি sin θ = 3/5 হয়, তেন্তে cos θ ৰ মান কি? (θ সূক্ষ্মকোণ)
    (A) 4/5
    (B) 3/4
    (C) 5/3
    (D) 5/4
    Answer: 4/5
    Explanation: If sin θ = 3/5, then cos θ = √(1 − 9/25) = √(16/25) = 4/5.
    sin θ = 3/5 হ'লে cos θ = √(1 − 9/25) = √(16/25) = 4/5।
    Q12. The value of sec 0° is:
    sec 0° ৰ মান কি?
    (A) 0
    (B) 1
    (C) Undefined অনিৰ্ধাৰিত
    (D) ∞
    Answer: 1
    Explanation: sec 0° = 1.
    sec 0° = 1।
    Q13. cos(90° − θ) is equal to:
    cos(90° − θ) ৰ মান কি?
    (A) cos θ
    (B) sin θ
    (C) −sin θ
    (D) tan θ
    Answer: sin θ
    Explanation: cos(90° − θ) = sin θ.
    cos(90° − θ) = sin θ।
    Q14. The maximum value of sin θ is:
    sin θ ৰ সৰ্বোচ্চ মান কি?
    (A) 0
    (B) 1/2
    (C) 1
    (D) √2
    Answer: 1
    Explanation: The maximum value of sin θ is 1.
    sin θ ৰ সৰ্বোচ্চ মান 1।
    Q15. If tan θ = 1, then θ is: (0° < θ < 90°)
    যদি tan θ = 1 হয়, তেন্তে θ ৰ মান কি? (0° < θ < 90°)
    (A) 30°
    (B) 60°
    (C) 45°
    (D) 90°
    Answer: 45°
    Explanation: tan 45° = 1, so θ = 45°.
    tan 45° = 1, গতিকে θ = 45°।
    Q16. 1 + cot²θ is equal to:
    1 + cot²θ ৰ মান কি?
    (A) sec²θ
    (B) cosec²θ
    (C) tan²θ
    (D) sin²θ
    Answer: cosec²θ
    Explanation: 1 + cot²θ = cosec²θ.
    1 + cot²θ = cosec²θ।
    Q17. The value of sin 0° + cos 90° is:
    sin 0° + cos 90° ৰ মান কি?
    (A) 1
    (B) 2
    (C) 0
    (D) 1/2
    Answer: 0
    Explanation: sin 0° + cos 90° = 0 + 0 = 0.
    sin 0° + cos 90° = 0 + 0 = 0।
    Q18. If cos θ = 12/13, then sin θ is: (θ is acute)
    যদি cos θ = 12/13 হয়, তেন্তে sin θ ৰ মান কি? (θ সূক্ষ্মকোণ)
    (A) 5/13
    (B) 12/5
    (C) 13/5
    (D) 5/12
    Answer: 5/13
    Explanation: If cos θ = 12/13, then sin θ = √(1 − 144/169) = √(25/169) = 5/13.
    cos θ = 12/13 হ'লে sin θ = √(1 − 144/169) = √(25/169) = 5/13।
    Q19. The value of 2 sin 30° cos 30° is:
    2 sin 30° cos 30° ৰ মান কি?
    (A) 1/2
    (B) √3/2
    (C) 1
    (D) √3
    Answer: √3/2
    Explanation: 2 sin 30° cos 30° = sin 60° = √3/2.
    2 sin 30° cos 30° = sin 60° = √3/2।
    Q20. tan θ is equal to:
    tan θ সমান:
    (A) cos θ / sin θ
    (B) sin θ / cos θ
    (C) 1 / sin θ
    (D) 1 / cos θ
    Answer: sin θ / cos θ
    Explanation: tan θ = sin θ / cos θ.
    tan θ = sin θ / cos θ।
    Q21. The value of cos 30° is:
    cos 30° ৰ মান কি?
    (A) 1/2
    (B) √3/2
    (C) 1
    (D) 0
    Answer: √3/2
    Explanation: cos 30° = √3/2.
    cos 30° = √3/2।
    Q22. If sin A = cos A, then A is: (0° < A < 90°)
    যদি sin A = cos A হয়, তেন্তে A ৰ মান কি? (0° < A < 90°)
    (A) 30°
    (B) 60°
    (C) 45°
    (D) 90°
    Answer: 45°
    Explanation: In the first quadrant, sin A = cos A only when A = 45°.
    প্ৰথম চতুৰ্থাংশত sin A = cos A কেৱল A = 45° হ'লেহে হয়।
    Q23. The value of tan 30° × tan 60° is:
    tan 30° × tan 60° ৰ মান কি?
    (A) √3
    (B) 1/√3
    (C) 0
    (D) 1
    Answer: 1
    Explanation: tan 30° × tan 60° = (1/√3) × √3 = 1.
    tan 30° × tan 60° = (1/√3) × √3 = 1।
    Q24. cosec θ is equal to:
    cosec θ সমান:
    (A) 1 / cos θ
    (B) 1 / sin θ
    (C) 1 / tan θ
    (D) sin θ / cos θ
    Answer: 1 / sin θ
    Explanation: cosec θ = 1 / sin θ.
    cosec θ = 1 / sin θ।
    Q25. The value of sin 60° + cos 30° is:
    sin 60° + cos 30° ৰ মান কি?
    (A) √3
    (B) 1
    (C) √3/2
    (D) 1/2
    Answer: √3
    Explanation: sin 60° + cos 30° = √3/2 + √3/2 = √3.
    sin 60° + cos 30° = √3/2 + √3/2 = √3।
