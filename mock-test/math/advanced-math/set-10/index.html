    Advanced Math Mock Test — Set 10

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. The distance between the points (0, 0) and (3, 4) is:
    (0, 0) আৰু (3, 4) বিন্দু দুটাৰ মাজৰ দূৰত্ব কিমান?
    (A) 5 5
    (B) 7 7
    (C) 25 25
    (D) 1 1
    Answer: 5
    5
    Explanation: d = √(3² + 4²) = √25 = 5.
    d = √(3² + 4²) = √25 = 5।
    Q2. The slope of the line through (1, 2) and (3, 6) is:
    (1, 2) আৰু (3, 6) ৰ মাজেৰে যোৱা ৰেখাৰ ঢাল কিমান?
    (A) 2 2
    (B) 1/2 1/2
    (C) 4 4
    (D) −2 −2
    Answer: 2
    2
    Explanation: Slope = (6 − 2)/(3 − 1) = 4/2 = 2.
    ঢাল = (6 − 2)/(3 − 1) = 4/2 = 2।
    Q3. The midpoint of the segment joining (2, 4) and (6, 8) is:
    (2, 4) আৰু (6, 8) যোগ কৰা ৰেখাখণ্ডৰ মধ্যবিন্দু কি?
    (A) (4, 6) (4, 6)
    (B) (8, 12) (8, 12)
    (C) (2, 2) (2, 2)
    (D) (3, 3) (3, 3)
    Answer: (4, 6)
    (4, 6)
    Explanation: Midpoint = ((2 + 6)/2, (4 + 8)/2) = (4, 6).
    মধ্যবিন্দু = ((2 + 6)/2, (4 + 8)/2) = (4, 6)।
    Q4. The equation of the x-axis is:
    x-অক্ষৰ সমীকৰণ কি?
    (A) y = 0 y = 0
    (B) x = 0 x = 0
    (C) x = y x = y
    (D) y = 1 y = 1
    Answer: y = 0
    y = 0
    Explanation: Every point on the x-axis has y = 0.
    x-অক্ষৰ প্ৰতিটো বিন্দুৰ y = 0।
    Q5. The distance of the point (3, 4) from the origin is:
    মূলবিন্দুৰপৰা (3, 4) বিন্দুৰ দূৰত্ব কিমান?
    (A) 5 5
    (B) 7 7
    (C) 12 12
    (D) 1 1
    Answer: 5
    5
    Explanation: d = √(3² + 4²) = 5.
    d = √(3² + 4²) = 5।
    Q6. The slope of the line y = 2x + 3 is:
    y = 2x + 3 ৰেখাৰ ঢাল কিমান?
    (A) 2 2
    (B) 3 3
    (C) −2 −2
    (D) 1/2 1/2
    Answer: 2
    2
    Explanation: Comparing with y = mx + c, the slope m = 2.
    y = mx + c ৰ সৈতে তুলনা কৰি ঢাল m = 2।
    Q7. The value of log₁₀ 100 is:
    log₁₀ 100 ৰ মান কি?
    (A) 2 2
    (B) 10 10
    (C) 1 1
    (D) 100 100
    Answer: 2
    2
    Explanation: Since 10² = 100, log₁₀ 100 = 2.
    10² = 100 হোৱাত log₁₀ 100 = 2।
    Q8. The value of log₂ 8 is:
    log₂ 8 ৰ মান কি?
    (A) 3 3
    (B) 2 2
    (C) 4 4
    (D) 8 8
    Answer: 3
    3
    Explanation: Since 2³ = 8, log₂ 8 = 3.
    2³ = 8 হোৱাত log₂ 8 = 3।
    Q9. The derivative of x² with respect to x is:
    x ৰ সাপেক্ষে x² ৰ অৱকলজ কি?
    (A) 2x 2x
    (B) x x
    (C) x² x²
    (D) 2 2
    Answer: 2x
    2x
    Explanation: d/dx (x²) = 2x.
    d/dx (x²) = 2x।
    Q10. The derivative of sin x with respect to x is:
    x ৰ সাপেক্ষে sin x ৰ অৱকলজ কি?
    (A) cos x cos x
    (B) −cos x −cos x
    (C) sin x sin x
    (D) −sin x −sin x
    Answer: cos x
    cos x
    Explanation: d/dx (sin x) = cos x.
    d/dx (sin x) = cos x।
    Q11. The integral ∫ x dx is:
    সমাকল ∫ x dx ৰ মান কি?
    (A) x²/2 + C x²/2 + C
    (B) x² + C x² + C
    (C) 2x + C 2x + C
    (D) x + C x + C
    Answer: x²/2 + C
    x²/2 + C
    Explanation: ∫ x dx = x²/2 + C.
    ∫ x dx = x²/2 + C।
    Q12. The integral ∫ dx is:
    সমাকল ∫ dx ৰ মান কি?
    (A) x + C x + C
    (B) 1 + C 1 + C
    (C) x² + C x² + C
    (D) C C
    Answer: x + C
    x + C
    Explanation: ∫ dx = x + C.
    ∫ dx = x + C।
    Q13. The value of lim (x→1) (x² − 1)/(x − 1) is:
    lim (x→1) (x² − 1)/(x − 1) ৰ মান কি?
    (A) 2 2
    (B) 1 1
    (C) 0 0
    (D) Does not exist অস্তিত্ব নাই
    Answer: 2
    2
    Explanation: (x² − 1)/(x − 1) = x + 1 for x ≠ 1, so the limit is 2.
    x ≠ 1 ৰ বাবে (x² − 1)/(x − 1) = x + 1, গতিকে সীমা 2।
    Q14. The derivative of eˣ with respect to x is:
    x ৰ সাপেক্ষে eˣ ৰ অৱকলজ কি?
    (A) eˣ eˣ
    (B) x eˣ x eˣ
    (C) eˣ/x eˣ/x
    (D) 1 1
    Answer: eˣ
    eˣ
    Explanation: d/dx (eˣ) = eˣ.
    d/dx (eˣ) = eˣ।
    Q15. log a + log b is equal to:
    log a + log b ৰ মান কি?
    (A) log(ab) log(ab)
    (B) log(a + b) log(a + b)
    (C) log(a/b) log(a/b)
    (D) log a × log b log a × log b
    Answer: log(ab)
    log(ab)
    Explanation: By the product rule, log a + log b = log(ab).
    গুণন নিয়ম অনুসৰি log a + log b = log(ab)।
    Q16. The value of log 1 is:
    log 1 ৰ মান কি?
    (A) 0 0
    (B) 1 1
    (C) ∞ ∞
    (D) −1 −1
    Answer: 0
    0
    Explanation: log 1 = 0 for any base.
    যিকোনো ভিত্তিৰ বাবে log 1 = 0।
    Q17. The derivative of a constant is:
    এটা ধ্ৰুৱকৰ অৱকলজ কি?
    (A) 0 0
    (B) 1 1
    (C) the constant itself ধ্ৰুৱকটো নিজেই
    (D) undefined অনিৰ্ধাৰিত
    Answer: 0
    0
    Explanation: The derivative of any constant is 0.
    যিকোনো ধ্ৰুৱকৰ অৱকলজ 0।
    Q18. The value of ∫₁² x dx is:
    ∫₁² x dx ৰ মান কি?
    (A) 3/2 3/2
    (B) 1/2 1/2
    (C) 2 2
    (D) 3 3
    Answer: 3/2
    3/2
    Explanation: ∫₁² x dx = [x²/2]₁² = 4/2 − 1/2 = 3/2.
    ∫₁² x dx = [x²/2]₁² = 4/2 − 1/2 = 3/2।
    Q19. The slope of the line 2x + 3y = 6 is:
    2x + 3y = 6 ৰেখাৰ ঢাল কিমান?
    (A) −2/3 −2/3
    (B) 2/3 2/3
    (C) 3/2 3/2
    (D) −3/2 −3/2
    Answer: −2/3
    −2/3
    Explanation: y = (6 − 2x)/3 = −(2/3)x + 2, so slope = −2/3.
    y = (6 − 2x)/3 = −(2/3)x + 2, গতিকে ঢাল = −2/3।
    Q20. The area of the triangle with vertices (0, 0), (4, 0) and (0, 3) is:
    (0, 0), (4, 0) আৰু (0, 3) শীৰ্ষবিন্দু থকা ত্ৰিভুজৰ কালি কিমান?
    (A) 6 6
    (B) 12 12
    (C) 7 7
    (D) 3 3
    Answer: 6
    6
    Explanation: Area = (1/2) × base × height = (1/2) × 4 × 3 = 6.
    কালি = (1/2) × ভূমি × উচ্চতা = (1/2) × 4 × 3 = 6।
    Q21. The derivative of ln x with respect to x is:
    x ৰ সাপেক্ষে ln x ৰ অৱকলজ কি?
    (A) 1/x 1/x
    (B) x x
    (C) ln x ln x
    (D) 1 1
    Answer: 1/x
    1/x
    Explanation: d/dx (ln x) = 1/x.
    d/dx (ln x) = 1/x।
    Q22. The value of logₐ 1 (for a > 0, a ≠ 1) is:
    logₐ 1 ৰ মান কি (a > 0, a ≠ 1)?
    (A) 0 0
    (B) 1 1
    (C) a a
    (D) ∞ ∞
    Answer: 0
    0
    Explanation: Since a⁰ = 1, logₐ 1 = 0.
    a⁰ = 1 হোৱাত logₐ 1 = 0।
    Q23. The equation of the line with slope 2 and y-intercept 3 is:
    ঢাল 2 আৰু y-ছেদ 3 থকা ৰেখাৰ সমীকৰণ কি?
    (A) y = 2x + 3 y = 2x + 3
    (B) y = 3x + 2 y = 3x + 2
    (C) y = 2x − 3 y = 2x − 3
    (D) y = −2x + 3 y = −2x + 3
    Answer: y = 2x + 3
    y = 2x + 3
    Explanation: Using y = mx + c with m = 2, c = 3, we get y = 2x + 3.
    y = mx + c ৰ সূত্ৰত m = 2, c = 3 বহুৱাই y = 2x + 3 পোৱা যায়।
    Q24. The integral ∫ cos x dx is:
    সমাকল ∫ cos x dx ৰ মান কি?
    (A) sin x + C sin x + C
    (B) −sin x + C −sin x + C
    (C) cos x + C cos x + C
    (D) −cos x + C −cos x + C
    Answer: sin x + C
    sin x + C
    Explanation: ∫ cos x dx = sin x + C.
    ∫ cos x dx = sin x + C।
    Q25. The value of lim (x→∞) 1/x is:
    lim (x→∞) 1/x ৰ মান কি?
    (A) 0 0
    (B) 1 1
    (C) ∞ ∞
    (D) undefined অনিৰ্ধাৰিত
    Answer: 0
    0
    Explanation: As x grows large, 1/x approaches 0.
    x ডাঙৰ হোৱাৰ লগে লগে 1/x শূন্যৰ ফালে আগবাঢ়ে।
