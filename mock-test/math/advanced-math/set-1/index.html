    Advanced Math Mock Test — Set 1

    25 bilingual questions with answers and explanations. Take the timed test online or read the full set below.

    25 Questions with Answers

    Q1. If x + 1/x = 3, then the value of x² + 1/x² is:
    যদি x + 1/x = 3 হয়, তেন্তে x² + 1/x² ৰ মান কি?
    (A) 7 7
    (B) 9 9
    (C) 5 5
    (D) 11 11
    Answer: 7
    7
    Explanation: x² + 1/x² = (x + 1/x)² − 2 = 3² − 2 = 7.
    x² + 1/x² = (x + 1/x)² − 2 = 3² − 2 = 7।
    Q2. The roots of the equation x² − 5x + 6 = 0 are:
    x² − 5x + 6 = 0 সমীকৰণৰ মূল দুটা কি?
    (A) 1 and 6 1 আৰু 6
    (B) 2 and 3 2 আৰু 3
    (C) −2 and −3 −2 আৰু −3
    (D) 5 and 1 5 আৰু 1
    Answer: 2 and 3
    2 আৰু 3
    Explanation: x² − 5x + 6 = (x − 2)(x − 3), so the roots are 2 and 3.
    x² − 5x + 6 = (x − 2)(x − 3), গতিকে মূল দুটা 2 আৰু 3।
    Q3. If a + b + c = 0, then a³ + b³ + c³ is equal to:
    যদি a + b + c = 0 হয়, তেন্তে a³ + b³ + c³ ৰ মান কি?
    (A) 0 0
    (B) abc abc
    (C) 3abc 3abc
    (D) 2abc 2abc
    Answer: 3abc
    3abc
    Explanation: Using a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca); since a + b + c = 0, we get a³ + b³ + c³ = 3abc.
    a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) সূত্ৰ ব্যৱহাৰ কৰি, a + b + c = 0 হোৱাত a³ + b³ + c³ = 3abc।
    Q4. The quadratic equation whose roots are 2 and 5 is:
    যি দ্বিঘাত সমীকৰণৰ মূল 2 আৰু 5, সেই সমীকৰণটো কি?
    (A) x² − 7x + 10 = 0 x² − 7x + 10 = 0
    (B) x² + 7x + 10 = 0 x² + 7x + 10 = 0
    (C) x² − 7x − 10 = 0 x² − 7x − 10 = 0
    (D) x² − 10x + 7 = 0 x² − 10x + 7 = 0
    Answer: x² − 7x + 10 = 0
    x² − 7x + 10 = 0
    Explanation: Sum of roots = 7 and product = 10, so the equation is x² − 7x + 10 = 0.
    মূলৰ যোগফল 7 আৰু গুণফল 10, গতিকে সমীকৰণ x² − 7x + 10 = 0।
    Q5. If 2x + 3y = 12 and 3x + 2y = 13, then x + y is:
    যদি 2x + 3y = 12 আৰু 3x + 2y = 13 হয়, তেন্তে x + y ৰ মান কি?
    (A) 4 4
    (B) 6 6
    (C) 5 5
    (D) 7 7
    Answer: 5
    5
    Explanation: Adding the two equations: 5x + 5y = 25, hence x + y = 5.
    দুয়োটা সমীকৰণ যোগ কৰি: 5x + 5y = 25, গতিকে x + y = 5।
    Q6. The value of (a + b)² − (a − b)² is:
    (a + b)² − (a − b)² ৰ মান কি?
    (A) 2ab 2ab
    (B) 4ab 4ab
    (C) a² − b² a² − b²
    (D) 0 0
    Answer: 4ab
    4ab
    Explanation: (a + b)² − (a − b)² = 4ab.
    (a + b)² − (a − b)² = 4ab।
    Q7. If α and β are the roots of x² − 7x + 12 = 0, then α + β is:
    যদি x² − 7x + 12 = 0 ৰ মূল α আৰু β হয়, তেন্তে α + β ৰ মান কি?
    (A) 12 12
    (B) 5 5
    (C) −7 −7
    (D) 7 7
    Answer: 7
    7
    Explanation: For x² − 7x + 12 = 0, the sum of roots α + β = −(−7)/1 = 7.
    x² − 7x + 12 = 0 ৰ বাবে মূলৰ যোগফল α + β = 7।
    Q8. The remainder when x³ − 2x² + 3x − 4 is divided by (x − 1) is:
    x³ − 2x² + 3x − 4 ক (x − 1) ৰে ভাগ কৰিলে অৱশেষ কিমান?
    (A) −2 −2
    (B) 0 0
    (C) 2 2
    (D) −1 −1
    Answer: −2
    −2
    Explanation: By the remainder theorem, put x = 1: 1 − 2 + 3 − 4 = −2.
    ভাগশেষ উপপাদ্য অনুসৰি x = 1 বহুৱাই: 1 − 2 + 3 − 4 = −2।
    Q9. If x = 2 + √3, then the value of x + 1/x is:
    যদি x = 2 + √3 হয়, তেন্তে x + 1/x ৰ মান কি?
    (A) 2√3 2√3
    (B) 4 4
    (C) 2 2
    (D) √3 √3
    Answer: 4
    4
    Explanation: Since x = 2 + √3, 1/x = 2 − √3, so x + 1/x = 4.
    x = 2 + √3 হোৱাত 1/x = 2 − √3, গতিকে x + 1/x = 4।
    Q10. The degree of the polynomial 5x³ + 2x² − 7x + 1 is:
    5x³ + 2x² − 7x + 1 বহুপদটোৰ ঘাত কিমান?
    (A) 2 2
    (B) 1 1
    (C) 3 3
    (D) 5 5
    Answer: 3
    3
    Explanation: The degree is the highest power of x, which is 3.
    বহুপদটোৰ ঘাত x ৰ সৰ্বোচ্চ ঘাত, অৰ্থাৎ 3।
    Q11. The discriminant of x² − 4x + 4 = 0 is:
    x² − 4x + 4 = 0 ৰ ডিস্ক্ৰিমিনেণ্ট কিমান?
    (A) 4 4
    (B) 2 2
    (C) 16 16
    (D) 0 0
    Answer: 0
    0
    Explanation: Discriminant D = b² − 4ac = (−4)² − 4(1)(4) = 16 − 16 = 0.
    নিৰ্ণায়ক D = b² − 4ac = (−4)² − 4(1)(4) = 16 − 16 = 0।
    Q12. If one root of x² − 8x + k = 0 is 2, then k is:
    যদি x² − 8x + k = 0 ৰ এটা মূল 2 হয়, তেন্তে k ৰ মান কি?
    (A) 8 8
    (B) 12 12
    (C) 16 16
    (D) 10 10
    Answer: 12
    12
    Explanation: Put x = 2: 4 − 16 + k = 0, so k = 12.
    x = 2 বহুৱাই: 4 − 16 + k = 0, গতিকে k = 12।
    Q13. If 2ˣ = 32, then x is:
    যদি 2ˣ = 32 হয়, তেন্তে x ৰ মান কি?
    (A) 4 4
    (B) 6 6
    (C) 5 5
    (D) 8 8
    Answer: 5
    5
    Explanation: 32 = 2⁵, so x = 5.
    32 = 2⁵, গতিকে x = 5।
    Q14. If x + y = 10 and xy = 21, then x² + y² is:
    যদি x + y = 10 আৰু xy = 21 হয়, তেন্তে x² + y² ৰ মান কি?
    (A) 58 58
    (B) 100 100
    (C) 42 42
    (D) 79 79
    Answer: 58
    58
    Explanation: x² + y² = (x + y)² − 2xy = 100 − 42 = 58.
    x² + y² = (x + y)² − 2xy = 100 − 42 = 58।
    Q15. The factorization of x² − 9 is:
    x² − 9 ৰ উৎপাদক বিশ্লেষণ কি?
    (A) (x − 9)(x + 1) (x − 9)(x + 1)
    (B) (x − 3)(x + 3) (x − 3)(x + 3)
    (C) (x − 3)² (x − 3)²
    (D) (x + 9)(x − 1) (x + 9)(x − 1)
    Answer: (x − 3)(x + 3)
    (x − 3)(x + 3)
    Explanation: Using a² − b² = (a − b)(a + b), x² − 9 = (x − 3)(x + 3).
    a² − b² = (a − b)(a + b) সূত্ৰৰপৰা x² − 9 = (x − 3)(x + 3)।
    Q16. The expansion of (a + b)³ is:
    (a + b)³ ৰ সম্প্ৰসাৰণ কি?
    (A) a³ + b³ a³ + b³
    (B) a³ + b³ + 3ab a³ + b³ + 3ab
    (C) a³ + b³ + 3ab(a + b) a³ + b³ + 3ab(a + b)
    (D) a³ − b³ + 3ab(a − b) a³ − b³ + 3ab(a − b)
    Answer: a³ + b³ + 3ab(a + b)
    a³ + b³ + 3ab(a + b)
    Explanation: (a + b)³ = a³ + b³ + 3ab(a + b).
    (a + b)³ = a³ + b³ + 3ab(a + b)।
    Q17. If the product of the roots of x² − 6x + k = 0 is 8, then k is:
    যদি x² − 6x + k = 0 ৰ মূল দুটাৰ গুণফল 8 হয়, তেন্তে k ৰ মান কি?
    (A) 6 6
    (B) −8 −8
    (C) 14 14
    (D) 8 8
    Answer: 8
    8
    Explanation: Product of roots = c/a = k/1 = k, so k = 8.
    মূলৰ গুণফল = k/1 = k, গতিকে k = 8।
    Q18. The graph of a linear equation in two variables is a:
    দুটা চলকৰ ৰৈখিক সমীকৰণৰ লেখখন কি?
    (A) Circle বৃত্ত
    (B) Straight line সৰলৰেখা
    (C) Parabola পৰাবৃত্ত
    (D) Point বিন্দু
    Answer: Straight line
    সৰলৰেখা
    Explanation: The graph of a linear equation in two variables is always a straight line.
    দুটা চলকৰ ৰৈখিক সমীকৰণৰ লেখ সদায় এডাল সৰলৰেখা।
    Q19. If x − y = 3 and xy = 10, then x³ − y³ is:
    যদি x − y = 3 আৰু xy = 10 হয়, তেন্তে x³ − y³ ৰ মান কি?
    (A) 27 27
    (B) 117 117
    (C) 90 90
    (D) 63 63
    Answer: 117
    117
    Explanation: x³ − y³ = (x − y)³ + 3xy(x − y) = 27 + 3 × 10 × 3 = 117.
    x³ − y³ = (x − y)³ + 3xy(x − y) = 27 + 3 × 10 × 3 = 117।
    Q20. The zero of the polynomial p(x) = 2x − 8 is:
    p(x) = 2x − 8 বহুপদটোৰ শূন্য কি?
    (A) 8 8
    (B) −4 −4
    (C) 4 4
    (D) 2 2
    Answer: 4
    4
    Explanation: 2x − 8 = 0 gives x = 4.
    2x − 8 = 0 ৰপৰা x = 4।
    Q21. If a : b = 3 : 4, then (3a + 2b) : (4a + 3b) is:
    যদি a : b = 3 : 4 হয়, তেন্তে (3a + 2b) : (4a + 3b) কি?
    (A) 17 : 24 17 : 24
    (B) 3 : 4 3 : 4
    (C) 5 : 7 5 : 7
    (D) 8 : 9 8 : 9
    Answer: 17 : 24
    17 : 24
    Explanation: Put a = 3, b = 4: (3a + 2b) : (4a + 3b) = (9 + 8) : (12 + 12) = 17 : 24.
    a = 3, b = 4 বহুৱাই: (3a + 2b) : (4a + 3b) = (9 + 8) : (12 + 12) = 17 : 24।
    Q22. The nature of roots of x² + 4x + 5 = 0 is:
    x² + 4x + 5 = 0 ৰ মূল দুটাৰ প্ৰকৃতি কি?
    (A) Real and equal বাস্তৱ আৰু সমান
    (B) Real and unequal বাস্তৱ আৰু অসমান
    (C) Not real বাস্তৱ নহয়
    (D) Rational and equal পৰিমেয় আৰু সমান
    Answer: Not real
    বাস্তৱ নহয়
    Explanation: D = 4² − 4(1)(5) = −4 < 0, so the roots are not real.
    D = 4² − 4(1)(5) = −4 < 0, গতিকে মূলবোৰ অবাস্তৱ।
    Q23. If 3ˣ⁺¹ = 81, then x is:
    যদি 3ˣ⁺¹ = 81 হয়, তেন্তে x ৰ মান কি?
    (A) 4 4
    (B) 2 2
    (C) 5 5
    (D) 3 3
    Answer: 3
    3
    Explanation: 81 = 3⁴, so x + 1 = 4 and x = 3.
    81 = 3⁴, গতিকে x + 1 = 4 আৰু x = 3।
    Q24. The value of (x + 4)(x − 4) is:
    (x + 4)(x − 4) ৰ মান কি?
    (A) x² − 16 x² − 16
    (B) x² + 16 x² + 16
    (C) x² − 8x + 16 x² − 8x + 16
    (D) x² − 8 x² − 8
    Answer: x² − 16
    x² − 16
    Explanation: (x + 4)(x − 4) = x² − 16.
    (x + 4)(x − 4) = x² − 16।
    Q25. If the sum and product of the roots of a quadratic equation are 5 and 6 respectively, the equation is:
    যদি এটা দ্বিঘাত সমীকৰণৰ মূল দুটাৰ যোগফল 5 আৰু গুণফল 6 হয়, সমীকৰণটো কি?
    (A) x² + 5x + 6 = 0 x² + 5x + 6 = 0
    (B) x² − 5x + 6 = 0 x² − 5x + 6 = 0
    (C) x² − 5x − 6 = 0 x² − 5x − 6 = 0
    (D) x² + 6x + 5 = 0 x² + 6x + 5 = 0
    Answer: x² − 5x + 6 = 0
    x² − 5x + 6 = 0
    Explanation: The equation is x² − (sum)x + product = 0, i.e. x² − 5x + 6 = 0.
    সমীকৰণ x² − (যোগফল)x + গুণফল = 0, অৰ্থাৎ x² − 5x + 6 = 0।
