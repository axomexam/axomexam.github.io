      Software & Operating System

      Software and Operating Systems - Study Notes

      Software questions check whether a candidate can distinguish programs from hardware, classify software correctly and describe the job of an operating system. These ideas appear in ADRE, APSC, Assam Police, SSC and Railway papers, and they also support later topics such as MS Office and cyber security. This page presents the classification of software and the functions of an operating system in a form that is easy to revise.

      Hardware, software and firmware

      Hardware is the physical part of a computer that you can touch. Software is the set of instructions that tells the hardware what to do. Firmware is a special kind of software stored permanently on a chip, such as the BIOS, that starts the machine before the operating system loads. A program is a collection of instructions, and an algorithm is the step-by-step logic behind it.

      Types of software

      System software manages the computer itself and includes the operating system, device drivers, utilities and language translators. Application software lets the user perform a task and includes general-purpose programs such as word processors and spreadsheets, customised software built for one organisation, and utility programs such as antivirus tools and disk cleaners. Language translators convert source code into machine code: a compiler translates the whole program at once, an interpreter translates line by line, and an assembler translates assembly language into machine language. The main categories of application software are packaged, customised, utility, and general-purpose software.

      What an operating system does

      An operating system is the master program that sits between the user, the application software and the hardware. It performs process management, memory management, file management, device management and security. It provides the user interface, whether graphical with windows, icons and a pointer, or a command line where the user types instructions. It schedules tasks, manages users and permissions, and handles input and output. Common examples are Microsoft Windows, macOS, Linux and its distributions, Android and iOS for mobile devices, and Unix which influenced many of them. Windows is proprietary, while Linux is open source.

      Booting and other key terms

      Booting is the process of starting a computer and loading the operating system into memory. A cold boot starts from a powered-off state, and a warm boot restarts a running machine. The kernel is the core of the operating system that always stays in memory. A shell is the interface that accepts user commands. Multitasking runs several programs apparently at once, multiprogramming keeps several jobs in memory, and multiprocessing uses more than one processor. Time sharing allows many users to use one computer simultaneously, and real-time systems respond within a fixed time limit.

      Utility and open-source software

      Utility software helps maintain the system and includes disk defragmentation tools, backup programs, compression tools such as WinZip and WinRAR, and antivirus programs. Open-source software publishes its source code and can be freely studied and modified, for example Linux, LibreOffice and Mozilla Firefox. Proprietary software keeps its source code private and is licensed, for example Microsoft Office. Freeware is free of cost but not necessarily open source, and shareware is distributed for a trial period.

      Quick revision

      • Operating system is system software, not application software.
      • Compiler translates the entire program; interpreter translates line by line.
      • Kernel is the core of the operating system.
      • Android and iOS are mobile operating systems; Linux is open source.
