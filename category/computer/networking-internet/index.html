    Networking & Internet

    Networking and the Internet: Types, Devices and Protocols

    Networking questions check three things: how computers are joined together, what each connecting device does, and which protocol or service performs which task. The terms are short, they repeat across papers, and a candidate who links each term to its one-line job rarely loses these marks. This note gives the vocabulary, then the network types and layouts, then the devices and protocols, and finally the mistakes to avoid.

    Core Vocabulary

    • Computer network: two or more computers connected to share data, resources and services.
    • Node: any device attached to a network, such as a computer or a printer.
    • LAN: a local area network confined to a room, a building or a campus.
    • MAN: a metropolitan area network covering a city.
    • WAN: a wide area network covering a large region or the whole world.
    • PAN: a personal area network covering a few metres around one person.
    • Topology: the layout in which nodes are connected, such as bus, star, ring, mesh or tree.
    • Protocol: the set of rules that governs how data is exchanged on a network.
    • IP address: the unique address identifying a device on a network, for example 192.168.0.1.
    • MAC address: the permanent physical address burned into a network card.
    • DNS: the domain name system, which converts a domain name into an IP address.
    • Bandwidth: the amount of data a connection can carry in a given time.
    • Router: a device that joins different networks and forwards data between them.
    • Web browser: software used to view pages on the World Wide Web.

    How the Network Types Differ

    Size is the only real difference between the four network types, and each is named for the area it covers. A PAN reaches a few metres around a person, usually over Bluetooth. A LAN covers one room, building or campus. A MAN spreads across a city. A WAN covers states, countries or the globe, and the internet is simply the largest WAN in existence. Most exam questions either ask for a full form or describe an area and ask which type fits, so learning the four areas in order of size answers both.

    Topologies and Their Trade-offs

    The layout of the connections is called the topology. In a bus topology every node shares one backbone cable, which is cheap but means a single break can stop the whole network. In a star topology every node connects to a central hub or switch; it is easy to manage and is the most common design today. A ring topology joins nodes in a loop. A mesh topology connects every node to every other node and gives the highest reliability at the highest cabling cost. A tree topology links several star networks in a hierarchy.

    Devices, Each With One Job

    A modem converts the signal arriving over a telephone, cable or fibre line into a form the computer can use. A hub repeats incoming data to all its ports, so every device receives it. A switch learns which device sits on which port and sends data only to the correct one, which is why it is faster than a hub. A router connects different networks and chooses the best path for data between them. A gateway joins two networks that use different protocols, and repeaters and bridges extend or divide a network. If a question names a job, ask which device does exactly that job and nothing more.

    Protocols and Internet Services

    The internet runs on the TCP/IP suite: TCP breaks data into packets and reassembles them at the far end, while IP addresses and routes each packet. Above that sit the application protocols: HTTP and HTTPS for the web, FTP for file transfer, and SMTP to send mail with POP3 or IMAP to receive it. HTTPS is the encrypted form of HTTP, and the padlock in the address bar signals it. DNS resolves a name such as axomexam.in into a numeric address, and DHCP automatically hands an IP address to a device joining a network. Remember that the WWW is one service running on the internet; the internet itself is the global network of networks, and an ISP is the company that provides access to it. IPv4 addresses are 32 bits long, while IPv6 uses 128 bits.

    Common Traps

    • Treating the internet and the World Wide Web as the same; the web is one service on the internet.
    • Mixing a hub with a switch; a hub broadcasts, a switch targets one port.
    • Calling FTP a web protocol; it transfers files.
    • Confusing SMTP, which sends mail, with POP3 and IMAP, which receive it.
    • Swapping IPv4 and IPv6; IPv4 is 32-bit, IPv6 is 128-bit.
    • Interchanging HTTP and HTTPS; HTTPS is the secure version.

    How to Revise This Section

    Write two tables. The first pairs each abbreviation with its full form and the service it supports; the second pairs each device with its one-line job. Then sketch the five topologies and note one merit and one demerit beside each, because questions often describe a layout instead of naming it. Practise by covering the right-hand column and reciting it, then uncovering and checking. The pairs that trip you up most — hub versus switch, internet versus WWW — deserve a separate line at the top of the page, since they are the ones the paper returns to.

    Frequently Asked Questions

    What is the full form of LAN and WAN?

    LAN is local area network and WAN is wide area network, covering a small area and a large region respectively.

    Which device joins two different networks?

    A router links two separate networks and passes data from one to the other.

    Which protocol is used to send e-mail?

    SMTP, the simple mail transfer protocol, sends e-mail, while POP3 and IMAP receive it.

    What is the job of DNS?

    DNS, the domain name system, converts a human-readable domain name into a numeric IP address.

    What is the difference between the internet and the WWW?

    The internet is the worldwide web of interconnected networks; the World Wide Web is one service of linked pages running on top of it.

    নেটৱৰ্কিং প্ৰশ্নই তিনিটা কথা পৰীক্ষা কৰে: কম্পিউটাৰবোৰ কেনেকৈ সংযোগ কৰা হয়, প্ৰতিটো সংযোগী যন্ত্ৰই কি কৰে, আৰু কোনটো protocol বা service এ কোনটো কাম কৰে। শব্দবোৰ চুটি, প্ৰশ্নপত্ৰত পুনৰ আহে, আৰু প্ৰতিটো শব্দক তাৰ এশাৰী কামৰ লগত জুৰি ৰখা প্ৰাৰ্থীয়ে এই নম্বৰবোৰ বিৰলেহে হেৰুৱায়। এই টোকাত প্ৰথমে পৰিভাষা, তাৰ পিছত network ৰ প্ৰকাৰ আৰু বিন্যাস, তাৰ পিছত যন্ত্ৰ আৰু protocol, আৰু শেষত এৰাই চলিবলগীয়া ভুলবোৰ দিয়া হৈছে।

    মূল পৰিভাষা

    • Computer network: তথ্য, সম্পদ আৰু সেৱা ভগাই ল'বলৈ দুটা বা ততোধিক কম্পিউটাৰৰ সংযোগ।
    • Node: network ত সংযুক্ত যিকোনো যন্ত্ৰ, যেনে কম্পিউটাৰ বা printer।
    • LAN: এটা কোঠা, ভৱন বা campus ৰ দৰে সৰু এলেকা সামৰি লোৱা local area network।
    • MAN: এখন চহৰ সামৰি লোৱা metropolitan area network।
    • WAN: ডাঙৰ অঞ্চল বা গোটেই পৃথিৱী সামৰি লোৱা wide area network।
    • PAN: এজন ব্যক্তিৰ চাৰিওফালে কেইমিটাৰমান সামৰি লোৱা personal area network।
    • Topology: node বোৰ সংযোগ কৰা বিন্যাস, যেনে bus, star, ring, mesh বা tree।
    • Protocol: network ত তথ্য কেনেকৈ বিনিময় হ'ব নিয়ন্ত্ৰণ কৰা নিয়মৰ সংহতি।
    • IP address: network ত যন্ত্ৰ চিনাক্ত কৰা অদ্বিতীয় ঠিকনা, যেনে 192.168.0.1।
    • MAC address: network card ত সোমাই থকা স্থায়ী ভৌতিক ঠিকনা।
    • DNS: domain name ক IP address লৈ সলোৱা domain name system।
    • Bandwidth: এটা সংযোগে নিৰ্দিষ্ট সময়ত কঢ়িয়াব পৰা তথ্যৰ পৰিমাণ।
    • Router: বেলেগ network জোৰা লগাই তথ্য আগবঢ়োৱা যন্ত্ৰ।
    • Web browser: World Wide Web ৰ পৃষ্ঠা চাবলৈ ব্যৱহৃত software।

    Network ৰ প্ৰকাৰবোৰৰ পাৰ্থক্য

    চাৰিটা network প্ৰকাৰৰ মাজত আচল পাৰ্থক্য কেৱল আকাৰ, আৰু প্ৰতিটোৰ নাম ই সামৰি লোৱা এলেকাৰ পৰা হয়। PAN এ এজন ব্যক্তিৰ চাৰিওফালে কেইমিটাৰমান পায়, সাধাৰণতে Bluetooth ৰে। LAN এ এটা কোঠা, ভৱন বা campus সামৰে। MAN এ এখন চহৰত বিয়পে। WAN এ ৰাজ্য, দেশ বা গোটেই পৃথিৱী সামৰে, আৰু internet হৈছে মাথোঁ আটাইতকৈ ডাঙৰ WAN। বেছিভাগ প্ৰশ্নই হয় full form সোধে, নহয় এটা এলেকা বৰ্ণনা কৰি কোন প্ৰকাৰ সোধে; গতিকে চাৰিটা এলেকা আকাৰৰ ক্ৰমত শিকিলে দুয়োটাৰে উত্তৰ পোৱা যায়।

    Topology আৰু সিহঁতৰ লাভ-লোকসান

    সংযোগৰ বিন্যাসক topology বোলা হয়। Bus topology ত প্ৰতিটো node এ এটা মূল cable ভাগ কৰে, যি সস্তা কিন্তু এটা ঠাই ভাঙিলে গোটেই network বন্ধ হ'ব পাৰে। Star topology ত প্ৰতিটো node এ কেন্দ্ৰীয় hub বা switch লৈ সংযুক্ত; ই পৰিচালনা কৰা সহজ আৰু আজি আটাইতকৈ সাধাৰণ বিন্যাস। Ring topology এ node বোৰক এটা বৃত্তত জোৰা লগায়। Mesh topology এ প্ৰতিটো node ক আন প্ৰতিটোৰ লগত সংযোগ কৰি আটাইতকৈ বেছি নিৰ্ভৰযোগ্যতা দিয়ে, কিন্তু cable খৰচো আটাইতকৈ বেছি। Tree topology এ কেইবাটাও star network ক শ্ৰেণীবদ্ধভাৱে জোৰা লগায়।

    যন্ত্ৰ, প্ৰতিটোৰ এটা কাম

    Modem এ Telephone, cable বা fibre লাইনৰ পৰা অহা সংকেতক কম্পিউটাৰে ব্যৱহাৰ কৰিব পৰা ৰূপলৈ সলায়। Hub এ অহা তথ্য আটাই port লৈ পুনৰাবৃত্তি কৰে, গতিকে প্ৰতিটো যন্ত্ৰই সেয়া পায়। Switch এ কোন যন্ত্ৰ কোন port ত আছে শিকি কেৱল সঠিক port লৈহে তথ্য পঠিয়ায়, সেয়ে ই hub তকৈ দ্ৰুত। Router এ বেলেগ network সংযোগ কৰি সিহঁতৰ মাজত তথ্যৰ বাবে শ্ৰেষ্ঠ পথ বাছি লয়। Gateway এ বেলেগ protocol ব্যৱহাৰ কৰা দুটা network জোৰা লগায়, আৰু repeater লগতে bridge এ network বঢ়ায় বা ভাগ কৰে। প্ৰশ্নত যদি এটা কাম কোৱা হয়, তেন্তে কোন যন্ত্ৰই ঠিক সেই কামটো কৰে, আৰু তাতকৈ বেছি নকৰে, সেয়া ভাবক।

    Protocol আৰু Internet সেৱা

    Internet TCP/IP suite ত চলে: TCP এ তথ্যক packet লৈ ভাগ কৰি আন মূৰত পুনৰ একত্ৰিত কৰে, আনহাতে IP এ প্ৰতিটো packet ৰ ঠিকনা নিৰ্ণয় কৰি পথ দেখুৱায়। তাৰ ওপৰত থাকে application protocol: web ৰ HTTP আৰু HTTPS, file transfer ৰ FTP, আৰু mail পঠিয়াবলৈ SMTP লগতে ল'বলৈ POP3 বা IMAP। HTTPS হৈছে HTTP ৰ এনক্ৰিপ্ট কৰা ৰূপ, আৰু address bar ৰ padlock ইয়াক দেখুৱায়। DNS এ axomexam.in ৰ দৰে নামক সংখ্যাযুক্ত ঠিকনালৈ সলায়, আৰু DHCP এ network ত যোগ দিয়া যন্ত্ৰক স্বয়ংক্ৰিয়ভাৱে IP address দিয়ে। মনত ৰাখক, WWW হৈছে internet ত চলা এটা সেৱা; internet নিজেই হৈছে বিশ্বব্যাপী network ৰ network, আৰু ISP হৈছে ইয়াৰ সুবিধা দিয়া কোম্পানী। IPv4 ৰ ঠিকনা 32 bit দীঘল, আনহাতে IPv6 এ 128 bit ব্যৱহাৰ কৰে।

    সাধাৰণ ফান্দ

    • Internet আৰু World Wide Web একে ভবা; web হৈছে internet ৰ এটা সেৱা।
    • Hub আৰু switch মিলাই দিয়া; hub এ broadcast কৰে, switch এ এটা port লক্ষ্য কৰে।
    • FTP ক web protocol বোলা; ই file transfer কৰে।
    • SMTP, যি mail পঠিয়ায়, POP3 আৰু IMAP, যি mail লয়, মিলাই দিয়া।
    • IPv4 আৰু IPv6 ওলোটাই দিয়া; IPv4 32-bit, IPv6 128-bit।
    • HTTP আৰু HTTPS সলনি কৰা; HTTPS সুৰক্ষিত সংস্কৰণ।

    এই অংশ কেনেকৈ পুনৰালোচনা কৰিব

    দুখন তালিকা লিখক। প্ৰথমখনে প্ৰতিটো abbreviation ক তাৰ full form আৰু ই সমৰ্থন কৰা service ৰ লগত জুৰি দিয়ে; দ্বিতীয়খনে প্ৰতিটো যন্ত্ৰক তাৰ এশাৰী কামৰ লগত জুৰি দিয়ে। তাৰ পিছত পাঁচটা topology আঁকি প্ৰতিটোৰ কাষত এটা গুণ আৰু এটা দোষ লিখক, কাৰণ প্ৰশ্নই সঘনাই নাম নলৈ বিন্যাস বৰ্ণনা কৰে। সোঁফালৰ স্তম্ভ ঢাকি পঢ়ি আৰু তাৰ পিছত মুকলি কৰি পৰীক্ষা কৰি অভ্যাস কৰক। যি যোৰবোৰে আপোনাক আটাইতকৈ বেছি ধৰে — hub বনাম switch, internet বনাম WWW — সেইবোৰ পৃষ্ঠাৰ ওপৰত সুকীয়া শাৰীত ৰাখক, কাৰণ প্ৰশ্নপত্ৰই সেইবোৰলৈকে ঘূৰি আহে।

    সঘনাই সোধা প্ৰশ্ন

    LAN আৰু WAN ৰ full form কি?

    LAN হৈছে local area network, যি সৰু এলেকা সামৰে, আৰু WAN হৈছে wide area network, যি ডাঙৰ অঞ্চল সামৰে।

    কোন যন্ত্ৰই দুটা বেলেগ network জোৰা লগায়?

    Router এ দুটা সুকীয়া network সংযোগ কৰি এটাৰ পৰা আনটোলৈ তথ্য পাচ কৰে।

    E-mail পঠিয়াবলৈ কোন protocol ব্যৱহৃত হয়?

    SMTP, অৰ্থাৎ simple mail transfer protocol, ইমেইল পঠিয়ায়, আৰু POP3 লগতে IMAP ইমেইল লয়।

    DNS ৰ কাম কি?

    DNS, অৰ্থাৎ domain name system, এ মানুহে পঢ়িব পৰা domain name ক সংখ্যাযুক্ত IP address লৈ সলায়।

    Internet আৰু WWW ৰ পাৰ্থক্য কি?

    Internet হৈছে আন্তঃসংযুক্ত network ৰ বিশ্বব্যাপী জাল; World Wide Web হৈছে তাৰ ওপৰত চলা সংযুক্ত পৃষ্ঠাৰ এটা সেৱা।
