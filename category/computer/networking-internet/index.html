      Networking & Internet

      Computer Networking and the Internet - Exam Notes

      Networking questions test whether you can name the right device, protocol or network type for a given situation. The topic appears in every computer awareness paper and, once learned, it is almost impossible to forget because the terms fit together like a diagram. This page explains networks by size, the devices that connect them, the protocols that move data and the internet vocabulary that examiners use.

      Networks classified by size

      A personal area network, or PAN, covers a few metres around one person, such as a phone connected to wireless earbuds. A local area network, or LAN, covers a single building or campus and is usually owned by one organisation. A metropolitan area network, or MAN, spans a city, while a wide area network, or WAN, covers a country or the whole world. The internet itself is the largest WAN. A network's topology describes how the nodes are arranged: bus, star, ring, mesh, tree and hybrid are the common arrangements, and the star topology using a central switch is the most widely deployed today.

      Connecting devices

      A hub broadcasts every incoming signal to all ports and is now obsolete. A switch learns the physical address of each connected device and forwards data only to the correct port. A router joins different networks and chooses the best path for a packet, which is why it connects your home LAN to the internet. A modem converts the digital signal of a computer into the form carried by a telephone, cable or fibre line. A gateway translates between two dissimilar networks, and an access point provides Wi-Fi coverage. Repeaters and bridges extend and segment older networks.

      Protocols you must know

      A protocol is a set of rules for communication. TCP and IP work together: IP is responsible for addressing and routing packets, while TCP ensures that all packets arrive in order and without error. The OSI model divides communication into seven layers, and the simpler TCP/IP model uses four. HTTP and HTTPS transfer web pages, with HTTPS adding encryption. FTP transfers files, SMTP sends email, POP3 and IMAP retrieve email, and DNS translates human-readable domain names into IP addresses. DHCP automatically assigns IP addresses to devices.

      Internet basics and vocabulary

      An IP address identifies a device on a network; IPv4 uses 32-bit addresses in four groups while IPv6 uses 128-bit addresses. A URL is the complete address of a resource, made of the protocol, the domain name and the path. The World Wide Web is a service that runs on the internet and consists of linked hypertext documents. A web browser such as Chrome or Firefox requests pages, and a web server stores and delivers them. Bandwidth measures the amount of data a connection can carry per second, while latency measures the delay. A cookie is a small file that a website stores on the user's computer to remember information.

      Points that are asked again and again

      • Switch works at the data link layer; router works at the network layer.
      • IPv4 is 32-bit and IPv6 is 128-bit.
      • DNS converts domain names to IP addresses.
      • HTTPS uses port 443, HTTP uses port 80, FTP uses ports 20 and 21.
      • Wi-Fi is a wireless LAN technology based on the IEEE 802.11 family of standards.
