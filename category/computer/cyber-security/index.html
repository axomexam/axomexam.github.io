      Cyber Security

      Cyber Security - Complete Notes for Computer Awareness Exams

      Cyber security is one of the fastest growing sections of the computer awareness paper in ADRE, APSC, Assam Police, SSC and Railway recruitment tests. Examiners rarely ask deep technical questions; instead they test whether you understand the basic vocabulary of online safety, the names of common threats and the everyday practices that protect a user, a device and a network. These notes cover every point that has appeared repeatedly in previous papers, followed by a study plan you can finish in a single sitting.

      Why cyber security matters

      Every time you log in to a portal, pay a fee online or download a PDF, data travels between your device and a server. Cyber security is the collection of technologies, processes and habits that keep that data private, correct and available only to the right people. In government recruitment exams the topic is grouped under "Computer Awareness" and carries two to four marks, which are among the easiest to secure because the facts are stable and do not change with current affairs.

      The CIA triad

      Almost every definition in this subject is built on three pillars, together called the CIA triad. Confidentiality means information is readable only by authorised users and is protected by passwords and encryption. Integrity means the data has not been altered in transit, which is guaranteed by checksums and digital signatures. Availability means the service remains reachable when a genuine user needs it, which is why organisations use backups and firewalls. Any attack you read about damages one or more of these three pillars.

      Types of malware you must remember

      A virus attaches itself to a legitimate file and spreads when that file is executed. A worm spreads across a network on its own without any host file or user action. A trojan hides inside software that looks useful and then opens a back door for an attacker. Ransomware encrypts the victim's files and demands payment for the key. Spyware secretly records activity, and keyloggers capture every keystroke to steal passwords. Adware floods the screen with unwanted advertisements, while a rootkit buries itself deep in the operating system so that it is almost impossible to detect. For exams, learn the one-line difference between a virus and a worm, because that comparison is asked very frequently.

      Common attacks and their meanings

      Phishing is a fake email, SMS or website that imitates a trusted brand to trick you into revealing credentials. Pharming redirects a genuine web address to a fraudulent copy without the user noticing. A man-in-the-middle attack secretly relays and possibly alters communication between two parties. Denial of service floods a server with traffic so that real users cannot reach it, and a distributed denial of service does the same from thousands of compromised machines. Brute force repeatedly guesses passwords, SQL injection inserts malicious database commands through an input box, and social engineering simply persuades a person to break a rule.

      Defensive tools and safe habits

      A firewall filters incoming and outgoing traffic against a set of rules. Antivirus software detects and removes known malware using signatures and behaviour analysis. Encryption converts readable plain text into unreadable cipher text, and a digital signature proves that a message came from the stated sender and was not changed. A virtual private network creates an encrypted tunnel over a public network. Two-factor authentication adds a second proof of identity beyond the password. In daily life, use strong and different passwords, keep software updated, avoid public Wi-Fi for banking, verify the padlock and the exact spelling of a URL, and never share an OTP with anyone.

      Quick revision points

      • HTTPS, shown by the padlock, means the connection is encrypted using TLS.
      • A strong password mixes upper and lower case letters, digits and symbols and is at least twelve characters long.
      • Backups protect availability; encryption protects confidentiality; hashing protects integrity.
      • Cyber crime in India is reported through the national portal and the 1930 helpline.

      Revise this page once, then attempt the Cyber Security question set on axomexam in both English and Assamese. If you can explain the CIA triad and name five malware types from memory, you are ready for any question this topic can throw at you.
