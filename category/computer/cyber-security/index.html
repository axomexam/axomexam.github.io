      Cyber Security

      Cyber Security: Threats, Safety and Cyber Laws

      Cyber security questions test whether a candidate can name the common online threats, tell one from another and recall the basic rules of safe internet use and the main provisions of the cyber law. The questions are direct and fact based, so a short, well-organised revision secures this section quickly.

      This deep-study note covers the basic terms, the types of malware, the kinds of attacks, safe practices, encryption and the cyber laws of India, the question patterns, a solving method, the traps examiners set and a preparation plan. After reading it, a candidate should be able to identify a threat or a rule without hesitation.

      Basic Terms

      • Cyber security: the protection of computers, networks and data from online threats and unauthorised access.
      • Cyber crime: any crime committed using a computer or the internet.
      • Malware: malicious software such as a virus, worm, trojan, ransomware or spyware.
      • Virus: a program that attaches itself to a file and spreads when the file is opened.
      • Worm: a program that copies itself and spreads across a network on its own.
      • Trojan horse: harmful code hidden inside a useful-looking program.
      • Ransomware: malware that locks a user's files and demands payment to unlock them.
      • Spyware: software that secretly watches a user's activity and sends the data to someone else.
      • Phishing: tricking a user into giving personal details through fake e-mails, messages or websites.
      • Hacking: gaining unauthorised access to a computer or network.
      • Firewall: a barrier that monitors and filters the traffic entering or leaving a network.
      • Antivirus: software that detects and removes malware.
      • Encryption: converting readable data into a coded form so that only the right person can read it.
      • Password: a secret string of characters used to prove a user's identity.

      Core Concepts and Rules

      • A virus needs a host file and a user action, while a worm spreads by itself over a network.
      • A trojan looks useful but works in secret, and ransomware locks files and asks for money.
      • Phishing, smishing and vishing are the same trick done by e-mail, SMS and voice call.
      • A firewall filters network traffic, and an antivirus scans files and removes malware.
      • Encryption converts plain text into cipher text and decryption reverses it.
      • A strong password is long, mixes letters, digits and symbols and is not reused.
      • Two-factor authentication asks for two proofs, such as a password and a one-time code.
      • A digital signature proves the sender's identity and that a message was not changed.
      • A VPN creates a secure, private channel over a public network.
      • In India cyber crimes are dealt with under the Information Technology Act, 2000.

      Types of Malware and Attacks

      Malware is a general name for harmful software. A virus attaches to a file and runs when the file is opened, and it needs a host. A worm is similar but spreads on its own across a network without a user opening a file. A trojan hides inside a useful-looking program and performs secret harmful work. Ransomware locks files or the whole system and demands a payment to release them. Spyware and keyloggers quietly record activity and keystrokes and send them to the attacker, and adware floods the user with unwanted advertisements. Among attacks, phishing uses fake e-mails or websites to steal details, and its forms by SMS and phone call are called smishing and vishing. A denial-of-service attack floods a service so that real users cannot reach it. Identity theft uses another person's personal details, and social engineering simply tricks a person into revealing secrets.

      Safety Practices and Cyber Laws

      Safe use begins with a strong password that is changed from time to time and never shared, and with two-factor authentication wherever it is offered. Software and the operating system should be updated, an antivirus and a firewall should be kept on, and links and attachments from unknown senders should not be opened. Personal details should not be posted publicly, and public wi-fi should not be used for banking. Data should be backed up, since a backup is the best defence against ransomware. In India the main law is the Information Technology Act, 2000, which was amended in 2008 and deals with offences such as unauthorised access, identity theft, publishing obscene material and cyber terrorism, and it recognises electronic records and digital signatures. The CERT-In is the national agency for responding to cyber security incidents.

      Types of Questions Asked

      The most common pattern asks which threat matches a given description, such as which malware spreads by itself. The second asks the full form or meaning of a term such as VPN or CERT-In. The third asks the name of the Indian cyber law. The fourth asks a safe practice, such as the rule for a strong password. The fifth asks the difference between two terms, such as a virus and a worm. Direct identification questions take most of the marks.

      Steps to Solve a Cyber Security Question

      First, read the question and see whether it asks for a threat, a tool, a rule or a law. Second, if it asks for a threat, match the key clue, such as self-spreading for a worm or locked files for ransomware. Third, if it asks for a tool, recall its one-line job, such as a firewall filtering traffic. Fourth, if it asks for a law, remember the Information Technology Act, 2000. Fifth, remove options that belong to a different category. Finally, check the full form word by word, because one wrong word hides the correct answer.

      Examination Trends

      In Assam recruitment papers malware types, phishing and its forms, encryption, firewall and antivirus, safe practices and the IT Act, 2000 appear most often, followed by terms such as VPN, digital signature, DDoS and identity theft. Questions are short and single fact based, so steady revision is enough. The same definitions repeat with small changes, which makes this section quick to secure.

      Common Mistakes to Avoid

      • Do not confuse a virus with a worm; a worm spreads on its own.
      • Do not confuse a trojan with a virus; a trojan hides inside a useful program.
      • Do not call a firewall an antivirus; both protect, but in different ways.
      • Do not confuse encryption with decryption, since one locks and the other unlocks.
      • Do not forget that the Indian cyber law is the IT Act, 2000.
      • Do not mix phishing, smishing and vishing; they are e-mail, SMS and voice.

      How to Prepare This Topic

      Make a table of the malware types with their one-line definition and one clue that gives each away. Next write the common attacks, such as phishing and denial of service, with one example each. Then list the safe practices, including strong passwords, updating software and using a firewall and antivirus. Finally, write the key points of the IT Act, 2000 and the role of CERT-In.

      Attempt twenty questions a day and keep a register of the definitions and full forms you got wrong, because the same items recur. Revise the difference between a virus and a worm, and between a firewall and an antivirus, aloud, since these are the most common traps. In the last week revise only the tables and the register, and the section will be ready.

      Quick Revision Tips

      • A virus needs a host; a worm spreads on its own.
      • A trojan hides, ransomware locks, spyware watches.
      • Phishing is e-mail, smishing is SMS, vishing is voice.
      • Encryption locks data into cipher text; decryption unlocks it.
      • The Indian cyber law is the Information Technology Act, 2000.

      Final Revision Note

      On the last day, revise the malware table, the safe practices and the IT Act points, then attempt a timed set of twenty questions. For every wrong answer, write the exact term that was missed. Cyber security questions reward clear definitions, and a candidate who has them answers fast and gains easy marks.

      Frequently Asked Questions

      What is the difference between a virus and a worm?

      A virus attaches to a file and spreads when the file is opened, while a worm spreads by itself across a network without user action.

      What is phishing?

      Phishing is tricking a user into revealing personal details through fake e-mails, messages or websites.

      What is the main cyber law of India?

      The Information Technology Act, 2000, amended in 2008, is the main cyber law of India.

      What is the job of a firewall?

      A firewall monitors and filters the traffic entering or leaving a network to block unauthorised access.

      What is ransomware?

      Ransomware is malware that locks a user's files or system and demands a payment to unlock them.

      চাইবাৰ সুৰক্ষা: ভাবুকি, সুৰক্ষা আৰু চাইবাৰ আইন

      Cyber security ৰ প্ৰশ্নই পৰীক্ষা কৰে যে সাধাৰণ online ভাবুকিবোৰ প্ৰাৰ্থীয়ে নাম ল'ব পাৰে নে নাই, এটাক আনটোৰ পৰা বেলেগ কৰিব পাৰে নে নাই, আৰু সুৰক্ষিত internet ব্যৱহাৰৰ মূল নিয়ম আৰু চাইবাৰ আইনৰ মূল ধাৰাবোৰ মনত আছে নে নাই। প্ৰশ্নবোৰ পোনপটীয়া আৰু তথ্যভিত্তিক, গতিকে চুটি কিন্তু সুসংগঠিত পুনৰালোচনাই এই অংশ দ্ৰুতভাৱে জনা যায়।

      এই গভীৰ অধ্যয়ন টোকাত মূল পৰিভাষা, malware ৰ প্ৰকাৰ, আক্ৰমণৰ ধৰণ, সুৰক্ষিত অভ্যাস, encryption আৰু ভাৰতৰ চাইবাৰ আইন, প্ৰশ্নৰ ধৰণ, সমাধানৰ পদ্ধতি, পৰীক্ষকে পতা ফান্দ আৰু প্ৰস্তুতিৰ পৰিকল্পনা দিয়া হৈছে। পঢ়াৰ পিছত প্ৰাৰ্থীয়ে ভাবুকি বা নিয়ম দ্বিধা নকৰি চিনি পাব।

      মূল পৰিভাষা

      • Cyber security: computer, network আৰু data ক online ভাবুকি আৰু অননুমোদিত প্ৰৱেশৰ পৰা সুৰক্ষা দিয়া।
      • Cyber crime: কম্পিউটাৰ বা internet ব্যৱহাৰ কৰি কৰা যিকোনো অপৰাধ।
      • Malware: virus, worm, trojan, ransomware বা spyware ৰ দৰে ক্ষতিকাৰক software।
      • Virus: file এটাত লাগি থকা আৰু file খুলিলে বিয়পি পৰা কাৰ্যসূচী।
      • Worm: নিজে নিজে copy হৈ network ত বিয়পি পৰা কাৰ্যসূচী।
      • Trojan horse: উপকাৰী যেন লগা কাৰ্যসূচীৰ ভিতৰত লুকুৱাই ৰখা ক্ষতিকাৰক code।
      • Ransomware: ব্যৱহাৰকাৰীৰ file বন্ধ কৰি খুলিবলৈ টকা দাবী কৰা malware।
      • Spyware: গোপনে ব্যৱহাৰকাৰীৰ কাম চাই তথ্য আনলৈ পঠিওৱা software।
      • Phishing: ভুৱা e-mail, message বা website ৰে ব্যক্তিগত তথ্য লোৱাৰ ছল।
      • Hacking: কম্পিউটাৰ বা network লৈ অননুমোদিত প্ৰৱেশ লাভ কৰা।
      • Firewall: network লৈ অহা-যোৱা traffic মনিটৰ আৰু filter কৰা বাধা।
      • Antivirus: malware ধৰা পেলাই আঁতৰোৱা software।
      • Encryption: কেৱল সঠিক ব্যক্তিয়ে পঢ়িব পৰাকৈ তথ্যক coded ৰূপলৈ সলোৱা।
      • Password: ব্যৱহাৰকাৰীৰ পৰিচয় প্ৰমাণ কৰিবলৈ ব্যৱহৃত গোপন আখৰৰ শাৰী।

      মুখ্য ধাৰণা আৰু নিয়ম

      • Virus এ host file আৰু ব্যৱহাৰকাৰীৰ কাম বিচাৰে, আনহাতে worm এ নিজে নিজে network ত বিয়পে।
      • Trojan উপকাৰী যেন লাগি গোপনে কাম কৰে, আৰু ransomware য়ে file বন্ধ কৰি টকা বিচাৰে।
      • Phishing, smishing আৰু vishing একেই ছল, ক্ৰমে e-mail, SMS আৰু ফোন কলৰ জৰিয়তে।
      • Firewall এ network traffic filter কৰে, আৰু antivirus এ file scan কৰি malware আঁতৰায়।
      • Encryption য়ে plain text ক cipher text লৈ সলায় আৰু decryption য়ে উলটি কৰে।
      • বলৱান password দীঘল, আখৰ-সংখ্যা-চিহ্ন মিহলি আৰু পুনৰ ব্যৱহাৰ নোহোৱা।
      • Two-factor authentication য়ে দুটা প্ৰমাণ বিচাৰে, যেনে password আৰু এটা one-time code।
      • Digital signature য়ে প্ৰেৰকৰ পৰিচয় আৰু বাৰ্তা সলনি নোহোৱা প্ৰমাণ কৰে।
      • VPN য়ে ৰাজহুৱা network ৰ ওপৰত সুৰক্ষিত, ব্যক্তিগত channel বনায়।
      • ভাৰতত চাইবাৰ অপৰাধ Information Technology Act, 2000 ৰ অধীনত চোৱা হয়।

      Malware আৰু আক্ৰমণৰ প্ৰকাৰ

      Malware হৈছে ক্ষতিকাৰক software ৰ সাধাৰণ নাম। Virus এ file এটাত লাগি থাকে আৰু file খুলিলে চলে, আৰু ই এটা host বিচাৰে। Worm ইয়াৰ দৰেই কিন্তু কোনো file নুখুলাকৈ নিজে নিজে network ত বিয়পে। Trojan এ উপকাৰী যেন লগা কাৰ্যসূচীৰ ভিতৰত লুকাই গোপনে ক্ষতিকাৰক কাম কৰে। Ransomware য়ে file বা গোটেই system বন্ধ কৰি মুকলি কৰিবলৈ টকা দাবী কৰে। Spyware আৰু keylogger এ গোপনে কাম আৰু কি-ষ্ট্ৰোক ৰেকৰ্ড কৰি আক্ৰমণকাৰীলৈ পঠিয়ায়, আৰু adware য়ে অবাঞ্ছিত বিজ্ঞাপনেৰে উপচাই পেলায়। আক্ৰমণৰ ভিতৰত phishing এ ভুৱা e-mail বা website ৰে তথ্য চুৰি কৰে, আৰু SMS আৰু ফোন কলৰ ৰূপক ক্ৰমে smishing আৰু vishing বোলা হয়। Denial-of-service আক্ৰমণে সেৱা এটা উপচাই দিয়ে যাতে প্ৰকৃত ব্যৱহাৰকাৰীয়ে ইয়াক পালোৱা নাপায়। Identity theft য়ে আন এজনৰ ব্যক্তিগত তথ্য ব্যৱহাৰ কৰে, আৰু social engineering য়ে সাধাৰণতে এজন ব্যক্তিক ঠগি গোপন তথ্য উলিয়ায়।

      সুৰক্ষিত অভ্যাস আৰু চাইবাৰ আইন

      সুৰক্ষিত ব্যৱহাৰ আৰম্ভ হয় এটা বলৱান password ৰে, যি সময়ে সময়ে সলাই সদায় গোপন ৰাখিব লাগে, আৰু য'ত পোৱা যায় তাত two-factor authentication ৰে। Software আৰু operating system আপডেট কৰি ৰাখিব লাগে, antivirus আৰু firewall জ্বলাই ৰাখিব লাগে, আৰু অচিনাকি প্ৰেৰকৰ link বা attachment নুখুলিব। ব্যক্তিগত তথ্য ৰাজহুৱাভাৱে নিদিব, আৰু ৰাজহুৱা wi-fi ত banking নকৰিব। তথ্যৰ backup ৰাখিব, কাৰণ ransomware ৰ বিৰুদ্ধে backup হৈছে শ্ৰেষ্ঠ সুৰক্ষা। ভাৰতত মূল আইন হৈছে Information Technology Act, 2000, যি 2008 চনত সংশোধন কৰা হয় আৰু অননুমোদিত প্ৰৱেশ, identity theft, অশ্লীল সমল প্ৰকাশ আৰু cyber terrorism ৰ দৰে অপৰাধ চম্ভালে, লগতে electronic record আৰু digital signature মানি লয়। CERT-In হৈছে চাইবাৰ সুৰক্ষা ঘটনাৰ প্ৰতিক্ৰিয়াৰ ৰাষ্ট্ৰীয় সংস্থা।

      সোধা প্ৰশ্নৰ প্ৰকাৰ

      আটাইতকৈ বেছি অহা ধৰণ হ'ল দিয়া বৰ্ণনাৰ লগত কোন ভাবুকি মিলে সোধা, যেনে কোন malware নিজে নিজে বিয়পে। দ্বিতীয়ত VPN বা CERT-In ৰ দৰে শব্দৰ full form বা অৰ্থ সোধা হয়। তৃতীয়ত ভাৰতৰ চাইবাৰ আইনৰ নাম সোধা হয়। চতুৰ্থত সুৰক্ষিত অভ্যাস এটা, যেনে বলৱান password ৰ নিয়ম, সোধা হয়। পঞ্চমত virus আৰু worm ৰ দৰে দুটা শব্দৰ পাৰ্থক্য সোধা হয়। পোনপটীয়া চিনাক্তকৰণ প্ৰশ্নই বেছি নম্বৰ লয়।

      Cyber Security প্ৰশ্ন সমাধানৰ স্তৰ

      প্ৰথমে প্ৰশ্ন পঢ়ি ই ভাবুকি, সঁজুলি, নিয়ম নে আইন বিচাৰে চাওক। দ্বিতীয়ে ভাবুকি হ'লে মূল সূত্ৰটো মিলাওক, যেনে নিজে বিয়পাৰ বাবে worm বা file বন্ধৰ বাবে ransomware। তৃতীয়ে সঁজুলি হ'লে তাৰ এশাৰী কাম মনত পেলাওক, যেনে firewall এ traffic filter কৰে। চতুৰ্থে আইন হ'লে Information Technology Act, 2000 মনত ৰাখক। পঞ্চমে বেলেগ শ্ৰেণীৰ বিকল্প আতৰাওক। শেষত full form শব্দে শব্দে পৰীক্ষা কৰক, কাৰণ এটা ভুল শব্দই শুদ্ধ উত্তৰ লুকুৱায়।

      পৰীক্ষাৰ প্ৰৱণতা

      অসমৰ নিয়োগ পৰীক্ষাত malware ৰ প্ৰকাৰ, phishing আৰু তাৰ ৰূপ, encryption, firewall আৰু antivirus, সুৰক্ষিত অভ্যাস আৰু IT Act, 2000 আটাইতকৈ বেছি আহে, তাৰ পিছত VPN, digital signature, DDoS আৰু identity theft ৰ দৰে শব্দ। প্ৰশ্ন চুটি আৰু এটা তথ্যভিত্তিক, গতিকে নিয়মীয়া পুনৰালোচনেই যথেষ্ট। একেই সংজ্ঞা সৰু সালসলনিৰে পুনৰ আহে, যাৰ ফলত এই অংশ দ্ৰুতভাৱে জনা যায়।

      সাধাৰণ ভুল

      • Virus আৰু worm মিলাই নিদিব; worm এ নিজে নিজে বিয়পে।
      • Trojan আৰু virus মিলাই নিদিব; trojan এ উপকাৰী কাৰ্যসূচীৰ ভিতৰত লুকায়।
      • Firewall ক antivirus নুবুলিব; দুয়োৱে সুৰক্ষা দিয়ে, কিন্তু বেলেগ ধৰণে।
      • Encryption আৰু decryption মিলাই নিদিব, এটাই বন্ধ কৰে আনটোৱে খোলে।
      • ভাৰতৰ চাইবাৰ আইন IT Act, 2000 যে, নাপাহৰিব।
      • Phishing, smishing আৰু vishing মিলাই নিদিব; সিহঁত e-mail, SMS আৰু voice।

      প্ৰস্তুতি কেনেকৈ কৰিব

      Malware ৰ প্ৰকাৰ আৰু সিহঁতৰ এশাৰী সংজ্ঞা, লগতে প্ৰতিটোক চিনাক্ত কৰা এটা সূত্ৰ লৈ তালিকা বনাওক। তাৰ পিছত phishing আৰু denial of service ৰ দৰে সাধাৰণ আক্ৰমণ, প্ৰতিটোৰ এটা উদাহৰণ সৈতে লিখক। তাৰ পিছত বলৱান password, software আপডেট আৰু firewall-antivirus ৰ দৰে সুৰক্ষিত অভ্যাস লিখক। শেষত IT Act, 2000 ৰ মূল কথা আৰু CERT-In ৰ ভূমিকা লিখক।

      দিনে কুৰিটা প্ৰশ্ন কৰি ভুল হোৱা সংজ্ঞা আৰু full form ৰ এখন তালিকা ৰাখক, কাৰণ একেই বস্তু পুনৰ আহে। Virus আৰু worm ৰ, লগতে firewall আৰু antivirus ৰ পাৰ্থক্য উচ্চস্বৰে পুনৰালোচনা কৰক, কাৰণ এয়াই আটাইতকৈ সাধাৰণ ফান্দ। শেষ সপ্তাহত কেৱল তালিকা আৰু ৰেজিষ্টাৰ চাওক, তেতিয়া এই অংশ সাজু হ'ব।

      দ্ৰুত পুনৰালোচনাৰ টিপছ

      • Virus এ host বিচাৰে; worm এ নিজে নিজে বিয়পে।
      • Trojan লুকায়, ransomware বন্ধ কৰে, spyware চায়।
      • Phishing e-mail, smishing SMS, vishing voice।
      • Encryption য়ে data ক cipher text ত বন্ধ কৰে; decryption য়ে খোলে।
      • ভাৰতৰ চাইবাৰ আইন Information Technology Act, 2000।

      শেষ পুনৰালোচনা

      শেষ দিনা malware ৰ তালিকা, সুৰক্ষিত অভ্যাস আৰু IT Act ৰ কথা পুনৰালোচনা কৰি কুৰিটা প্ৰশ্নৰ সময়বদ্ধ সংহতি কৰক। প্ৰতিটো ভুল উত্তৰৰ বাবে বাদ পৰা শব্দটো লিখি ৰাখক। Cyber security ৰ প্ৰশ্নই স্পষ্ট সংজ্ঞা বিচাৰে, আৰু সংজ্ঞা জনা প্ৰাৰ্থীয়ে দ্ৰুতভাৱে উত্তৰ দি সহজ নম্বৰ পায়।

      সঘনাই সোধা প্ৰশ্ন

      Virus আৰু worm ৰ পাৰ্থক্য কি?

      Virus এ file এটাত লাগি থাকে আৰু file খুলিলে বিয়পে, আনহাতে worm এ ব্যৱহাৰকাৰীৰ কাম নালাগে নিজে নিজে network ত বিয়পে।

      Phishing কি?

      Phishing হৈছে ভুৱা e-mail, message বা website ৰে ব্যক্তিগত তথ্য উলিওৱাৰ ছল।

      ভাৰতৰ মূল চাইবাৰ আইন কি?

      Information Technology Act, 2000, যি 2008 চনত সংশোধন কৰা হয়, ভাৰতৰ মূল চাইবাৰ আইন।

      Firewall ৰ কাম কি?

      Firewall এ network লৈ অহা-যোৱা traffic মনিটৰ আৰু filter কৰি অননুমোদিত প্ৰৱেশ ৰোধ কৰে।

      Ransomware কি?

      Ransomware হৈছে এনে malware, যি ব্যৱহাৰকাৰীৰ file বা system বন্ধ কৰি মুকলি কৰিবলৈ টকা দাবী কৰে।
