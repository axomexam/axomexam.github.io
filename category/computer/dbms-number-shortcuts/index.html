      DBMS, Number System & Shortcuts

      DBMS Basics and Number System Shortcuts

      This topic combines two small but reliable scoring areas of the computer awareness paper: database management and the number systems of digital electronics. In ADRE, APSC, Assam Police, SSC and Railway exams you will usually see one or two questions from each. The database part is vocabulary-based, while the number system part rewards a candidate who knows a few fast conversion tricks. Both are covered below.

      What a database and a DBMS are

      A database is an organised collection of related data stored so that it can be retrieved, updated and managed efficiently. A database management system, or DBMS, is the software that creates, stores and controls that data. Examples include MySQL, Oracle, Microsoft SQL Server, PostgreSQL and SQLite. A relational database stores data in tables, also called relations, and links them through common fields. A record or row is one complete entry, and a field or column is one attribute of that entry. The degree of a table is its number of columns and the cardinality is its number of rows.

      Keys and SQL

      A primary key uniquely identifies each record and cannot be null or duplicated. A candidate key is any field that could serve as a primary key, a foreign key in one table refers to the primary key of another table and creates a relationship, and a composite key is made of two or more fields. SQL, the structured query language, is the standard language for working with relational databases. SELECT retrieves data, INSERT adds a record, UPDATE modifies it, DELETE removes it, and CREATE builds a table or database. Normalisation is the process of organising data to reduce redundancy and improve integrity.

      Number systems

      Digital computers use the binary system, which has only the digits zero and one. The decimal system has ten digits, the octal system has eight and uses digits zero to seven, and the hexadecimal system has sixteen and uses digits zero to nine plus the letters A to F for the values ten to fifteen. The base of a number system is the count of symbols it uses: two for binary, eight for octal, ten for decimal and sixteen for hexadecimal.

      Shortcut conversion tricks

      To convert binary to decimal, write powers of two from right to left above each digit and add the powers where the digit is one. To convert decimal to binary, repeatedly divide by two and read the remainders from bottom to top. Octal and hexadecimal are easy partners of binary because each octal digit equals exactly three binary bits and each hexadecimal digit equals exactly four bits. So to change binary to octal, group the bits in threes from the right; to change binary to hexadecimal, group them in fours from the right. To convert decimal to octal, divide repeatedly by eight, and to convert decimal to hexadecimal, divide repeatedly by sixteen, remembering to write the remainder as a letter when it is ten or more.

      Frequently asked conversions

      • Decimal 10 is binary 1010, octal 12 and hexadecimal A.
      • Decimal 15 is binary 1111 and hexadecimal F.
      • Binary 1100 is decimal 12 and hexadecimal C.
      • One kilobyte is 1024 bytes, and 1024 equals two to the power ten.

      Number conversion becomes fast only with practice. Work through ten conversions on paper today, then attempt the DBMS and number system questions on axomexam in both languages.
