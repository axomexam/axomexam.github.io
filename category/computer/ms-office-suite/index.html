      MS Office Suite

      MS Office Suite - Notes and Shortcuts for Computer Awareness

      The Microsoft Office suite is the most frequently tested office application family in Indian recruitment exams. Questions on Word, Excel and PowerPoint appear in ADRE, APSC, Assam Police, SSC, Railway and court-clerk papers because these tools are used daily in government offices. This guide summarises what each application does, the features and shortcuts that examiners love, and the file formats you must recognise at a glance.

      Why MS Office is asked

      Recruitment boards assume that a candidate joining a government office will prepare letters, maintain data tables and make presentations. The computer awareness section therefore checks whether you know what each component of the suite is used for and whether you can identify common commands and their keyboard shortcuts. The questions are factual, so a single revision of the tables below is usually enough.

      Microsoft Word

      Word is a word processor used to create, format and print text documents such as letters, notices and reports. Important features include styles and themes, page layout and margins, headers and footers, mail merge for sending the same letter to many recipients, track changes for review, tables, and find and replace. Word files are saved with the .docx extension in modern versions and .doc in older versions. Mail merge is the single most repeated Word topic in exams because it combines a main document with a data source.

      Microsoft Excel

      Excel is a spreadsheet program used for calculation, analysis and charts. A file is called a workbook, which contains worksheets made of columns labelled A, B, C and rows labelled 1, 2, 3. The intersection of a row and a column is a cell, and the active cell is shown in the name box. A formula always begins with the equals sign. The most useful functions are SUM, AVERAGE, COUNT, MIN, MAX, IF, and the lookup functions VLOOKUP and HLOOKUP. Cells can be referenced relatively, absolutely with the dollar sign, or mixed. Charts such as column, line and pie visually present the data. Excel files use the .xlsx extension.

      Microsoft PowerPoint

      PowerPoint is a presentation program. A presentation is a series of slides, each of which can hold text boxes, images, charts and media. The slide master controls the design of every slide, transitions control how one slide changes into the next, and animations control how individual objects appear. A presentation can be run as a slide show with the F5 key. The standard extension is .pptx. Do not confuse a transition, which applies between slides, with an animation, which applies to an object on a slide.

      Shortcuts worth memorising

      • Ctrl + C copy, Ctrl + X cut, Ctrl + V paste, Ctrl + Z undo, Ctrl + Y redo.
      • Ctrl + B bold, Ctrl + I italic, Ctrl + U underline, Ctrl + S save, Ctrl + P print.
      • Ctrl + N new file, Ctrl + O open, Ctrl + F find, Ctrl + A select all.
      • In Excel, F2 edits the active cell, Alt + equals inserts AutoSum, and Ctrl + Arrow moves to the edge of the data.

      Other components

      Access is a database management program, Outlook handles email and calendars, Publisher designs newsletters and posters, and OneNote is used for digital note-taking. Together with Word, Excel and PowerPoint these make up the Office suite. For most state exams you only need to know the purpose and file extension of each.
