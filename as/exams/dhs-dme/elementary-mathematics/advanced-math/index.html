    Q1. If x + 1/x = 3, then the value of x² + 1/x² is:
    (A) 7
    (B) 9
    (C) 5
    (D) 11
    Answer: A) 7

    Explanation: x² + 1/x² = (x + 1/x)² − 2 = 3² − 2 = 7.

    (A) 0
    (B) abc
    (C) 3abc
    (D) 2abc
    Answer: C) 3abc
    a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) সূত্ৰ ব্যৱহাৰ কৰি, a + b + c = 0 হোৱাত a³ + b³ + c³ = 3abc।
    Explanation: Using a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca); since a + b + c = 0, we get a³ + b³ + c³ = 3abc.
