    ৮০ টা প্ৰশ্ন আৰু উত্তৰ

    ১. CPU-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) চেণ্ট্ৰেল প্ৰচেছিং ইউনিট (Central Processing Unit)
    (B) চেণ্ট্ৰেল প্ৰগ্ৰাম ইউনিট (Central Program Unit)
    (C) কম্পিউটাৰ পাৰ্ছনেল ইউনিট (Computer Personal Unit)
    (D) কণ্ট্ৰোল প্ৰচেছিং ইউনিট (Control Processing Unit)
    উত্তৰ: A) চেণ্ট্ৰেল প্ৰচেছিং ইউনিট
    ব্যাখ্যা: CPU ৰ সম্পূৰ্ণ ৰূপ Central Processing Unit। ই কম্পিউটাৰৰ মূল অংশ যি সকলো নিৰ্দেশ আৰু তথ্য প্ৰক্ৰিয়া কৰে।
    ২. কম্পিউটাৰৰ মস্তিষ্ক কি?
    (A) CPU
    (B) মনিটৰ (Monitor)
    (C) কীব’ৰ্ড (Keyboard)
    (D) মাউছ (Mouse)
    ব্যাখ্যা: CPU ক কম্পিউটাৰৰ মগজু বুলি কোৱা হয় কাৰণ ই সকলো গণনা কৰে আৰু প্ৰতিটো কাৰ্য নিয়ন্ত্ৰণ কৰে।
    Answer: A) CPU
    ৩. তলৰ কোনটো ইনপুট ডিভাইচ?
    (A) কীব’ৰ্ড (Keyboard)
    (B) প্ৰিণ্টাৰ (Printer)
    (C) স্পীকাৰ (Speaker)
    (D) মনিটৰ (Monitor)
    উত্তৰ: A) কীব’ৰ্ড
    ব্যাখ্যা: কীবৰ্ড এটা ইনপুট সঁজুলি। ইয়াৰ দ্বাৰা কম্পিউটাৰত লিখা, সংখ্যা আৰু নিৰ্দেশ প্ৰৱেশ কৰা হয়।
    ৪. তলৰ কোনটো আউটপুট ডিভাইচ?
    (A) প্ৰিণ্টাৰ (Printer)
    (B) স্কেনাৰ (Scanner)
    (C) মাউছ (Mouse)
    (D) মাইক্ৰফোন (Microphone)
    উত্তৰ: A) প্ৰিণ্টাৰ
    ব্যাখ্যা: প্ৰিণ্টাৰ এটা আউটপুট সঁজুলি। ই নথিপত্ৰ আৰু ছবিৰ কাগজত ছপা প্ৰতি (hard copy) বনায়।
    ৫. RAM-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ৰেণ্ডম এক্সেছ মেমেৰী (Random Access Memory)
    (B) ৰিড এক্সেছ মেমেৰী (Read Access Memory)
    (C) ৰেডি এপ্লিকেচন মডিউল (Ready Application Module)
    (D) ৰান অল মেমেৰী (Run All Memory)
    উত্তৰ: A) ৰেণ্ডম এক্সেছ মেমেৰী
    ব্যাখ্যা: RAM ৰ সম্পূৰ্ণ ৰূপ Random Access Memory। ই বৰ্তমান ব্যৱহৃত তথ্য আৰু প্ৰগ্ৰাম অস্থায়ীভাৱে সংৰক্ষণ কৰে।
    ৬. ROM-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ৰিড অনলি মেমেৰী (Read Only Memory)
    (B) ৰেণ্ডম অনলি মেমেৰী (Random Only Memory)
    (C) ৰান অনলি মেমেৰী (Run Only Memory)
    (D) ৰেপিড অপেন মেমেৰী (Rapid Open Memory)
    উত্তৰ: A) ৰিড অনলি মেমেৰী
    ব্যাখ্যা: ROM ৰ সম্পূৰ্ণ ৰূপ Read Only Memory। ইয়াৰ তথ্য স্থায়ী আৰু সাধাৰণতে কেৱল পঢ়িব পাৰি, সলনি কৰিব নোৱাৰি।
    ৭. কোন মেমেৰী ভলেটাইল?
    (A) RAM
    (B) ROM
    (C) হাৰ্ড ডিস্ক (Hard disk)
    (D) CD-ROM
    ব্যাখ্যা: RAM অস্থিৰ (volatile) স্মৃতি, অৰ্থাৎ কম্পিউটাৰ বন্ধ কৰিলে ইয়াৰ তথ্য মচ যায়।
    Answer: A) RAM
    ৮. ১ বাইট কিমানৰ সমান?
    (A) ৪ বিট (4 bits)
    (B) ৮ বিট (8 bits)
    (C) ২ বিট (2 bits)
    (D) ১৬ বিট (16 bits)
    উত্তৰ: B) ৮ বিট
    ব্যাখ্যা: ১ বাইট = ৮ বিট। বিট হৈছে তথ্যৰ আটাইতকৈ সৰু একক, যাৰ মান ০ বা ১ হয়।
    ৯. ১ কিলোবাইট (KB) কিমানৰ সমান?

    (B) ১০২৪ বাইট (1024 bytes)
    (C) ১০২৪ বিট (1024 bits)
    (D) ১০০ বাইট (100 bytes)
    উত্তৰ: B) ১০২৪ বাইট
    ব্যাখ্যা: ১ কিলবাইট (KB) = ১০২৪ বাইট।
    ১০. কম্পিউটাৰত তথ্যৰ আটাইতকৈ সৰু একক কি?

    (B) বিট (Bit)
    (C) নিবল (Nibble)
    (D) ৱৰ্ড (Word)
    উত্তৰ: B) বিট
    ব্যাখ্যা: কম্পিউটাৰত তথ্যৰ আটাইতকৈ সৰু একক হৈছে বিট, যি ০ বা ১ ৰূপত প্ৰকাশ পায়।
    ১১. MS Word কিৰ উদাহৰণ?
    (A) অপাৰেটিং চিষ্টেম (Operating system)
    (B) এপ্লিকেচন ছফটৱেৰ (Application software)
    (C) হাৰ্ডৱেৰ (Hardware)
    (D) ক’ম্পাইলাৰ (Compiler)
    উত্তৰ: B) এপ্লিকেচন ছফটৱেৰ
    ব্যাখ্যা: MS Word এপ্লিকেশ্যন চফটৱেৰ, যি নথিপত্ৰ সাজিব, সম্পাদনা আৰু ফৰ্মেট কৰিবলৈ ব্যৱহাৰ হয়।
    ১২. Windows কিৰ উদাহৰণ?
    (A) এপ্লিকেচন ছফটৱেৰ (Application software)
    (B) অপাৰেটিং চিষ্টেম (Operating system)
    (C) প্ৰগ্ৰামিং ভাষা (Programming language)
    (D) হাৰ্ডৱেৰ (Hardware)
    উত্তৰ: B) অপাৰেটিং চিষ্টেম
    ব্যাখ্যা: Windows এটা অপাৰেটিং ছিষ্টেম যি কম্পিউটাৰৰ হাৰ্ডৱেৰ, চফটৱেৰ আৰু ফাইল পৰিচালনা কৰে।
    ১৩. তলৰ কোনটো হাৰ্ডৱেৰ?
    (A) MS Excel
    (B) মাউছ (Mouse)
    (C) Linux
    (D) Google Chrome
    উত্তৰ: B) মাউছ
    ব্যাখ্যা: মাউছ হাৰ্ডৱেৰ। হাৰ্ডৱেৰ মানে কম্পিউটাৰৰ ভৌতিক অংশ যিবোৰ স্পৰ্শ কৰিব পাৰি।
    ১৪. ALU-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) এপ্লিকেচন লজিক ইউনিট (Application Logic Unit)
    (B) এৰে লজিক ইউনিট (Array Logic Unit)
    (C) এৰিথমেটিক লজিক ইউনিট (Arithmetic Logic Unit)
    (D) এডভান্সড লজিক ইউনিট (Advanced Logic Unit)
    উত্তৰ: C) এৰিথমেটিক লজিক ইউনিট
    ব্যাখ্যা: ALU ৰ সম্পূৰ্ণ ৰূপ Arithmetic Logic Unit। ই CPU ৰ ভিতৰত গাণিতিক আৰু যুক্তিমূলক কাৰ্য সম্পাদন কৰে।
    ১৫. কাৰ্ছৰৰ বাওঁফালৰ আখৰ মচিবলৈ কোন কি ব্যৱহাৰ হয়?

    (B) Shift
    (C) Backspace
    (D) Tab

    ১৮. WWW-ৰ সম্পূৰ্ণ অৰ্থ কি?

    ব্যাখ্যা: WWW ৰ সম্পূৰ্ণ ৰূপ World Wide Web। ই ইণ্টাৰনেটত উপলব্ধ ৱেবপৃষ্ঠাৰ সংগ্ৰহ।
    ১৯. HTTP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) হাইপাৰ টেক্সট ট্ৰান্সফাৰ প্লান (Hyper Text Transfer Plan)
    (B) হাই টেক্সট ট্ৰান্সফাৰ প্ৰট’কল (High Text Transfer Protocol)
    (C) হাইপাৰ টেক্সট ট্ৰান্সফাৰ প্ৰট’কল (Hyper Text Transfer Protocol)
    (D) হাইপাৰ টুল ট্ৰান্সফাৰ প্ৰট’কল (Hyper Tool Transfer Protocol)
    উত্তৰ: C) হাইপাৰ টেক্সট ট্ৰান্সফাৰ প্ৰট’কল
    ব্যাখ্যা: HTTP ৰ সম্পূৰ্ণ ৰূপ Hyper Text Transfer Protocol। ই ৱেবত তথ্য কেনেকৈ স্থানান্তৰ হয় তাৰ নিয়ম নিৰ্ধাৰণ কৰে।
    ২০. কম্পিউটাৰ ভাইৰাছ কি?

    (B) এটা প্ৰিণ্টাৰ (A type of printer)
    (C) এটা ইনপুট ডিভাইচ (An input device)

    উত্তৰ: D) এটা ক্ষতিকাৰক প্ৰগ্ৰাম
    ব্যাখ্যা: কম্পিউটাৰ ভাইৰাছ এটা ক্ষতিকাৰক প্ৰগ্ৰাম যি নিজকে কপি কৰি ফাইলৰ ক্ষতি বা চিষ্টেম লেহেম কৰিব পাৰে।
    ২১. তলৰ কোনটো অপাৰেটিং চিষ্টেমৰ উদাহৰণ?

    (B) Adobe Photoshop

    ২২. USB-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ইউনাইটেড ছিৰিয়েল বাছ (United Serial Bus)

    ব্যাখ্যা: USB ৰ সম্পূৰ্ণ ৰূপ Universal Serial Bus। ই কম্পিউটাৰৰ সৈতে সঁজুলি সংযোগ কৰিবলৈ ব্যৱহৃত এটা সাধাৰণ প'ৰ্ট।
    ২৩. IP ঠিকনাত IP-ৰ অৰ্থ কি?

    (C) ইনপুট প্ৰট’কল (Input Protocol)
    (D) ইণ্টাৰনেট প্ৰট’কল (Internet Protocol)
    উত্তৰ: D) ইণ্টাৰনেট প্ৰট’কল
    ব্যাখ্যা: IP address ত IP ৰ অৰ্থ Internet Protocol, যি নেটৱৰ্কত সঁজুলি চিনাক্ত আৰু অৱস্থিত কৰে।
    ২৪. তলৰ কোনটো স্থায়ী সংৰক্ষণ?

    ব্যাখ্যা: হাৰ্ড ডিস্ক স্থায়ী গৌণ সংৰক্ষণ। বিদ্যুৎ বন্ধ হ'লেও ইয়াত থকা তথ্য থাকে।
    ২৫. টেলিফোন লাইনৰ জৰিয়তে কম্পিউটাৰ ইণ্টাৰনেটত সংযোগ কৰা পৰম্পৰাগত যন্ত্ৰ কি?

    ২৬. কম্পিউটাৰত তথ্যৰ আটাইতকৈ সৰু একক কোনটো?

    ২৭. ১ KB কিমান বাইটৰ সমান?
