    সূচকৰ নিয়মবোৰেই অধ্যায়টোৰ ইঞ্জিন। একে ভূমিৰ দুটা ঘাত পূৰণ কৰিলে ঘাতাংকবোৰ যোগ হয়, গতিকে ২^৩ গুণ ২^৪ = ২^৭, যি এশ আঠাইশ। হৰণ কৰিলে ঘাতাংকবোৰ বিয়োগ হয়, গতিকে ৫^৬ ÷ ৫^৪ = ৫^২, যি পঁচিশ। এটা ঘাতক আকৌ ঘাতলৈ কৰিলে ঘাতাংকবোৰ পূৰণ হয়, গতিকে (২^৩)^২ = ২^৬, যি চৌষষ্ঠি। শূন্য নহ'ল যিকোনো ভূমিৰ ঘাত শূন্য হ'লে মান এক, আৰু ঋণাত্মক ঘাতাংকে প্ৰতিক্ৰম বুজায়, গতিকে ২^−৩ = ১/২^৩, যি এক-অষ্টমাংশ।

    ভগ্ন ঘাতাংকে ঘাত আৰু মূল সংযোগ কৰে। এক-দ্বিতীয়াংশ ঘাত মানে বৰ্গমূল, গতিকে ১৬^(১/২) = ৪। এক-তৃতীয়াংশ ঘাত মানে ঘনমূল, গতিকে ২৭^(১/৩) = ৩। দুই-তৃতীয়াংশৰ দৰে ঘাত মানে ঘনমূলক বৰ্গলৈ তোলা, গতিকে ৬৪^(২/৩) = ৪^২ = ১৬। এটা ভগ্ন ঘাতাংকক প্ৰথমে এটা মূল তাৰ পিছত এটা ঘাত হিচাপে, নাইবা প্ৰথমে এটা ঘাত তাৰ পিছত এটা মূল হিচাপে পঢ়াটোৱেই দক্ষতা, আৰু ক্ৰমে উত্তৰ নসলায়।

    এটা কৰণীক প্ৰায়ে এটা পূৰ্ণবৰ্গ উলিয়াই সৰল কৰিব পাৰি। √৮ = √(৪×২) = ২√২। একেদৰে √১২ = ২√৩, √১৮ = ৩√২, √৩২ = ৪√২, √৫০ = ৫√২, আৰু √৭৫ = ৫√৩। নিয়মটো হৈছে মূলৰ তলৰ সংখ্যাটোক আটাইতকৈ ডাঙৰ পূৰ্ণবৰ্গ উৎপাদক আৰু বাকী অংশত ভাগ কৰা, তাৰ পিছত সেই উৎপাদকৰ বৰ্গমূল সন্মুখত উলিওৱা।

    কৰণীবোৰ যোগ বা বিয়োগ কৰোঁতে বীজগণিতীয় পদ যেনেদৰে ব্যৱহাৰ কৰা হয়। কেৱল সদৃশ কৰণী, অৰ্থাৎ মূলৰ তলত একে সংখ্যা থকা কৰণী, একত্ৰিত কৰিব পাৰি, গতিকে ২√৩ + ৩√৩ = ৫√৩, আৰু ৫√২ − ২√২ = ৩√২। √১৮ আৰু √৮ যোগ কৰিবলৈ প্ৰথমে প্ৰতিটোক ৩√২ আৰু ২√২ লৈ সৰল কৰক, তাৰ পিছত যোগ কৰি ৫√২ পাওক। পূৰণ আৰু হৰণ সহজ, কাৰণ মূলবোৰ একত্ৰিত কৰিব পাৰি: √২ × √৮ = √১৬ = ৪, আৰু √(১৬/২৫) = ৪/৫।

    হৰমূলদকৰণে এটা ভগ্নাংশৰ তলৰ পৰা মূল আঁতৰায়, যি উত্তৰৰ মানক চূড়ান্ত ৰূপ। ১/√২ হৰমূলদ কৰিবলৈ ওপৰ আৰু তলক √২ ৰে পূৰণ কৰক, যি √২/২ দিয়ে। হৰটো √২+১ ৰ দৰে এটা যোগফল বা পাৰ্থক্য হ'লে ইয়াৰ সংযুগ্মৰে পূৰণ কৰক, যি দ্বিতীয় পদৰ চিহ্ন সলনি কৰি পোৱা একেই ৰাশি। গতিকে ১/(√২+১) = √২−১ হয়, কাৰণ হৰটো ২−১ = ১ হয়।

    সংযুগ্ম ভালদৰে বুজি লোৱা উচিত, কাৰণ ই এটা গোটেই প্ৰশ্ন-পৰিয়ালৰ চাবি। এটা ৰাশি আৰু ইয়াৰ সংযুগ্মৰ গুণফলে দুটা বৰ্গৰ পাৰ্থক্য ব্যৱহাৰ কৰে, গতিকে (√৫+√২)(√৫−√২) = ৫−২ = ৩, এটা পৰিমেয় সংখ্যা। এইটোৱেই হ'ল সংযুগ্মৰে পূৰণ কৰিলে হৰৰ পৰা মূল আঁতৰি যায়, আৰু একেই ধাৰণাই ১/(√৭+√৫) ৰ দৰে প্ৰশ্নৰ উত্তৰ দিয়ে, যি (√৭−√৫)/২ হয়।

    কৰণী তুলনা কৰা এটা নিজা প্ৰশ্ন-প্ৰকাৰ। যিহেতু বৰ্গমূল ফলন ইয়াৰ যুক্তিৰ সৈতে বাঢ়ে, মূলৰ তলত ডাঙৰ সংখ্যাই ডাঙৰ মূল দিয়ে, গতিকে √৫ > √৩। কৰণীৰ গুণাংক থাকিলে তুলনা কৰাৰ আগতে গুণাংকটো মূলৰ ভিতৰলৈ আনক: ২√৩ = √১২ আৰু ৩√২ = √১৮, গতিকে ৩√২ ডাঙৰ। একেই পদ্ধতিয়ে দেখুৱায় √৮ আৰু ২√২ সমান, কাৰণ ৮ = ৪ × ২।

    সূচকৰ সমীকৰণ দুয়ো ফালৰ ভূমি একে কৰি সমাধান কৰা হয়। যদি ২^x = ৩২, ৩২ ক ২^৫ হিচাপে লিখক, গতিকে x = ৫। যদি ৩^x = ৮১, ৮১ ক ৩^৪ হিচাপে লিখক, গতিকে x = ৪। যদি অজ্ঞাত ৰাশিটো এটা গুণাংকৰ সৈতে ঘাতাংকত থাকে, যেনে ২^(২x) = ১৬, ১৬ ক ২^৪ হিচাপে লিখক, গতিকে ২x = ৪ আৰু x = ২। ভূমি এটা ভগ্নাংশ হ'লেও একেই পদ্ধতি কাম কৰে, গতিকে (১/২)^x = ১/৮ ত x = ৩।

    আৰু দুটা তথ্য পোনপটীয়া প্ৰশ্ন হিচাপে আহে। শূন্য নহ'ল যিকোনো সংখ্যাক শূন্যৰে হৰণ কৰাৰ মান অসংজ্ঞায়িত, আৰু ঋণাত্মক সংখ্যাৰ বৰ্গমূল এটা বাস্তৱ সংখ্যা নহয়, গতিকে এনে এটা বিকল্প ভুল। দহৰ ঘাতত অংকৰ সংখ্যা ঘাতাংক যোগ এক, গতিকে ১০^৫ ত ছয়টা অংক। সৰু সংখ্যাৰ ঘাত মনত ৰাখিলে, যেনে ২^১০ = ১০২৪ আৰু ৩^৪ = ৮১, পোনপটীয়া-মানৰ প্ৰশ্নৰ পৰা প্ৰায় গোটেই পৰিশ্ৰম আঁতৰি যায়।

    এটা কৰণীৰ ক্ৰম হৈছে মূলৰ সূচকাংক। বৰ্গমূলৰ ক্ৰম দুই, ঘনমূলৰ ক্ৰম তিনি, আদি, গতিকে ∛৮ ৰ ক্ৰম তিনি। মূলৰ তলৰ সংখ্যাটোক কৰণীয় বোলা হয়। দুটা কৰণীক সদৃশ কৰণী বোলা হয় যেতিয়া সিহঁতৰ একেই ক্ৰম আৰু একেই কৰণীয় থাকে, আৰু কেৱল সদৃশ কৰণীক পোনপটীয়াকৈ যোগ বা বিয়োগ কৰিব পাৰি। ক্ৰম আৰু কৰণীয় চিনি পোৱাটোৱেই প্ৰায় প্ৰতিটো কৰণী-সৰলীকৰণৰ প্ৰথম পদক্ষেপ।

    এই অধ্যায়ৰ প্ৰস্তুতিৰ আটাইতকৈ ভাল উপায় হৈছে সূচকৰ নিয়ম, ভগ্ন আৰু ঋণাত্মক ঘাতাংকৰ অৰ্থ, অন্ততঃ ত্ৰিশলৈকে পূৰ্ণবৰ্গ আৰু অন্ততঃ পোন্ধৰলৈকে পূৰ্ণঘন, আৰু মানক কৰণী-সৰলীকৰণ মনত ৰখা। এটা মিশ্ৰ ৰাশিক এটা ঘাতলৈ সলনিওৱাৰ অভ্যাস কৰক, আৰু যোগফল বা পাৰ্থক্য থকা হৰ হৰমূলদ কৰাৰ অভ্যাস কৰক। এই সঁজুলিবোৰৰ সৈতে প্ৰশ্নপত্ৰৰ কৰণী আৰু সূচকৰ প্ৰশ্নবোৰ নিৰ্ভৰযোগ্য, সূত্ৰ-চালিত নম্বৰ হৈ পৰে।

    সূচকৰ নিয়মবোৰ প্ৰয়োগ কৰোঁতে এটা সাধাৰণ ভুল এৰি চলা উচিত। (a+b)^2 ক a^2 + b^2 বুলি লিখিব নোৱাৰি; ইয়াৰ সঠিক মান a^2 + 2ab + b^2। একেদৰে a^m + a^n ৰ সৈতে a^(m+n) সমান নহয়, কেৱল পূৰণতহে ঘাতাংক যোগ হয়। আৰু a^(−n) ক ঋণাত্মক সংখ্যা বুলি ভাবিব নালাগে; ই কেৱল প্ৰতিক্ৰম, গতিকে ২^−৩ ধনাত্মক ১/৮। এই সৰু বিভ্ৰান্তিবোৰেই পৰীক্ষাত ভুল উত্তৰৰ আটাইতকৈ সাধাৰণ কাৰণ, গতিকে প্ৰতিটো পদক্ষেপত নিয়মটো মনত পেলাই লিখাটো অভ্যাস কৰক।

    কৰণীৰ সৈতে কাম কৰোঁতে আন এটা উপযোগী কৌশল হৈছে কৰণীয়ক মৌলিক উৎপাদকত ভাঙি চোৱা। √৭২ বিচাৰিবলৈ ৭২ = ৩৬ × ২ বুলি লিখি √৩৬ × √২ = ৬√২ পোৱা যায়। একেইদৰে √৯৮ = √(৪৯×২) = ৭√২ আৰু √২৪৩ = √(৮১×৩) = ৯√৩। এটা কৰণী আটাইতকৈ সৰল ৰূপত আছে বুলি তেতিয়াহে ধৰা যায় যেতিয়া মূলৰ তলৰ সংখ্যাত একৰ বাহিৰে আন কোনো পূৰ্ণবৰ্গ উৎপাদক নাথাকে। এই পৰীক্ষাটো প্ৰতিবাৰ কৰাটো ভাল অভ্যাস, কাৰণ প্ৰশ্নই প্ৰায়ে উত্তৰ আটাইতকৈ সৰল ৰূপত বিচাৰে।

    মনত ৰখাৰ যোগ্য মূল তথ্য

    • a^m × a^n = a^(m+n); a^m / a^n = a^(m−n); (a^m)^n = a^(mn)।
    • a^0 = ১ যিকোনো অশূন্য a ৰ বাবে; a^(−n) = ১/a^n।
    • a^(১/২) বৰ্গমূল, a^(১/৩) ঘনমূল, a^(m/n) হৈছে n-সংখ্যক মূলক m-সংখ্যক ঘাতলৈ তোলা।
    • কৰণী এটা অপৰিমেয় মূল; √n কৰণী হয় কেৱল যেতিয়া n পূৰ্ণবৰ্গ নহয়।
    • √n সৰল কৰিবলৈ আটাইতকৈ ডাঙৰ পূৰ্ণবৰ্গ উৎপাদক পৃথক কৰক: √৮ = ২√২, √৫০ = ৫√২।
    • কেৱল সদৃশ কৰণী (একে কৰণীয়) পোনপটীয়াকৈ যোগ বা বিয়োগ কৰিব পাৰি।
    • √a × √b = √(ab); √a / √b = √(a/b)।
    • ১/√a হৰমূলদ কৰিবলৈ √a/√a ৰে পূৰণ কৰক; ১/(√a+√b) হৰমূলদ কৰিবলৈ সংযুগ্ম (√a−√b) ৰে পূৰণ কৰক।
    • (√a+√b)(√a−√b) = a − b, এটা পৰিমেয় সংখ্যা।
    • দুয়ো ফাল বৰ্গ কৰি, নাইবা গুণাংক মূলৰ ভিতৰলৈ আনি কৰণী তুলনা কৰক।
    • a^x = b সমাধান কৰিবলৈ দুয়ো ফাল একে ভূমিৰে লিখি ঘাতাংকবোৰ সমান কৰক।
    • ঘাতবোৰ জানক: ২^১০ = ১০২৪, ৩^৪ = ৮১, ৫^৩ = ১২৫, আৰু ১ ৰ পৰা ১৫ লৈ ঘন।

    সততে সোধা প্ৰশ্ন

    কৰণী ঠিক কি?

    কৰণী হৈছে এনে এটা সংখ্যাৰ অপৰিমেয় মূল যি এটা পূৰ্ণ ঘাত নহয়। ২ ৰ বৰ্গমূল এটা কৰণী কাৰণ ইয়াৰ মান কেতিয়াও শেষ বা পুনৰাবৃত্তি নহয়, কিন্তু ৯ ৰ বৰ্গমূল কৰণী নহয় কাৰণ ই ঠিক তিনিৰ সমান।

    √১৮ আৰু √৮ ৰ দৰে দুটা কৰণী কেনেকৈ যোগ কৰিম?

    প্ৰথমে প্ৰতিটো কৰণীক ইয়াৰ মূল ৰূপলৈ সৰল কৰক, তাৰ পিছত সদৃশ কৰণী যোগ কৰক। √১৮ = ৩√২ আৰু √৮ = ২√২, গতিকে যোগফল ৫√২।

    হৰমূলদ কৰোঁতে সংযুগ্মৰে কিয় পূৰণ কৰোঁ?

    কাৰণ এটা কৰণী ৰাশি আৰু ইয়াৰ সংযুগ্মৰ গুণফলে দুটা বৰ্গৰ পাৰ্থক্য ব্যৱহাৰ কৰি পৰিমেয় হৈ পৰে। উদাহৰণস্বৰূপে (√৫+√২)(√৫−√২) = ৫−২ = ৩, গতিকে হৰৰ পৰা মূল আঁতৰি যায়।

    দুটা কৰণী দ্ৰুতভাৱে কেনেকৈ তুলনা কৰিম?

    দুয়োটাকে বৰ্গ কৰক, নাইবা যিকোনো গুণাংক মূলৰ ভিতৰলৈ আনি কৰণীয়বোৰ তুলনা কৰক। যিহেতু ২√৩ = √১২ আৰু ৩√২ = √১৮, ৩√২ ডাঙৰ।

    ২^(২x) = ১৬ ৰ দৰে সমীকৰণ সমাধান কৰাৰ আটাইতকৈ দ্ৰুত উপায় কি?

    দুয়ো ফাল একে ভূমিৰে লিখি ঘাতাংকবোৰ সমান কৰক। ষোল্ল হৈছে ২^৪, গতিকে ২x = ৪ আৰু x = ২। ভূমি যিয়েই নহওক পদ্ধতি একেই।

    RRB NTPC পৰীক্ষাৰ গণিত। প্ৰশ্ন আৰু ব্যাখ্যাবোৰ শেহতীয়া অসম নিয়োগ পত্ৰত ব্যৱহৃত আৰ্হি অনুসৰি প্ৰস্তুত, আৰু প্ৰতিটো অধ্যায় এনে ধৰণে লিখা হৈছে যাতে পৰীক্ষা কক্ষত পদ্ধতিটো পুনৰ উলিয়াব পাৰি।
