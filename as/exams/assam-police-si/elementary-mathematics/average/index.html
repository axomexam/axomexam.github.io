    ২০ টা প্ৰশ্ন আৰু উত্তৰ

    ১. ৫, ১০, ১৫, ২০ আৰু ২৫ ৰ গৰ নিৰ্ণয় কৰা।
    (A) ১২ (12)
    (B) ১৩ (13)
    (C) ১৫ (15)
    (D) ১৭ (17)
    উত্তৰ: C) ১৫
    ব্যাখ্যা: যোগফল = ৫ + ১০ + ১৫ + ২০ + ২৫ = ৭৫। গৰ = যোগফল / সংখ্যা = ৭৫ / ৫ = ১৫।
    ২. প্ৰথম ৫ টা যুগ্ম স্বাভাৱিক সংখ্যাৰ গৰ নিৰ্ণয় কৰা।
    (A) ৬ (6)
    (B) ৭ (7)
    (C) ৮ (8)
    (D) ১০ (10)
    উত্তৰ: A) ৬
    ব্যাখ্যা: প্ৰথম ৫ টা যুগ্ম সংখ্যা হ'ল ২, ৪, ৬, ৮, ১০। যোগফল = ৩০। গৰ = ৩০ / ৫ = ৬।
    ৩. প্ৰথম n টা স্বাভাৱিক সংখ্যাৰ গৰ ১৫। n ৰ মান নিৰ্ণয় কৰা।
    (A) ২৫ (25)
    (B) ২৭ (27)
    (C) ২৯ (29)
    (D) ৩১ (31)
    উত্তৰ: C) ২৯
    ব্যাখ্যা: প্ৰথম n টা স্বাভাৱিক সংখ্যাৰ গৰ = (n + ১) / ২ = ১৫, গতিকে n + ১ = ৩০ আৰু n = ২৯।
    ৪. প্ৰথম ১০ টা স্বাভাৱিক সংখ্যাৰ বৰ্গৰ গৰ নিৰ্ণয় কৰা।
    (A) ৩৫ (35)
    (B) ৩৮.৫ (38.5)
    (C) ৪০ (40)
    (D) ৪২ (42)
    উত্তৰ: B) ৩৮.৫
    ব্যাখ্যা: বৰ্গৰ যোগফল = n(n+১)(২n+১)/৬ = ১০ × ১১ × ২১ / ৬ = ৩৮৫। গৰ = ৩৮৫ / ১০ = ৩৮.৫।
    ৫. ১ ৰ পৰা ২০ লৈকে সকলো ক্ৰমিক সংখ্যাৰ গৰ নিৰ্ণয় কৰা।
    (A) ১০.৫ (10.5)
    (B) ১১ (11)
    (C) ১১.৫ (11.5)
    (D) ১২ (12)
    উত্তৰ: A) ১০.৫
    ব্যাখ্যা: ১ ৰ পৰা n লৈকে ক্ৰমিক সংখ্যাৰ গৰ = (১ + n) / ২ = (১ + ২০) / ২ = ১০.৫।
    ৬. প্ৰথম ১০ টা যুগ্ম স্বাভাৱিক সংখ্যা (২, ৪, ৬, ..., ২০) ৰ গৰ নিৰ্ণয় কৰা।
    (A) ৮ (8)
    (B) ৯ (9)
    (C) ১০ (10)
    (D) ১১ (11)
    উত্তৰ: D) ১১
    ব্যাখ্যা: প্ৰথম n টা যুগ্ম সংখ্যাৰ গৰ = n + ১ = ১০ + ১ = ১১। আকৌ (২ + ২০) / ২ = ১১।
    ৭. ১১ টা সংখ্যাৰ গৰ ৩০। যদি ৪০ সংখ্যাটো বাদ দিয়া হয়, নতুন গৰ কিমান হ'ব?
    (A) ২৯ (29)
    (B) ২৯.৫ (29.5)
    (C) ৩০ (30)
    (D) ৩০.৫ (30.5)
    উত্তৰ: A) ২৯
    ব্যাখ্যা: মুঠ = ১১ × ৩০ = ৩৩০। ৪০ বাদ দিয়াৰ পিছত বাকী যোগফল = ৩৩০ - ৪০ = ২৯০, আৰু সংখ্যা = ১০। নতুন গৰ = ২৯০ / ১০ = ২৯।
    ৮. এজন বেটছমেনৰ ১০ টা ইনিংছত গৰ ৩০ ৰান। তেওঁৰ গৰ ৩৫ লৈ বৃদ্ধি কৰিবলৈ পৰৱৰ্তী ইনিংছত কিমান ৰান কৰিব লাগিব?
    (A) ৭০ (70)
    (B) ৭৫ (75)
    (C) ৮০ (80)
    (D) ৮৫ (85)
    উত্তৰ: D) ৮৫
    ব্যাখ্যা: ১১ টা ইনিংছৰ প্ৰয়োজনীয় মুঠ = ১১ × ৩৫ = ৩৮৫। বৰ্তমান মুঠ = ১০ × ৩০ = ৩০০। প্ৰয়োজনীয় ৰান = ৩৮৫ - ৩০০ = ৮৫।
    ৯. এখন শ্ৰেণীত ২০ জন ল'ৰাৰ গৰ নম্বৰ ৬০ আৰু ৩০ জনী ছোৱালীৰ গৰ নম্বৰ ৭০। গোটেই শ্ৰেণীৰ গৰ নম্বৰ নিৰ্ণয় কৰা।
    (A) ৬৬ (66)
    (B) ৬৪ (64)
    (C) ৬৮ (68)
    (D) ৭০ (70)
    উত্তৰ: A) ৬৬
    ব্যাখ্যা: মুঠ নম্বৰ = ২০ × ৬০ + ৩০ × ৭০ = ১২০০ + ২১০০ = ৩৩০০। মুঠ ছাত্ৰ-ছাত্ৰী = ৫০। গৰ = ৩৩০০ / ৫০ = ৬৬।
    ১০. এখন গাৰীয়ে ৩০ কিমি/ঘণ্টা বেগেৰে ৬০ কিমি আৰু ৬০ কিমি/ঘণ্টা বেগেৰে ৬০ কিমি অতিক্ৰম কৰে। গোটেই যাত্ৰাৰ গৰ বেগ নিৰ্ণয় কৰা।
    (A) ৩৪ (34)
    (B) ৩৬ (36)
    (C) ৩৮ (38)
    (D) ৪০ (40)
    উত্তৰ: D) ৪০
    ব্যাখ্যা: সময় = ৬০/৩০ + ৬০/৬০ = ২ + ১ = ৩ ঘণ্টা। মুঠ দুৰত্ব = ১২০ কিমি। গৰ বেগ = ১২০ / ৩ = ৪০ কিমি/ঘণ্টা।
    ১১. ৪ টা সংখ্যাৰ গৰ ২৫। যদি প্ৰতিটো সংখ্যা ৫ ৰে বৃদ্ধি কৰা হয়, নতুন গৰ কিমান হ'ব?
    (A) ২৫ (25)
    (B) ৩০ (30)
    (C) ৩৫ (35)
    (D) ৪০ (40)
    উত্তৰ: B) ৩০
    ব্যাখ্যা: প্ৰতিটো সংখ্যা ৫ ৰে বৃদ্ধি কৰিলে গৰও ৫ ৰে বৃদ্ধি হয়। নতুন গৰ = ২৫ + ৫ = ৩০।
    ১২. ৮ টা সংখ্যাৰ গৰ ১২। যদি প্ৰতিটো সংখ্যাক ৩ ৰে পূৰণ কৰা হয়, নতুন গৰ কিমান হ'ব?
    (A) ১২ (12)
    (B) ২৪ (24)
    (C) ৩৬ (36)
    (D) ৪৮ (48)
    উত্তৰ: C) ৩৬
    ব্যাখ্যা: প্ৰতিটো সংখ্যাক ৩ ৰে পূৰণ কৰিলে গৰও ৩ ৰে পূৰণ হয়। নতুন গৰ = ১২ × ৩ = ৩৬।
    ১৩. ৩ টা ক্ৰমিক সংখ্যাৰ গৰ ২০। ইয়াৰ ভিতৰৰ আটাইতকৈ ডাঙৰটো নিৰ্ণয় কৰা।
    (A) ২১ (21)
    (B) ২০ (20)
    (C) ২২ (22)
    (D) ২৩ (23)
    উত্তৰ: A) ২১
    ব্যাখ্যা: ক্ৰমিক সংখ্যাৰ ক্ষেত্ৰত গৰটোওই মাজৰ সংখ্যা, গতিকে সংখ্যাকৈটা ১৯, ২০, ২১। আটাইতকৈ ডাঙৰটো ২১।
    ১৪. ৫ টা ক্ৰমিক যুগ্ম সংখ্যাৰ গৰ ২৪। আটাইতকৈ ডাঙৰ সংখ্যাটো নিৰ্ণয় কৰা।
    (A) ২০ (20)
    (B) ২২ (22)
    (C) ২৬ (26)
    (D) ২৮ (28)
    উত্তৰ: D) ২৮
    ব্যাখ্যা: গৰটোওই মাজৰ সংখ্যা, গতিকে সংখ্যাকৈটা ২০, ২২, ২৪, ২৬, ২৮। আটাইতকৈ ডাঙৰটো ২৮।
    ১৫. ১১ টা ফলাফলৰ গৰ ৩০। প্ৰথম ৬ টাৰ গৰ ২৮ আৰু শেষৰ ৬ টাৰ গৰ ৩২। ৬ নম্বৰ ফলাফলটো নিৰ্ণয় কৰা।
    (A) ২৬ (26)
    (B) ২৮ (28)
    (C) ৩০ (30)
    (D) ৩২ (32)
    উত্তৰ: C) ৩০
    ব্যাখ্যা: ১১ টাৰ মুঠ = ১১ × ৩০ = ৩৩০। প্ৰথম ৬ টাৰ যোগফল = ৬ × ২৮ = ১৬৮ আৰু শেষৰ ৬ টাৰ = ৬ × ৩২ = ১৯২, একেলগে ৩৬০। ৬ নম্বৰ ফলাফল দুবাৰ গণনা হয়, গতিকে ই ৩৬০ - ৩৩০ = ৩০।
    ১৬. ২০ টা সংখ্যাৰ গৰ ১২। যদি প্ৰথম ১০ টা সংখ্যাৰ গৰ ১০, তেন্তে বাকী ১০ টা সংখ্যাৰ গৰ নিৰ্ণয় কৰা।
    (A) ১২ (12)
    (B) ১৪ (14)
    (C) ১৫ (15)
    (D) ১৬ (16)
    উত্তৰ: B) ১৪
    ব্যাখ্যা: মুঠ = ২০ × ১২ = ২৪০। প্ৰথম ১০ টাৰ যোগফল = ১০ × ১০ = ১০০। বাকী ১০ টাৰ যোগফল = ২৪০ - ১০০ = ১৪০। গৰ = ১৪০ / ১০ = ১৪।
    ১৭. ৭ টা সংখ্যাৰ গৰ ৪০। প্ৰথম ৪ টাৰ গৰ ৩৫ আৰু শেষৰ ৪ টাৰ গৰ ৪৫। ৪ নম্বৰ সংখ্যাটো নিৰ্ণয় কৰা।
    (A) ৪০ (40)
    (B) ৩৫ (35)
    (C) ৪৫ (45)
    (D) ৫০ (50)
    উত্তৰ: A) ৪০
    ব্যাখ্যা: ৭ টাৰ মুঠ = ৭ × ৪০ = ২৮০। প্ৰথম ৪ টাৰ যোগফল = ৪ × ৩৫ = ১৪০ আৰু শেষৰ ৪ টাৰ = ৪ × ৪৫ = ১৮০, একেলগে ৩২০। ৪ নম্বৰ সংখ্যা দুবাৰ গণনা হয়, গতিকে ই ৩২০ - ২৮০ = ৪০।
    ১৮. ১০ টা পৰ্যবেক্ষণৰ গৰ ১৫। পিছত ধৰা পৰিল যে ৩৫ মান এটা পৰ্যবেক্ষণ ৫৩ বুলি ভুলকৈ পঢ়়া হৈছিল। শুদ্ধ গৰ নিৰ্ণয় কৰা।
    (A) ১৩.৫ (13.5)
    (B) ১৩ (13)
    (C) ১৩.২ (13.2)
    (D) ১৪ (14)
    উত্তৰ: C) ১৩.২
    ব্যাখ্যা: ভুল মুঠ = ১০ × ১৫ = ১৫০। শুদ্ধ মুঠ = ১৫০ - ৫৩ + ৩৫ = ১৩২। শুদ্ধ গৰ = ১৩২ / ১০ = ১৩.২।
    ১৯. ১ ৰ পৰা ১০০ লৈকে সকলো স্বাভাৱিক সংখ্যাৰ গৰ নিৰ্ণয় কৰা।
    (A) ৫০ (50)
    (B) ৫০.৫ (50.5)
    (C) ৫১ (51)
    (D) ৫৫ (55)
    উত্তৰ: B) ৫০.৫
    ব্যাখ্যা: ১ ৰ পৰা n লৈকে সংখ্যাৰ গৰ = (১ + n) / ২ = (১ + ১০০) / ২ = ৫০.৫।
    ২০. প্ৰথম ২০ টা স্বাভাৱিক সংখ্যাৰ গৰ নিৰ্ণয় কৰা।
    (A) ১০ (10)
    (B) ১০.২ (10.2)
    (C) ১১ (11)
    (D) ১০.৫ (10.5)
    উত্তৰ: D) ১০.৫
    ব্যাখ্যা: প্ৰথম n টা স্বাভাৱিক সংখ্যাৰ গৰ = (n + ১) / ২ = (২০ + ১) / ২ = ২১ / ২ = ১০.৫।
