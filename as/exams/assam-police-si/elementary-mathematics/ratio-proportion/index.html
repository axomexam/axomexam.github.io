    ১৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. ১২০০ টকা দুজন ব্যক্তিৰ মাজত ২ : ৩ অনুপাতত ভাগ কৰা হ'ল। ডাঙৰ অংশটো নিৰ্ণয় কৰা।
    (A) ৪৮০ টকা (480 rupees)
    (B) ৬০০ টকা (600 rupees)
    (C) ৭২০ টকা (720 rupees)
    (D) ৮০০ টকা (800 rupees)
    উত্তৰ: C) ৭২০ টকা
    ব্যাখ্যা: মুঠ অংশ = ২ + ৩ = ৫। এটা অংশ = ১২০০ / ৫ = ২৪০। ডাঙৰ অংশ = ৩ × ২৪০ = ৭২০ টকা।
    ২. ৯ আৰু ১৬ ৰ মাজৰ মধ্যম সমানুপাত নিৰ্ণয় কৰা।
    (A) ১২ (12)
    (B) ২৫ (25)
    (C) ১৪৪ (144)
    (D) ১৩ (13)
    উত্তৰ: A) ১২
    ব্যাখ্যা: মধ্যম সমানুপাত = √(৯ × ১৬) = √১৪৪ = ১২।
    ৩. ২ : ৩ আৰু ৪ : ৫ ৰ মিশ্ৰ অনুপাত নিৰ্ণয় কৰা।
    (A) ৮ : ১৫ (8 : 15)
    (B) ২ : ৫ (2 : 5)
    (C) ৬ : ১৫ (6 : 15)
    (D) ৮ : ১২ (8 : 12)
    উত্তৰ: A) ৮ : ১৫
    ব্যাখ্যা: মিশ্ৰ অনুপাত = (২ × ৪) : (৩ × ৫) = ৮ : ১৫।
    ৪. ৩ : ৪ ৰ বৰ্গ অনুপাত নিৰ্ণয় কৰা।
    (A) ৬ : ৮ (6 : 8)
    (B) ৯ : ১৬ (9 : 16)
    (C) ১৬ : ৯ (16 : 9)
    (D) ৩ : ৮ (3 : 8)
    উত্তৰ: B) ৯ : ১৬
    ব্যাখ্যা: a : b ৰ বৰ্গ অনুপাত = a² : b² = ৩² : ৪² = ৯ : ১৬।
    ৫. দুজন ব্যক্তিৰ বয়সৰ অনুপাত ৫ : ৭ আৰু তেওঁলোকৰ বয়সৰ যোগফল ৪৮ বছৰ। সৰু ব্যক্তিজনৰ বয়স নিৰ্ণয় কৰা।
    (A) ২৪ বছৰ (24 years)
    (B) ২৮ বছৰ (28 years)
    (C) ২০ বছৰ (20 years)
    (D) ১৮ বছৰ (18 years)
    উত্তৰ: C) ২০ বছৰ
    ব্যাখ্যা: মুঠ অংশ = ৫ + ৭ = ১২। এটা অংশ = ৪৮ / ১২ = ৪। সৰু ব্যক্তিৰ বয়স = ৫ × ৪ = ২০ বছৰ।
    ৬. দুটা সংখ্যাৰ অনুপাত ৩ : ৪ আৰু তেওঁলোকৰ যোগফল ৬৩। ডাঙৰ সংখ্যাটো নিৰ্ণয় কৰা।
    (A) ২৭ (27)
    (B) ৩৬ (36)
    (C) ৪৫ (45)
    (D) ২৮ (28)
    উত্তৰ: B) ৩৬
    ব্যাখ্যা: মুঠ অংশ = ৩ + ৪ = ৭। এটা অংশ = ৬৩ / ৭ = ৯। ডাঙৰ সংখ্যা = ৪ × ৯ = ৩৬।
    ৭. x : ৬ = ১৫ : ১৮ হ'লে × নিৰ্ণয় কৰা।
    (A) ৪ (4)
    (B) ৬ (6)
    (C) ৫ (5)
    (D) ৭ (7)
    উত্তৰ: C) ৫
    ব্যাখ্যা: x : ৬ = ১৫ : ১৮ ৰ পৰা ১৮x = ৯০, গতিকে × = ৯০ / ১৮ = ৫।
    ৮. ৪ : ৫ ৰ ব্যস্ত অনুপাত নিৰ্ণয় কৰা।
    (A) ৫ : ৪ (5 : 4)
    (B) ৪ : ৫ (4 : 5)
    (C) ১৬ : ২৫ (16 : 25)
    (D) ১ : ৪ (1 : 4)
    উত্তৰ: A) ৫ : ৪
    ব্যাখ্যা: ৪ : ৫ ৰ ব্যস্ত অনুপাত পদ দুটা পৰস্পৰ সলনি কৰি পোৱা যায় = ৫ : ৪।
    ৯. ৫০০০ টকা A, B আৰু C ৰ মাজত ২ : ৩ : ৫ অনুপাতত ভাগ কৰা হ'ল। C ৰ অংশ নিৰ্ণয় কৰা।
    (A) ১০০০ টকা (1000 rupees)
    (B) ১৫০০ টকা (1500 rupees)
    (C) ২৫০০ টকা (2500 rupees)
    (D) ২০০০ টকা (2000 rupees)
    উত্তৰ: C) ২৫০০ টকা
    ব্যাখ্যা: মুঠ অংশ = ২ + ৩ + ৫ = ১০। এটা অংশ = ৫০০০ / ১০ = ৫০০। C ৰ অংশ = ৫ × ৫০০ = ২৫০০ টকা।
    ১০. দুটা সংখ্যাৰ অনুপাত ৫ : ৮ আৰু তেওঁলোকৰ পাৰ্থক্য ২৭। সৰু সংখ্যাটো নিৰ্ণয় কৰা।
    (A) ৪৫ (45)
    (B) ৭২ (72)
    (C) ৩৬ (36)
    (D) ৫৪ (54)
    উত্তৰ: A) ৪৫
    ব্যাখ্যা: অংশৰ পাৰ্থক্য = ৮ - ৫ = ৩। এটা অংশ = ২৭ / ৩ = ৯। সৰু সংখ্যা = ৫ × ৯ = ৪৫।
    ১১. ৯ আৰু ১২ ৰ তৃতীয় সমানুপাত নিৰ্ণয় কৰা।
    (A) ১৪ (14)
    (B) ১৫ (15)
    (C) ১৮ (18)
    (D) ১৬ (16)
    উত্তৰ: D) ১৬
    ব্যাখ্যা: তৃতীয় সমানুপাত × ধৰা হওক। তেন্তে ৯ : ১২ = ১২ : x, গতিকে × = (১২ × ১২) / ৯ = ১৬।
    ১২. যদি A : B = ২ : ৩ আৰু B : C = ৪ : ৫, তেন্তে A : C নিৰ্ণয় কৰা।
    (A) ৮ : ১৫ (8 : 15)
    (B) ২ : ৫ (2 : 5)
    (C) ৩ : ৫ (3 : 5)
    (D) ৮ : ১২ (8 : 12)
    উত্তৰ: A) ৮ : ১৫
    ব্যাখ্যা: B ৰাশিক সমান কৰা: A : B = ২ : ৩ = ৮ : ১২ আৰু B : C = ৪ : ৫ = ১২ : ১৫। গতিকে A : C = ৮ : ১৫।
    ১৩. ৩ : ৫ ৰ প্ৰতিটো পদত কি সংখ্যা যোগ কৰিলে অনুপাত ৫ : ৭ হ'ব?
    (A) ১ (1)
    (B) ২ (2)
    (C) ৩ (3)
    (D) ৪ (4)
    উত্তৰ: B) ২
    ব্যাখ্যা: x যোগ কৰা হওক: (৩ + x) / (৫ + x) = ৫ / ৭, গতিকে ২১ + ৭x = ২৫ + ৫x, ২x = ৪, × = ২।
    ১৪. যদি a : b = ৭ : ৫, তেন্তে (a + b) : (a - b) নিৰ্ণয় কৰা।
    (A) ৬ : ১ (6 : 1)
    (B) ১ : ৬ (1 : 6)
    (C) ১২ : ৫ (12 : 5)
    (D) ৭ : ২ (7 : 2)
    উত্তৰ: A) ৬ : ১
    ব্যাখ্যা: a = ৭k আৰু b = ৫k ধৰা হওক। তেন্তে a + b = ১২k আৰু a - b = ২k, গতিকে অনুপাত = ১২k : ২k = ৬ : ১।
    ১৫. ৮১ : ৪৯ ৰ বৰ্গমূল অনুপাত নিৰ্ণয় কৰা।
    (A) ৭ : ৯ (7 : 9)
    (B) ৪০ : ৫ (40 : 5)
    (C) ৯ : ৭ (9 : 7)
    (D) ৩ : ৭ (3 : 7)
    উত্তৰ: C) ৯ : ৭
    ব্যাখ্যা: বৰ্গমূল অনুপাত = √৮১ : √৪৯ = ৯ : ৭।

    Assam Police Sub-Inspector (SI) পৰীক্ষাৰ যোগ্যতা আৰু প্ৰাথমিক গণিত। প্ৰশ্ন আৰু ব্যাখ্যাবোৰ শেহতীয়া অসম নিয়োগ পত্ৰত ব্যৱহৃত আৰ্হি অনুসৰি প্ৰস্তুত, আৰু প্ৰতিটো অধ্যায় এনে ধৰণে লিখা হৈছে যাতে পৰীক্ষা কক্ষত পদ্ধতিটো পুনৰ উলিয়াব পাৰি।
