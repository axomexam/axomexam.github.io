    ৭০ টা প্ৰশ্ন আৰু উত্তৰ

    ১. Doctor : Hospital :: Teacher : ?
    (A) বিদ্যালয় (School)
    (B) শিক্ষাৰ্থী (Student)
    (C) কিতাপ (Book)
    (D) শ্ৰেণী (Class)
    উত্তৰ: A) বিদ্যালয়
    ব্যাখ্যা: ডাক্তৰে চিকিৎসালয়ত কাম কৰে; শিক্ষকে বিদ্যালয়ত কাম কৰে।
    ২. Farmer : Field :: Fisherman : ?
    (A) নদী (River)
    (B) নাৱ (Boat)
    (C) জাল (Net)
    (D) মাছ (Fish)
    উত্তৰ: A) নদী
    ব্যাখ্যা: কৃষকে পথাৰত কাম কৰে; মাছমৰীয়াই নদীত কাম কৰে।
    ৩. Chef : Kitchen :: Pilot : ?
    (A) ককপিট (Cockpit)
    (B) বিমান (Aeroplane)
    (C) বিমানবন্দৰ (Airport)
    (D) আকাশ (Sky)
    উত্তৰ: A) ককপিট
    ব্যাখ্যা: ৰান্ধনীয়ে ৰান্ধনীঘৰত কাম কৰে; বিমানচালকে ককপিটত কাম কৰে।
    ৪. Lawyer : Court :: Doctor : ?
    (A) ৰোগী (Patient)
    (B) ঔষধ (Medicine)
    (C) নাৰ্ছ (Nurse)
    (D) চিকিৎসালয় (Hospital)
    উত্তৰ: D) চিকিৎসালয়
    ব্যাখ্যা: উকীলে আদালতত কাম কৰে; ডাক্তৰে চিকিৎসালয়ত কাম কৰে।
    ৫. Judge : Court :: Scientist : ?
    (A) পৰীক্ষা (Experiment)
    (B) কিতাপ (Book)
    (C) বিশ্ববিদ্যালয় (University)
    (D) পৰীক্ষাগাৰ (Laboratory)
    উত্তৰ: D) পৰীক্ষাগাৰ
    ব্যাখ্যা: ন্যায়াধীশে আদালতত কাম কৰে; বিজ্ঞানীয়ে পৰীক্ষাগাৰত কাম কৰে।
    ৬. Carpenter : Saw :: Tailor : ?
    (A) কাপোৰ (Cloth)
    (B) সূতা (Thread)
    (C) বেজী (Needle)
    (D) বুটাম (Button)
    উত্তৰ: C) বেজী
    ব্যাখ্যা: বাঢ়ৈয়ে কৰত ব্যৱহাৰ কৰে; দৰ্জীয়ে বেজী ব্যৱহাৰ কৰে।
    ৭. Farmer : Plough :: Soldier : ?
    (A) ইউনিফৰ্ম (Uniform)
    (B) যুদ্ধ (War)
    (C) বন্দুক (Gun)
    (D) সেনাবাহিনী (Army)
    উত্তৰ: C) বন্দুক
    ব্যাখ্যা: কৃষকে নাঙল ব্যৱহাৰ কৰে; সৈনিকে বন্দুক ব্যৱহাৰ কৰে।
    ৮. Painter : Brush :: Blacksmith : ?
    (A) লো (Iron)
    (B) হাতুৰী (Hammer)
    (C) জুই (Fire)
    (D) ভাঁটি (Furnace)
    উত্তৰ: B) হাতুৰী
    ব্যাখ্যা: চিত্ৰকৰে তুলিকা ব্যৱহাৰ কৰে; কামাৰে হাতুৰী ব্যৱহাৰ কৰে।
    ৯. Barber : Razor :: Gardener : ?
    (A) ফুল (Flower)
    (B) খন্তি (Spade)
    (C) গছ (Plant)
    (D) পানী (Water)
    উত্তৰ: B) খন্তি
    ব্যাখ্যা: নাপিতে খুৰ ব্যৱহাৰ কৰে; মালীয়ে খন্তি ব্যৱহাৰ কৰে।
    ১০. Surgeon : Scalpel :: Woodcutter : ?
    (A) খৰি (Wood)
    (B) কুঠাৰ (Axe)
    (C) গছ (Tree)
    (D) হাবি (Forest)
    উত্তৰ: B) কুঠাৰ
    ব্যাখ্যা: শল্য চিকিৎসকে অস্ত্ৰ ব্যৱহাৰ কৰে; খৰিকটীয়াই কুঠাৰ ব্যৱহাৰ কৰে।
    ১১. Finger : Hand :: Toe : ?
    (A) ভৰি (Foot)
    (B) ঠেং (Leg)
    (C) নখ (Nail)
    (D) গোৰোহা (Heel)
    উত্তৰ: A) ভৰি
    ব্যাখ্যা: আঙুলি হাতৰ অংশ; ভৰিৰ আঙুলি ভৰিৰ অংশ।
    ১২. Page : Book :: Brick : ?
    (A) বেৰ (Wall)
    (B) ঘৰ (House)
    (C) চিমেণ্ট (Cement)
    (D) অট্টালিকা (Building)
    উত্তৰ: A) বেৰ
    ব্যাখ্যা: পৃষ্ঠা কিতাপৰ অংশ; ইটা বেৰৰ অংশ।
    ১৩. Wheel : Car :: Wing : ?
    (A) চৰাই (Bird)
    (B) পাখি (Feather)
    (C) আকাশ (Sky)
    (D) বিমান (Aeroplane)
    উত্তৰ: D) বিমান
    ব্যাখ্যা: চকা গাড়ীৰ অংশ; ডেউকা বিমানৰ অংশ।
    ১৪. Petal : Flower :: Word : ?
    (A) আখৰ (Letter)
    (B) ব্যাকৰণ (Grammar)
    (C) অনুচ্ছেদ (Paragraph)
    (D) বাক্য (Sentence)
    উত্তৰ: D) বাক্য
    ব্যাখ্যা: পাহি ফুলৰ অংশ; শব্দ বাক্যৰ অংশ।
    ১৫. Branch : Tree :: Arm : ?
    (A) ঠেং (Leg)
    (B) শৰীৰ (Body)
    (C) হাত (Hand)
    (D) কান্ধ (Shoulder)
    উত্তৰ: B) শৰীৰ
    ব্যাখ্যা: ডাল গছৰ অংশ; বাহু শৰীৰৰ অংশ।
    ১৬. Tree : Bark :: Human : ?
    (A) ছাল (Skin)
    (B) নখ (Nail)
    (C) চুলি (Hair)
    (D) তেজ (Blood)
    উত্তৰ: A) ছাল
    ব্যাখ্যা: ছাল গছৰ বাহিৰৰ আৱৰণ; ছাল মানুহৰ বাহিৰৰ আৱৰণ।
    ১৭. Country : State :: State : ?
    (A) নগৰ (City)
    (B) চহৰ (Town)
    (C) জিলা (District)
    (D) গাঁও (Village)
    উত্তৰ: C) জিলা
    ব্যাখ্যা: ৰাজ্য দেশৰ অংশ; জিলা ৰাজ্যৰ অংশ।
    ১৮. Army : Soldier :: Team : ?
    (A) অধিনায়ক (Captain)
    (B) খেল (Game)
    (C) খেলুৱৈ (Player)
    (D) প্ৰশিক্ষক (Coach)
    উত্তৰ: C) খেলুৱৈ
    ব্যাখ্যা: সেনাবাহিনী সৈনিকৰে গঠিত; দল খেলুৱৈৰে গঠিত।
    ১৯. Forest : Tree :: Garden : ?
    (A) ঘাঁহ (Grass)
    (B) গছ (Plant)
    (C) ফুল (Flower)
    (D) পাত (Leaf)
    উত্তৰ: C) ফুল
    ব্যাখ্যা: হাবি গছেৰে ভৰা; বাৰী ফুলেৰে ভৰা।
    ২০. Clock : Hand :: Fan : ?
    (A) মটৰ (Motor)
    (B) বিজুলী (Electricity)
    (C) বতাহ (Air)
    (D) পাখি (Blade)
    উত্তৰ: D) পাখি
    ব্যাখ্যা: ঘড়ীত কাঁটা থাকে; পাখাত পাখি থাকে।
    ২১. Cow : Calf :: Dog : ?
    (A) মেকুৰী পোৱালি (Kitten)
    (B) পোৱালি (Cub)
    (C) কুকুৰ পোৱালি (Puppy)
    (D) ভেৰা পোৱালি (Lamb)
    উত্তৰ: C) কুকুৰ পোৱালি
    ব্যাখ্যা: গাইৰ পোৱালি গো-পোৱালি; কুকুৰৰ পোৱালি কুকুৰ পোৱালি।
    ২২. Cat : Kitten :: Sheep : ?
    (A) গো-পোৱালি (Calf)
    (B) কুকুৰ পোৱালি (Puppy)
    (C) ভেৰা পোৱালি (Lamb)
    (D) ছাগলী পোৱালি (Kid)
    উত্তৰ: C) ভেৰা পোৱালি
    ব্যাখ্যা: মেকুৰীৰ পোৱালি মেকুৰী পোৱালি; ভেৰাৰ পোৱালি ভেৰা পোৱালি।
    ২৩. Horse : Foal :: Goat : ?
    (A) ভেৰা পোৱালি (Lamb)
    (B) ছাগলী পোৱালি (Kid)
    (C) গো-পোৱালি (Calf)
    (D) পোৱালি (Cub)
    উত্তৰ: B) ছাগলী পোৱালি
    ব্যাখ্যা: ঘোঁৰাৰ পোৱালি ঘোঁৰা পোৱালি; ছাগলীৰ পোৱালি ছাগলী পোৱালি।
    ২৪. Lion : Cub :: Hen : ?
    (A) কুকুৰা পোৱালি (Chick)
    (B) হাঁহ পোৱালি (Duckling)
    (C) মেকুৰী পোৱালি (Kitten)
    (D) কুকুৰ পোৱালি (Puppy)
    উত্তৰ: A) কুকুৰা পোৱালি
    ব্যাখ্যা: সিংহৰ পোৱালি পোৱালি; কুকুৰাৰ পোৱালি কুকুৰা পোৱালি।
    ২৫. Deer : Fawn :: Frog : ?
    (A) মাছ পোৱালি (Fry)
    (B) ভেকুলী পোৱালি (Tadpole)
    (C) পাৰ পোৱালি (Squab)
    (D) গো-পোৱালি (Calf)
    উত্তৰ: B) ভেকুলী পোৱালি
    ব্যাখ্যা: হৰিণৰ পোৱালি হৰিণ পোৱালি; ভেকুলীৰ পোৱালি জেঠী।
    ২৬. Dog : Bark :: Cat : ?
    (A) গৰ্জন (Roar)
    (B) ভেঁ ভেঁ (Bleat)
    (C) ঘোঁৰ ঘোঁৰ (Grunt)
    (D) মিউ মিউ (Mew)
    উত্তৰ: D) মিউ মিউ
    ব্যাখ্যা: কুকুৰে ভউ ভউ কৰে; মেকুৰীয়ে মিউ মিউ কৰে।
    ২৭. Lion : Roar :: Horse : ?
    (A) হেঁচা (Neigh)
    (B) ভউ ভউ (Bark)
    (C) হাম্বা (Moo)
    (D) কুৱাক (Quack)
    উত্তৰ: A) হেঁচা
    ব্যাখ্যা: সিংহে গৰ্জন কৰে; ঘোঁৰাই হেঁচা মাৰে।
    ২৮. Cow : Moo :: Sheep : ?

    ৩০. Duck : Quack :: Crow : ?

    ৩১. Bee : Hive :: Ant : ?

    ৩২. Lion : Den :: Bird : ?
    (A) মৌচাক (Hive)
    (B) গাঁত (Burrow)

    ৩৩. Rabbit : Burrow :: Horse : ?

    ৩৪. Spider : Web :: Dog : ?
    (A) মৌচাক (Hive)

    উত্তৰ: D) কুকুৰৰ ঘৰ

    ৩৫. Fish : Aquarium :: Bird : ?
    (A) মাছৰ টেংকী (Aquarium)
    (B) বাহ (Nest)

    (D) পিঞ্জৰা (Cage)
    উত্তৰ: D) পিঞ্জৰা
    ব্যাখ্যা: মাছ মাছৰ টেংকীত ৰখা হয়; চৰাই পিঞ্জৰাত ৰখা হয়।
    ৩৬. King : Queen :: Lion : ?
    (A) সিংহী (Lioness)
    (B) বাঘিনী (Tigress)
    (C) নাহৰফুটুকী (Leopard)
    (D) পোৱালি (Cub)
    উত্তৰ: A) সিংহী
    ব্যাখ্যা: ৰাণী ৰজাৰ স্ত্ৰীলিংগ; সিংহী সিংহৰ স্ত্ৰীলিংগ।
    ৩৭. Cock : Hen :: Bull : ?
    (A) গো-পোৱালি (Calf)
    (B) গাই (Cow)
    (C) বলদ (Ox)
    (D) ম'হ (Buffalo)
    উত্তৰ: B) গাই
    ব্যাখ্যা: কুকুৰা মাইকী কুকুৰাৰ স্ত্ৰীলিংগ; গাই ষাঁড়ৰ স্ত্ৰীলিংগ।
    ৩৮. Horse : Mare :: Dog : ?
    (A) কুকুৰ পোৱালি (Puppy)
    (B) কুকুৰী (Bitch)
    (C) মেকুৰী (Cat)
    (D) সিংহী (Lioness)

    অসম আৰক্ষী কনিষ্টবল (AB & UB) পৰীক্ষাৰ বাবে সাদৃশ্য (Analogy)

    Analogy SLPRB অসম আৰক্ষী কনিষ্টবল (AB & UB) পৰীক্ষাৰ যুক্তি-বিচাৰৰ এটা বিষয় য'ত এযোৰ শব্দ বা সংখ্যা আৰু সিহঁতৰ মাজৰ সম্পৰ্ক দিয়া হয়, আৰু প্ৰাৰ্থীয়ে একেই সম্পৰ্ক থকা দ্বিতীয় যোৰ এটা বিচাৰিব লাগে। প্ৰশ্নবোৰত সাধাৰণ জ্ঞান বা গণনাৰ প্ৰয়োজন নাই, কেৱল প্ৰথম যোৰৰ সম্পৰ্কটো নাম দিব পৰাৰ আৰু মিলাব পৰাৰ ক্ষমতা। Analogy পৰীক্ষাই দুটা বস্তুৰ মাজত সাদৃশ্য দেখা যায় নে নাই তাক পৰীক্ষা কৰে, আৰু সাধাৰণ সম্পৰ্কবোৰ জনাৰ পিছত ই আটাইতকৈ দ্ৰুত বিষয়বোৰৰ এটা। এই পৃষ্ঠাই সাধাৰণ সম্পৰ্কবোৰ, কৰা উদাহৰণ, পদ্ধতি আৰু নম্বৰ কাঢ়ি নিয়া ফান্দবোৰ ব্যাখ্যা কৰে। সমল অসম নিযুক্তি পৰীক্ষাৰ বাবে ব্যৱহৃত মানক যুক্তি-বিচাৰৰ প্ৰসংগ পুথিৰ আধাৰত প্ৰস্তুত কৰা হয় আৰু প্ৰকাশৰ আগতে পৰ্যালোচনা কৰা হয়।

    বিষয়টোৰ অৰ্থ

    Analogy এ কয় যে দুটা বস্তু এটা নিৰ্দিষ্ট ধৰণে একে। পৰীক্ষাত এটা যোৰ দিয়া হয়, যেনে "Doctor is to Hospital", আৰু প্ৰাৰ্থীয়ে বিকল্পবোৰৰপৰা একেই ধৰণৰ সম্পৰ্ক দেখুওৱা যোৰ বাছনি কৰিব লাগে, যেনে "Teacher is to School"। প্ৰথম যোৰৰ সম্পৰ্কটো স্পষ্টকৈ পঢ়িব লাগে, কাৰণ একেই দুটা শব্দৰ এটাতকৈ বেছি সম্পৰ্ক থাকিব পাৰে, আৰু প্ৰশ্নত দিয়া সম্পৰ্কটোহে মিলাব লাগে।

    শব্দ analogy ৰ সাধাৰণ সম্পৰ্ক

    • কৰ্মী আৰু কৰ্মস্থলী: Doctor আৰু Hospital, Teacher আৰু School।
    • কৰ্মী আৰু সঁজুলি: Carpenter আৰু Saw, Farmer আৰু Plough।
    • অংশ আৰু গোট: Wheel আৰু Car, Finger আৰু Hand।
    • কাৰণ আৰু ফল: Rain আৰু Flood, Fire আৰু Smoke।
    • শ্ৰেণী আৰু সদস্য: Fruit আৰু Mango, Bird আৰু Sparrow।
    • বিপৰীত: Hot আৰু Cold, Day আৰু Night।
    • সমাৰ্থক: Begin আৰু Commence, Brave আৰু Courageous।
    • পোৱালি আৰু পিতৃ-মাতৃ: Calf আৰু Cow, Puppy আৰু Dog।
    • উৎপাদ আৰু কেঁচামাল: Bread আৰু Flour, Cloth আৰু Cotton।
    • তীব্ৰতাৰ স্তৰ: Warm আৰু Hot, Drizzle আৰু Storm।

    সংখ্যা আৰু আখৰ analogy

    সংখ্যা analogy ত সম্পৰ্কটো বৰ্গ, ঘন, দুগুণ, আধা, মৌলিক বা ক্ৰমিক সংখ্যা হ'ব পাৰে। আখৰ analogy ত সম্পৰ্কটো সাধাৰণতে বৰ্ণমালাৰ স্থান, এটা স্থিৰ জাঁপ বা উলোটা স্থান। উদাহৰণস্বৰূপ, 4 ৰ লগত 16 ৰ সম্পৰ্ক বৰ্গৰ দৰে হ'লে 5 ৰ লগত 25 ৰ সম্পৰ্ক। B ৰ লগত D দুটা স্থান জাঁপৰ দ্বাৰা সম্পৰ্কিত হ'লে F ৰ লগত H একেই ধৰণে সম্পৰ্কিত।

    কৰা উদাহৰণ

    উদাহৰণ এক: Hand is to Glove as Foot is to what। হাতত glove পিন্ধা হয়, সেয়ে উত্তৰ shoe, যি ভৰিত পিন্ধা হয়। উদাহৰণ দুই: Pen is to Write as Knife is to what। Pen ৰে লিখা হয়, সেয়ে knife ৰে কটা হয়। উদাহৰণ তিন: 8 is to 64 as 9 is to what। ইয়াত 8 ৰ বৰ্গ 64, সেয়ে 9 ৰ বৰ্গ 81। উদাহৰণ চাৰি: AB is to DC as EF is to what। প্ৰতিটো আখৰ দুটা স্থান আগুৱাইছে, সেয়ে EF হয় GH।

    পৰীক্ষাত এই বিষয় কেনেকৈ আহে

    এই বিষয়টো সাধাৰণতে দুটাৰপৰা চাৰিটা বস্তুনিষ্ঠ প্ৰশ্ন হিচাপে, প্ৰতিটোৰ এক নম্বৰ, আহে। সাধাৰণ ৰূপবোৰ হৈছে শব্দ analogy, সংখ্যা analogy আৰু আখৰ analogy। এইবোৰৰ আটাইবোৰ প্ৰথমে দিয়া যোৰৰ সম্পৰ্ক এটা চুটি বাক্যাংশত নাম দি তাৰ পিছত কোনটো বিকল্পই একেই সম্পৰ্ক দেখুৱায় পৰীক্ষা কৰি উত্তৰ দিয়া হয়।

    চুটি উপায় আৰু দ্ৰুতিৰ পদ্ধতি

    • বিকল্প চোৱাৰ আগতে দিয়া যোৰৰ সম্পৰ্ক এটা চুটি বাক্যাংশত নাম দিয়ক।
    • সম্পৰ্কটো যোৰৰ ওপৰত লিখি ৰাখক যাতে পাহৰি নাযায়।
    • প্ৰতিটো বিকল্প কেৱল সেই এটা সম্পৰ্কৰ সৈতে পৰীক্ষা কৰক।
    • সংখ্যা analogy ৰ বাবে প্ৰথমে বৰ্গ, ঘন, দুগুণ, আধা আৰু মৌলিক সম্পৰ্ক পৰীক্ষা কৰক।
    • আখৰ analogy ৰ বাবে আখৰবোৰৰ তলত বৰ্ণমালাৰ স্থান লিখক।

    এৰাই চলিবলগীয়া সাধাৰণ ভুল

    • দিয়া যোৰৰপৰা বেলেগ সম্পৰ্ক থকা বিকল্প এটা বিচাৰি পোৱা।
    • যোৰটো ভুল ক্ৰমত পঢ়া, যিয়ে সম্পৰ্কটো ওলোটা কৰে।
    • সমাৰ্থক সম্পৰ্কক বিপৰীত সম্পৰ্কৰ লগত মিহলাই পেলোৱা।
    • নিজে সত্য কিন্তু দিয়া সম্পৰ্কৰ সৈতে নমিলা যোৰ এটা বাছনি কৰা।
    • যোৰত দুটা শব্দৰ ক্ৰম আওকাণ কৰা।

    প্ৰস্তুতি পৰিকল্পনা

    1. এই পৃষ্ঠাত থকা সাধাৰণ শব্দ-সম্পৰ্কবোৰ শিকক।
    2. যোৰ এটাৰ সম্পৰ্ক এটা চুটি বাক্যাংশত নাম দিয়াৰ অনুশীলন কৰক।
    3. সংখ্যা আৰু আখৰ analogy পৃথকভাৱে সমাধান কৰক।
    4. যোৰ দিয়া ক্ৰমত পঢ়ক আৰু উত্তৰতো সেই ক্ৰম ৰাখক।
    5. সাধাৰণ সম্পৰ্কবোৰ সপ্তাহত এবাৰ পুনৰাবৃত্তি কৰক।

    অনুশীলনৰ বাবে আৰু প্ৰশ্ন

    • Bird is to Fly as Fish is to Swim।
    • Author is to Book as Composer is to Symphony।
    • Butterfly is to Caterpillar as Frog is to Tadpole।
    • 5 is to 25 as 12 is to 144, কাৰণ সম্পৰ্ক বৰ্গ।
    • AZ is to BY as CX is to DW, কাৰণ প্ৰথম আখৰ আগুৱায় আৰু দ্বিতীয় পিছলৈ যায়।

    দ্ৰুত পুনৰালোচনা তালিকা

    • কৰ্মী আৰু কৰ্মস্থলী, কৰ্মী আৰু সঁজুলি।
    • অংশ আৰু গোট, কাৰণ আৰু ফল।
    • শ্ৰেণী আৰু সদস্য, পোৱালি আৰু পিতৃ-মাতৃ।
    • বিপৰীত, সমাৰ্থক আৰু তীব্ৰতাৰ স্তৰ।
    • জাঁপ, বৰ্গ আৰু ঘনৰ দ্বাৰা সংখ্যা আৰু আখৰ analogy।

    সাধু সোধা প্ৰশ্ন

    যুক্তি-বিচাৰত analogy কি?

    Analogy হৈছে এটা যুক্তি-বিচাৰৰ বিষয় য'ত এটা নিৰ্দিষ্ট সম্পৰ্কৰ সৈতে শব্দ বা সংখ্যাৰ এযোৰ দিয়া হয়, আৰু প্ৰাৰ্থীয়ে একেই সম্পৰ্ক থকা আন এযোৰ বিচাৰিব লাগে।

    Analogy সমাধানৰ প্ৰথম খোজ কি?

    দিয়া যোৰৰ সম্পৰ্ক এটা চুটি বাক্যাংশত নাম দিয়ক, আৰু তাৰ পিছত প্ৰতিটো বিকল্প কেৱল সেই একেই সম্পৰ্কৰ সৈতে পৰীক্ষা কৰক।

    Analogy ত সাধাৰণ জ্ঞান লাগে নেকি?

    নালাগে। উত্তৰ দিয়া যোৰৰ দুটা শব্দৰ মাজৰ সম্পৰ্কৰপৰা পোৱা যায়, বাহিৰৰ জ্ঞানৰপৰা নহয়, যদিও সাধাৰণ শব্দৰ চিনে দ্ৰুতি বঢ়ায়।

    সংখ্যা analogy কেনেকৈ সমাধান কৰা হয়?

    দিয়া যোৰৰ গাণিতিক সম্পৰ্ক বিচাৰক, যেনে বৰ্গ, ঘন, দুগুণ, আধা বা মৌলিক, আৰু নতুন সংখ্যাটোত একেই সম্পৰ্ক প্ৰয়োগ কৰক।

    যোৰৰ ক্ৰম কিয় গুৰুত্বপূৰ্ণ?

    কাৰণ সম্পৰ্কটো এটা দিশত কাম কৰে। "Doctor is to Hospital" আৰু "Hospital is to Doctor" একে নহয়, সেয়ে উত্তৰতো একেই ক্ৰম ৰাখিব লাগে।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
