    A sample of the comp fundamentals questions

    A few worked questions from this page, with the marked answer and the explanation, so you can see the level and the format before you start practising.

    • Q1. CPU stands for? CPU-ৰ সম্পূৰ্ণ অৰ্থ কি?
      (A) Central Processing Unit চেণ্ট্ৰেল প্ৰচেছিং ইউনিট   (B) Central Program Unit চেণ্ট্ৰেল প্ৰগ্ৰাম ইউনিট   (C) Computer Personal Unit কম্পিউটাৰ পাৰ্ছনেল ইউনিট   (D) Control Processing Unit কণ্ট্ৰোল প্ৰচেছিং ইউনিট
      Answer: Central Processing Unit Explanation: CPU stands for Central Processing Unit. It is the main part of a computer that processes all instructions and data.
    • Q2. The brain of the computer is? কম্পিউটাৰৰ মস্তিষ্ক কি?
      (A) CPU   (B) Monitor মনিটৰ   (C) Keyboard কীব’ৰ্ড   (D) Mouse মাউছ
      Answer: CPU Explanation: The CPU is called the brain of the computer because it performs all calculations and controls every operation.
    • Q3. Which of the following is an input device? তলৰ কোনটো ইনপুট ডিভাইচ?
      (A) Keyboard কীব’ৰ্ড   (B) Printer প্ৰিণ্টাৰ   (C) Speaker স্পীকাৰ   (D) Monitor মনিটৰ
      Answer: Keyboard Explanation: A keyboard is an input device. It is used to enter text, numbers and commands into the computer.
    • Q4. Which of the following is an output device? তলৰ কোনটো আউটপুট ডিভাইচ?
      (A) Printer প্ৰিণ্টাৰ   (B) Scanner স্কেনাৰ   (C) Mouse মাউছ   (D) Microphone মাইক্ৰফোন
      Answer: Printer Explanation: A printer is an output device. It produces a hard copy of documents and images on paper.

    How to use the comp fundamentals mock test

    • Attempt a set under the timer without pausing, to copy exam conditions.
    • Read the explanation for every question you got wrong immediately after the set.
