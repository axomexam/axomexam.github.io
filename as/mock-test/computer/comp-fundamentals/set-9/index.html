    গৃহপৃষ্ঠা/মক টেষ্ট/কম্পিউটাৰ সজাগতা/Fundamentals/Set 9

    Comp Fundamentals মক টেষ্ট — ছেট 9

    মক টেষ্ট ছেট 9 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. মাদাৰব’ৰ্ডক আন কি নামেৰে জনা যায়?
    (A) চিষ্টেম ব’ৰ্ড (System board)
    (B) ছাউণ্ড কাৰ্ড (Sound card)
    (C) ভিডিঅ’ কাৰ্ড (Video card)
    (D) পাৱাৰ ছাপ্লাই (Power supply)
    উত্তৰ: চিষ্টেম ব’ৰ্ড
    ব্যাখ্যা: মাদাৰব’ৰ্ডক চিষ্টেম ব’ৰ্ডও কোৱা হয়, কাৰণ ই কম্পিউটাৰৰ সকলো মূল অংশ সংযুক্ত কৰে।
    ২. কোন সঁজুলিক কম্পিউটাৰৰ মগজু বুলি কোৱা হয়?
    (A) RAM
    (B) CPU
    (C) হাৰ্ড ডিস্ক (Hard disk)
    (D) মনিটৰ (Monitor)
    ব্যাখ্যা: CPU ক কম্পিউটাৰৰ মগজু কোৱা হয়, কাৰণ ই সকলো নিৰ্দেশনা আৰু তথ্য প্ৰক্ৰিয়া কৰে।
    Answer: CPU
    ৩. GPU-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) জেনেৰেল প্ৰচেছিং ইউনিট (General Processing Unit)
    (B) গ্ৰাফিকেল প্ৰচেছ ইউনিট (Graphical Process Unit)
    (C) গ্ৰাফিক্স প্ৰচেছিং ইউনিট (Graphics Processing Unit)
    (D) গ্ৰাফিক্স প্ৰগ্ৰাম ইউনিট (Graphics Program Unit)
    উত্তৰ: গ্ৰাফিক্স প্ৰচেছিং ইউনিট
    ব্যাখ্যা: GPU ৰ সম্পূৰ্ণ ৰূপ Graphics Processing Unit, যি মূলতঃ ছবি আৰু ভিডিঅ’ ৰেণ্ডাৰ কৰিবলৈ ব্যৱহাৰ হয়।
    ৪. RAM কোন ধৰণৰ স্মৃতি?
    (A) অস্থিৰ নহয় (Non-volatile)
    (B) অস্থিৰ (Volatile)
    (C) স্থায়ী (Permanent)
    (D) কেৱল পঢ়িব পৰা (Read-only)
    উত্তৰ: অস্থিৰ
    ব্যাখ্যা: RAM অস্থিৰ স্মৃতি, গতিকে বিদ্যুৎ বন্ধ হ'লে ইয়াৰ তথ্য নোহোৱা হয়।
    ৫. কেশ্ব স্মৃতি ক’ত অৱস্থিত?
    (A) হাৰ্ড ডিস্কৰ ভিতৰত (Inside the hard disk)
    (B) মনিটৰৰ ভিতৰত (Inside the monitor)
    (C) কীব’ৰ্ডত (On the keyboard)
    (D) CPU আৰু মূল স্মৃতিৰ মাজত (Between the CPU and main memory)
    উত্তৰ: CPU আৰু মূল স্মৃতিৰ মাজত
    ব্যাখ্যা: কেশ্ব স্মৃতি CPU আৰু মূল স্মৃতিৰ মাজত থাকে, যাতে সঘনাই ব্যৱহৃত তথ্য দ্ৰুতভাৱে পাব পাৰি।
    ৬. ১ বাইট কিমান বিটৰ সমান?
    (A) ৮ বিট (8 bits)
    (B) ১৬ বিট (16 bits)
    (C) ৪ বিট (4 bits)
    (D) ৩২ বিট (32 bits)
    উত্তৰ: ৮ বিট
    ব্যাখ্যা: এক বাইট ৮ টা বিটেৰে গঠিত।
    ৭. বাইনেৰী সংখ্যা পদ্ধতিয়ে কোন অংক ব্যৱহাৰ কৰে?
    (A) ১ আৰু ২ (1 and 2)
    (B) ০ আৰু ৯ (0 and 9)
    (C) ০ আৰু ১ (0 and 1)
    (D) ২ আৰু ৩ (2 and 3)
    উত্তৰ: ০ আৰু ১
    ব্যাখ্যা: বাইনেৰী সংখ্যা পদ্ধতিয়ে কেৱল দুটা অংক, ০ আৰু ১ ব্যৱহাৰ কৰে।
    ৮. হেক্সাডেচিমেল সংখ্যা পদ্ধতিৰ ভিত্তি কি?
    (A) ২ (2)
    (B) ৮ (8)
    (C) ১০ (10)
    (D) ১৬ (16)
    উত্তৰ: ১৬
    ব্যাখ্যা: হেক্সাডেচিমেল সংখ্যা পদ্ধতিৰ ভিত্তি ১৬; ই ০ৰ পৰা ৯ লৈকে অংক আৰু Aৰ পৰা F লৈকে আখৰ ব্যৱহাৰ কৰে।
    ৯. কোন ছফ্টৱেৰে কম্পিউটাৰ হাৰ্ডৱেৰ পৰিচালনা কৰে আৰু অন্য ছফ্টৱেৰক সেৱা প্ৰদান কৰে?
    (A) MS Word
    (B) অপাৰেটিং চিষ্টেম (Operating system)
    (C) Google Chrome
    (D) VLC প্লেয়াৰ (VLC player)
    উত্তৰ: অপাৰেটিং চিষ্টেম
    ব্যাখ্যা: অপাৰেটিং চিষ্টেমে হাৰ্ডৱেৰ পৰিচালনা কৰে আৰু অন্য ছফ্টৱেৰ চলাৰ বাবে প্লেটফৰ্ম প্ৰদান কৰে।
    ১০. তলৰ কোনটো এপ্লিকেশ্যন ছফ্টৱেৰৰ উদাহৰণ?
    (A) Windows
    (B) Linux
    (C) MS Word
    (D) BIOS
    ব্যাখ্যা: MS Word এপ্লিকেশ্যন ছফ্টৱেৰ, যি নথি সৃষ্টি আৰু সম্পাদনাৰ বাবে তৈয়াৰ কৰা হৈছে।
    Answer: MS Word
    ১১. তলৰ কোনটো অপাৰেটিং চিষ্টেম?
    (A) Windows
    (B) MS Word
    (C) Photoshop
    (D) Chrome
    ব্যাখ্যা: Windows এটা অপাৰেটিং চিষ্টেম, আনবোৰ এপ্লিকেশ্যন ছফ্টৱেৰ।
    Answer: Windows
    ১২. Apple-এ Mac কম্পিউটাৰৰ বাবে কোন অপাৰেটিং চিষ্টেম বিকশিত কৰে?
    (A) Windows
    (B) macOS
    (C) Linux
    (D) Android
    ব্যাখ্যা: macOS হৈছে Apple-এ ইয়াৰ Mac কম্পিউটাৰৰ বাবে বিকশিত কৰা অপাৰেটিং চিষ্টেম।
    Answer: macOS
    ১৩. কম্পাইলাৰে কি ৰূপান্তৰ কৰে?
    (A) মেচিন ভাষাক উচ্চ-স্তৰৰ ভাষালৈ (Machine language into high-level language)
    (B) উচ্চ-স্তৰৰ ভাষাক এছেম্বলি ভাষালৈ (High-level language into assembly language)
    (C) এছেম্বলি ভাষাক উচ্চ-স্তৰৰ ভাষালৈ (Assembly language into high-level language)
    (D) উচ্চ-স্তৰৰ ভাষাক মেচিন ভাষালৈ (High-level language into machine language)
    উত্তৰ: উচ্চ-স্তৰৰ ভাষাক মেচিন ভাষালৈ
    ব্যাখ্যা: কম্পাইলাৰে সমগ্ৰ উচ্চ-স্তৰৰ ভাষাৰ প্ৰগ্ৰাম একে সময়তে মেচিন ভাষালৈ অনুবাদ কৰে।
    ১৪. এছেম্বলি ভাষা কি ধৰণৰ?
    (A) উচ্চ-স্তৰৰ ভাষা (High-level language)
    (B) নিম্ন-স্তৰৰ ভাষা (Low-level language)
    (C) প্ৰাকৃতিক ভাষা (Natural language)
    (D) কুৱেৰী ভাষা (Query language)
    উত্তৰ: নিম্ন-স্তৰৰ ভাষা
    ব্যাখ্যা: এছেম্বলি ভাষা নিম্ন-স্তৰৰ ভাষা, যি বাইনেৰী কোডৰ সলনি স্মৃতিসহায়ক চিহ্ন ব্যৱহাৰ কৰে।
    ১৫. এলগৰিদম কি?
    (A) এটা কম্পিউটাৰ হাৰ্ডৱেৰ (A computer hardware)
    (B) এটা প্ৰগ্ৰামিং ভাষা (A programming language)
    (C) সমস্যা সমাধানৰ বাবে ধাপে ধাপে পদ্ধতি (A step-by-step procedure to solve a problem)
    (D) এক ধৰণৰ স্মৃতি (A type of memory)
    উত্তৰ: সমস্যা সমাধানৰ বাবে ধাপে ধাপে পদ্ধতি
    ব্যাখ্যা: এলগৰিদম হৈছে সমস্যা সমাধানৰ বাবে সীমিত ধাপে ধাপে পদ্ধতি।
    ১৬. এলগৰিদমক graphical ৰূপত দেখুৱাবলৈ তলৰ কোনটো ব্যৱহাৰ হয়?
    (A) ফ্ল’চাৰ্ট (Flowchart)
    (B) এলগৰিদম (Algorithm)
    (C) প্ৰগ্ৰাম (Program)
    (D) কম্পাইলাৰ (Compiler)
    উত্তৰ: ফ্ল’চাৰ্ট
    ব্যাখ্যা: ফ্ল’চাৰ্টে মানক চিহ্ন ব্যৱহাৰ কৰি এলগৰিদমৰ ধাপসমূহ graphical ৰূপত দেখুৱায়।
    ১৭. HDMI-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) হাই ডেফিনিশ্যন মিডিয়া ইন্টাৰফেচ (High Definition Media Interface)
    (B) হাই ডিজিটেল মাল্টিমিডিয়া ইন্টাৰফেচ (High Digital Multimedia Interface)
    (C) হাই ডেফিনিশ্যন মাল্টি ইন্টাৰফেচ (High Definition Multi Interface)
    (D) হাই ডেফিনিশ্যন মাল্টিমিডিয়া ইন্টাৰফেচ (High Definition Multimedia Interface)
    উত্তৰ: হাই ডেফিনিশ্যন মাল্টিমিডিয়া ইন্টাৰফেচ
    ব্যাখ্যা: HDMI ৰ সম্পূৰ্ণ ৰূপ High Definition Multimedia Interface, যি অডিঅ’ আৰু ভিডিঅ’ প্ৰেৰণ কৰে।
    ১৮. মনিটৰ সংযোগ কৰিবলৈ সাধাৰণতে কোন প’ৰ্ট ব্যৱহাৰ হয়?
    (A) USB
    (B) HDMI
    (C) ইথাৰনেট (Ethernet)
    (D) অডিঅ’ জেক (Audio jack)
    ব্যাখ্যা: মনিটৰ বা ডিস্প্লে কম্পিউটাৰৰ সৈতে সংযোগ কৰিবলৈ HDMI সাধাৰণতে ব্যৱহৃত হয়।
    Answer: HDMI
    ১৯. বাছনি কৰা লিখা কপি কৰিবলৈ কোন চৰ্টকাট কী ব্যৱহাৰ হয়?
    (A) Ctrl + C
    (B) Ctrl + V
    (C) Ctrl + X
    (D) Ctrl + Z
    ব্যাখ্যা: Ctrl + C ব্যৱহাৰ কৰি বাছনি কৰা সমল ক্লিপব’ৰ্ডলৈ কপি কৰা হয়।
    Answer: Ctrl + C
    ২০. কপি কৰা সমল পেষ্ট কৰিবলৈ কোন চৰ্টকাট কী ব্যৱহাৰ হয়?
    (A) Ctrl + C
    (B) Ctrl + V
    (C) Ctrl + S
    (D) Ctrl + P
    ব্যাখ্যা: Ctrl + V ব্যৱহাৰ কৰি ক্লিপব’ৰ্ডত থকা সমল পেষ্ট কৰা হয়।
    Answer: Ctrl + V
    ২১. খোলা উইণ্ড’ৰ মাজত সলনি কৰিবলৈ কোন কী সংযোগ ব্যৱহাৰ হয়?
    (A) Ctrl + Tab
    (B) Shift + Tab
    (C) Alt + F4
    (D) Alt + Tab
    ব্যাখ্যা: Alt + Tab ব্যৱহাৰ কৰি বৰ্তমান খোলা উইণ্ড’ বা এপ্লিকেশ্যনৰ মাজত সলনি কৰা হয়।
    Answer: Alt + Tab
    ২২. কোন কী সংযোগে ফাইল Recycle Bin-লৈ নপঠিয়াই স্থায়ীভাৱে মচি পেলায়?
    (A) Ctrl + Delete
    (B) Alt + Delete
    (C) Shift + Delete
    (D) Delete
    ব্যাখ্যা: Shift + Delete এ বাছনি কৰা ফাইল Recycle Bin-লৈ নিনি স্থায়ীভাৱে মচি পেলায়।
    Answer: Shift + Delete
    ২৩. Windows-ত মচা ফাইলসমূহ অস্থায়ীভাৱে ক’ত সংৰক্ষিত হয়?
    (A) Recycle Bin
    (B) My Computer
    (C) Control Panel
    (D) Task Manager
    ব্যাখ্যা: মচা ফাইলসমূহ অস্থায়ীভাৱে Recycle Bin-ত থাকে আৰু পুনৰুদ্ধাৰ কৰিব পাৰি।
    Answer: Recycle Bin
    ২৪. .docx ফাইল এক্সটেনশনে কোন ধৰণৰ ফাইল সূচায়?
    (A) Excel কৰ্মপত্ৰ (Excel worksheet)
    (B) Word নথি (Word document)
    (C) PowerPoint উপস্থাপন (PowerPoint presentation)
    (D) Notepad ফাইল (Notepad file)
    উত্তৰ: Word নথি
    ব্যাখ্যা: .docx এক্সটেনশন Microsoft Word-ত তৈয়াৰ কৰা নথিৰ বাবে ব্যৱহৃত হয়।
    ২৫. কোন সঁজুলিয়ে ডিজিটেল সংকেতক এনালগ সংকেতলৈ আৰু উল্টাকৈ ৰূপান্তৰ কৰে?
    (A) ৰাউটাৰ (Router)
    (B) চুইচ (Switch)
    (C) হাব (Hub)
    (D) মডেম (Modem)
    উত্তৰ: মডেম
    ব্যাখ্যা: মডেমে সংকেত মডুলেট আৰু ডিমডুলেট কৰি ডিজিটেল আৰু এনালগ ৰূপৰ মাজত ৰূপান্তৰ কৰে।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
