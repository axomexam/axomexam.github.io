    গৃহপৃষ্ঠা/মক টেষ্ট/কম্পিউটাৰ সজাগতা/Fundamentals/Set 2

    Comp Fundamentals মক টেষ্ট — ছেট 2

    মক টেষ্ট ছেট 2 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. GUI-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) গ্ৰাফিকেল ইউজাৰ ইণ্টাৰফেচ (Graphical User Interface)
    (B) জেনেৰেল ইউজাৰ ইণ্টাৰফেচ (General User Interface)
    (C) গ্ৰাফিকেল ইউনিভাৰ্চেল ইণ্টাৰফেচ (Graphical Universal Interface)
    (D) গ্ৰাফিক ইউনিক ইনপুট (Graphic Unique Input)
    উত্তৰ: গ্ৰাফিকেল ইউজাৰ ইণ্টাৰফেচ
    ব্যাখ্যা: GUI ৰ সম্পূৰ্ণ ৰূপ Graphical User Interface। ই আইকন, উইণ্ড' আৰু মেনুৰ জৰিয়তে কম্পিউটাৰ চলাবলৈ দিয়ে, লিখিত নিৰ্দেশ নহয়।
    ২. প্ৰথম প্ৰজন্মৰ কম্পিউটাৰে কি ব্যৱহাৰ কৰিছিল?
    (A) ভেকুৱাম টিউব (Vacuum tubes)
    (B) ট্ৰান্সিষ্টৰ (Transistors)
    (C) ইণ্টিগ্ৰেটেড চাৰ্কিট (Integrated circuits)
    (D) মাইক্ৰ’প্ৰচেছৰ (Microprocessors)
    উত্তৰ: ভেকুৱাম টিউব
    ব্যাখ্যা: প্ৰথম প্ৰজন্মৰ কম্পিউটাৰে ভেকুৱাম টিউব ব্যৱহাৰ কৰিছিল, যিবোৰ ডাঙৰ, তপত আৰু অধিক বিদ্যুৎ খৰচী আছিল।
    ৩. দ্বিতীয় প্ৰজন্মৰ কম্পিউটাৰে কি ব্যৱহাৰ কৰিছিল?
    (A) ট্ৰান্সিষ্টৰ (Transistors)
    (B) ভেকুৱাম টিউব (Vacuum tubes)
    (C) মাইক্ৰ’প্ৰচেছৰ (Microprocessors)
    (D) কৃত্রিম বুদ্ধিমত্তা চিপ (Artificial intelligence chips)
    উত্তৰ: ট্ৰান্সিষ্টৰ
    ব্যাখ্যা: দ্বিতীয় প্ৰজন্মৰ কম্পিউটাৰে ট্ৰেনজিষ্টৰ ব্যৱহাৰ কৰিছিল, যিবোৰ ভেকুৱাম টিউবতকৈ সৰু, দ্ৰুত আৰু নিৰ্ভৰযোগ্য আছিল।
    ৪. তৃতীয় প্ৰজন্মৰ কম্পিউটাৰে কি ব্যৱহাৰ কৰিছিল?
    (A) ইণ্টিগ্ৰেটেড চাৰ্কিট (Integrated circuits)
    (B) ভেকুৱাম টিউব (Vacuum tubes)
    (C) কেৱল ট্ৰান্সিষ্টৰ (Transistors only)
    (D) কেৱল মেগনেটিক ড্ৰাম (Magnetic drums only)
    উত্তৰ: ইণ্টিগ্ৰেটেড চাৰ্কিট
    ব্যাখ্যা: তৃতীয় প্ৰজন্মৰ কম্পিউটাৰে ইন্টিগ্ৰেটেড চাৰ্কিট (IC) ব্যৱহাৰ কৰিছিল, য'ত এটা চিপত বহু ট্ৰেনজিষ্টৰ থাকে।
    ৫. চতুৰ্থ প্ৰজন্মৰ কম্পিউটাৰ কিৰ ওপৰত ভিত্তি কৰে?
    (A) মাইক্ৰ’প্ৰচেছৰ (Microprocessors)
    (B) ভেকুৱাম টিউব (Vacuum tubes)
    (C) ট্ৰান্সিষ্টৰ (Transistors)
    (D) ষ্টীম ইঞ্জিন (Steam engines)
    উত্তৰ: মাইক্ৰ’প্ৰচেছৰ
    ব্যাখ্যা: চতুৰ্থ প্ৰজন্মৰ কম্পিউটাৰ মাইক্ৰ'প্ৰচেছৰৰ ওপৰত আধাৰিত, য'ত সম্পূৰ্ণ CPU এটা চিপত সন্নিবিষ্ট হয়।
    ৬. কম্পিউটাৰৰ জনক বুলি কাক জনা যায়?
    (A) চাৰ্লছ বেবেজ (Charles Babbage)
    (B) বিল গেটছ (Bill Gates)
    (C) টিম বাৰ্নাৰ্ছ-লী (Tim Berners-Lee)
    (D) ষ্টিভ জব্ছ (Steve Jobs)
    উত্তৰ: চাৰ্লছ বেবেজ
    ব্যাখ্যা: চাৰ্লছ বেবেজে এনালিটিকেল ইঞ্জিন ডিজাইন কৰিছিল আৰু তেওঁক কম্পিউটাৰৰ পিতৃ বুলি কোৱা হয়।
    ৭. ৱৰ্ল্ড ৱাইড ৱেবৰ জনক বুলি কাক জনা যায়?
    (A) টিম বাৰ্নাৰ্ছ-লী (Tim Berners-Lee)
    (B) চাৰ্লছ বেবেজ (Charles Babbage)
    (C) এলেন ট্যুৰিং (Alan Turing)
    (D) জন নেপিয়াৰ (John Napier)
    উত্তৰ: টিম বাৰ্নাৰ্ছ-লী
    ব্যাখ্যা: টিম বাৰ্নাৰ্ছ-লীয়ে ১৯৮৯ চনত World Wide Web আৱিষ্কাৰ কৰিছিল।
    ৮. MS Excel মূলতঃ কিৰ বাবে ব্যৱহাৰ হয়?
    (A) প্ৰেজেণ্টেশ্বন তৈয়াৰ (Making presentations)
    (B) স্প্ৰেডশ্বীট আৰু হিচাপ (Spreadsheet and calculations)
    (C) ইণ্টাৰনেট ব্ৰাউজ (Browsing the internet)
    (D) কেৱল ইমেইল পঠোৱা (Sending email only)
    উত্তৰ: স্প্ৰেডশ্বীট আৰু হিচাপ
    ব্যাখ্যা: MS Excel এটা স্প্ৰেডশ্বীট প্ৰগ্ৰাম যি গণনা, তালিকা, চাৰ্ট আৰু তথ্য বিশ্লেষণৰ বাবে ব্যৱহাৰ হয়।
    ৯. MS PowerPoint কি তৈয়াৰ কৰিবলৈ ব্যৱহাৰ হয়?
    (A) কেৱল ডেটাবেছ (Databases only)
    (B) প্ৰেজেণ্টেশ্বন (Presentations)
    (C) অপাৰেটিং চিষ্টেম (Operating systems)
    (D) কম্পিউটাৰ চিপ (Computer chips)
    উত্তৰ: প্ৰেজেণ্টেশ্বন
    ব্যাখ্যা: MS PowerPoint স্লাইডভিত্তিক উপস্থাপন (presentation) সাজিবলৈ ব্যৱহাৰ হয়।
    ১০. Ctrl + S শ্বৰ্টকাট কিৰ বাবে?
    (A) কাট (Cut)
    (B) ছেভ (Save)
    (C) প্ৰিণ্ট (Print)
    (D) আনডু (Undo)
    উত্তৰ: ছেভ
    ব্যাখ্যা: Ctrl + S বৰ্তমান নথিপত্ৰ সংৰক্ষণ (save) কৰাৰ শৰ্টকাট।
    ১১. Ctrl + Z শ্বৰ্টকাট কিৰ বাবে?
    (A) ৰিডু (Redo)
    (B) আনডু (Undo)
    (C) ছেভ (Save)
    (D) কপি (Copy)
    উত্তৰ: আনডু
    ব্যাখ্যা: Ctrl + Z শেহতীয়া কাৰ্য বাতিল (undo) কৰাৰ শৰ্টকাট।
    ১২. Ctrl + A শ্বৰ্টকাট কিৰ বাবে?
    (A) বাওঁফালে এলাইন (Align left)
    (B) সকলো বাছনি (Select all)
    (C) ফাইল খোলা (Open a file)
    (D) উইণ্ড’ বন্ধ (Close window)
    উত্তৰ: সকলো বাছনি
    ব্যাখ্যা: Ctrl + A বৰ্তমান উইণ্ড' বা নথিপত্ৰৰ সকলো সমল বাছনি কৰাৰ শৰ্টকাট।
    ১৩. এটা নিবল কিমানৰ সমান?
    (A) ৮ বিট (8 bits)
    (B) ৪ বিট (4 bits)
    (C) ১৬ বিট (16 bits)
    (D) ২ বিট (2 bits)
    উত্তৰ: ৪ বিট
    ব্যাখ্যা: এক নিবল = ৪ বিট, অৰ্থাৎ এক বাইটৰ আধা।
    ১৪. ১ মেগাবাইট (MB) কিমানৰ সমান?
    (A) ১০২৪ বাইট (1024 bytes)
    (B) ১০২৪ GB (1024 GB)
    (C) ১০২৪ KB (1024 KB)
    (D) ১০০০ বিট (1000 bits)
    উত্তৰ: ১০২৪ KB
    ব্যাখ্যা: ১ মেগাবাইট (MB) = ১০২৪ কিলবাইট (KB)।
    ১৫. ১ গিগাবাইট (GB) কিমানৰ সমান?
    (A) ১০২৪ KB (1024 KB)
    (B) ১০২৪ বাইট (1024 bytes)
    (C) ১০২৪ MB (1024 MB)
    (D) সদায় কেৱল ১০০০ MB (1000 MB only decimal always)
    উত্তৰ: ১০২৪ MB
    ব্যাখ্যা: ১ গিগাবাইট (GB) = ১০২৪ মেগাবাইট (MB)।
    ১৬. তলৰ কোনটো গৌণ সংৰক্ষণ যন্ত্ৰ?
    (A) RAM
    (B) ৰেজিষ্টাৰ (Register)
    (C) পেন ড্ৰাইভ (Pen drive)
    (D) ক্যাশ (Cache)
    উত্তৰ: পেন ড্ৰাইভ
    ব্যাখ্যা: পেন ড্ৰাইভ এটা বহনযোগ্য গৌণ সংৰক্ষণ সঁজুলি; বিদ্যুৎ বন্ধ হ'লেও তথ্য থাকে।
    ১৭. ক্যাশ মেমেৰী কি?
    (A) এটা প্ৰিণ্টাৰ (A type of printer)
    (B) এটা আউটপুট ডিভাইচ (An output device)
    (C) CPU আৰু RAM-ৰ মাজৰ অতি দ্ৰুত মেমেৰী (A very fast memory between CPU and RAM)
    (D) এটা প্ৰগ্ৰামিং ভাষা (A programming language)
    উত্তৰ: CPU আৰু RAM-ৰ মাজৰ অতি দ্ৰুত মেমেৰী
    ব্যাখ্যা: কেশ্ব হৈছে CPU আৰু RAM ৰ মাজত থকা সৰু, অতি দ্ৰুত স্মৃতি যি সঘনাই ব্যৱহৃত তথ্য সংৰক্ষণ কৰে।
    ১৮. URL-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ইউনিফৰ্ম ৰিছ’ৰ্চ লিংক (Uniform Resource Link)
    (B) ইউনিভাৰ্চেল ৰেকৰ্ড ল’কেটৰ (Universal Record Locator)
    (C) ইউনিফৰ্ম ৰিছ’ৰ্চ ল’কেটৰ (Uniform Resource Locator)
    (D) ইউনিক ৰিছ’ৰ্চ ল’কেটৰ (Unique Resource Locator)
    উত্তৰ: ইউনিফৰ্ম ৰিছ’ৰ্চ ল’কেটৰ
    ব্যাখ্যা: URL ৰ সম্পূৰ্ণ ৰূপ Uniform Resource Locator। ই ইণ্টাৰনেটত থকা ৱেবপৃষ্ঠা বা ফাইলৰ ঠিকনা।
    ১৯. HTML কিৰ বাবে ব্যৱহাৰ হয়?
    (A) কেৱল ডেটাবেছ তৈয়াৰ (Create databases only)
    (B) C প্ৰগ্ৰাম ক’ম্পাইল (Compile C programs)
    (C) ৱেব পৃষ্ঠা তৈয়াৰ (Create web pages)

    ২০. তলৰ কোনটো ৱেব ব্ৰাউজাৰ?

    (B) Windows 10

    ২১. Email-ৰ অৰ্থ কি?

    ২২. @ চিহ্ন ক’ত ব্যৱহাৰ হয়?
    (A) কেৱল ডাক ঠিকনা (Postal address only)

    ২৩. কম্পিউটাৰৰ মেচিন ভাষা মূলতঃ কোন ৰূপত?

    ২৪. ক’ম্পাইলাৰ কি কৰে?

    (D) উচ্চস্তৰৰ ভাষাক মেচিন ভাষালৈ ৰূপান্তৰ কৰে (Converts high-level language to machine language)
    উত্তৰ: উচ্চস্তৰৰ ভাষাক মেচিন ভাষালৈ ৰূপান্তৰ কৰে
    ব্যাখ্যা: কম্পাইলাৰে সম্পূৰ্ণ উচ্চ-স্তৰৰ ভাষাৰ প্ৰগ্ৰামক একে সময়তে মেচিন ভাষালৈ ৰূপান্তৰ কৰে।
    ২৫. ইণ্টাৰপ্ৰিটাৰে কি কৰে?
    (A) এটা হাৰ্ডৱেৰ ফেন (Is a hardware fan)
    (B) এটা ইনপুট ডিভাইচ (Is an input device)
    (C) কেৱল ROM সংৰক্ষণ কৰে (Stores only ROM)
    (D) ক’ড শাৰী শাৰীকৈ অনুবাদ আৰু চলায় (Translates and executes code line by line)
    উত্তৰ: ক’ড শাৰী শাৰীকৈ অনুবাদ আৰু চলায়
    ব্যাখ্যা: ইণ্টাৰপ্ৰিটাৰে প্ৰগ্ৰাম শাৰী শাৰী কৰি ৰূপান্তৰ কৰি চলায়।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
