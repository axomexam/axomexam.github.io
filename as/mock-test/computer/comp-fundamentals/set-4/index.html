    গৃহপৃষ্ঠা/মক টেষ্ট/কম্পিউটাৰ সজাগতা/Fundamentals/Set 4

    Comp Fundamentals মক টেষ্ট — ছেট 4

    মক টেষ্ট ছেট 4 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. কম্পিউটাৰৰ হাৰ্ডৱেৰ নিয়ন্ত্ৰণ কৰা ছফটৱেৰক কি বোলে?
    (A) অপাৰেটিং চিষ্টেম (Operating system)
    (B) স্প্ৰেডশ্বীট (Spreadsheet)
    (C) কেৱল ব্ৰাউজাৰ (Browser only)
    (D) স্কেনাৰ (Scanner)
    উত্তৰ: অপাৰেটিং চিষ্টেম
    ব্যাখ্যা: যি চফটৱেৰে হাৰ্ডৱেৰ নিয়ন্ত্ৰণ কৰি কম্পিউটাৰৰ সকলো কাৰ্য পৰিচালনা কৰে তাক অপাৰেটিং ছিষ্টেম বোলা হয়।
    ২. কম্পিউটাৰৰ ভৌতিক অংশক কি বোলে?
    (A) হাৰ্ডৱেৰ (Hardware)
    (B) ছফটৱেৰ (Software)
    (C) সদায় কেৱল ফাৰ্মৱেৰ (Firmware only always)
    (D) মেলৱেৰ (Malware)
    উত্তৰ: হাৰ্ডৱেৰ
    ব্যাখ্যা: কম্পিউটাৰৰ যিবোৰ ভৌতিক অংশ দেখা আৰু স্পৰ্শ কৰিব পাৰি তাক হাৰ্ডৱেৰ বোলা হয়, যেনে CPU আৰু মনিটৰ।
    ৩. কম্পিউটাৰে ব্যৱহাৰ কৰা প্ৰগ্ৰাম আৰু তথ্যক কি বোলে?
    (A) ছফটৱেৰ (Software)
    (B) হাৰ্ডৱেৰ (Hardware)
    (C) কেৱল পেৰিফেৰেল (Peripherals only)
    (D) কেবিনেট (Cabinets)
    উত্তৰ: ছফটৱেৰ
    ব্যাখ্যা: কম্পিউটাৰে ব্যৱহাৰ কৰা প্ৰগ্ৰাম, নিৰ্দেশ আৰু তথ্যক চফটৱেৰ বোলা হয়।
    ৪. CPU-ৰ কোন এককে গাণিতিক কাম কৰে?
    (A) ALU
    (B) CU
    (C) কেৱল MU (MU only)
    (D) মনিটৰ (Monitor)
    ব্যাখ্যা: CPU ৰ ALU (Arithmetic Logic Unit) য়ে যোগ, বিয়োগ আদি গাণিতিক কাৰ্য সম্পাদন কৰে।
    Answer: ALU
    ৫. CPU-ত CU-ৰ অৰ্থ কি?
    (A) কণ্ট্ৰোল ইউনিট (Control Unit)
    (B) ক্যাশ ইউনিট (Cache Unit)
    (C) চেণ্ট্ৰেল USB (Central USB)
    (D) কম্পিউটাৰ ইউনিট (Computer Unit)
    উত্তৰ: কণ্ট্ৰোল ইউনিট
    ব্যাখ্যা: CPU ত CU ৰ সম্পূৰ্ণ ৰূপ Control Unit। ই কম্পিউটাৰৰ কাৰ্য পৰিচালনা আৰু সমন্বয় কৰে।
    ৬. তলৰ কোনটো পইণ্টিং ডিভাইচ?
    (A) মাউছ (Mouse)
    (B) প্ৰিণ্টাৰ (Printer)
    (C) স্পীকাৰ (Speaker)
    (D) হেডফোন (Headphones)
    উত্তৰ: মাউছ
    ব্যাখ্যা: মাউছ এটা পইণ্টিং সঁজুলি যি পইণ্টাৰ লগাই পৰ্দাত বস্তু বাছনি কৰিবলৈ ব্যৱহাৰ হয়।
    ৭. OCR-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) অপ্টিকেল কেৰেক্টাৰ ৰিডাৰ / ৰিকগনিচন (Optical Character Reader / Recognition)
    (B) আউটপুট কণ্ট্ৰোল ৰেজিষ্টাৰ (Output Control Register)
    (C) অনলাইন কম্পিউটাৰ ৰেকৰ্ড (Online Computer Record)
    (D) অপ্টিকেল কালাৰ RAM (Optical Colour RAM)
    উত্তৰ: অপ্টিকেল কেৰেক্টাৰ ৰিডাৰ / ৰিকগনিচন
    ব্যাখ্যা: OCR ৰ সম্পূৰ্ণ ৰূপ Optical Character Reader/Recognition। ই ছপা বা হাতেৰে লিখা লিখাক সম্পাদনযোগ্য ডিজিটেল লিখালৈ ৰূপান্তৰ কৰে।
    ৮. MICR মূলতঃ ক’ত ব্যৱহাৰ হয়?
    (A) গেম (Games)
    (B) বেংক চেক (Bank cheques)
    (C) সংগীত প্লেয়াৰ (Music players)
    (D) কেৱল ফটো সম্পাদনা (Photo editing only)
    উত্তৰ: বেংক চেক
    ব্যাখ্যা: MICR মূলতঃ বেংকত চেক প্ৰক্ৰিয়াকৰণৰ বাবে ব্যৱহাৰ হয়।
    ৯. বাৰক’ড ৰিডাৰ কিৰ বাবে ব্যৱহাৰ হয়?
    (A) কিতাপ প্ৰিণ্ট (Print books)
    (B) সামগ্ৰীত ছপা বাৰক’ড পঢ়া (Read printed barcodes on products)
    (C) CPU ঠাণ্ডা কৰা (Cool the CPU)
    (D) চিঠি টাইপ (Type letters)
    উত্তৰ: সামগ্ৰীত ছপা বাৰক’ড পঢ়া
    ব্যাখ্যা: বাৰক'ড ৰিডাৰে সামগ্ৰীৰ ওপৰত ছপা বাৰক'ড স্কেন কৰি তাৰ তথ্য পঢ়ে।
    ১০. SSD-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) চুপাৰ স্পীড ডিস্ক (Super Speed Disk)
    (B) চলিড ষ্টেট ড্ৰাইভ (Solid State Drive)
    (C) চিষ্টেম ষ্ট’ৰেজ ডিভাইচ (System Storage Device)
    (D) ছিৰিয়েল ষ্ট’ৰেজ ড্ৰাইভ (Serial Storage Drive)
    উত্তৰ: চলিড ষ্টেট ড্ৰাইভ
    ব্যাখ্যা: SSD ৰ সম্পূৰ্ণ ৰূপ Solid State Drive। ই ফ্লেশ্ব স্মৃতিত তথ্য ৰাখে আৰু ইয়াত চলন্ত অংশ নাই।
    ১১. কোন সংৰক্ষণ সাধাৰণতে দ্ৰুত?
    (A) মেগনেটিক টেপ (Magnetic tape)
    (B) HDD-তকৈ SSD (SSD compared with HDD)
    (C) ফ্লপি ডিস্ক (Floppy disk)
    (D) পাঞ্চ কাৰ্ড (Punch card)
    উত্তৰ: HDD-তকৈ SSD
    ব্যাখ্যা: SSD সাধাৰণতে HDD তকৈ দ্ৰুত, কাৰণ ইয়াত কোনো চলন্ত যান্ত্ৰিক অংশ নাই।
    ১২. ক্লাউড কম্পিউটিং মানে কি?
    (A) কেৱল পাঞ্চ কাৰ্ডত হিচাপ (Computing only on punch cards)
    (B) ইণ্টাৰনেটভিত্তিক সংৰক্ষণ আৰু সেৱা ব্যৱহাৰ (Using internet-based storage and services)
    (C) কেৱল অফলাইন টাইপৰাইটাৰ (Using only offline typewriters)
    (D) এটা প্ৰিণ্টাৰৰ চিয়াহী (A type of printer ink)
    উত্তৰ: ইণ্টাৰনেটভিত্তিক সংৰক্ষণ আৰু সেৱা ব্যৱহাৰ
    ব্যাখ্যা: ক্লাউড কম্পিউটিং মানে স্থানীয় সঁজুলিৰ সলনি ইণ্টাৰনেট-আধাৰিত সংৰক্ষণ আৰু কম্পিউটিং সেৱা ব্যৱহাৰ কৰা।
    ১৩. Google Drive কিৰ উদাহৰণ?
    (A) অপাৰেটিং চিষ্টেম (Operating system)
    (B) ক্লাউড ষ্ট’ৰেজ (Cloud storage)
    (C) ইনপুট ডিভাইচ (Input device)
    (D) CPU ৰেজিষ্টাৰ (CPU register)
    উত্তৰ: ক্লাউড ষ্ট’ৰেজ
    ব্যাখ্যা: Google Drive ক্লাউড সংৰক্ষণৰ উদাহৰণ, য'ত ফাইল দূৰৱৰ্তী চাৰ্ভাৰত ৰখা হয়।
    ১৪. ব্লুটুথ কিৰ বাবে ব্যৱহাৰ হয়?
    (A) কেৱল ডাঙৰ মানচিত্ৰ প্ৰিণ্ট (Printing huge maps only)
    (B) RAM ঠাণ্ডা কৰা (Cooling RAM)
    (C) চুটি দূৰত্বৰ বেতাৰ যোগাযোগ (Short-range wireless communication)
    (D) কেৱল CD ফৰ্মেট (Formatting CDs only)
    উত্তৰ: চুটি দূৰত্বৰ বেতাৰ যোগাযোগ
    ব্যাখ্যা: ব্লুটুথ ফোন আৰু হেডফোনৰ দৰে সঁজুলিৰ মাজত চুটি পৰিসৰৰ তাৰবিহীন যোগাযোগৰ বাবে ব্যৱহাৰ হয়।
    ১৫. Wi-Fi কিৰ বাবে ব্যৱহাৰ হয়?
    (A) নথি স্কেন (Scan documents)
    (B) হাৰ্ড ডিস্কৰ ভৌতিক আকাৰ বৃদ্ধি (Increase hard disk size physically)
    (C) ডিভাইচক বেতাৰ নেটৱৰ্কত সংযোগ (Connect devices to a wireless network)
    (D) কাগজত গ্ৰাফ আঁকা (Draw graphs on paper)
    উত্তৰ: ডিভাইচক বেতাৰ নেটৱৰ্কত সংযোগ
    ব্যাখ্যা: ৱাই-ফাই সঁজুলিক তাৰবিহীন নেটৱৰ্কত সংযোগ কৰি ইন্টাৰনেট আৰু তথ্য সুবিধা দিয়ে।
    ১৬. IP ঠিকনাই কি চিনাক্ত কৰে?
    (A) প্ৰিণ্টাৰ চিয়াহীৰ ৰং (A printer ink colour)
    (B) কেৱল কীব’ৰ্ড লেআউট (A keyboard layout only)
    (C) নেটৱৰ্কৰ এটা ডিভাইচ (A device on a network)
    (D) এটা প্ৰকাৰৰ ভাইৰাছ (A type of virus)
    উত্তৰ: নেটৱৰ্কৰ এটা ডিভাইচ
    ব্যাখ্যা: এটা IP ঠিকনাই নেটৱৰ্কত সঁজুলি চিনাক্ত কৰি তাৰ ওচৰলৈ তথ্য পঠিয়াবলৈ সহায় কৰে।
    ১৭. ড’মেইন নাম কি?
    (A) এটা প্ৰকাৰৰ RAM (A type of RAM)
    (B) এটা প্ৰিণ্টাৰ প’ৰ্ট (A printer port)
    (C) google.com-ৰ দৰে পঢ়িব পৰা ৱেবছাইট ঠিকনা (A human-readable website address like google.com)
    (D) এটা ALU চাৰ্কিট (An ALU circuit)
    উত্তৰ: google.com-ৰ দৰে পঢ়িব পৰা ৱেবছাইট ঠিকনা
    ব্যাখ্যা: ডমেইন নাম এটা মানুহে পঢ়িব পৰা ৱেবছাইট ঠিকনা, যেনে google.com, যি এটা IP ঠিকনালৈ মেপ কৰা হয়।
    ১৮. চাৰ্চ ইঞ্জিনৰ উদাহৰণ কি?
    (A) MS Excel
    (B) ন’টপেড (Notepad)
    (C) Google
    (D) পেইণ্ট (Paint)
    ব্যাখ্যা: Google এটা চাৰ্চ ইঞ্জিন যি ইণ্টাৰনেটত তথ্য বিচাৰিবলৈ ব্যৱহাৰ হয়।
    Answer: Google
    ১৯. ডাউনল’ড মানে কি?
    (A) আপোনাৰ PC-ৰ পৰা ইণ্টাৰনেটলৈ ফাইল পঠোৱা (Sending a file from your PC to internet)
    (B) ফাইল মচা (Deleting a file)
    (C) ইণ্টাৰনেটৰ পৰা কম্পিউটাৰলৈ ফাইল কপি কৰা (Copying a file from internet to your computer)
    (D) ফাইল প্ৰিণ্ট কৰা (Printing a file)
    উত্তৰ: ইণ্টাৰনেটৰ পৰা কম্পিউটাৰলৈ ফাইল কপি কৰা
    ব্যাখ্যা: ডাউনলোডিং মানে ইণ্টাৰনেট বা চাৰ্ভাৰৰ পৰা ফাইল নিজৰ কম্পিউটাৰলৈ কপি কৰা।
    ২০. আপল’ড মানে কি?
    (A) কেৱল ইমেইল পোৱা (Receiving email only)
    (B) পৃষ্ঠা স্কেন (Scanning a page)
    (C) RAM ফৰ্মেট (Formatting RAM)
    (D) কম্পিউটাৰৰ পৰা ইণ্টাৰনেট / চাৰ্ভাৰলৈ ফাইল পঠোৱা (Sending a file from your computer to the internet / server)
    উত্তৰ: কম্পিউটাৰৰ পৰা ইণ্টাৰনেট / চাৰ্ভাৰলৈ ফাইল পঠোৱা
    ব্যাখ্যা: আপলোডিং মানে নিজৰ কম্পিউটাৰৰ পৰা ফাইল ইণ্টাৰনেট বা দূৰৱৰ্তী চাৰ্ভাৰলৈ পঠোৱা।
    ২১. ইমেইলত CC-ৰ অৰ্থ কি?
    (A) কম্পিউটাৰ ক’ড (Computer Code)
    (B) চেণ্ট্ৰেল কপি (Central Copy)
    (C) কণ্ট্ৰোল ক্লিক (Control Click)
    (D) কাৰ্বন কপি (Carbon Copy)
    উত্তৰ: কাৰ্বন কপি
    ব্যাখ্যা: ইমেইলত CC ৰ অৰ্থ Carbon Copy। CC ত থকা ব্যক্তিয়ে মেইলৰ এটা প্ৰতি পায় আৰু তেওঁলোকৰ নাম আটাইকে দেখে।
    ২২. ইমেইলত BCC-ৰ অৰ্থ কি?
    (A) বেছিক কাৰ্বন কপি (Basic Carbon Copy)
    (B) বেকআপ কম্পিউটাৰ কপি (Backup Computer Copy)
    (C) বাইনেৰী কণ্ট্ৰোল ক’ড (Binary Control Code)
    (D) ব্লাইণ্ড কাৰ্বন কপি (Blind Carbon Copy)
    উত্তৰ: ব্লাইণ্ড কাৰ্বন কপি
    ব্যাখ্যা: ইমেইলত BCC ৰ অৰ্থ Blind Carbon Copy। BCC ত থকা প্ৰাপকসকল আন প্ৰাপকৰ পৰা লুকুৱাই ৰখা হয়।
    ২৩. Ctrl + P শ্বৰ্টকাট সাধাৰণতে কিৰ বাবে?
    (A) পেষ্ট (Paste)
    (B) সদায় কেৱল প্ৰিণ্ট পূৰ্বদৰ্শন (Print preview only always)
    (C) কেৱল গেম পজ (Pause a game only)
    (D) প্ৰিণ্ট (Print)
    উত্তৰ: প্ৰিণ্ট
    ব্যাখ্যা: Ctrl + P সাধাৰণতে বৰ্তমান নথিপত্ৰ বা পৃষ্ঠা ছপা কৰিবলৈ ব্যৱহাৰ হয়।
    ২৪. F1 কি সাধাৰণতে কিৰ বাবে?
    (A) ৰিফ্ৰেছ (Refresh)
    (B) ৰিনেম (Rename)
    (C) ফুল স্ক্ৰীন (Full screen)
    (D) সহায় (Help)
    উত্তৰ: সহায়
    ব্যাখ্যা: F1 কীয়ে বেছিভাগ প্ৰগ্ৰামত সহায় (help) খুলিবলৈ ব্যৱহাৰ হয়।
    ২৫. Windows ডেস্কটপ বা ফ’ল্ডাৰ ৰিফ্ৰেছ কৰিবলৈ সাধাৰণ শ্বৰ্টকাট কি?
    (A) F2
    (B) F1
    (C) F12
    (D) F5
    ব্যাখ্যা: F5 Windows ডেস্কটপ, ফ'ল্ডাৰ বা ৱেবপৃষ্ঠা সতেজ (refresh) কৰাৰ সাধাৰণ শৰ্টকাট।
    Answer: F5
