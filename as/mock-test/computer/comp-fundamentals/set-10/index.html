    গৃহপৃষ্ঠা/মক টেষ্ট/কম্পিউটাৰ সজাগতা/Fundamentals/Set 10

    Comp Fundamentals মক টেষ্ট — ছেট 10

    মক টেষ্ট ছেট 10 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. কম্পিউটাৰত তথ্যৰ আটাইতকৈ সৰু একক কোনটো?
    (A) বাইট (Byte)
    (B) বিট (Bit)
    (C) নিবল (Nibble)
    (D) কিলোবাইট (Kilobyte)
    উত্তৰ: বিট
    ব্যাখ্যা: বিট হৈছে তথ্যৰ আটাইতকৈ সৰু একক, যাৰ মান ০ বা ১ হ'ব পাৰে।
    ২. ১ KB কিমান বাইটৰ সমান?
    (A) ১০০০ বাইট (1000 bytes)
    (B) ১০২৪ বাইট (1024 bytes)
    (C) ৫১২ বাইট (512 bytes)
    (D) ২০৪৮ বাইট (2048 bytes)
    উত্তৰ: ১০২৪ বাইট
    ব্যাখ্যা: ১ KB (কিলোবাইট) = ১০২৪ বাইট।
    ৩. তলৰ কোনটো আটাইতকৈ দ্ৰুত স্মৃতি?
    (A) হাৰ্ড ডিস্ক (Hard disk)
    (B) RAM
    (C) ৰেজিষ্টাৰ (Register)
    (D) কেশ্ব (Cache)
    উত্তৰ: ৰেজিষ্টাৰ
    ব্যাখ্যা: ৰেজিষ্টাৰ CPU-ৰ ভিতৰত থাকে আৰু আটাইতকৈ দ্ৰুত স্মৃতি।
    ৪. CPU-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) চেণ্ট্ৰেল প্ৰচেছ ইউনিট (Central Process Unit)
    (B) চেণ্ট্ৰেল প্ৰচেছিং ইউনিট (Central Processing Unit)
    (C) কম্পিউটাৰ প্ৰচেছিং ইউনিট (Computer Processing Unit)
    (D) চেণ্ট্ৰেল প্ৰগ্ৰাম ইউনিট (Central Program Unit)
    উত্তৰ: চেণ্ট্ৰেল প্ৰচেছিং ইউনিট
    ব্যাখ্যা: CPU ৰ সম্পূৰ্ণ ৰূপ Central Processing Unit, যি নিৰ্দেশনা সম্পাদন আৰু তথ্য প্ৰক্ৰিয়া কৰে।
    ৫. RAM-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ৰেপিড এক্সেছ মেম’ৰী (Rapid Access Memory)
    (B) ৰিড এক্সেছ মেম’ৰী (Read Access Memory)
    (C) ৰেনডম এক্সেছ মেম’ৰী (Random Access Memory)
    (D) ৰেনডম এভেইলেবল মেম’ৰী (Random Available Memory)
    উত্তৰ: ৰেনডম এক্সেছ মেম’ৰী
    ব্যাখ্যা: RAM ৰ সম্পূৰ্ণ ৰূপ Random Access Memory, য'ত তথ্য যিকোনো ক্ৰমত পঢ়া আৰু লিখা যায়।
    ৬. BIOS ছেটিং কোন চিপত সংৰক্ষিত হয়?
    (A) CMOS
    (B) RAM
    (C) ROM
    (D) কেশ্ব (Cache)
    ব্যাখ্যা: BIOS ছেটিং CMOS চিপত সংৰক্ষিত হয়, যি এটা সৰু বেটাৰীৰ দ্বাৰা সমৰ্থিত।
    Answer: CMOS
    ৭. নথিৰ হাৰ্ড কপি তৈয়াৰ কৰিবলৈ কোন সঁজুলি ব্যৱহাৰ হয়?
    (A) মনিটৰ (Monitor)
    (B) স্পীকাৰ (Speaker)
    (C) প্ৰজেক্টৰ (Projector)
    (D) প্ৰিণ্টাৰ (Printer)
    উত্তৰ: প্ৰিণ্টাৰ
    ব্যাখ্যা: প্ৰিণ্টাৰে ডিজিটেল নথিৰ কাগজত হাৰ্ড কপি উৎপন্ন কৰে।
    ৮. WWW-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ৱৰ্ল্ড ৱেব ৱাইড (World Web Wide)
    (B) ৱাইড ৱৰ্ল্ড ৱেব (Wide World Web)
    (C) ৱৰ্ল্ড ৱাইড ৱেব (World Wide Web)
    (D) ৱেব ৱৰ্ল্ড ৱাইড (Web World Wide)
    উত্তৰ: ৱৰ্ল্ড ৱাইড ৱেব
    ব্যাখ্যা: WWW ৰ সম্পূৰ্ণ ৰূপ World Wide Web; ই ইন্টাৰনেটত সংযুক্ত নথিৰ ব্যৱস্থা।
    ৯. HTTP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল (HyperText Transfer Protocol)
    (B) হাইপাৰটেক্সট ট্ৰান্সমিশ্যন প্ৰ’ট’কল (HyperText Transmission Protocol)
    (C) হাই ট্ৰান্সফাৰ টেক্সট প্ৰ’ট’কল (High Transfer Text Protocol)
    (D) হাইপাৰ ট্ৰান্সফাৰ টেক্সট প্ৰ’ট’কল (Hyper Transfer Text Protocol)
    উত্তৰ: হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল
    ব্যাখ্যা: HTTP ৰ সম্পূৰ্ণ ৰূপ HyperText Transfer Protocol, যি ইন্টাৰনেটত ৱেব পৃষ্ঠা প্ৰেৰণ কৰিবলৈ ব্যৱহৃত হয়।
    ১০. HTTPS-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল চিষ্টেম (HyperText Transfer Protocol System)
    (B) হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ছাৰ্ভাৰ (HyperText Transfer Protocol Server)
    (C) হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ষ্টেণ্ডাৰ্ড (HyperText Transfer Protocol Standard)
    (D) হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ছিকিউৰ (HyperText Transfer Protocol Secure)
    উত্তৰ: হাইপাৰটেক্সট ট্ৰান্সফাৰ প্ৰ’ট’কল ছিকিউৰ
    ব্যাখ্যা: HTTPS ৰ সম্পূৰ্ণ ৰূপ HyperText Transfer Protocol Secure, যি ব্ৰাউজাৰ আৰু ছাৰ্ভাৰৰ মাজত তথ্য এনক্ৰিপ্ট কৰে।
    ১১. IP-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ইণ্টাৰনেট প্ৰগ্ৰাম (Internet Program)
    (B) ইণ্টাৰনেট প্ৰ’ট’কল (Internet Protocol)
    (C) ইণ্টাৰনেল প্ৰ’ট’কল (Internal Protocol)
    (D) ইণ্টাৰনেট প্ৰ’ভাইডাৰ (Internet Provider)
    উত্তৰ: ইণ্টাৰনেট প্ৰ’ট’কল
    ব্যাখ্যা: IP ৰ সম্পূৰ্ণ ৰূপ Internet Protocol, যি নেটৱৰ্কত সঁজুলি চিনাক্ত কৰে আৰু তথ্য পথ প্ৰদৰ্শন কৰে।
    ১২. WiFi-ৰ সম্পূৰ্ণ অৰ্থ কি?
    (A) ৱায়াৰলেছ ফাইণ্ডাৰ (Wireless Finder)
    (B) ৱায়াৰ ফিডেলিটি (Wire Fidelity)
    (C) ৱায়াৰলেছ ফিডেলিটি (Wireless Fidelity)
    (D) ৱাইড ফিডেলিটি (Wide Fidelity)
    উত্তৰ: ৱায়াৰলেছ ফিডেলিটি
    ব্যাখ্যা: WiFi ৰ সম্পূৰ্ণ ৰূপ Wireless Fidelity, যি তাৰবিহীন নেটৱৰ্ক সংযোগৰ বাবে ব্যৱহৃত প্ৰযুক্তি।
    ১৩. প্ৰতিটো ইমেইল ঠিকনাত কোন চিহ্ন থাকে?
    (A) @
    (B) #
    (C) $
    (D) %
    ব্যাখ্যা: প্ৰতিটো ইমেইল ঠিকনাত @ চিহ্ন থাকে, যি ব্যৱহাৰকাৰী নাম আৰু ডমেইন নাম পৃথক কৰে।
    Answer: @
    ১৪. ৱেব পৃষ্ঠা ৰিফ্ৰেশ কৰিবলৈ কোন ফাংচন কী ব্যৱহাৰ হয়?
    (A) F1
    (B) F2
    (C) F3
    (D) F5
    ব্যাখ্যা: অধিকাংশ ব্ৰাউজাৰত ৱেব পৃষ্ঠা ৰিফ্ৰেশ বা পুনৰ লোড কৰিবলৈ F5 ব্যৱহাৰ হয়।
    Answer: F5
    ১৫. বাছনি কৰা ফাইলৰ নাম সলনি কৰিবলৈ কোন ফাংচন কী ব্যৱহাৰ হয়?
    (A) F1
    (B) F2
    (C) F3
    (D) F5
    ব্যাখ্যা: Windows-ত বাছনি কৰা ফাইলত F2 টিপিলে ইয়াৰ নাম সলনি কৰিব পাৰি।
    Answer: F2
    ১৬. Ctrl + Alt + Delete সাধাৰণতে কি খুলিবলৈ ব্যৱহাৰ হয়?
    (A) Recycle Bin
    (B) Control Panel
    (C) Task Manager
    (D) My Computer
    ব্যাখ্যা: Ctrl + Alt + Delete এ ছিকিউৰিটি স্ক্ৰীন খোলে, যাৰ পৰা Task Manager খুলিব পাৰি।
    Answer: Task Manager
    ১৭. কোন কী ব্যৱহাৰ কৰি কোনো কাৰ্য বাতিল কৰা হয়?
    (A) Esc
    (B) Enter
    (C) Tab
    (D) Shift
    ব্যাখ্যা: Esc (Escape) কী সাধাৰণতে কোনো কাৰ্য বাতিল বা ওলাই যাবলৈ ব্যৱহাৰ হয়।
    Answer: Esc
    ১৮. কোন কীএ কাৰ্চৰক শাৰীৰ শেষলৈ লৈ যায়?
    (A) Home
    (B) Insert
    (C) End
    (D) Page Up
    ব্যাখ্যা: End কীএ কাৰ্চৰক বৰ্তমান শাৰীৰ শেষলৈ লৈ যায়।
    Answer: End
    ১৯. কোন কীএ কাৰ্চৰৰ বাওঁফালৰ আখৰ মচি পেলায়?
    (A) Delete
    (B) Backspace
    (C) Enter
    (D) Tab
    ব্যাখ্যা: Backspace কীএ কাৰ্চৰৰ ঠিক বাওঁফালে থকা আখৰ মচি পেলায়।
    Answer: Backspace
    ২০. উপস্থাপন তৈয়াৰ কৰিবলৈ কোন ছফ্টৱেৰ ব্যৱহাৰ হয়?
    (A) MS Word
    (B) MS Excel
    (C) MS Access
    (D) MS PowerPoint
    ব্যাখ্যা: MS PowerPoint এপ্লিকেশ্যন ছফ্টৱেৰ, যি স্লাইডশ্ব’ উপস্থাপন তৈয়াৰ কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: MS PowerPoint
    ২১. ছবি সম্পাদনা কৰিবলৈ মূলতঃ কোন ছফ্টৱেৰ ব্যৱহাৰ হয়?
    (A) Photoshop
    (B) MS Word
    (C) Notepad
    (D) MS Excel
    ব্যাখ্যা: Photoshop এটা জনপ্ৰিয় এপ্লিকেশ্যন ছফ্টৱেৰ, যি ছবি সম্পাদনা আৰু পৰিৱৰ্তন কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: Photoshop
    ২২. তলৰ কোনটো ছাৰ্চ ইঞ্জিন?
    (A) Facebook
    (B) YouTube
    (C) Google
    (D) WhatsApp
    ব্যাখ্যা: Google এটা ছাৰ্চ ইঞ্জিন, যি ইন্টাৰনেটত তথ্য বিচাৰিবলৈ ব্যৱহাৰ হয়।
    Answer: Google
    ২৩. ৱেব পৃষ্ঠা তৈয়াৰ কৰিবলৈ তলৰ কোনটো মাৰ্কআপ ভাষা ব্যৱহাৰ হয়?
    (A) HTML
    (B) Java
    (C) Python
    (D) C
    ব্যাখ্যা: HTML এটা মাৰ্কআপ ভাষা, যি ৱেব পৃষ্ঠাত সমলৰ গঠন তৈয়াৰ কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: HTML
    ২৪. ৱেব পৃষ্ঠা styling কৰিবলৈ কোন ভাষা ব্যৱহাৰ হয়?
    (A) CSS
    (B) HTML
    (C) Java
    (D) SQL
    ব্যাখ্যা: CSS (Cascading Style Sheets) ব্যৱহাৰ কৰি ৱেব পৃষ্ঠাৰ বিন্যাস আৰু ৰূপ নিয়ন্ত্ৰণ কৰা হয়।
    Answer: CSS
    ২৫. ৱেব পৃষ্ঠাত ইন্টাৰেক্টিভিটি যোগ কৰিবলৈ কোন ভাষা ব্যৱহাৰ হয়?
    (A) HTML
    (B) CSS
    (C) SQL
    (D) JavaScript
    ব্যাখ্যা: JavaScript এটা স্ক্ৰিপ্টিং ভাষা, যি ৱেব পৃষ্ঠাক ইন্টাৰেক্টিভ কৰিবলৈ ব্যৱহাৰ হয়।
    Answer: JavaScript
