    Ms Office মক টেষ্ট — ছেট 8

    মক টেষ্ট ছেট 8 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. MS Word-ত লিখনী বিচাৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + F
    (B) Ctrl + H
    (C) Ctrl + P
    (D) Ctrl + D
    ব্যাখ্যা: Ctrl + F য়ে MS Word-ত Find বিকল্প খোলে।
    Answer: Ctrl + F
    ২. MS Word-ত Find and Replace ৰ বাবে কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + T
    (B) Ctrl + H
    (C) Ctrl + F
    (D) Ctrl + R
    ব্যাখ্যা: Ctrl + H য়ে Find and Replace ডায়লগ বক্স খোলে।
    Answer: Ctrl + H
    ৩. নথিপত্ৰত ফুটনোট ক'ত দেখা যায়?
    (A) হেডাৰত (In the header)
    (B) মাৰ্জিনত (In the margin)
    (C) পৃষ্ঠাৰ তলত (At the bottom of the page)
    (D) পৃষ্ঠাৰ ওপৰত (At the top of the page)
    উত্তৰ: পৃষ্ঠাৰ তলত
    ব্যাখ্যা: ফুটনোট পৃষ্ঠাৰ তলত দেখা যায়।
    ৪. MS Word-ত Ctrl + Enter য়ে কি সন্নিবেশ কৰে?
    (A) শাৰী বিভাজন (A line break)
    (B) এটা টেবুল (A table)
    (C) এখন ছবি (A picture)
    (D) পৃষ্ঠা বিভাজন (A page break)
    উত্তৰ: পৃষ্ঠা বিভাজন
    ব্যাখ্যা: Ctrl + Enter য়ে MS Word-ত পৃষ্ঠা বিভাজন সন্নিবেশ কৰে।
    ৫. Word ডকুমেণ্টৰ শিৰোনামা আৰু গাঁথনি দেখুওৱা ভিউ কোনটো?
    (A) আউটলাইন ভিউ (Outline view)
    (B) প্ৰিন্ট লে'আউট (Print Layout)
    (C) ৱেব লে'আউট (Web Layout)
    (D) ফুল স্ক্ৰীন ৰিডিং (Full Screen Reading)
    উত্তৰ: আউটলাইন ভিউ
    ব্যাখ্যা: আউটলাইন ভিউয়ে নথিপত্ৰৰ শিৰোনামা আৰু গাঁথনি দেখুৱায়।
    ৬. Excel-ত সৰ্বোচ্চ মান ঘূৰাই দিয়া ফলন কোনটো?
    (A) LARGE
    (B) MAX
    (C) MIN
    (D) SUM
    ব্যাখ্যা: MAX ফলনে এটা পৰিসৰৰ সৰ্বোচ্চ মান ঘূৰাই দিয়ে।
    Answer: MAX
    ৭. Excel-ত তৰ্কমূলক পৰীক্ষাৰ বাবে কোন ফলন ব্যৱহাৰ হয়?
    (A) COUNT
    (B) NOW
    (C) IF
    (D) SUM
    ব্যাখ্যা: IF ফলনে তৰ্কমূলক পৰীক্ষা কৰি দুটা মানৰ এটা ঘূৰাই দিয়ে।
    Answer: IF
    ৮. Excel ফাইলক কি বোলে?
    (A) ৱৰ্কশ্বীট (Worksheet)
    (B) স্লাইড (Slide)
    (C) ডকুমেণ্ট (Document)
    (D) ৱৰ্কবুক (Workbook)
    উত্তৰ: ৱৰ্কবুক
    ব্যাখ্যা: Excel ফাইলক ৱৰ্কবুক বোলে, যি ৱৰ্কশ্বীটবোৰ ধৰি ৰাখে।
    ৯. Excel-ত বৰ্তমান তাৰিখ সন্নিবেশ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + ;
    (B) Ctrl + :
    (C) Ctrl + D
    (D) Ctrl + T
    ব্যাখ্যা: Excel-ত Ctrl + ; য়ে বৰ্তমান তাৰিখ সন্নিবেশ কৰে।
    Answer: Ctrl + ;
    ১০. উলম্ব টেবুলৰ প্ৰথম স্তম্ভত মান বিচাৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) MATCH
    (B) VLOOKUP
    (C) HLOOKUP
    (D) INDEX
    ব্যাখ্যা: VLOOKUP য়ে উলম্ব টেবুলৰ প্ৰথম স্তম্ভত মান বিচাৰে।
    Answer: VLOOKUP
    ১১. Excel চেলত ##### দেখুওৱাৰ অৰ্থ কি?
    (A) চেল খালী (The cell is empty)
    (B) মানটো লিখনী (The value is text)
    (C) স্তম্ভ বহল নহয় (The column is too narrow)
    (D) সূত্ৰ ভুল (The formula is wrong)
    উত্তৰ: স্তম্ভ বহল নহয়
    ব্যাখ্যা: মানটো দেখুৱাবলৈ স্তম্ভ বহল নহ'লে ##### দেখা যায়।
    ১২. Excel-ত Conditional Formatting কিৰ বাবে ব্যৱহাৰ হয়?
    (A) তথ্য সজোৱা (Sorting the data)
    (B) শ্বীট প্ৰিন্ট কৰা (Printing the sheet)
    (C) চেল মাৰ্জ কৰা (Merging cells)
    (D) চৰ্ত অনুসৰি চেল ফৰ্মেট কৰা (Formatting cells based on conditions)
    উত্তৰ: চৰ্ত অনুসৰি চেল ফৰ্মেট কৰা
    ব্যাখ্যা: Conditional Formatting য়ে নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা চেলৰ ৰূপ সলনি কৰে।
    ১৩. PowerPoint-ত বৰ্তমান স্লাইডৰ প্ৰতিলিপি বনাবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + D
    (B) Ctrl + M
    (C) Ctrl + N
    (D) Ctrl + C
    ব্যাখ্যা: PowerPoint-ত Ctrl + D য়ে বাছনি কৰা স্লাইডৰ প্ৰতিলিপি বনায়।
    Answer: Ctrl + D
    ১৪. PowerPoint-ত থীম প্ৰয়োগ কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Transitions
    (B) Design
    (C) Home
    (D) Insert
    ব্যাখ্যা: PowerPoint-ত থীম আৰু ভেৰিয়েণ্ট প্ৰয়োগ কৰিবলৈ Design টেব ব্যৱহাৰ হয়।
    Answer: Design
    ১৫. PowerPoint-ত Presenter View য়ে কি দেখুৱায়?
    (A) কেৱল স্লাইড থাম্বনেইল (Only the slide thumbnails)
    (B) কেৱল ফাইলৰ নাম (Only the file name)
    (C) স্পীকাৰ নোট আৰু পৰৱৰ্তী স্লাইড (Speaker notes and the next slide)
    (D) কেৱল বৰ্তমান স্লাইড (Only the current slide)
    উত্তৰ: স্পীকাৰ নোট আৰু পৰৱৰ্তী স্লাইড
    ব্যাখ্যা: Presenter View য়ে স্পীকাৰ নোট, বৰ্তমান স্লাইড আৰু পৰৱৰ্তী স্লাইড দেখুৱায়।
    ১৬. PowerPoint-ত এটা স্লাইড কি?
    (A) এবিধ চাৰ্ট (A type of chart)
    (B) সংৰক্ষিত ফাইল (A saved file)
    (C) কীবৰ্ড চৰ্টকাট (A keyboard shortcut)
    (D) প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠা (A single page of a presentation)
    উত্তৰ: প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠা
    ব্যাখ্যা: স্লাইড হৈছে প্ৰেজেণ্টেচনৰ এটা পৃষ্ঠা।
    ১৭. বৰ্তমান স্লাইডৰপৰা স্লাইড শ্ব' আৰম্ভ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Shift + F5
    (B) F5
    (C) Ctrl + F5
    (D) Alt + F5
    ব্যাখ্যা: Shift + F5 য়ে বৰ্তমান স্লাইডৰপৰা স্লাইড শ্ব' আৰম্ভ কৰে।
    Answer: Shift + F5
    ১৮. MS Access কি ধৰণৰ চফটৱেৰ?
    (A) প্ৰেজেণ্টেচন চফটৱেৰ (Presentation software)
    (B) ৰিলেচনেল ডেটাবেছ মেনেজমেণ্ট চিষ্টেম (Relational database management system)
    (C) শব্দ প্ৰক্ৰিয়াকৰণ চফটৱেৰ (Word processing software)
    (D) স্প্ৰেডশ্বীট চফটৱেৰ (Spreadsheet software)
    উত্তৰ: ৰিলেচনেল ডেটাবেছ মেনেজমেণ্ট চিষ্টেম
    ব্যাখ্যা: MS Access এটা ৰিলেচনেল ডেটাবেছ মেনেজমেণ্ট চিষ্টেম।
    ১৯. কোন Access ডেটা টাইপে স্বয়ংক্ৰিয়ভাৱে অদ্বিতীয় সংখ্যা সৃষ্টি কৰে?
    (A) সংখ্যা (Number)
    (B) তাৰিখ/সময় (Date/Time)
    (C) অট'নাম্বাৰ (AutoNumber)
    (D) চুটি লিখনী (Short Text)
    উত্তৰ: অট'নাম্বাৰ
    ব্যাখ্যা: AutoNumber ডেটা টাইপে প্ৰতিটো ৰেকৰ্ডৰ বাবে স্বয়ংক্ৰিয়ভাৱে অদ্বিতীয় সংখ্যা সৃষ্টি কৰে।
    ২০. পুনৰাবৃত্তিমূলক কাম স্বয়ংক্ৰিয় কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) টেবুল (Table)
    (B) কুৱেৰী (Query)
    (C) ৰিপৰ্ট (Report)
    (D) মেক্ৰ' (Macro)
    উত্তৰ: মেক্ৰ'
    ব্যাখ্যা: MS Access-ত কাম স্বয়ংক্ৰিয় কৰিবলৈ মেক্ৰ' ব্যৱহাৰ হয়।
    ২১. ইমেইলত CC ৰ অৰ্থ কি?
    (A) Carbon Copy
    (B) Blind Carbon Copy
    (C) Computer Copy
    (D) Common Copy
    ব্যাখ্যা: CC ৰ সম্পূৰ্ণ ৰূপ হৈছে Carbon Copy।
    Answer: Carbon Copy
    ২২. সভা আৰু অপয়ন্টমেণ্টৰ সময় নিৰ্ধাৰণ কৰিবলৈ Outlook-ৰ কোন সুবিধা ব্যৱহাৰ হয়?
    (A) নোটছ (Notes)
    (B) কেলেণ্ডাৰ (Calendar)
    (C) কণ্টেক্টছ (Contacts)
    (D) টাস্কছ (Tasks)
    উত্তৰ: কেলেণ্ডাৰ
    ব্যাখ্যা: Calendar সুবিধা সভা আৰু অপয়ন্টমেণ্টৰ সময় নিৰ্ধাৰণ কৰিবলৈ ব্যৱহাৰ হয়।
    ২৩. MS Office-ত বাছনি কৰা বস্তু কপি কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + V
    (B) Ctrl + Z
    (C) Ctrl + C
    (D) Ctrl + X
    ব্যাখ্যা: Ctrl + C য়ে বাছনি কৰা বস্তু ক্লিপব'ৰ্ডলৈ কপি কৰে।
    Answer: Ctrl + C
    ২৪. MS Office-ত টেমপ্লেট কি?
    (A) সংৰক্ষিত ইমেইল (A saved email)
    (B) এবিধ চাৰ্ট (A type of chart)
    (C) কীবৰ্ড চৰ্টকাট (A keyboard shortcut)
    (D) পূৰ্ব-পৰিকল্পিত নথিপত্ৰৰ আৰ্হি (A pre-designed document format)
    উত্তৰ: পূৰ্ব-পৰিকল্পিত নথিপত্ৰৰ আৰ্হি
    ব্যাখ্যা: টেমপ্লেট হৈছে নতুন নথিপত্ৰৰ আৰম্ভণি বিন্দু হিচাপে ব্যৱহৃত পূৰ্ব-পৰিকল্পিত আৰ্হি।
    ২৫. MS Office-ত সহায় (Help) পাবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) F1
    (B) F2
    (C) F5
    (D) F7
    ব্যাখ্যা: F1 য়ে MS Office-ত সহায় উইণ্ডো খোলে।
    Answer: F1
