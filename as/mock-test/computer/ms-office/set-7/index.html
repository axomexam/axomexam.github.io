    Ms Office মক টেষ্ট — ছেট 7

    মক টেষ্ট ছেট 7 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. MS Word-ত নথিপত্ৰ প্ৰিন্ট কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + P
    (B) Ctrl + S
    (C) Ctrl + O
    (D) Ctrl + N
    ব্যাখ্যা: Ctrl + P য়ে MS Word-ত প্ৰিন্টৰ বিকল্প খোলে।
    Answer: Ctrl + P
    ২. MS Word-ত বানান আৰু ব্যাকৰণ পৰীক্ষা কৰিবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) F9
    (B) F7
    (C) F1
    (D) F5
    ব্যাখ্যা: F7 য়ে MS Word-ত বানান আৰু ব্যাকৰণ পৰীক্ষা আৰম্ভ কৰে।
    Answer: F7
    ৩. Word ডকুমেণ্টত হেডাৰ ক'ত দেখা যায়?
    (A) পৃষ্ঠাৰ মাজত (In the middle of the page)
    (B) কেৱল শেষ পৃষ্ঠাত (Only on the last page)
    (C) পৃষ্ঠাৰ ওপৰত (At the top of the page)
    (D) পৃষ্ঠাৰ তলত (At the bottom of the page)
    উত্তৰ: পৃষ্ঠাৰ ওপৰত
    ব্যাখ্যা: হেডাৰ প্ৰতিটো পৃষ্ঠাৰ ওপৰত দেখা যায়।
    ৪. Word-ত Track Changes সুবিধা কিৰ বাবে ব্যৱহাৰ হয়?
    (A) নথিপত্ৰ প্ৰিন্ট কৰা (To print the document)
    (B) শব্দ গণনা কৰা (To count the words)
    (C) ফণ্ট সলনি কৰা (To change the font)
    (D) নথিপত্ৰত কৰা পৰিৱৰ্তন লিপিবদ্ধ কৰা (To record edits made to a document)
    উত্তৰ: নথিপত্ৰত কৰা পৰিৱৰ্তন লিপিবদ্ধ কৰা
    ব্যাখ্যা: Track Changes য়ে সকলো পৰিৱৰ্তন লিপিবদ্ধ কৰে, যাতে পৰ্যালোচনা কৰিব পাৰি।
    ৫. Word টেমপ্লেট ফাইলৰ এক্সটেনশ্যন কি?
    (A) .dotx
    (B) .docx
    (C) .docm
    (D) .pdf
    ব্যাখ্যা: Word টেমপ্লেটে .dotx এক্সটেনশ্যন ব্যৱহাৰ কৰে।
    Answer: .dotx
    ৬. Excel-ত সংখ্যাৰ গড় নিৰ্ণয় কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) MAX
    (B) AVERAGE
    (C) SUM
    (D) COUNT
    ব্যাখ্যা: AVERAGE ফলনে এটা পৰিসৰৰ গাণিতিক গড় ঘূৰাই দিয়ে।
    Answer: AVERAGE
    ৭. Excel-ত AutoSum ৰ বাবে কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Alt + S
    (B) Ctrl + S
    (C) Alt + =
    (D) Ctrl + =
    ব্যাখ্যা: Excel-ত Alt + = য়ে AutoSum সূত্ৰ সন্নিবেশ কৰে।
    Answer: Alt + =
    ৮. চৰ্ত পূৰণ কৰা চেলৰ সংখ্যা গণনা কৰিবলৈ কোন ফলন ব্যৱহাৰ হয়?
    (A) COUNT
    (B) SUMIF
    (C) IF
    (D) COUNTIF
    ব্যাখ্যা: COUNTIF য়ে নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা চেলবোৰ গণনা কৰে।
    Answer: COUNTIF
    ৯. Excel-ত Freeze Panes ৰ উদ্দেশ্য কি?
    (A) স্ক্ৰল কৰাৰ সময়তো শাৰী বা স্তম্ভ দেখা ৰখা (Keep rows or columns visible while scrolling)
    (B) বাছনি কৰা শাৰীবোৰ লুকুৱা (Hide the selected rows)
    (C) খালী শাৰীবোৰ মচা (Delete empty rows)
    (D) চাৰ্টৰ প্ৰকাৰ সলনি কৰা (Change the chart type)
    উত্তৰ: স্ক্ৰল কৰাৰ সময়তো শাৰী বা স্তম্ভ দেখা ৰখা
    ব্যাখ্যা: Freeze Panes য়ে স্ক্ৰল কৰাৰ সময়তো বাছনি কৰা শাৰী বা স্তম্ভ দেখা ৰাখে।
    ১০. এটা লিখনীৰ আখৰৰ সংখ্যা ঘূৰাই দিয়া ফলন কোনটো?
    (A) TRIM
    (B) LEN
    (C) LEFT
    (D) MID
    ব্যাখ্যা: LEN ফলনে এটা লিখনীৰ আখৰৰ সংখ্যা ঘূৰাই দিয়ে।
    Answer: LEN
    ১১. Excel-ত Filter সুবিধা কিৰ বাবে ব্যৱহাৰ হয়?
    (A) চেলবোৰ মাৰ্জ কৰা (To merge the cells)
    (B) ফণ্টৰ ৰং সলনি কৰা (To change the font colour)
    (C) কেৱল চৰ্ত পূৰণ কৰা শাৰী দেখুওৱা (To show only rows that meet a condition)
    (D) তথ্য বৰ্ণানুক্ৰমে সজোৱা (To sort the data alphabetically)
    উত্তৰ: কেৱল চৰ্ত পূৰণ কৰা শাৰী দেখুওৱা
    ব্যাখ্যা: Filter য়ে কেৱল নিৰ্দিষ্ট চৰ্ত পূৰণ কৰা শাৰীবোৰ দেখুৱায়।
    ১২. Excel-ত PivotTable সন্নিবেশ কৰিবলৈ কোন টেব ব্যৱহাৰ হয়?
    (A) Home
    (B) View
    (C) Formulas
    (D) Insert
    ব্যাখ্যা: Excel-ত PivotTable Insert টেবৰপৰা সন্নিবেশ কৰা হয়।
    Answer: Insert
    ১৩. PowerPoint-ত নতুন স্লাইড যোগ কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + M
    (B) Ctrl + N
    (C) Ctrl + S
    (D) Ctrl + P
    ব্যাখ্যা: PowerPoint-ত Ctrl + M য়ে নতুন স্লাইড যোগ কৰে।
    Answer: Ctrl + M
    ১৪. চলি থকা স্লাইড শ্ব' শেষ কৰিবলৈ কোন কী ব্যৱহাৰ হয়?
    (A) স্পেচবাৰ (Spacebar)
    (B) Esc
    (C) Enter
    (D) Tab
    ব্যাখ্যা: PowerPoint-ত চলি থকা স্লাইড শ্ব' শেষ কৰিবলৈ Esc কী ব্যৱহাৰ হয়।
    Answer: Esc
    ১৫. Transition কিমানৰ মাজত প্ৰয়োগ কৰা হয়?
    (A) দুটা ফণ্টৰ মাজত (Two fonts)
    (B) দুটা টেবৰ মাজত (Two tabs)
    (C) দুটা স্লাইডৰ মাজত (Two slides)
    (D) স্লাইডৰ দুটা বস্তুৰ মাজত (Two objects on a slide)
    উত্তৰ: দুটা স্লাইডৰ মাজত
    ব্যাখ্যা: Transition হৈছে দুটা স্লাইডৰ মাজত ঘটা প্ৰভাৱ।
    ১৬. স্লাইডবোৰ সৰু থাম্বনেইল হিচাপে দেখুওৱা ভিউ কোনটো?
    (A) Normal ভিউ (Normal view)
    (B) Reading ভিউ (Reading view)
    (C) Outline ভিউ (Outline view)
    (D) Slide Sorter ভিউ (Slide Sorter view)
    উত্তৰ: Slide Sorter ভিউ
    ব্যাখ্যা: Slide Sorter ভিউত সকলো স্লাইড থাম্বনেইল হিচাপে দেখা যায়, যাতে সজাই পৰিবৰ্তন কৰিব পাৰি।
    ১৭. পোনপটীয়াকৈ স্লাইড শ্ব' হিচাপে খোলা PowerPoint ফাইল কোনটো?
    (A) .ppsx
    (B) .pptx
    (C) .potx
    (D) .docx
    ব্যাখ্যা: .ppsx ফাইল পোনপটীয়াকৈ স্লাইড শ্ব' ম'ডত খোলে।
    Answer: .ppsx
    ১৮. তথ্য প্ৰৱেশ কৰিবলৈ সহজ স্ক্ৰীন প্ৰদান কৰা Access বস্তু কোনটো?
    (A) মেক্ৰ' (Macro)
    (B) ফৰ্ম (Form)
    (C) টেবুল (Table)
    (D) ৰিপৰ্ট (Report)
    উত্তৰ: ফৰ্ম
    ব্যাখ্যা: ফৰ্মে তথ্য প্ৰৱেশ আৰু সম্পাদনাৰ বাবে ব্যৱহাৰকাৰী-বান্ধৱ স্ক্ৰীন প্ৰদান কৰে।
    ১৯. ছপা কৰিব পৰা আউটপুট তৈয়াৰ কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) কুৱেৰী (Query)
    (B) টেবুল (Table)
    (C) ৰিপৰ্ট (Report)
    (D) ফৰ্ম (Form)
    উত্তৰ: ৰিপৰ্ট
    ব্যাখ্যা: ৰিপৰ্টে তথ্য ছপা কৰিব পৰা ৰূপত উপস্থাপন কৰে।
    ২০. তথ্য উদ্ধাৰ বা ফিল্টাৰ কৰিবলৈ Access-ৰ কোন বস্তু ব্যৱহাৰ হয়?
    (A) টেবুল (Table)
    (B) ফৰ্ম (Form)
    (C) ৰিপৰ্ট (Report)
    (D) কুৱেৰী (Query)
    উত্তৰ: কুৱেৰী
    ব্যাখ্যা: কুৱেৰীয়ে টেবুলৰপৰা তথ্য উদ্ধাৰ, ফিল্টাৰ আৰু সজোৱাৰ বাবে ব্যৱহাৰ হয়।
    ২১. Outlook-ত লোৱা ইমেইলবোৰ কোন ফোল্ডাৰত থাকে?
    (A) ইনবক্স (Inbox)
    (B) প্ৰেৰিত আইটেম (Sent Items)
    (C) ড্ৰাফ্ট (Drafts)
    (D) আউটবক্স (Outbox)
    উত্তৰ: ইনবক্স
    ব্যাখ্যা: লোৱা ইমেইলবোৰ Inbox ত সংৰক্ষিত থাকে।
    ২২. Outlook-ত প্ৰাপ্ত ইমেইলৰ উত্তৰ দিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + S
    (B) Ctrl + R
    (C) Ctrl + F
    (D) Ctrl + N
    ব্যাখ্যা: Outlook-ত বাছনি কৰা ইমেইলৰ উত্তৰ দিবলৈ Ctrl + R ব্যৱহাৰ হয়।
    Answer: Ctrl + R
    ২৩. MS Office-ত শেষ কাৰ্য বাতিল কৰিবলৈ কোন চৰ্টকাট ব্যৱহাৰ হয়?
    (A) Ctrl + X
    (B) Ctrl + C
    (C) Ctrl + Z
    (D) Ctrl + Y
    ব্যাখ্যা: Ctrl + Z য়ে শেষ কাৰ্য বাতিল কৰে।
    Answer: Ctrl + Z
    ২৪. MS Office ৰিবনত কি থাকে?
    (A) কেৱল ফণ্ট (Only fonts)
    (B) সংৰক্ষিত ফাইল (Saved files)
    (C) ইমেইল বাৰ্তা (Email messages)
    (D) টেবত সংগঠিত কামৰ সঁজুলি (Commands organised in tabs)
    উত্তৰ: টেবত সংগঠিত কামৰ সঁজুলি
    ব্যাখ্যা: ৰিবনত টেবত সংগঠিত কামৰ সঁজুলি থাকে।
    ২৫. কোন MS Office এপ্লিকেচন স্প্ৰেডশ্বীট প্ৰগ্ৰাম?
    (A) Excel
    (B) Word
    (C) PowerPoint
    (D) Access
    ব্যাখ্যা: Excel হৈছে MS Office ৰ স্প্ৰেডশ্বীট প্ৰগ্ৰাম।
    Answer: Excel
