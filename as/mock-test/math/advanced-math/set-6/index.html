    Advanced Math মক টেষ্ট — ছেট 6

    উচ্চ গণিতত বীজগণিত, জ্যামিতি, ত্ৰিকোণমিতি, সংখ্যা প্ৰণালী আৰু উচ্চস্তৰৰ সমস্যা সমাধান সামৰি লোৱা হৈছে। মক টেষ্ট ছেট 6 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. যদি x + 1/x = 4 হয়, তেন্তে x² + 1/x² ৰ মান কি?
    (A) 14
    (B) 16
    (C) 12
    (D) 18
    ব্যাখ্যা: x² + 1/x² = (x + 1/x)² − 2 = 4² − 2 = 14।
    Answer: 14
    ২. যদি x − 1/x = 5 হয়, তেন্তে x² + 1/x² ৰ মান কি?
    (A) 23
    (B) 25
    (C) 27
    (D) 29
    ব্যাখ্যা: x² + 1/x² = (x − 1/x)² + 2 = 5² + 2 = 27।
    Answer: 27
    ৩. x² + 5x + 6 ৰ উৎপাদক বিশ্লেষণ কি?
    (A) (x + 1)(x + 6)
    (B) (x + 2)(x + 3)
    (C) (x − 2)(x − 3)
    (D) (x + 5)(x + 1)
    ব্যাখ্যা: x² + 5x + 6 = (x + 2)(x + 3), কাৰণ 2 + 3 = 5 আৰু 2 × 3 = 6।
    Answer: (x + 2)(x + 3)
    ৪. যদি a + b = 5 আৰু a − b = 3 হয়, তেন্তে ab ৰ মান কি?
    (A) 4
    (B) 5
    (C) 3
    (D) 2
    ব্যাখ্যা: সমাধান কৰি a = 4 আৰু b = 1, গতিকে ab = 4।
    Answer: 4
    ৫. অভেদ ব্যৱহাৰ কৰি (102)² ৰ মান কি?
    (A) 10404
    (B) 10204
    (C) 10004
    (D) 10440
    ব্যাখ্যা: (100 + 2)² = 100² + 2 × 100 × 2 + 2² = 10000 + 400 + 4 = 10404।
    Answer: 10404
    ৬. যদি a + b + c = 9 আৰু ab + bc + ca = 26 হয়, তেন্তে a² + b² + c² ৰ মান কি?
    (A) 29
    (B) 31
    (C) 27
    (D) 25
    ব্যাখ্যা: a² + b² + c² = (a + b + c)² − 2(ab + bc + ca) = 81 − 52 = 29।
    Answer: 29
    ৭. x³ − 8 ৰ উৎপাদক বিশ্লেষণ কি?
    (A) (x − 2)(x² + 2x + 4)
    (B) (x − 2)(x² − 2x + 4)
    (C) (x + 2)(x² − 2x + 4)
    (D) (x − 2)³
    ব্যাখ্যা: a³ − b³ = (a − b)(a² + ab + b²) সূত্ৰৰপৰা x³ − 8 = (x − 2)(x² + 2x + 4)।
    Answer: (x − 2)(x² + 2x + 4)
    ৮. যদি x + 1/x = 2 হয়, তেন্তে x³ + 1/x³ ৰ মান কি?
    (A) 6
    (B) 8
    (C) 2
    (D) 4
    ব্যাখ্যা: x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 8 − 6 = 2।
    Answer: 2
    ৯. x³ + 3x² + 3x + 1 ক (x + 1) ৰে ভাগ কৰিলে অৱশেষ কিমান?
    (A) 0
    (B) 1
    (C) −1
    (D) 2
    ব্যাখ্যা: x = −1 বহুৱাই: −1 + 3 − 3 + 1 = 0, গতিকে অৱশেষ 0।
    Answer: 0
    ১০. যদি x = √5 + 2 হয়, তেন্তে x − 1/x ৰ মান কি?
    (A) 4
    (B) 2√5
    (C) 2
    (D) √5
    ব্যাখ্যা: 1/x = √5 − 2, গতিকে x − 1/x = (√5 + 2) − (√5 − 2) = 4।
    Answer: 4
    ১১. √(6 + √(6 + √(6 + …))) ৰ মান কি?
    (A) 3
    (B) 2
    (C) 6
    (D) 4
    ব্যাখ্যা: x = √(6 + x) ধৰি, x² = 6 + x, যাৰপৰা x = 3 (ধনাত্মক মূল)।
    Answer: 3
    ১২. যদি a + b = 3 আৰু ab = 2 হয়, তেন্তে a³ + b³ ৰ মান কি?
    (A) 9
    (B) 7
    (C) 11
    (D) 15
    ব্যাখ্যা: a³ + b³ = (a + b)³ − 3ab(a + b) = 27 − 18 = 9।
    Answer: 9
    ১৩. সৰল কৰা: (a + b)³ − (a − b)³।
    (A) 2b(3a² + b²)
    (B) 2a(3b² + a²)
    (C) 6ab(a + b)
    (D) 2b²(3a + b)
    ব্যাখ্যা: (a + b)³ − (a − b)³ = 6a²b + 2b³ = 2b(3a² + b²)।
    Answer: 2b(3a² + b²)
    ১৪. যদি x² + 1/x² = 7 হয়, তেন্তে x − 1/x ৰ মান কি?
    (A) √5
    (B) √7
    (C) 5
    (D) 3
    ব্যাখ্যা: (x − 1/x)² = x² + 1/x² − 2 = 7 − 2 = 5, গতিকে x − 1/x = √5।
    Answer: √5
    ১৫. x² − 1 আৰু x² − 2x + 1 ৰ গৰিষ্ঠ সাধাৰণ উৎপাদক কি?
    (A) x − 1
    (B) x + 1
    (C) (x − 1)²
    (D) x² − 1
    ব্যাখ্যা: x² − 1 = (x − 1)(x + 1) আৰু x² − 2x + 1 = (x − 1)², গতিকে HCF = x − 1।
    Answer: x − 1
    ১৬. যদি a/3 = b/4 = c/5 হয়, তেন্তে (a + b + c)/c ৰ মান কি?
    (A) 12/5
    (B) 5/12
    (C) 3/5
    (D) 7/5
    ব্যাখ্যা: a = 3k, b = 4k, c = 5k ধৰি (a + b + c)/c = 12k/5k = 12/5।
    Answer: 12/5
    ১৭. 999 × 1001 ৰ মান কি?
    (A) 999999
    (B) 999899
    (C) 999099
    (D) 998999
    ব্যাখ্যা: 999 × 1001 = (1000 − 1)(1000 + 1) = 1000² − 1² = 999999।
    Answer: 999999
    ১৮. যদি x + y = 5 আৰু x² + y² = 13 হয়, তেন্তে xy ৰ মান কি?
    (A) 6
    (B) 5
    (C) 12
    (D) 4
    ব্যাখ্যা: xy = ((x + y)² − (x² + y²))/2 = (25 − 13)/2 = 6।
    Answer: 6
    ১৯. a³ + b³ ৰ উৎপাদক কি?
    (A) (a + b)(a² − ab + b²)
    (B) (a + b)(a² + ab + b²)
    (C) (a − b)(a² + ab + b²)
    (D) (a + b)³
    ব্যাখ্যা: a³ + b³ = (a + b)(a² − ab + b²)।
    Answer: (a + b)(a² − ab + b²)
    ২০. যদি p(x) = x² − 3x + 2 হয়, তেন্তে p(2) ৰ মান কি?
    (A) 0
    (B) 2
    (C) 4
    (D) −2
    ব্যাখ্যা: p(2) = 4 − 6 + 2 = 0।
    Answer: 0
    ২১. (2 + √3)(2 − √3) ৰ মান কি?
    (A) 1
    (B) 7
    (C) 4
    (D) −1
    ব্যাখ্যা: (2 + √3)(2 − √3) = 2² − (√3)² = 4 − 3 = 1।
    Answer: 1
    ২২. যদি 5ˣ = 625 হয়, তেন্তে x ৰ মান কি?
    (A) 4
    (B) 3
    (C) 5
    (D) 6
    ব্যাখ্যা: 625 = 5⁴, গতিকে x = 4।
    Answer: 4
    ২৩. যদি x − 1/x = 3 হয়, তেন্তে x³ − 1/x³ ৰ মান কি?
    (A) 36
    (B) 27
    (C) 18
    (D) 30
    ব্যাখ্যা: x³ − 1/x³ = (x − 1/x)³ + 3(x − 1/x) = 27 + 9 = 36।
    Answer: 36
    ২৪. (a + b)⁴ ৰ সম্প্ৰসাৰণত কিমানটা পদ থাকে?
    (A) 5
    (B) 4
    (C) 6
    (D) 3
    ব্যাখ্যা: (a + b)ⁿ ৰ সম্প্ৰসাৰণত n + 1 টা পদ থাকে, গতিকে ইয়াত 4 + 1 = 5।
    Answer: 5
    ২৫. যদি a + b + c = 0 আৰু a² + b² + c² = 16 হয়, তেন্তে ab + bc + ca ৰ মান কি?
    (A) −8
    (B) 8
    (C) −16
    (D) 16
    ব্যাখ্যা: ab + bc + ca = ((a + b + c)² − (a² + b² + c²))/2 = (0 − 16)/2 = −8।
    Answer: −8

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
