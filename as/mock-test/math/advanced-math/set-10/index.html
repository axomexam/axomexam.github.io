    Advanced Math মক টেষ্ট — ছেট 10

    উচ্চ গণিতত বীজগণিত, জ্যামিতি, ত্ৰিকোণমিতি, সংখ্যা প্ৰণালী আৰু উচ্চস্তৰৰ সমস্যা সমাধান সামৰি লোৱা হৈছে। মক টেষ্ট ছেট 10 ত এই বিষয়ৰ দ্বিভাষিক প্ৰশ্ন আছে, প্ৰতিটোৰ উত্তৰ আৰু চুটি ব্যাখ্যাৰ সৈতে। অনুশীলনৰ বাবে অনলাইনত সময়বদ্ধ পৰীক্ষা দিয়ক বা তলত সম্পূৰ্ণ ছেট পঢ়ক।

    ২৫ টা প্ৰশ্ন আৰু উত্তৰ

    ১. (0, 0) আৰু (3, 4) বিন্দু দুটাৰ মাজৰ দূৰত্ব কিমান?
    (A) 5
    (B) 7
    (C) 25
    (D) 1
    ব্যাখ্যা: d = √(3² + 4²) = √25 = 5।
    Answer: 5
    ২. (1, 2) আৰু (3, 6) ৰ মাজেৰে যোৱা ৰেখাৰ ঢাল কিমান?
    (A) 2
    (B) 1/2
    (C) 4
    (D) −2
    ব্যাখ্যা: ঢাল = (6 − 2)/(3 − 1) = 4/2 = 2।
    Answer: 2
    ৩. (2, 4) আৰু (6, 8) যোগ কৰা ৰেখাখণ্ডৰ মধ্যবিন্দু কি?
    (A) (4, 6)
    (B) (8, 12)
    (C) (2, 2)
    (D) (3, 3)
    ব্যাখ্যা: মধ্যবিন্দু = ((2 + 6)/2, (4 + 8)/2) = (4, 6)।
    Answer: (4, 6)
    ৪. x-অক্ষৰ সমীকৰণ কি?
    (A) y = 0
    (B) x = 0
    (C) x = y
    (D) y = 1
    ব্যাখ্যা: x-অক্ষৰ প্ৰতিটো বিন্দুৰ y = 0।
    Answer: y = 0
    ৫. মূলবিন্দুৰপৰা (3, 4) বিন্দুৰ দূৰত্ব কিমান?
    (A) 5
    (B) 7
    (C) 12
    (D) 1
    ব্যাখ্যা: d = √(3² + 4²) = 5।
    Answer: 5
    ৬. y = 2x + 3 ৰেখাৰ ঢাল কিমান?
    (A) 2
    (B) 3
    (C) −2
    (D) 1/2
    ব্যাখ্যা: y = mx + c ৰ সৈতে তুলনা কৰি ঢাল m = 2।
    Answer: 2
    ৭. log₁₀ 100 ৰ মান কি?
    (A) 2
    (B) 10
    (C) 1
    (D) 100
    ব্যাখ্যা: 10² = 100 হোৱাত log₁₀ 100 = 2।
    Answer: 2
    ৮. log₂ 8 ৰ মান কি?
    (A) 3
    (B) 2
    (C) 4
    (D) 8
    ব্যাখ্যা: 2³ = 8 হোৱাত log₂ 8 = 3।
    Answer: 3
    ৯. x ৰ সাপেক্ষে x² ৰ অৱকলজ কি?
    (A) 2x
    (B) x
    (C) x²
    (D) 2
    ব্যাখ্যা: d/dx (x²) = 2x।
    Answer: 2x
    ১০. x ৰ সাপেক্ষে sin x ৰ অৱকলজ কি?
    (A) cos x
    (B) −cos x
    (C) sin x
    (D) −sin x
    ব্যাখ্যা: d/dx (sin x) = cos x।
    Answer: cos x
    ১১. সমাকল ∫ x dx ৰ মান কি?
    (A) x²/2 + C
    (B) x² + C
    (C) 2x + C
    (D) x + C
    ব্যাখ্যা: ∫ x dx = x²/2 + C।
    Answer: x²/2 + C
    ১২. সমাকল ∫ dx ৰ মান কি?
    (A) x + C
    (B) 1 + C
    (C) x² + C
    (D) C
    ব্যাখ্যা: ∫ dx = x + C।
    Answer: x + C
    ১৩. lim (x→1) (x² − 1)/(x − 1) ৰ মান কি?
    (A) 2
    (B) 1
    (C) 0
    (D) অস্তিত্ব নাই (Does not exist)
    ব্যাখ্যা: x ≠ 1 ৰ বাবে (x² − 1)/(x − 1) = x + 1, গতিকে সীমা 2।
    Answer: 2
    ১৪. x ৰ সাপেক্ষে eˣ ৰ অৱকলজ কি?
    (A) eˣ
    (B) x eˣ
    (C) eˣ/x
    (D) 1
    ব্যাখ্যা: d/dx (eˣ) = eˣ।
    Answer: eˣ
    ১৫. log a + log b ৰ মান কি?
    (A) log(ab)
    (B) log(a + b)
    (C) log(a/b)
    (D) log a × log b
    ব্যাখ্যা: গুণন নিয়ম অনুসৰি log a + log b = log(ab)।
    Answer: log(ab)
    ১৬. log 1 ৰ মান কি?
    (A) 0
    (B) 1
    (C) ∞
    (D) −1
    ব্যাখ্যা: যিকোনো ভিত্তিৰ বাবে log 1 = 0।
    Answer: 0
    ১৭. এটা ধ্ৰুৱকৰ অৱকলজ কি?
    (A) 0
    (B) 1
    (C) ধ্ৰুৱকটো নিজেই (the constant itself)
    (D) অনিৰ্ধাৰিত (undefined)
    ব্যাখ্যা: যিকোনো ধ্ৰুৱকৰ অৱকলজ 0।
    Answer: 0
    ১৮. ∫₁² x dx ৰ মান কি?
    (A) 3/2
    (B) 1/2
    (C) 2
    (D) 3
    ব্যাখ্যা: ∫₁² x dx = [x²/2]₁² = 4/2 − 1/2 = 3/2।
    Answer: 3/2
    ১৯. 2x + 3y = 6 ৰেখাৰ ঢাল কিমান?
    (A) −2/3
    (B) 2/3
    (C) 3/2
    (D) −3/2
    ব্যাখ্যা: y = (6 − 2x)/3 = −(2/3)x + 2, গতিকে ঢাল = −2/3।
    Answer: −2/3
    ২০. (0, 0), (4, 0) আৰু (0, 3) শীৰ্ষবিন্দু থকা ত্ৰিভুজৰ কালি কিমান?
    (A) 6
    (B) 12
    (C) 7
    (D) 3
    ব্যাখ্যা: কালি = (1/2) × ভূমি × উচ্চতা = (1/2) × 4 × 3 = 6।
    Answer: 6
    ২১. x ৰ সাপেক্ষে ln x ৰ অৱকলজ কি?
    (A) 1/x
    (B) x
    (C) ln x
    (D) 1
    ব্যাখ্যা: d/dx (ln x) = 1/x।
    Answer: 1/x
    ২২. logₐ 1 ৰ মান কি (a > 0, a ≠ 1)?
    (A) 0
    (B) 1
    (C) a
    (D) ∞
    ব্যাখ্যা: a⁰ = 1 হোৱাত logₐ 1 = 0।
    Answer: 0
    ২৩. ঢাল 2 আৰু y-ছেদ 3 থকা ৰেখাৰ সমীকৰণ কি?
    (A) y = 2x + 3
    (B) y = 3x + 2
    (C) y = 2x − 3
    (D) y = −2x + 3
    ব্যাখ্যা: y = mx + c ৰ সূত্ৰত m = 2, c = 3 বহুৱাই y = 2x + 3 পোৱা যায়।
    Answer: y = 2x + 3
    ২৪. সমাকল ∫ cos x dx ৰ মান কি?
    (A) sin x + C
    (B) −sin x + C
    (C) cos x + C
    (D) −cos x + C
    ব্যাখ্যা: ∫ cos x dx = sin x + C।
    Answer: sin x + C
    ২৫. lim (x→∞) 1/x ৰ মান কি?
    (A) 0
    (B) 1
    (C) ∞
    (D) অনিৰ্ধাৰিত (undefined)
    ব্যাখ্যা: x ডাঙৰ হোৱাৰ লগে লগে 1/x শূন্যৰ ফালে আগবাঢ়ে।
    Answer: 0

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
