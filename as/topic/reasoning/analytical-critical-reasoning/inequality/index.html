    অসমতা (ক'ডেড আৰু পোনপটীয়া) — প্ৰশ্নোত্তৰ

    অসমতা সমস্যাবোৰ সমাধান কৰক — পোনপটীয়া চিহ্নযুক্ত অসমতা আৰু চিহ্ন-অৰ্থ উদ্ধাৰেৰে ক'ডেড অসমতা সম্পৰ্ক।

    ৪৬ টা প্ৰশ্ন আৰু উত্তৰ

    ১. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: P @ Q; Q @ R; R # S। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) Q = R
    (B) Q < S
    (C) P > R
    (D) P = S
    ব্যাখ্যা: চিহ্ন উদ্ধাৰ কৰিলে '@' অৰ্থ '>' আৰু '#' অৰ্থ '<'। সেয়ে P > Q > R < S। P > Q আৰু Q > R ৰ পৰা P > R পোৱা যায়, গতিকে C শুদ্ধ। Q > R হোৱাৰ বাবে Q = R অসত্য; কেৱল R < S জনা যায়, সেয়ে Q < S আৰু P = S নিশ্চিত নহয়।
    Answer: C
    ২. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: A $ B; B # C; C & D। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) A > C
    (B) B > C
    (C) A = C
    (D) B < D
    ব্যাখ্যা: '$' অৰ্থ '≥', '#' অৰ্থ '<' আৰু '&' অৰ্থ '='। সেয়ে A ≥ B < C = D। B < C আৰু C = D ৰ পৰা B < D পোৱা যায়, গতিকে D শুদ্ধ। A ≥ B আৰু B < C ৰ পৰা C ৰ সৈতে A ৰ সম্পৰ্ক নিৰ্ণয় নহয়, সেয়ে A > C, B > C আৰু A = C অসত্য।
    Answer: D
    ৩. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: X % Y; Y # Z; Z & W। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) X = Y
    (B) Y > W
    (C) X < W
    (D) X = W
    ব্যাখ্যা: '%' অৰ্থ '≤', '#' অৰ্থ '<', '&' অৰ্থ '='। সেয়ে X ≤ Y < Z = W। শৃংখলাবদ্ধ কৰি X < W পোৱা যায়, গতিকে C। Y < Z = W হোৱাৰ বাবে Y > W অসত্য; X ≤ Y আৰু X < W ৰ বাবে X = Y আৰু X = W অসম্ভৱ।
    Answer: C
    ৪. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: M @ N; N @ O; O % P; P # Q। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) M = O
    (B) N > Q
    (C) O = P
    (D) M > O
    ব্যাখ্যা: '@' অৰ্থ '>', '%' অৰ্থ '≤', '#' অৰ্থ '<'। সেয়ে M > N > O ≤ P < Q। M > N আৰু N > O ৰ পৰা M > O পোৱা যায়, গতিকে D নিশ্চিত। M = O আৰু O = P অসত্য (কঠোৰ অসমতা), আৰু Q ৰ সৈতে N ৰ সম্পৰ্ক নিৰ্ণয় কৰিব নোৱাৰি।
    Answer: D
    ৫. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: M # N; N $ O; O % P; P & Q। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) M > P
    (B) Q ≥ O
    (C) N = Q
    (D) M = Q
    ব্যাখ্যা: '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤', '&' অৰ্থ '='। সেয়ে M < N ≥ O ≤ P = Q। Q = P ≥ O হোৱাৰ বাবে Q ≥ O পোৱা যায়, গতিকে B শুদ্ধ। M > P নিৰ্ণয় কৰিব নোৱাৰি, আৰু N = Q, M = Qও প্ৰমাণিত নহয়।
    Answer: B
    ৬. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: A @ B; B $ C; C # D; D & E। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) B = D
    (B) A = C
    (C) A > C
    (D) C = E
    ব্যাখ্যা: '@' অৰ্থ '>', '$' অৰ্থ '≥', '#' অৰ্থ '<', '&' অৰ্থ '='। সেয়ে A > B ≥ C < D = E। A > B ≥ C ৰ পৰা A > C পোৱা যায়, গতিকে C শুদ্ধ। B ≥ C < D ৰ বাবে B = D অসম্ভৱ; A = C আৰু C = E কঠোৰ সম্পৰ্কৰ বিৰোধী।
    Answer: C
    ৭. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: T @ U; U # V; V @ W; W & X। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) U > X
    (B) V > X
    (C) T > V
    (D) T > X
    ব্যাখ্যা: '@' অৰ্থ '>', '#' অৰ্থ '<', '&' অৰ্থ '='। সেয়ে T > U < V > W = X। V > W = X হোৱাৰ বাবে V > X নিশ্চিত, গতিকে B। V ৰ সৰু ফালে U আৰু T থকাৰ বাবে U > X, T > V আৰু T > X সিদ্ধান্ত কৰিব নোৱাৰি।
    Answer: B
    ৮. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: P % Q; Q & R; R @ S; S # T। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) P < R
    (B) Q = S
    (C) S > P
    (D) Q > S
    ব্যাখ্যা: '%' অৰ্থ '≤', '&' অৰ্থ '=', '@' অৰ্থ '>', '#' অৰ্থ '<'। সেয়ে P ≤ Q = R > S < T। Q = R > S হোৱাৰ বাবে Q > S নিশ্চিত, গতিকে D। P = R হ'বও পাৰে, সেয়ে P < R নিশ্চিত নহয়; Q = S অসত্য আৰু S > P নিৰ্ণয় কৰিব নোৱাৰি।
    Answer: D
    ৯. উক্তি: P > Q; Q ≥ R; R = S। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) P > R
    (B) Q > S
    (C) S = P
    (D) Q = S
    ব্যাখ্যা: পোনপটীয়াভাৱে: P > Q ≥ R = S। P > Q আৰু Q ≥ R একলগ কৰি P > R পোৱা যায়, গতিকে A শুদ্ধ। Q ≥ S সমানও হ'ব পাৰে, সেয়ে Q > S নিশ্চিত নহয়; S = P আৰু Q = S স্পষ্টভাৱে অসত্য।
    Answer: A
    ১০. উক্তি: A = B; B > C; C ≥ D। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) A > C
    (B) B = D
    (C) A = C
    (D) C = D
    ব্যাখ্যা: দিয়া আছে A = B > C ≥ D। A = B আৰু B > C ৰ পৰা A > C পোৱা যায়, গতিকে A। B > C ≥ D ৰ বাবে B > D হয়, সেয়ে B = D অসত্য; A = C আৰু C = D অসমতাৰ বিৰোধী।
    Answer: A
    ১১. উক্তি: R > S; S = T; T < U। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) R = T
    (B) T > S
    (C) R > T
    (D) R < U
    ব্যাখ্যা: উক্তি: R > S = T < U। R > S আৰু S = T ৰ পৰা R > T পোৱা যায়, গতিকে C শুদ্ধ। T = S হোৱাৰ বাবে T > S অসত্য, R = T অসত্য, আৰু R > S = T < U ৰ পৰা R < U নিৰ্ণয় কৰিব নোৱাৰি।
    Answer: C
    ১২. উক্তি: X ≥ Y; Y > Z; Z ≥ W। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) X = W
    (B) X > Z
    (C) Z > W
    (D) Y < W
    ব্যাখ্যা: উক্তি: X ≥ Y > Z ≥ W। X ≥ Y আৰু Y > Z ৰ পৰা X > Z পোৱা যায়, গতিকে B। X = W প্ৰমাণিত নহয়, Z ≥ W হোৱাৰ বাবে Z > W নিশ্চিত নহয়, আৰু Y > Z ≥ W ৰ পৰা Y > W হয় সেয়ে Y < W অসম্ভৱ।
    Answer: B
    ১৩. উক্তি: P < Q; Q < R; R < S। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) S < P
    (B) Q = R
    (C) P = S
    (D) P < S
    ব্যাখ্যা: উক্তি: P < Q < R < S। তিনিওটা অসমতা শৃংখলাবদ্ধ কৰি P < S পোৱা যায়, গতিকে D। S < P, Q = R আৰু P = S দিয়া কঠোৰ ক্ৰমক ওলোটা বা অস্বীকাৰ কৰে।
    Answer: D
    ১৪. উক্তি: M = N; N > O; O > P; P ≥ Q। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) M = P
    (B) N = O
    (C) M > P
    (D) P = Q
    ব্যাখ্যা: উক্তি: M = N > O > P ≥ Q। M = N আৰু N > O > P ৰ পৰা M > P পোৱা যায়, গতিকে C। M = P, N = O আৰু P = Q অসত্য কাৰণ প্ৰাসংগিক সম্পৰ্কবোৰ কঠোৰ (বা শেষটো ≥)।
    Answer: C
    ১৫. উক্তি: A ≥ B; B = C; C ≥ D। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) A > D
    (B) A ≥ D
    (C) A = D
    (D) B < D
    ব্যাখ্যা: উক্তি: A ≥ B = C ≥ D। অ-কঠোৰ অসমতাবোৰ শৃংখলাবদ্ধ কৰি A ≥ D পোৱা যায়, গতিকে B। A > D আৰু A = D পৃথকে বাধ্যতামূলক নহয়, আৰু B = C ≥ D ৰ বাবে B < D অসত্য।
    Answer: B
    ১৬. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: K @ L; L & M; M $ N; N # O। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) K > N
    (B) L = N
    (C) M > N
    (D) O < K
    ব্যাখ্যা: '@' >, '&' =, '$' ≥, '#' <। সেয়ে K > L = M ≥ N < O। K > L = M ≥ N ৰ পৰা K > N পোৱা যায়, গতিকে A। M ≥ N হোৱাৰ বাবে L = N বাধ্যতামূলক নহয়, M > N নিশ্চিত নহয়, আৰু O < K নিৰ্ণয় কৰিব নোৱাৰি।
    Answer: A
    ১৭. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: A $ B; B & C; C % D; D $ E; E # F। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) A > F
    (B) C > E
    (C) B ≤ D
    (D) A = D
    ব্যাখ্যা: '$' ≥, '&' =, '%' ≤, '#' <। সেয়ে A ≥ B = C ≤ D ≥ E < F। B = C ≤ D হোৱাৰ বাবে B ≤ D নিশ্চিত, গতিকে C। দিয়া শৃংখলাৰ পৰা A > F, C > E আৰু A = D নিৰ্ণয় কৰিব নোৱাৰি।
    Answer: C
    ১৮. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: X % Y; Y # Z; Z $ W; W % V; V & U। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) Y = W
    (B) X < Z
    (C) Z > U
    (D) X = Z
    ব্যাখ্যা: '%' ≤, '#' <, '$' ≥, '&' =। সেয়ে X ≤ Y < Z ≥ W ≤ V = U। X ≤ Y < Z ৰ পৰা X < Z পোৱা যায়, গতিকে B। Z ত শৃংখলাৰ দিশ সলনি হোৱাৰ বাবে Y = W, Z > U আৰু X = Z অনুসৰণ নকৰে।
    Answer: B
    ১৯. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: M $ N; N # O; O & P; P % Q; Q # R। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) M = R
    (B) M > P
    (C) N < P
    (D) O > Q
    ব্যাখ্যা: '$' ≥, '#' <, '&' =, '%' ≤। সেয়ে M ≥ N < O = P ≤ Q < R। N < O = P হোৱাৰ বাবে N < P পোৱা যায়, গতিকে C। শৃংখলাই M = R, M > P আৰু O > Q সমৰ্থন নকৰে।
    Answer: C
    ২০. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: A @ B; B & C; C @ D; D # E; E @ F। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) F > C
    (B) D > E
    (C) A > D
    (D) A = C
    ব্যাখ্যা: '@' >, '&' =, '#' <। সেয়ে A > B = C > D < E > F। A > B = C > D ৰ পৰা A > D পোৱা যায়, গতিকে C। F > C, D > E আৰু A = C কঠোৰ শৃংখলাৰ পৰা ওলোৱা নাই বা বিৰোধী।
    Answer: C
    ২১. তলত, '@' অৰ্থ '>', '#' অৰ্থ '<', '$' অৰ্থ '≥', '%' অৰ্থ '≤' আৰু '&' অৰ্থ '='। উক্তি: P @ Q; Q $ R; R # S; S % T; T & U। তলৰ কোনটো সঁচাকৈয়ে সত্য?
    (A) Q = S
    (B) P > R
    (C) S = U
    (D) P = R

    অসমতা (প্ৰত্যক্ষ আৰু সংকেতিত): প্ৰকাৰ, পদ্ধতি আৰু উদাহৰণ

    অসমতা হৈছে এটা যুক্তি বিষয় য'ত কেইবাটাও বাক্যই ডাঙৰতকৈ, সৰুতকৈ, সমান, ডাঙৰ বা সমান, আৰু সৰু বা সমান চিহ্ন ব্যৱহাৰ কৰি ৰাশিবোৰৰ মাজৰ সম্পৰ্ক দেখুৱায়। এই বাক্যবোৰৰপৰা এটা বা ততোধিক সিদ্ধান্ত দিয়া হয় আৰু প্ৰাৰ্থীয়ে নিৰ্ণয় কৰিব লাগে কোনটো সিদ্ধান্ত বাক্যবোৰৰপৰা নিশ্চিতভাৱে ওলায়। পদ্ধতিটো হ'ল বাক্যবোৰ এটা শৃংখললৈ জোৰা লগাই তাৰ পিছত সোধা দুটা ৰাশিৰ মাজৰ সম্পৰ্ক পঢ়া।

    এই বিষয়টোৰ বিশেষত্ব হ'ল ই সম্পূৰ্ণ চিহ্নভিত্তিক, গতিকে ভালদৰে অভ্যাস কৰা প্ৰাৰ্থীয়ে কোনো দীঘল গণনা নকৰাকৈয়ে সমাধান কৰিব পাৰে। সংকেতিত ৰূপত বিভিন্ন চিহ্নই সাধাৰণ চিহ্নবোৰৰ ঠাই লয়, গতিকে প্ৰাৰ্থীয়ে প্ৰথমে চিহ্নবোৰ ডিক'ড কৰি তাৰ পিছত একে পদ্ধতি প্ৰয়োগ কৰিব লাগে। এই লেখাটোৱে অসমতাৰ সম্পূৰ্ণ গভীৰ পুনৰালোচনা আগবঢ়ায়। ই মৌলিক পৰিভাষা, সংযোগৰ নিয়ম, সংকেতিত ৰূপ, সমাধানৰ ক্ৰম, সাধাৰণ ভুল আৰু এক প্ৰায়োগিক প্ৰস্তুতি আঁচনি ব্যাখ্যা কৰে যাতে APSC, ADRE, অসম আৰক্ষী, SSC আৰু ৰে'লৱে পৰীক্ষাত এই বিষয়টো দ্ৰুত আৰু নিৰ্ভৰযোগ্য নম্বৰৰ উৎস হৈ পৰে।

    • ডাঙৰতকৈ (>): বাওঁ ৰাশি সোঁ ৰাশিতকৈ ডাঙৰ।

    • সৰু বা সমান (≤): বাওঁ ৰাশি সোঁ ৰাশিতকৈ সৰু নাইবা সমান।

    • সাধাৰণ পদ: দুটা বাক্যত ওলোৱা আৰু সিহঁতক জোৰা লগোৱা ৰাশি।
    • শৃংখল: এটা সাধাৰণ পদেদি জোৰা লগা দুটা বা ততোধিক বাক্য।
    • সংকেতিত অসমতা: এনে প্ৰশ্ন য'ত সাধাৰণ চিহ্নৰ ঠাইত বিশেষ চিহ্ন ব্যৱহাৰ কৰা হয়।

    অসমতা প্ৰশ্নৰ প্ৰকাৰ

    প্ৰথম প্ৰকাৰ হৈছে প্ৰত্যক্ষ অসমতা, য'ত সাধাৰণ চিহ্ন দিয়া হয় আৰু সিদ্ধান্ত পৰীক্ষা কৰিব লাগে। দ্বিতীয় প্ৰকাৰ সংকেতিত অসমতা, য'ত চিহ্নই সাধাৰণ চিহ্নৰ ঠাই লয় আৰু প্ৰথমে ডিক'ড কৰিব লাগে। তৃতীয় প্ৰকাৰে দুটা বা তিনিটা সিদ্ধান্ত দি সোধে কোনবোৰ ওলায়। চতুৰ্থ প্ৰকাৰ হৈছে হয়-নাইবা ক্ষেত্ৰ, য'ত দুটা সিদ্ধান্তই একেলগে প্ৰতিটো সম্ভাৱনা সামৰি লয় আৰু সেয়ে এটা নিশ্চিতভাৱে সঁচা হয়। পঞ্চম প্ৰকাৰে অসমতাক সংকেতিত বা শব্দভিত্তিক বাক্যৰ লগত সংযোগ কৰে যাতে ডিক'ডিং খোজটোৱে প্ৰকৃত প্ৰত্যাহ্বান হয়।

    অসমতা প্ৰশ্ন সমাধানৰ খোজ

    প্ৰথমে প্ৰশ্নটো সংকেতিত হ'লে দিয়া তালিকাৰ সহায়ত প্ৰতিটো চিহ্ন ডিক'ড কৰা। দ্বিতীয়তে বাক্যবোৰক জোৰা লগোৱা সাধাৰণ পদবোৰ চিনি লোৱা। তৃতীয়তে চিহ্নৰ দিশ একে ৰাখি বাক্যবোৰ এটা শৃংখললৈ জোৰা লগোৱা। চতুৰ্থতে সিদ্ধান্তত নাম লোৱা দুটা ৰাশিৰ মাজৰ সম্পৰ্ক উলিওৱা। পঞ্চমতে প্ৰতিটো সিদ্ধান্ত সুকীয়াকৈ পৰীক্ষা কৰি ওলায় নে নোলায় চিহ্নিত কৰা। শেষত হয়-নাইবা প্ৰশ্নত দুটা সিদ্ধান্তই একেলগে আটাইবোৰ সম্ভাৱনা সামৰে নে নাই পৰীক্ষা কৰা, কাৰণ তেতিয়াহে হয়-নাইবা উত্তৰ শুদ্ধ হয়।

    পৰীক্ষাৰ প্ৰৱণতা

    প্ৰতিযোগিতামূলক পৰীক্ষাত অসমতা এখন দ্ৰুত নম্বৰ দিয়া বিষয় আৰু সাধাৰণতে তিনিটাৰপৰা পাঁচটা নম্বৰৰ হয়। প্ৰত্যক্ষ ৰূপতকৈ সংকেতিত অসমতা বেছি সোধা হয়। সিদ্ধান্ত সাধাৰণতে দুটা বা তিনিটা হয়, আৰু হয়-নাইবা প্ৰকাৰ নিয়মীয়াকৈ আহে। এই বিষয়টোত গণনা নালাগে, গতিকে সংযোগৰ নিয়ম ভালদৰে মনত থাকিলে ইয়াৰপৰাই প্ৰাৰ্থীয়ে প্ৰথমে চেষ্টা কৰা উচিত।

    পৰিহাৰ কৰিবলগীয়া সাধাৰণ ভুল

    • শৃংখল বনাওঁতে চিহ্নৰ দিশ ওলোটা নকৰিবা।

    • দুয়ো ৰাশি সমান হ'ব পৰা ক্ষেত্ৰটো উপেক্ষা নকৰিবা।
    • দুটা সিদ্ধান্তই একেলগে আটাইবোৰ সম্ভাৱনা না সামৰিলে হয়-নাইবা বুলি চিহ্নিত নকৰিবা।
    • সংকেতিত প্ৰশ্নত সমাধান কৰাৰ আগতে ডিক'ড কৰিবলৈ নাপাহৰিবা।

    এই বিষয়টো কেনেকৈ প্ৰস্তুতি কৰিব

    পাঁচটা চিহ্ন আৰু সেইবোৰ সংযোগ কৰাৰ নিয়ম মনত ৰাখি আৰম্ভ কৰা। তাৰ পিছত দুটা সিদ্ধান্তৰ প্ৰত্যক্ষ অসমতা অভ্যাস কৰা যেতিয়ালৈকে শৃংখল পদ্ধতি স্বয়ংক্ৰিয় নহয়। ইয়াৰ পিছত সংকেতিত অসমতালৈ যোৱা আৰু ডিক'ডিং তালিকা দ্ৰুতভাৱে লিখাৰ অভ্যাস কৰা। তাৰ পিছত হয়-নাইবা প্ৰশ্ন আৰু তিনিটা সিদ্ধান্তৰ প্ৰশ্ন চেষ্টা কৰা। এই বিষয়টো চুটি আৰু সঠিক, গতিকে কেইদিন দৈনিক দহৰপৰা পোন্ধৰটা প্ৰশ্ন অভ্যাস কৰিলেই ই নিশ্চিত নম্বৰৰ উৎস হৈ পৰে। যি প্ৰশ্নত চিহ্ন ওলোটা কৰিছিলা সেইবোৰ টোকা ৰাখা, কাৰণ এই বিষয়ত এয়ে আটাইতকৈ সাধাৰণ ভুল।

    গঢ়ি তোলাৰ যোগ্য আৰু এটা অভ্যাস হ'ল সিদ্ধান্তবোৰলৈ চোৱাৰ আগতে প্ৰতিটো বাক্যক সৰু কাঁড়-শৃংখল হিচাপে পুনৰ লিখা। চিহ্নবোৰক সৰল বাওঁৰপৰা-সোঁ ক্ৰমলৈ সলনি কৰিলে প্ৰশ্নৰ ভাষাৰপৰা হোৱা বিভ্ৰান্তি আঁতৰি যায়, আৰু হয়-নাইবা ক্ষেত্ৰটো চিনিবলৈ সহজ হয়। লগতে মনত ৰাখিবা, সঁচা হ'ব পৰা সিদ্ধান্ত আৰু নিশ্চিতভাৱে ওলোৱা সিদ্ধান্ত একে নহয়; কেৱল নিশ্চিত সম্পৰ্কহে গণ্য হয়। পৰীক্ষাত অসমতা আৰম্ভণিতে কৰা উচিত, কাৰণ ইয়াত খচৰা নালাগে আৰু প্ৰায়ে কেইছেকেণ্ডতে শেষ কৰিব পাৰি। পাঁচটা চিহ্ন আৰু সংযোগৰ নিয়ম মনত স্পষ্ট হ'লে এই বিষয়টো নিশ্চিত নম্বৰৰ উৎস হৈ পৰে। যিবোৰ প্ৰশ্নত ডাঙৰ আৰু সৰু চিহ্ন একেলগে থাকে, তাত কেতিয়াও খাপ খুৱাবলৈ যত্ন নকৰিবা; দিশ একে নহ'লে সম্পৰ্ক নাই বুলি নিৰ্ভয়ে সিদ্ধান্ত লোৱা, কাৰণ এয়ে আটাইতকৈ সাধাৰণ ফান্দ।

    তদুপৰি, অসমতাৰ প্ৰশ্নত সময় ৰাহি কৰাৰ এক সহজ উপায় হ'ল চিহ্নবোৰক সংখ্যাৰ দৰে নাভাবি এটা দিশ হিচাপে ভবা। যেতিয়া তুমি বাওঁৰপৰা সোঁলৈ এটা শৃংখল বনোৱা, তেতিয়া মাজৰ পদবোৰ আপুনি আঁতৰাই দিয়াৰ দৰে হয় আৰু কেৱল দুয়ো মূৰৰ ৰাশি ৰৈ যায়। এই অভ্যাসে যিকোনো দীঘল প্ৰশ্নকো কেইছেকেণ্ডতে সৰল কৰি তোলে। পৰীক্ষাত প্ৰথমে সেই প্ৰশ্নবোৰ বাছনি কৰা য'ত সিদ্ধান্তবোৰ চৰ্তৰ লগত পোনপটীয়াকৈ সংযুক্ত, আৰু যিবোৰত দুটা সিদ্ধান্তই পৰিপূৰক হয় সেইবোৰত হয়-নাইবা নিয়ম মনত পেলোৱা। এনেদৰে সৰু সৰু অভ্যাসে অসমতাক প্ৰতিটো পৰীক্ষাত নিশ্চিত নম্বৰৰ উৎস কৰি তোলে।

    সঘনাই সোধা প্ৰশ্ন

    যুক্তিত অসমতা কি?

    অসমতা হৈছে এটা যুক্তি বিষয় য'ত ডাঙৰতকৈ, সৰুতকৈ আৰু সমান চিহ্ন থকা বাক্য দিয়া হয় আৰু প্ৰাৰ্থীয়ে কোনটো সিদ্ধান্ত নিশ্চিতভাৱে ওলায় সেয়া নিৰ্ণয় কৰে।

    দুটা বাক্য কেতিয়া সংযোগ কৰিব পাৰি?

    দুটা বাক্য কেৱল তেতিয়াহে সংযোগ কৰিব পাৰি যেতিয়া সিহঁতে এটা সাধাৰণ পদ ভাগ কৰে আৰু চিহ্নৰ দিশ একে হয়।

    সংকেতিত অসমতা কি?

    সংকেতিত অসমতাত বিশেষ চিহ্নই সাধাৰণ ডাঙৰ, সৰু আৰু সমান চিহ্নৰ ঠাই লয়। প্ৰথমে চিহ্নবোৰ ডিক'ড কৰি তাৰ পিছত প্ৰত্যক্ষ প্ৰশ্নৰ দৰে সমাধান কৰা হয়।

    হয়-নাইবা ক্ষেত্ৰ কি?

    এই ক্ষেত্ৰত দুটা সিদ্ধান্তই একেলগে প্ৰতিটো সম্ভাৱনা সামৰি লয়, গতিকে এটা নিশ্চিতভাৱে সঁচা হয় আৰু উত্তৰ হয় এটা নাইবা আনটো ওলায়।

    কেতিয়াবা সম্পৰ্ক কিয় নোলায়?

    শৃংখলে দিশ সলনি কৰিলে, যেনে A B তকৈ ডাঙৰ আৰু B C তকৈ সৰু, তেন্তে A আৰু C ৰ মাজত কোনো নিৰ্দিষ্ট সম্পৰ্ক স্থাপন নহয়, গতিকে কোনো সিদ্ধান্ত নোলায়।

    এই পৃষ্ঠাৰ সমল অসমৰ প্ৰতিযোগিতামূলক পৰীক্ষাৰ বাবে প্ৰস্তুত কৰা হৈছে। প্ৰতিটো প্ৰশ্ন দ্বিভাষিক আৰু প্ৰতিটো উত্তৰ চমুকৈ ব্যাখ্যা কৰা হৈছে। সমল মানক প্ৰসংগ পুথি আৰু বিশ্বাসযোগ্য অনলাইন উৎসৰ আধাৰত প্ৰস্তুত কৰা হয়।
