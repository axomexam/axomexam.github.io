    কম্পিউটাৰ মৌলিক ধাৰণা আৰু হাৰ্ডৱেৰ — প্ৰশ্নোত্তৰ

    ৬৯ টা প্ৰশ্ন আৰু উত্তৰ

    ১. 'কম্পিউটাৰৰ পিতৃ' বুলি কাক কোৱা হয়?
    (A) Charles Babbage
    (B) Alan Turing
    (C) John von Neumann
    (D) Bill Gates
    উত্তৰ: Charles Babbage য়ে Analytical Engine ৰ নক্সা প্ৰস্তুত কৰিছিল আৰু তেওঁক কম্পিউটাৰৰ পিতৃ বোলা হয়।
    ব্যাখ্যা: Charles Babbage য়ে Difference Engine আৰু Analytical Engine বনাইছিল, যি আধুনিক কম্পিউটাৰৰ মৌলিক অংশ থকা প্ৰথম আৰ্হি, সেয়ে তেওঁক কম্পিউটাৰৰ পিতা বোলা হয়।
    ২. প্ৰথম সম্পূৰ্ণ ইলেকট্রনিক সাধাৰণ উদ্দেশ্যৰ কম্পিউটাৰ কোনটো আছিল?
    (A) ENIAC
    (B) UNIVAC
    (C) IBM PC
    (D) Altair 8800
    উত্তৰ: ENIAC (1946) কে প্ৰথম সম্পূৰ্ণ ইলেকট্রনিক সাধাৰণ উদ্দেশ্যৰ কম্পিউটাৰ বুলি গণ্য কৰা হয়।
    ব্যাখ্যা: ENIAC (Electronic Numerical Integrator And Computer), ১৯৪৬ চনত সম্পূৰ্ণ হোৱা, প্ৰথম সম্পূৰ্ণ ইলেক্ট্ৰনিক general-purpose কম্পিউটাৰ হিচাপে গণ্য কৰা হয়। UNIVAC ইয়াৰ পিছত আহিছিল।
    ৩. প্ৰথম প্ৰজন্মৰ কম্পিউটাৰত কোনটো ইলেকট্রনিক উপাদান ব্যৱহাৰ হৈছিল?
    (A) Vacuum tubes
    (B) Transistors
    (C) Integrated circuits
    (D) Microprocessors
    উত্তৰ: প্ৰথম প্ৰজন্মৰ কম্পিউটাৰত (1940-50) vacuum tube ব্যৱহাৰ হৈছিল।
    ব্যাখ্যা: প্ৰথম প্ৰজন্মৰ কম্পিউটাৰে (প্ৰায় ১৯৪০-১৯৫৬) vacuum tube ব্যৱহাৰ কৰিছিল, যিবোৰ ডাঙৰ আছিল, অধিক তাপ উৎপন্ন কৰিছিল আৰু বহু বিদ্যুৎ খৰচ কৰিছিল।
    ৪. তৃতীয় প্ৰজন্মৰ কম্পিউটাৰত কোনটো উপাদান ব্যৱহাৰ হৈছিল?
    (A) Integrated circuits (ICs)
    (B) Vacuum tubes
    (C) Transistors
    (D) Artificial intelligence chips
    উত্তৰ: তৃতীয় প্ৰজন্মৰ কম্পিউটাৰত Integrated Circuit (IC) ব্যৱহাৰ হৈছিল।
    ব্যাখ্যা: তৃতীয় প্ৰজন্মৰ কম্পিউটাৰে (১৯৬০ দশক) Integrated Circuit (IC) ব্যৱহাৰ কৰিছিল, য'ত বহু transistor এটা silicon chip ত ৰখা হয়, ফলত কম্পিউটাৰ সৰু আৰু বেছি নিৰ্ভৰযোগ্য হয়।
    ৫. এনেলগ আৰু ডিজিটাল দুয়ো ধৰণৰ তথ্য প্ৰক্ৰিয়া কৰা কম্পিউটাৰক ___ কম্পিউটাৰ বোলে।
    (A) Hybrid
    (B) Analog
    (C) Digital
    (D) Super
    উত্তৰ: Hybrid কম্পিউটাৰে এনেলগ আৰু ডিজিটাল দুয়ো তথ্য সামলে, যেনে হাস্পতালত।
    ব্যাখ্যা: Hybrid কম্পিউটাৰে analog আৰু digital দুয়োটাৰে বৈশিষ্ট্য একত্ৰিত কৰে, যেনে চিকিৎসালয়ত ৰোগী নিৰীক্ষণ কৰা যন্ত্ৰ।
    ৬. কোনটো কম্পিউটাৰ আটাইতকৈ বেগী আৰু ব্যয়বহুল?
    (A) Supercomputer
    (B) Mainframe computer
    (C) Microcomputer
    (D) Mini computer
    উত্তৰ: Supercomputer আটাইতকৈ বেগী, শক্তিশালী আৰু ব্যয়বহুল কম্পিউটাৰ।
    ব্যাখ্যা: Supercomputer হৈছে আটাইতকৈ দ্ৰুত আৰু শক্তিশালী কম্পিউটাৰ, বতৰৰ আগতীয়া জাননী, বৈজ্ঞানিক simulation আৰু মহাকাশ গৱেষণাত ব্যৱহৃত; ইহঁত আটাইতকৈ ব্যয়বহুল।
    ৭. CPU ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Central Processing Unit
    (B) Computer Personal Unit
    (C) Central Program Unit
    (D) Control Processing Unit
    উত্তৰ: CPU মানে Central Processing Unit, কম্পিউটাৰৰ মগজু।
    ব্যাখ্যা: CPU ৰ অৰ্থ Central Processing Unit। ইয়াক কম্পিউটাৰৰ মগজু বোলে আৰু ই সকলো instruction কাৰ্যকৰী কৰে।
    ৮. CPU ৰ কোন অংশই গণনা আৰু যুক্তিগত কাৰ্য কৰে?
    (A) ALU
    (B) CU
    (C) Registers
    (D) Cache
    উত্তৰ: Arithmetic and Logic Unit (ALU) য়ে সকলো গণনা আৰু যুক্তিগত তুলনা কৰে।
    ব্যাখ্যা: CPU ৰ এটা অংশ Arithmetic and Logic Unit (ALU) য়ে গাণিতিক ক্ৰিয়া (+, -, x, /) আৰু যুক্তিগত তুলনা (>, <, =) সম্পন্ন কৰে।
    ৯. CPU ৰ কোনটো এককে কম্পিউটাৰৰ কাৰ্য পৰিচালনা আৰু সমন্বয় কৰে?
    (A) Control Unit
    (B) Arithmetic Unit
    (C) Memory Unit
    (D) Input Unit
    উত্তৰ: Control Unit (CU) য়ে কম্পিউটাৰৰ সকলো কাৰ্য পৰিচালনা আৰু সমন্বয় কৰে।
    ব্যাখ্যা: Control Unit (CU) য়ে instruction আনয়ন আৰু decode কৰি আন অংশক ইয়াৰ কাৰ্যকৰী কৰিবলৈ নিৰ্দেশ দিয়ে, গোটেই কম্পিউটাৰ সমন্বয় কৰে।
    ১০. তলৰ কোনটো এটা ইনপুট ডিভাইচ?
    (A) Keyboard
    (B) Monitor
    (C) Printer
    (D) Speaker
    উত্তৰ: কীবোর্ডে তথ্য কম্পিউটাৰলৈ পঠায়, গতিকে ই ইনপুট ডিভাইচ।
    ব্যাখ্যা: Keyboard এটা input device কাৰণ ই টাইপ কৰা তথ্য আৰু আদেশ কম্পিউটাৰলৈ পঠিয়ায়। Monitor, printer আৰু speaker output device।
    ১১. তলৰ কোনটো এটা আউটপুট ডিভাইচ?
    (A) Monitor
    (B) Scanner
    (C) Mouse
    (D) Joystick
    উত্তৰ: মনিটৰে কম্পিউটাৰৰ আউটপুট ব্যৱহাৰকাৰীক দেখুৱায়।
    ব্যাখ্যা: Monitor য়ে প্ৰক্ৰিয়াকৃত ফলাফল দেখুৱায়, সেয়ে ই output device। Scanner, mouse আৰু joystick input device।
    ১২. বেংক চেকত মেগনেটিক ইনকত ছপা আখৰ পঢ়িবলৈ কোন ডিভাইচ ব্যৱহাৰ হয়?
    (A) MICR
    (B) OCR
    (C) OMR
    (D) Barcode reader
    উত্তৰ: MICR (Magnetic Ink Character Recognition) য়ে মেগনেটিক ইনকৰ আখৰ পঢ়ে, বেংকত ব্যৱহাৰ হয়।
    ব্যাখ্যা: MICR (Magnetic Ink Character Recognition) য়ে চুম্বকীয় চিয়াহীৰে ছপা আখৰ পঢ়ে, আৰু বেংকৰ চেক দ্ৰুত আৰু সুৰক্ষিতভাৱে প্ৰক্ৰিয়া কৰিবলৈ ব্যৱহাৰ হয়।
    ১৩. OMR ___ পৰীক্ষা কৰিবলৈ ব্যৱহাৰ হয়।
    (A) Objective উত্তৰপত্ৰ (Objective answer sheets)
    (B) চেকৰ ছহী (Cheque signatures)
    (C) Bar code (Bar codes)
    (D) Magnetic tape (Magnetic tapes)
    উত্তৰ: OMR (Optical Mark Reader) য়ে objective উত্তৰপত্ৰৰ পেঞ্চিল দাগ পঢ়ে।
    ব্যাখ্যা: OMR (Optical Mark Recognition) য়ে নিৰ্দিষ্ট স্থানত পেঞ্চিল বা কলমেৰে দিয়া চিন চিনাক্ত কৰে, সেয়ে objective (MCQ) উত্তৰ পত্ৰ মূল্যায়নত ব্যৱহৃত হয়।
    ১৪. কোন ডিভাইচে পোহৰ ব্যৱহাৰ কৰি ছপা পাঠক সম্পাদনাযোগ্য ডিজিটেল পাঠলৈ ৰূপান্তৰ কৰে?
    (A) OCR
    (B) OMR
    (C) MICR
    (D) Light pen
    উত্তৰ: OCR (Optical Character Recognition) য়ে ছপা বা হাতে লিখা পাঠক সম্পাদনাযোগ্য ডিজিটেল পাঠলৈ ৰূপান্তৰ কৰে।
    ব্যাখ্যা: OCR (Optical Character Recognition) য়ে পোহৰ ব্যৱহাৰ কৰি ছপা বা হাতে লিখা text স্কেন কৰি সম্পাদনযোগ্য ডিজিটেল text লৈ ৰূপান্তৰ কৰে, যি কম্পিউটাৰে প্ৰক্ৰিয়া কৰিব পাৰে।
    ১৫. লেপটপত মাউছৰ ঠাইত সাধাৰণতে কোনটো পয়েন্টিং ডিভাইচ ব্যৱহাৰ হয়?
    (A) Touchpad
    (B) Joystick
    (C) Light pen
    (D) Digitizer
    উত্তৰ: Touchpad হৈছে লেপটপত থকা পয়েন্টিং ডিভাইচ, মাউছৰ ঠাইত ব্যৱহাৰ হয়।
    ব্যাখ্যা: Touchpad হৈছে laptop ৰ keyboard ৰ তলত থকা সমতল, অন্তৰ্নিৰ্মিত pointing device; ইয়াত আঙুলি ঘঁহিলে mouse ৰ ঠাইত cursor লৰে।
    ১৬. Trackball এটা ___ ডিভাইচ।
    (A) Pointing
    (B) Printing
    (C) Scanning
    (D) Storage
    উত্তৰ: Trackball হৈছে ওলোটাই থোৱা মাউছৰ দৰে পয়েন্টিং ডিভাইচ।
    ব্যাখ্যা: Trackball এটা pointing device, যি ওলোটা mouse ৰ দৰে কাম কৰে, য'ত যন্ত্ৰ স্থিৰ থাকি হাতেৰে বলটো ঘূৰাই cursor লৰোৱা হয়।
    ১৭. খেলত গতিবিধি নিয়ন্ত্ৰণ কৰিবলৈ কোন ইনপুট ডিভাইচ ব্যৱহাৰ হয়?
    (A) Joystick
    (B) Scanner
    (C) Digitizer
    (D) Plotter
    উত্তৰ: Joystick হৈছে খেল নিয়ন্ত্ৰণৰ বাবে ব্যৱহৃত ইনপুট ডিভাইচ।
    ব্যাখ্যা: Joystick হৈছে গতি কৰিব পৰা লিভাৰ থকা এটা input device, মূলতঃ কম্পিউটাৰ খেলত গতি আৰু কাৰ্য নিয়ন্ত্ৰণত ব্যৱহৃত।
    ১৮. এইবোৰৰ ভিতৰত কোনটো কম্পিউটাৰৰ 'মগজু'?
    (A) CPU
    (B) Hard disk
    (C) Monitor
    (D) UPS
    উত্তৰ: CPU ক কম্পিউটাৰৰ মগজু বোলা হয় কাৰণ ই সকলো কাৰ্য নিয়ন্ত্ৰণ কৰে।
    ব্যাখ্যা: CPU ক কম্পিউটাৰৰ মগজু বোলা হয় কাৰণ ই তথ্য প্ৰক্ৰিয়া কৰে আৰু অন্য প্ৰতিটো অংশ নিয়ন্ত্ৰণ কৰে, যদিও প্ৰকৃত কাম ইয়াৰ ALU আৰু CU য়ে কৰে।
    ১৯. RAM ক ___ মেম'ৰী বুলিও জনা যায়।
    (A) Volatile
    (B) Non-volatile
    (C) Permanent
    (D) Secondary
    উত্তৰ: RAM volatile মেম'ৰী কাৰণ বিদ্যুৎ বন্ধ হ'লে ইয়াৰ তথ্য নাইকিয়া হয়।
    ব্যাখ্যা: RAM (Random Access Memory) volatile: বিদ্যুৎ বন্ধ হ'লে ইয়াত থকা সকলো হেৰায়, সেয়ে ফাইল disk ত save কৰিব লাগে।
    ২০. কোন মেম'ৰী non-volatile আৰু কম্পিউটাৰৰ স্থায়ী নিৰ্দেশ (BIOS) ৰখে?
    (A) ROM
    (B) RAM
    (C) Cache
    (D) Register
    উত্তৰ: ROM (Read Only Memory) non-volatile আৰু BIOS ৰ দৰে স্থায়ী নিৰ্দেশ ৰখে।
    ব্যাখ্যা: ROM (Read Only Memory) হৈছে non-volatile memory, বিদ্যুৎ বন্ধ হ'লেও ইয়াৰ content থাকে। ই BIOS ৰ দৰে স্থায়ী instruction সংৰক্ষণ কৰে, যিয়ে কম্পিউটাৰ আৰম্ভ কৰে।
    ২১. কোনটো UV পোহৰেৰে মচি পুনৰ লিখিব পাৰি?
    (A) EPROM
    (B) PROM
    (C) ROM
    (D) DRAM
    উত্তৰ: EPROM (Erasable Programmable ROM) ultraviolet পোহৰেৰে মচিব পাৰি।
    ব্যাখ্যা: EPROM (Erasable Programmable ROM) ক quartz window ৰ জৰিয়তে ultraviolet (UV) পোহৰ দি মচি পুনৰ program কৰিব পাৰি।
    ২২. কম্পিউটাৰত কোনটো মেম'ৰী আটাইতকৈ বেগী?
    (A) Register
    (B) RAM
    (C) Hard disk
    (D) DVD
    উত্তৰ: CPU ৰ register কম্পিউটাৰৰ আটাইতকৈ বেগী মেম'ৰী।

    Computer Fundamentals & Hardware (কম্পিউটাৰ মৌলিক জ্ঞান আৰু হাৰ্ডৱেৰ): ধাৰণা, যন্ত্ৰ আৰু পদ্ধতি

    Computer awareness ত প্ৰাৰ্থীয়ে কম্পিউটাৰ কেনেকৈ গঢ়ি তোলা হয়, ই কেনেকৈ তথ্য ৰাখে আৰু প্ৰক্ৰিয়া কৰে আৰু প্ৰতিটো যন্ত্ৰই কি কাম কৰে — সেইবোৰ কিমান ভালদৰে জানে তাক পৰীক্ষা কৰা হয়। প্ৰশ্নবোৰ পোনপটীয়া, তথ্যভিত্তিক আৰু বছৰে বছৰে পুনৰাবৃত্ত হয়, গতিকে মানক তথ্য আৰু কেইটামান সংজ্ঞা শিকা প্ৰাৰ্থীয়ে কম সময়তে পূৰ্ণ নম্বৰ পাব পাৰে।

    এই গভীৰ অধ্যয়ন টোকাত মূল পৰিভাষা, কম্পিউটাৰৰ প্ৰজন্ম, কম্পিউটাৰ চিষ্টেমৰ অংশ, মেমৰি আৰু সংৰক্ষণৰ স্তৰবিন্যাস, প্ৰশ্নৰ ধৰণ, স্তৰে স্তৰে সমাধানৰ পদ্ধতি, পৰীক্ষকে পতা ফান্দ আৰু প্ৰস্তুতিৰ পৰিকল্পনা দিয়া হৈছে। মনোযোগেৰে পঢ়াৰ পিছত প্ৰাৰ্থীয়ে কম্পিউটাৰ মৌলিক জ্ঞান আৰু হাৰ্ডৱেৰৰ প্ৰশ্ন দ্ৰুতভাৱে আৰু আত্মবিশ্বাসেৰে উত্তৰ দিব পাৰিব।

    মূল পৰিভাষা

    • Computer: তথ্য গ্ৰহণ কৰি নিৰ্দেশনা অনুসৰি প্ৰক্ৰিয়া কৰি কামৰ ফলাফল দিয়া ইলেকট্ৰনিক যন্ত্ৰ।
    • Data আৰু information: কেঁচা, অগোছাল তথ্য হৈছে data; প্ৰক্ৰিয়াকৃত অৰ্থপূৰ্ণ ফলাফল হৈছে information।
    • Hardware: কম্পিউটাৰৰ স্পৰ্শ কৰিব পৰা ভৌতিক অংশ, যেনে কীবৰ্ড আৰু মনিটৰ।
    • Software: হাৰ্ডৱেৰক কি কৰিব লাগে কোৱা কাৰ্যসূচী আৰু নিৰ্দেশনাৰ সমষ্টি।
    • Input device: কম্পিউটাৰত তথ্য সুমুৱাবলৈ ব্যৱহৃত যন্ত্ৰ, যেনে কীবৰ্ড বা মাউছ।
    • Output device: ফলাফল দেখুওৱা যন্ত্ৰ, যেনে মনিটৰ বা প্ৰিণ্টাৰ।
    • CPU: কেন্দ্ৰীয় প্ৰক্ৰিয়াকৰণ একক, কম্পিউটাৰৰ মগজু।
    • ALU: পাটিগণিত আৰু যুক্তি একক, যি হিচাপ আৰু তুলনা কৰে।
    • Control unit: নিৰ্দেশনা আনি, ভাঙি আৰু চলাবলৈ নিৰ্দেশ দিয়া অংশ।
    • Memory: তথ্য আৰু নিৰ্দেশনা ৰখা কম্পিউটাৰৰ অংশ।
    • Bit আৰু byte: bit এটা 0 বা 1, আৰু byte আঠটা bitৰ গোট।
    • Motherboard: CPU, মেমৰি আৰু আন অংশ সংযোগ কৰা মূল ছাৰ্কিট বৰ্ড।

    মুখ্য ধাৰণা আৰু নিয়ম

    • কম্পিউটাৰে input, process, output আৰু storage — এই চাৰি স্তৰ অনুসৰণ কৰে, কোনো স্তৰ এৰিব নোৱাৰি।
    • CPU ৰ তিনিটা অংশ: ALU, control unit আৰু register।
    • Primary memory ক CPU এ প্ৰত্যক্ষভাৱে ব্যৱহাৰ কৰে, secondary memory নকৰে।
    • RAM volatile, বিদ্যুৎ গ'লে তথ্য হেৰায়; ROM non-volatile, তথ্য ৰাখি থাকে।
    • গতিৰ ক্ৰম দ্ৰুতৰ পৰা লেহেমলৈ: register, cache, RAM, SSD, HDD, optical disk, magnetic tape।
    • এক byte = আঠ bit; এক KB = 1024 byte, এক MB = 1024 KB, এক GB = 1024 MB, এক TB = 1024 GB।
    • Input device এ তথ্য লয়, output device এ দেখুৱায়, কিছু যন্ত্ৰ যেনে touch screen দুয়োটা কাম কৰে।
    • Storage যন্ত্ৰ non-volatile, বিদ্যুৎ বন্ধ হ'লেও তথ্য থাকে।
    • von Neumann architecture ত তথ্য আৰু নিৰ্দেশনা একেই মেমৰিত ৰখা হয়।
    • কম্পিউটাৰৰ পাঁচটা প্ৰজন্ম প্ৰতিটোত ব্যৱহৃত মূল ইলেকট্ৰনিক যন্ত্ৰ অনুসৰি নাম দিয়া হয়।

    কম্পিউটাৰৰ প্ৰজন্ম

    প্ৰথম প্ৰজন্ম প্ৰায় 1940 ৰ পৰা 1956 লৈ vacuum tube ব্যৱহাৰ কৰিছিল, আকাৰত ডাঙৰ আছিল আৰু অধিক তাপ দিছিল; ENIAC আৰু UNIVAC ইয়াৰ উদাহৰণ। দ্বিতীয় প্ৰজন্মত 1956 ৰ পৰা 1963 লৈ vacuum tube ৰ ঠাইত transistor বহিছিল, সৰু আছিল আৰু assembly language ব্যৱহাৰ কৰিছিল, যেনে IBM 1401। তৃতীয় প্ৰজন্মত 1964 ৰ পৰা 1971 লৈ integrated circuit ব্যৱহাৰ কৰি কীবৰ্ড, মনিটৰ আৰু high-level language আনিছিল, যেনে IBM 360। চতুৰ্থ প্ৰজন্মত 1971 ৰ পৰা microprocessor আৰু VLSI আহিল, যাৰ ফলত personal computer আৰু graphical user interface ওলাইছিল, যেনে Intel 4004। পঞ্চম প্ৰজন্মত artificial intelligence, ULSI আৰু parallel processing ব্যৱহাৰ হয়।

    মেমৰি আৰু সংৰক্ষণৰ স্তৰবিন্যাস

    মেমৰি গতি আৰু খৰচ অনুসৰি স্তৰবিন্যাসত সজোৱা থাকে। Register CPU ৰ ভিতৰত থাকে আৰু আটাইতকৈ দ্ৰুত। Cache মেমৰি L1, L2 আৰু L3 স্তৰত সঘনাই ব্যৱহৃত তথ্য CPU ৰ ওচৰত ৰাখে। ইয়াৰ পিছত primary memory, যি দুই ধৰণৰ: RAM কাৰ্যক্ষম মেমৰি আৰু ROM ষ্টাৰ্ট-আপ নিৰ্দেশনা ৰখা মেমৰি। RAM ৰ দুই ধৰণ: static RAM দ্ৰুত আৰু refresh নালাগে, cache ত ব্যৱহাৰ হয়; dynamic RAM মূল মেমৰি, যাক সদায় refresh লগে। ROM ৰ PROM, EPROM আৰু EEPROM ধৰণ। Secondary storage, যেনে hard disk, SSD, optical disk আৰু flash drive, লেহেম কিন্তু non-volatile আৰু বেছি ধাৰণক্ষমতাৰ। Magnetic tape মূলত backup ৰ বাবে ব্যৱহাৰ হয়।

    সোধা প্ৰশ্নৰ প্ৰকাৰ

    আটাইতকৈ বেছি অহা ধৰণ হ'ল পোনপটীয়া তথ্য, যেনে কম্পিউটাৰৰ পিতৃ কাক কোৱা হয় বা এটা full form ৰ অৰ্থ কি। দ্বিতীয়ত যন্ত্ৰৰ শ্ৰেণী, অৰ্থাৎ ই input, output নে storage। তৃতীয়ত একক ৰূপান্তৰ, যেনে কিমান KB ত এক MB হয়। চতুৰ্থত তালিকা দি অমিলটো বা যোৰ বিচৰা হয়। পঞ্চমত কোন প্ৰজন্মই এটা বৈশিষ্ট্য বা উপাদান আনিছিল সোধা হয়। সংক্ষেপৰ full form নিয়মীয়াকৈ আহে।

    Computer Awareness প্ৰশ্ন সমাধানৰ স্তৰ

    প্ৰথমে প্ৰশ্ন পঢ়ি ই সংজ্ঞা, যন্ত্ৰৰ শ্ৰেণী, সংখ্যা নে নাম বিচাৰে নিৰ্ণয় কৰক। দ্বিতীয়ে অনুমান নকৰি মানক তথ্য মনত পেলাওক। তৃতীয়ে বেলেগ শ্ৰেণীৰ বিকল্প আতৰাওক, যেনে input যন্ত্ৰৰ তালিকাত এটা output যন্ত্ৰ। চতুৰ্থে এককৰ প্ৰশ্নত 1024 গুণক সাৱধানে ব্যৱহাৰ কৰি স্তৰ গণনা কৰক। পঞ্চমে যন্ত্ৰৰ প্ৰশ্নত তথ্যৰ দিশ নিশ্চিত কৰক। শেষত full form আখৰে আখৰে পৰীক্ষা কৰক, কাৰণ এটা ভুল শব্দই প্ৰায়ে শুদ্ধ বিকল্প লুকুৱায়।

    পৰীক্ষাৰ প্ৰৱণতা

    অসমৰ নিয়োগ পৰীক্ষাত মূল সংজ্ঞা, full form, প্ৰজন্ম, মেমৰি একক আৰু input-output যন্ত্ৰ আটাইতকৈ বেছি আহে, তাৰ পিছত storage যন্ত্ৰ আৰু CPU ৰ অংশ। প্ৰশ্ন চুটি আৰু এটা তথ্যভিত্তিক, গতিকে যুক্তি নহয়, পুনৰালোচনাই নম্বৰ আনে। একেই মানক তথ্য সৰু সালসলনিৰে পুনৰ আহে, যাৰ ফলত এই অংশ আটাইতকৈ সহজ হৈ পৰে।

    সাধাৰণ ভুল

    • মেমৰি আৰু storage এক কৰি নধৰিব; মেমৰি primary আৰু প্ৰায়ে volatile।
    • Input আৰু output যন্ত্ৰ মিলাই নিদিব; তথ্যৰ দিশ চাওক।
    • Full form অনুমান নকৰিব; মানক ৰূপ শিকক।
    • 1024, 1000 নহয়, যে binary একক সংযোগ কৰে নাপাহৰিব।
    • প্ৰজন্ম আৰু তাৰ উপাদান মিলাই নিদিব।
    • nibble ৰ দৰে সৰু একক নাপাহৰিব, যি চাৰিটা bit।

    প্ৰস্তুতি কেনেকৈ কৰিব

    পাঁচটা প্ৰজন্মৰ বছৰ, মূল উপাদান, ভাষা আৰু উদাহৰণ লৈ এখন পৃষ্ঠাৰ তালিকা বনাওক। তাৰ পিছত input, output আৰু storage যন্ত্ৰৰ তালিকা বনাই প্ৰতিটোৰ কাষত তথ্যৰ দিশ লিখক। তাৰ পিছত bit ৰ পৰা terabyte লৈ এককৰ শাৰী এখন কাৰ্ডত লিখি দৈনিক পুনৰালোচনা কৰক। প্ৰতিটো সংহতিত প্ৰতিটো full form ৰেখাংকন কৰি নজনাৰটো শিকি লওক।

    কম্পিউটাৰ চিষ্টেমৰ হাৰ্ডৱেৰ চিত্ৰ, যি CPU, মেমৰি আৰু input-output একক দেখুৱায়, পুনৰালোচনা কৰক, কাৰণ বহু প্ৰশ্ন ইয়াৰ পৰা আহে। দিনে কুৰিটা প্ৰশ্ন কৰি ভুল হোৱা তথ্যৰ এখন তালিকা ৰাখক; একেই তথ্য পুনৰ আহে। শেষ সপ্তাহত কেৱল সেই তালিকা আৰু এক পৃষ্ঠাৰ তালিকা চাওক, তেতিয়া এই অংশ সাজু হ'ব।

    দ্ৰুত পুনৰালোচনাৰ টিপছ

    • CPU ৰ ALU, control unit আৰু register থাকে।
    • RAM volatile, ROM non-volatile।
    • একক 1024 ৰে বাঢ়ে, আৰু আঠ bit ত এক byte।
    • প্ৰতিটো প্ৰজন্ম আৰু তাৰ মূল উপাদান জানক।
    • প্ৰতিটো যন্ত্ৰ input, output নে storage শ্ৰেণীবদ্ধ কৰক।

    শেষ পুনৰালোচনা

    শেষ দিনা প্ৰজন্মৰ তালিকা, যন্ত্ৰৰ তালিকা আৰু এককৰ শাৰী পুনৰালোচনা কৰি কুৰিটা প্ৰশ্নৰ সময়বদ্ধ সংহতি কৰক। প্ৰতিটো ভুল উত্তৰৰ বাবে বাদ পৰা তথ্যটো লিখি ৰাখক। Computer fundamentals আৰু hardware এ স্পষ্ট, শুদ্ধ তথ্য বিচাৰে; তথ্য থকা প্ৰাৰ্থীয়ে দ্বিধা নকৰি উত্তৰ দি সহজ নম্বৰ পায়।

    সঘনাই সোধা প্ৰশ্ন

    কম্পিউটাৰৰ পিতৃ কাক কোৱা হয়?

    Charles Babbage ক কম্পিউটাৰৰ পিতৃ কোৱা হয়, কাৰণ তেওঁ Analytical Engine সাজিছিল, যি প্ৰথম যান্ত্ৰিক সাধাৰণ উদ্দেশ্যৰ কম্পিউটাৰ।

    RAM আৰু ROM ৰ পাৰ্থক্য কি?

    RAM volatile কাৰ্যক্ষম মেমৰি, বিদ্যুৎ গ'লে তথ্য হেৰায়; ROM non-volatile আৰু ষ্টাৰ্ট-আপ নিৰ্দেশনা স্থায়ীভাৱে ৰাখে।

    এক byte ত কিমান bit থাকে?

    এক byte ত আঠটা bit থাকে, আৰু nibble হৈছে আধা byte, অৰ্থাৎ চাৰিটা bit।

    কোন প্ৰজন্মই microprocessor আনিছিল?

    চতুৰ্থ প্ৰজন্মই, 1971 ৰ পৰা, microprocessor আৰু VLSI আনিছিল, যাৰ ফলত personal computer ওলাইছিল।

    Touch screen input নে output যন্ত্ৰ?

    Touch screen দুয়োটা, কাৰণ ই output দেখুৱায় আৰু ব্যৱহাৰকাৰীয়ে চুই দিলে inputও লয়।
