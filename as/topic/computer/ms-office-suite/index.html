    নম্বৰ কঢ়িয়াই নিয়া ভুল

    • Extension মিলাই দিয়া; .xlsx এক্সেলৰ, ৱৰ্ডৰ নহয়।
    • Excel ৰ formula equals চিনৰ পৰা আৰম্ভ হ'ব লাগে, সেয়া পাহৰি যোৱা।
    • Workbook আৰু worksheet মিলাই দিয়া; workbook ত worksheet থাকে।
    • PowerPoint ক word processor বা Word ক spreadsheet বুলি ভবা।
    • Access ক পাহৰি যোৱা, যি চুইটৰ database সদস্য।

    এটা চুটি অধ্যয়ন অভ্যাস

    তিনিটা স্তম্ভৰ এটা তালিকা বনাওক: application, তাৰ লক্ষ্য, আৰু আগতীয়া extension। আটাইতকৈ বেছি অহা বাৰটা shortcut যোৰে যোৰে উচ্চস্বৰে পঢ়ি শিকক, কাৰণ copy-paste আৰু undo-redo ই আটাইতকৈ বেছি ওলোটাই দিয়া হয়। তাৰ পিছত Word, Excel আৰু PowerPoint ৰ প্ৰতিটোৰ বাবে এটা বাস্তৱ পৰিস্থিতি লিখক য'ত আপুনি সেয়া খুলিব; এটা তথ্য পৰিস্থিতিৰ লগত জুৰিলে কেৱল তালিকাতকৈ বহু বেছি ভালদৰে মনত থাকে। শেষত Excel ৰ মূল function আৰু PowerPoint ৰ view এটা কাৰ্ডত লিখি শেষ দিনা কেৱল সেই কাৰ্ডখন পুনৰালোচনা কৰক।

    সঘনাই সোধা প্ৰশ্ন

    Slide বনোৱাৰ বাবে MS Office ৰ কোন application ব্যৱহাৰ হয়?

    MS PowerPoint, যি slide ৰে presentation বনায়।

    Word দলিলৰ আগতীয়া file extension কি?

    Word 2007 বা তাৰ পিছৰ দলিল .docx হিচাপে সংৰক্ষিত হয়; পুৰণি সংস্কৰণত .doc আছিল।

    শেষ কাম undo কৰিবলৈ কোন shortcut ব্যৱহাৰ হয়?

    Ctrl+Z য়ে শেষ কাম undo কৰে, আৰু Ctrl+Y য়ে পুনৰ কৰে।

    Workbook আৰু worksheet ৰ পাৰ্থক্য কি?

    Workbook হৈছে গোটেই Excel file; worksheet হৈছে তাৰ ভিতৰৰ এখন row-column শীট।

    Record ৰাখি query চলোৱাৰ বাবে কোন application ব্যৱহাৰ হয়?

    MS Access, যি MS Office ৰ database application; ই table ত record ৰাখি তাৰ ওপৰত query চলায়।

    MS Office: Word, Excel, PowerPoint and Access

    Almost every MS Office question is really asking one thing: do you know which application is built for which job, and what its default file format and basic parts are called? The facts are few and they repeat, so a candidate who fixes them once rarely misses these marks again. This note lists the vocabulary, then works through the four main applications one by one, and finishes with the shortcuts and the traps that catch people.

    Vocabulary and Default Formats

    • MS Office: Microsoft's suite of application software for documents, spreadsheets, presentations, databases and e-mail.
    • MS Word: a word processor for creating, editing, formatting and printing text documents such as letters and reports.
    • MS Excel: a spreadsheet program for calculations, tables, charts and data analysis.
    • MS PowerPoint: a presentation program for building slideshows with text, images, charts and animation.
    • MS Access: a database management system for storing records in tables and running queries.
    • MS Outlook: an e-mail, calendar and contacts manager.
    • Ribbon: the strip of tabs and commands across the top of a Word, Excel or PowerPoint window.
    • Workbook: an Excel file that holds one or more worksheets.
    • Worksheet: a single grid of rows and columns inside a workbook.
    • Cell: the box where a row meets a column, named by a reference such as A1.
    • Formula: an expression that starts with an equals sign and calculates a value.
    • Function: a ready-made formula such as SUM, AVERAGE, IF or COUNT.
    • Slide: one page of a PowerPoint presentation.
    • Template: a pre-designed file that supplies a ready layout for a document, sheet or slide.

    Which Application for Which Job

    Word handles anything that is mainly text: a letter, a notice, a report, a resume. Excel handles anything that is mainly numbers: tables of figures, totals, charts, analysis. PowerPoint handles anything meant to be shown on a screen as a series of slides. Access handles anything that must store many related records and answer queries about them. Outlook takes care of e-mail, the calendar and contacts. Learn one sentence of purpose for each and most identification questions answer themselves.

    Word and Excel in Detail

    Word's examinable features are spell check, grammar check, find and replace, headers and footers, page setup, and mail merge, which merges a main document with a data source to print many personalised letters at once. Its current default format is .docx, with .doc used before Office 2007.

    Excel's features are formulas and functions, sorting, filtering, charts and pivot tables. Every formula begins with the equals sign, and the functions asked most are SUM, AVERAGE, MIN, MAX, COUNT and IF. A cell is addressed by its column letter followed by its row number, so B5 is column B, row 5. A workbook is the file; a worksheet is one grid inside it. The current default format is .xlsx, with .xls used earlier.

    PowerPoint and Access in Detail

    PowerPoint organises content into slides and offers several views: Normal for editing, Slide Sorter for reordering, Notes for speaker notes, and Slide Show for presenting. It supports transitions between slides and animations within them, and its default format is .pptx, with .ppt used before Office 2007.

    Access stores data in tables and answers questions through queries, and its default format is .accdb, with .mdb used by older versions. Where Word, Excel and PowerPoint are judged on what they produce, Access is judged on what it stores, which is why it is the odd one out in the suite.

    Shortcuts and a Few Numbers

    The shortcuts that recur most are Ctrl+C to copy, Ctrl+X to cut, Ctrl+V to paste, Ctrl+Z to undo, Ctrl+Y to redo, Ctrl+A to select all, Ctrl+S to save, Ctrl+P to print, and Ctrl+B, Ctrl+I and Ctrl+U for bold, italics and underline. Inside Excel, Ctrl+Arrow jumps to the edge of a block of data and F2 opens the active cell for editing. Old formats to remember are .doc, .xls and .ppt; the modern ones add an x: .docx, .xlsx and .pptx.

    Mistakes That Cost Marks

    • Mixing up the extensions; .xlsx belongs to Excel, not Word.
    • Forgetting that an Excel formula must open with the equals sign.
    • Confusing a workbook with a worksheet; the workbook holds the worksheets.
    • Calling PowerPoint a word processor, or Word a spreadsheet.
    • Overlooking Access, the database member of the suite.

    A Short Study Routine

    Build one three-column table: application, purpose, default extension. Learn the twelve common shortcuts by reading them aloud in pairs, since copy-paste and undo-redo are the ones most often swapped. Then, for each of Word, Excel and PowerPoint, write one real situation in which you would open it; attaching a fact to a situation makes it stick far better than a bare list. Finish by writing the main Excel functions and the PowerPoint views on a single card and revising only that card on the last day.

    Frequently Asked Questions

    Which MS Office application is used to create slides?

    MS PowerPoint is used to create presentations made of slides.

    What is the default file extension of a Word document?

    A Word 2007 or later document is saved as .docx; older versions used .doc.

    Which shortcut undoes the last action?

    Ctrl+Z undoes the last action, and Ctrl+Y redoes it.

    What is the difference between a workbook and a worksheet?

    A workbook is the whole Excel file; a worksheet is a single sheet of rows and columns within it.

    Which application stores records and runs queries?

    MS Access is the database application of MS Office; it stores records in tables and runs queries on them.
