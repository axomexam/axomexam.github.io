    DBMS, সংখ্যা পদ্ধতি আৰু চৰ্টকাট — প্ৰশ্নোত্তৰ

    ৬৮ টা প্ৰশ্ন আৰু উত্তৰ

    ১. সম্পর্কিত তথ্যৰ সুসংগঠিত সংগ্ৰহক ___ বোলে।
    (A) Database
    (B) Spreadsheet
    (C) Document
    (D) Presentation
    উত্তৰ: database হৈছে সম্পর্কিত তথ্যৰ সুসংগঠিত সংগ্ৰহ।
    ব্যাখ্যা: database হৈছে সম্পর্কিত তথ্যৰ সুসংগঠিত সংগ্ৰহ, যিটো সহজে সংৰক্ষণ, ব্যৱস্থাপনা আৰু আপডেট কৰিব পৰা যায়। spreadsheet, document বা presentation-এ এনে সুসংগঠিত তথ্যভাণ্ডাৰ নিদিয়ে।
    ২. database ৰ তথ্য ব্যৱস্থাপনা, সংৰক্ষণ আৰু পুনৰুদ্ধাৰ কৰা ছফ্টৱেৰক ___ বোলে।
    (A) DBMS
    (B) OS
    (C) Word processor
    (D) Browser
    উত্তৰ: DBMS (Database Management System) য়ে database ব্যৱস্থাপনা কৰে।
    ব্যাখ্যা: DBMS (Database Management System) হৈছে এনে ছফ্টৱেৰ যিয়ে database ৰ তথ্য সংৰক্ষণ, উদ্ধাৰ আৰু ব্যৱস্থাপনা কৰে, যেনে MySQL বা Oracle। Operating system, word processor বা browser-এ database ব্যৱস্থাপনা নকৰে।
    ৩. DBMS ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Database Management System
    (B) Data Business Management System
    (C) Digital Base Management System
    (D) Data Backup Management Software
    উত্তৰ: DBMS ৰ অৰ্থ Database Management System।
    ব্যাখ্যা: DBMS ৰ অৰ্থ Database Management System। এইটো ব্যৱহাৰকাৰী আৰু প্ৰকৃত database ৰ মাজত থকা ছফ্টৱেৰ স্তৰ।
    ৪. RDBMS ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Relational Database Management System
    (B) Real Database Management System
    (C) Remote Data Management System
    (D) Rapid Database Management System
    উত্তৰ: RDBMS ৰ অৰ্থ Relational Database Management System।
    ব্যাখ্যা: RDBMS ৰ অৰ্থ Relational Database Management System। ই তথ্য table (relation) হিচাপে সংৰক্ষণ কৰে আৰু primary key, foreign key আদি ব্যৱহাৰ কৰি table-বোৰ সংযোগ কৰে।
    ৫. তলৰ কোনটো database management system ৰ উদাহৰণ?
    (A) MySQL
    (B) MS Paint
    (C) VLC Player
    (D) Notepad
    উত্তৰ: MySQL হৈছে জনপ্ৰিয় relational DBMS।
    ব্যাখ্যা: MySQL হৈছে বিনামূলীয়া, open-source relational DBMS, ৱেব এপ্লিকেশ্যনত বহুলভাৱে ব্যৱহৃত। MS Paint, VLC Player আৰু Notepad database system নহয়।
    ৬. এইবোৰৰ কোনটো RDBMS?
    (A) Oracle
    (B) MS Word
    (C) Google Chrome
    (D) WinRAR
    উত্তৰ: Oracle বহুল ব্যৱহৃত relational database management system।
    ব্যাখ্যা: Oracle হৈছে ডাঙৰ প্ৰতিষ্ঠানত ব্যৱহৃত শক্তিশালী commercial RDBMS। MS Word, Google Chrome আৰু WinRAR database management system নহয়।
    ৭. database ত table ৰ অনুভূমিক row বোৰক ___ বোলে।
    (A) Record / tuple (Records / tuples)
    (B) Field (Fields)
    (C) Attribute (Attributes)
    (D) Key (Keys)
    উত্তৰ: table ৰ row বোৰক record বা tuple বোলে; প্ৰতিটো এটা সম্পূৰ্ণ প্ৰৱেশ।
    ব্যাখ্যা: table ৰ প্ৰতিটো অনুভূমিক row এটা সম্পূৰ্ণ record, যাক tuple বুলিও কোৱা হয়। আনহাতে column হৈছে field বা attribute।
    ৮. database table ত উলম্ব column বোৰক ___ বোলে।
    (A) Field / attribute (Fields / attributes)
    (B) Record (Records)
    (C) Tuple (Tuples)
    (D) Schema (Schemas)
    উত্তৰ: column বোৰক field/attribute বোলে, এটাত এটা ধৰণৰ তথ্য থাকে।
    ব্যাখ্যা: এটা column-ত সকলো record ৰ বাবে এটা নিৰ্দিষ্ট ধৰণৰ তথ্য থাকে, সেয়ে একে field বা attribute বোলে। row হৈছে record বা tuple।
    ৯. table ৰ প্ৰতিটো record অনন্যভাৱে চিনাক্ত কৰা field ক ___ বোলে।
    (A) Primary key
    (B) Foreign key
    (C) Secondary key
    (D) Candidate index
    উত্তৰ: primary key য়ে প্ৰতিটো record চিনাক্ত কৰে, যেনে ছাত্রৰ ভর্তি নম্বৰ।
    ব্যাখ্যা: primary key হৈছে এনে column যাৰ মান প্ৰতিটো row ৰ বাবে অদ্বিতীয়, যেনে ভর্তি নম্বৰ। ই প্ৰতিটো record অদ্বিতীয়ভাৱে চিনাক্ত কৰে আৰু NULL বা পুনৰাবৃত্তি হ'ব নোৱাৰে।
    ১০. এটা table ৰ আন table ৰ primary key লৈ নিৰ্দেশ কৰা field ক ___ বোলে।
    (A) Foreign key
    (B) Primary key
    (C) Composite key
    (D) Unique key
    উত্তৰ: foreign key য়ে আন table ৰ primary key উল্লেখ কৰি দুটা table সংযোগ কৰে।
    ব্যাখ্যা: foreign key হৈছে এটা table ৰ column যিয়ে আন এটা table ৰ primary key মান সংৰক্ষণ কৰে, ফলত দুটা table ৰ মাজত সংযোগ সৃষ্টি হয়।
    ১১. relational database ব্যৱস্থাপনা আৰু query ৰ ভাষা ___।
    (A) SQL
    (B) HTML
    (C) XML
    (D) COBOL
    উত্তৰ: SQL (Structured Query Language) database query আৰু ব্যৱস্থাপনাৰ বাবে ব্যৱহাৰ হয়।
    ব্যাখ্যা: SQL (Structured Query Language) হৈছে relational database সৃষ্টি, query আৰু ব্যৱস্থাপনাৰ মানক ভাষা। HTML আৰু XML য়ে content mark up কৰে, আনহাতে COBOL এটা programming ভাষা।
    ১২. SQL ৰ সম্পূৰ্ণ ৰূপ কি?
    (A) Structured Query Language
    (B) Simple Query Language
    (C) System Query Language
    (D) Standard Question Language
    উত্তৰ: SQL ৰ অৰ্থ Structured Query Language।
    ব্যাখ্যা: SQL ৰ অৰ্থ Structured Query Language। relational database ৰ সৈতে যোগাযোগ কৰিবলৈ ইয়াক ব্যৱহাৰ কৰা হয়।
    ১৩. table ৰ পৰা তথ্য পুনৰুদ্ধাৰৰ SQL command কোনটো?
    (A) SELECT
    (B) INSERT
    (C) UPDATE
    (D) DELETE
    উত্তৰ: SELECT য়ে database table ৰ পৰা তথ্য উদ্ধাৰ (query) কৰে।
    ব্যাখ্যা: SELECT এটা DQL command যিয়ে এটা বা একাধিক table ৰ পৰা row উদ্ধাৰ (query) কৰে, যেনে SELECT * FROM students।
    ১৪. table ত নতুন record যোগ কৰা SQL command কোনটো?
    (A) INSERT
    (B) SELECT
    (C) UPDATE
    (D) DELETE
    উত্তৰ: INSERT য়ে table ত নতুন row (record) যোগ কৰে।
    ব্যাখ্যা: INSERT য়ে table-ত নতুন row (record) যোগ কৰে, যেনে INSERT INTO students VALUES (...)।
    ১৫. বৰ্তমান record সলনি কৰা SQL command কোনটো?
    (A) UPDATE
    (B) INSERT
    (C) DELETE
    (D) SELECT
    উত্তৰ: UPDATE য়ে table ৰ বৰ্তমান তথ্য সলনি কৰে।
    ব্যাখ্যা: UPDATE য়ে table ৰ বৰ্তমান row সলনি কৰে। সাধাৰণতে WHERE clause সৈতে লিখা হয়, যাতে কেৱল নিৰ্দিষ্ট record সলনি হয়।
    ১৬. table ৰ পৰা record আঁতৰোৱা SQL command কোনটো?
    (A) DELETE
    (B) SELECT
    (C) INSERT
    (D) UPDATE
    উত্তৰ: DELETE য়ে table ৰ পৰা row আঁতৰায়।
    ব্যাখ্যা: DELETE য়ে table ৰ পৰা row আঁতৰায়। WHERE clause থাকিলে কেৱল বাছনি কৰা row আঁতৰে; নাথাকিলে সকলো row আঁতৰে।
    ১৭. relational database ত table ৰ row ক ___ বুলিও কোৱা হয়।
    (A) Tuple
    (B) Domain
    (C) Column
    (D) Key
    উত্তৰ: relational পৰিভাষাত row ক tuple আৰু column ক attribute বোলে।
    ব্যাখ্যা: relational database তত্ত্বত row ক tuple আৰু column ক attribute বোলে। গোটেই table ক relation বোলে।
    ১৮. field ত ৰাখিব পৰা সম্ভাব্য মানসমূহক তাৰ ___ বোলে।
    (A) Domain
    (B) Range cell
    (C) View
    (D) Index
    উত্তৰ: domain য়ে field ৰ বৈধ মানসমূহ নিৰ্ধাৰণ কৰে।
    ব্যাখ্যা: field ৰ domain হৈছে সেই field-ত সংৰক্ষণ কৰিব পৰা সকলো বৈধ মানৰ সংহতি, যেনে month field-ত কেৱল ১ ৰ পৰা ১২ লৈ মানহে চলিব।
    ১৯. তলৰ কোনটো database management system নহয়?
    (A) MS Paint
    (B) Oracle
    (C) SQL Server
    (D) PostgreSQL
    উত্তৰ: MS Paint চিত্ৰাংকন সা-সঁজুলি; আনবোৰ DBMS।
    ব্যাখ্যা: MS Paint এটা ছবি আৰু চিত্ৰাংকন সঁজুলি। Oracle, SQL Server আৰু PostgreSQL সবো relational database management system।
    ২০. কম্পিউটাৰে ভিতৰত ব্যৱহাৰ কৰা সংখ্যা পদ্ধতি ___।
    (A) Binary
    (B) Decimal
    (C) Octal
    (D) Hexadecimal
    উত্তৰ: কম্পিউটাৰে ভিতৰত 0 আৰু 1 থকা binary (base-2) সংখ্যা পদ্ধতি ব্যৱহাৰ কৰে।
    ব্যাখ্যা: কম্পিউটাৰে ভিতৰত binary পদ্ধতি ব্যৱহাৰ কৰে কাৰণ ডিজিটেল circuit-ত দুটা স্থিৰ অৱস্থা থাকে, ON (১) আৰু OFF (০)।
    ২১. binary সংখ্যা পদ্ধতিৰ base ___।
    (A) 2
    (B) 8
    (C) 10
    (D) 16
    উত্তৰ: binary ত base 2, অংক 0 আৰু 1।
    ব্যাখ্যা: binary পদ্ধতিৰ base ২; কেৱল দুটা অংক (০ আৰু ১) ব্যৱহাৰ হয়, সেয়ে প্ৰতিটো স্থান-মান ২ ৰ ঘাত।
    ২২. দশমিক সংখ্যা পদ্ধতিৰ base ___।
    (A) 10
    (B) 2
    (C) 16
    (D) 8
    উত্তৰ: দশমিক ত base 10, অংক 0 ৰ পৰা 9।
    ব্যাখ্যা: দশমিক পদ্ধতিৰ base ১০ আৰু ই ০ ৰ পৰা ৯ লৈ দহটা অংক ব্যৱহাৰ কৰে, সেয়ে প্ৰতিটো স্থান ১০ ৰ ঘাত বুজায়।
    ২৩. অক্টাল সংখ্যা পদ্ধতিৰ base ___।
    (A) 8
    (B) 2
    (C) 10
    (D) 16
    উত্তৰ: অক্টাল ত base 8, অংক 0 ৰ পৰা 7।
    ব্যাখ্যা: octal ৰ base ৮ আৰু ই কেৱল ০ ৰ পৰা ৭ লৈ অংক ব্যৱহাৰ কৰে।
    ২৪. হেক্সাডেসিমেল সংখ্যা পদ্ধতিৰ base ___।
    (A) 16
    (B) 8
    (C) 10
    (D) 2
    উত্তৰ: hexadecimal ত base 16, অংক 0-9 আৰু আখৰ A-F।
    ব্যাখ্যা: hexadecimal ৰ base ১৬ আৰু ই ০-৯ অংকৰ লগতে A-F আখৰ ব্যৱহাৰ কৰি ১০ ৰ পৰা ১৫ লৈ মান সূচায়।
    ২৫. binary 1010 ৰ দশমিক মান ___।
    (A) 10
    (B) 8
    (C) 12
    (D) 15
    উত্তৰ: 1010 = 1×8 + 0×4 + 1×2 + 0×1 = 8+2 = 10।
    ব্যাখ্যা: প্ৰতিটো bit-ক স্থান-মানৰে পূৰণ কৰক: 1010 = ১x৮ + ০x৪ + ১x২ + ০x১ = ৮ + ২ = ১০।
    ২৬. binary 1111 ৰ দশমিক মান ___।
    (A) 15
    (B) 7
    (C) 16
    (D) 8
    উত্তৰ: 1111 = 8+4+2+1 = 15।
    ব্যাখ্যা: 1111 = ৮ + ৪ + ২ + ১ = ১৫, যি চাৰিটা bit ৰে লিখিব পৰা সৰ্বাধিক সংখ্যা।
    ২৭. binary 1001 ৰ দশমিক মান ___।
    (A) 9
    (B) 8
    (C) 10
    (D) 11
    উত্তৰ: 1001 = 8 + 1 = 9।
    ব্যাখ্যা: 1001 = ১x৮ + ০x৪ + ০x২ + ১x১ = ৮ + ১ = ৯।
    ২৮. দশমিক 5 ৰ binary মান ___।
    (A) 101
    (B) 110
    (C) 100
    (D) 111
    উত্তৰ: 5 = 4+1, binary ত 101।
    ব্যাখ্যা: ৫ ক বাৰে বাৰে ২ ৰে ভাগ কৰক: ৫ = ৪ + ১, গতিকে binary ৰূপ ১০১।
    ২৯. দশমিক 10 ৰ binary মান ___।
    (A) 1010
    (B) 1100
    (C) 1001
    (D) 1110
    উত্তৰ: 10 = 8+2, binary ত 1010।
    ব্যাখ্যা: ১০ = ৮ + ২ = ২ৰ ঘাত ৩ যোগ ২ৰ ঘাত ১, গতিকে binary-ত ১০১০ লিখা হয়।
    ৩০. hexadecimal 'A' ৰ দশমিক মান ___।
    (A) 10
    (B) 11
    (C) 15
    (D) 9
    উত্তৰ: hexadecimal ত A=10, B=11, C=12, D=13, E=14, F=15।
    ব্যাখ্যা: hexadecimal অংক ৯ ৰ পিছত আখৰেৰে আগবাঢ়ে: A = ১০, B = ১১, C = ১২, D = ১৩, E = ১৪ আৰু F = ১৫।
    ৩১. hexadecimal ত 'F' ৰ মান ___।
    (A) 15
    (B) 14
    (C) 13
    (D) 16
    উত্তৰ: F সবাতোকৈ ডাঙৰ hex অংক, মান 15।
    ব্যাখ্যা: F হৈছে সৰ্বোচ্চ hexadecimal অংক আৰু ই দশমিক মান ১৫ সূচায়।
    ৩২. binary 1100 ৰ দশমিক মান ___।
    (A) 12
    (B) 10
    (C) 11
    (D) 14
    উত্তৰ: 1100 = 8+4 = 12।
    ব্যাখ্যা: 1100 = ১x৮ + ১x৪ = ৮ + ৪ = ১২।
    ৩৩. এটা nibble কিমান bit ৰ সমান?
    (A) 4
    (B) 8

    এই অধ্যায়ত এটা নিয়োগ পৰীক্ষাৰ প্ৰশ্নপত্ৰত সঘনাই একেলগে অহা তিনিটা বেলেগ দক্ষতা আছে: database ৰ পৰিভাষা, binary, octal, decimal আৰু hexadecimal ৰ মাজত সংখ্যাৰ ৰূপান্তৰ, আৰু Windows কম্পিউটাৰৰ দৈনন্দিন keyboard shortcut। প্ৰতিটোৱেই এটা নিৰ্দিষ্ট তথ্য, গতিকে তথ্যটো মনত থাকিলে উত্তৰ দিবলৈ কেইছেকেণ্ডহে লাগে। তলত তথ্যৰ তালিকা, সময় কম থকা অৱস্থাত ব্যৱহাৰ কৰিবলগীয়া ৰূপান্তৰৰ পদ্ধতি, আৰু প্ৰাৰ্থীসকলে আটাইতকৈ বেছি ভুল কৰা ঠাইবোৰ দিয়া হৈছে।

    জানিবলগীয়া Database পৰিভাষা

    • Data: অকলশৰে অলপ অৰ্থপূৰ্ণ কেঁচা তথ্য আৰু সংখ্যা।
    • Database: সহজে বিচাৰি উলিয়াব আৰু আপডেট কৰিব পৰাকৈ ৰখা সম্পৰ্কীয় তথ্যৰ সুসংগঠিত সংগ্ৰহ।
    • DBMS: database সৃষ্টি আৰু পৰিচালনা কৰা software; MySQL, Oracle, SQL Server আৰু MS Access ইয়াৰ সাধাৰণ উদাহৰণ।
    • RDBMS: key ৰে সংযুক্ত table ত তথ্য ৰখা DBMS।
    • Table: এটা বিষয়ৰ তথ্য ৰখা row আৰু column ৰ সংহতি।
    • Record: table ৰ এটা সম্পূৰ্ণ row, যি এটা entity বৰ্ণনা কৰে।
    • Field: table ৰ এটা column, যি প্ৰতিটো record ৰ এটা গুণ ধৰি ৰাখে।
    • Primary key: table ৰ প্ৰতিটো record অদ্বিতীয়ভাৱে চিনাক্ত কৰা field; ই কেতিয়াও খালী বা পুনৰাবৃত্তি হ'ব নোৱাৰে।
    • Foreign key: এটা table ক আন এটাৰ primary key লৈ সংযোগ কৰা field।
    • SQL: structured query language, তথ্য সৃষ্টি, পঢ়া, আপডেট আৰু মচিবলৈ ব্যৱহৃত মানক ভাষা।
    • Query: database ৰ পৰা তথ্য বিচৰা অনুৰোধ।
    • Normalisation: পুনৰাবৃত্তি আৰু অসংগতি কমাবলৈ table পুনৰ সংগঠিত কৰাৰ প্ৰক্ৰিয়া।
    • Number system: নিৰ্দিষ্ট digit ৰ সংহতি, অৰ্থাৎ base, ব্যৱহাৰ কৰি সংখ্যা লিখাৰ পদ্ধতি।
    • Bit: এটা binary digit, 0 বা 1, তথ্যৰ আটাইতকৈ সৰু একক।
    • Byte: আঠটা bit ৰ সংগ্ৰহ, যি এটা character ৰাখিব পাৰে।

    বেছিভাগ উত্তৰ নিৰ্ণয় কৰা নিয়ম

    • Database হৈছে তথ্য, আৰু DBMS হৈছে সেই তথ্য পৰিচালনা কৰা software; দুয়োটাক একে বুলি নাভাবিব।
    • কেৱল primary key অদ্বিতীয় হ'ব লাগে; foreign key পুনৰাবৃত্তি হ'ব পাৰে আৰু খালীও থাকিব পাৰে।
    • SQL ৰ কাম কৰা statement ক্ৰমে SELECT পঢ়িবলৈ, INSERT যোগ কৰিবলৈ, UPDATE সলাবলৈ আৰু DELETE মচিবলৈ, লগতে CREATE আৰু DROP table বনাব বা মচিবলৈ।
    • Base ক্ৰমে decimal 10, binary 2, octal 8 আৰু hexadecimal 16।
    • Octal হৈছে তিনি bit ৰ গোটত binary ৰ চুটি ৰূপ; hexadecimal এ চাৰি bit ৰ গোট লয়।
    • Hexadecimal ত A ৰ পৰা F লৈ অক্ষৰে 10 ৰ পৰা 15 লৈ মান সূচায়।
    • কম্পিউটাৰ মেমৰি 1000 নহয়, 1024 ৰ পৰ্যায়ত বাঢ়ে: 8 bit = 1 byte, 1024 byte = 1 KB, 1024 KB = 1 MB, 1024 MB = 1 GB আৰু 1024 GB = 1 TB।

    চাৰিটা সংখ্যা পদ্ধতিৰ পাৰ্থক্য

    সংখ্যা পদ্ধতিৰ নাম তাৰ base ৰ পৰা হয়, অৰ্থাৎ ই ব্যৱহাৰ কৰা বেলেগ digit ৰ সংখ্যাৰ পৰা। Decimal এ 0 ৰ পৰা 9 লৈ দহটা digit লয়। Binary এ কেৱল 0 আৰু 1 লয়। Octal এ 0 ৰ পৰা 7 লৈ আঠটা লয়। Hexadecimal এ ষোল্লটা চিহ্ন লয়: 0 ৰ পৰা 9, তাৰ পিছত দহৰ পৰা পোন্ধৰলৈ A, B, C, D, E আৰু F। আঠ, ষোল্ল আৰু দুই — আটাইবোৰেই দুইৰ ঘাত, গতিকে octal আৰু hexadecimal দীঘল binary শাৰী লিখাৰ চুটি উপায়; সেয়ে মেমৰি ঠিকনা সাধাৰণতে hexadecimal ত দেখুওৱা হয়। যিকোনো সংখ্যাত বাওঁফালৰ digit ৰ place value আটাইতকৈ ডাঙৰ, যাক most significant digit বোলা হয়; সোঁফালৰটো least significant।

    হাতেৰে ৰূপান্তৰ: কাম কৰা উদাহৰণ

    Decimal ৰ পৰা binary: দুৰে ভাগ কৰি প্ৰতিটো ভাগশেষ লিখি শেষৰ পৰা প্ৰথমলৈ পঢ়ক। 13 লওক। 13 ÷ 2 = 6, ভাগশেষ 1; 6 ÷ 2 = 3, ভাগশেষ 0; 3 ÷ 2 = 1, ভাগশেষ 1; 1 ÷ 2 = 0, ভাগশেষ 1। ওপৰলৈ পঢ়িলে 13 হয় 1101।

    Binary ৰ পৰা decimal: য'ত digit এক তাত place value যোগ কৰক। সোঁফালৰ পৰা place value ক্ৰমে 1, 2, 4, 8, 16। 1101 ৰ বাবে ই 8 + 4 + 0 + 1 = 13, যি প্ৰথম উদাহৰণটো মিলাই দিয়ে।

    Binary ৰ পৰা octal আৰু hexadecimal: bit বোৰ গোটত ভাগ কৰক। 1101 ক সোঁফালৰ পৰা তিনি তিনি কৰি ভাগ কৰিলে 1 আৰু 101 পোৱা যায়, গতিকে octal ৰূপ 15। একেখিনি bit চাৰি চাৰিকৈ ভাগ কৰিলে 1101 পোৱা যায়, গতিকে hexadecimal ৰূপ D। চাৰি bit ৰ গোটক nibble বোলা হয়, যি আধা byte।

    মেমৰিৰ আকাৰ আৰু 1024 ৰ শ্ৰেণী

    এটা bit এ এটা 0 বা 1 ধৰি ৰাখে। আঠটা bit এ এটা byte বনায়, যি এটা character ৰাখে। তাৰ পৰা প্ৰতিটো খোজ 1024 ৰে পূৰণ হয়: 1024 byte = এটা kilobyte, 1024 KB = এটা megabyte, 1024 MB = এটা gigabyte, 1024 GB = এটা terabyte আৰু 1024 TB = এটা petabyte। প্ৰশ্নত সাধাৰণতে এটা kilobyte ত কিমান byte বা এটা byte ত কিমান bit সোধা হয়, আৰু উত্তৰ 1024 আৰু 8।

    মনত ৰখাৰ যোগ্য Shortcut

    Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo আৰু Ctrl+Y redo। Ctrl+A এ আটাই বাছনি, Ctrl+S save, Ctrl+P print, Ctrl+F find কৰে, আৰু Ctrl+B, Ctrl+I লগতে Ctrl+U এ bold, italic আৰু underline দিয়ে। Alt+F4 এ সক্ৰিয় ৱিন্ডো বন্ধ কৰে, Alt+Tab এ খোলা ৱিন্ডোৰ মাজত সলনি কৰে, আৰু F5 এ চলিত পৃষ্ঠা বা ৱিন্ডো refresh কৰে। এটা সহজ যোৰ: undo ৰ Z ঠিক redo ৰ Y ৰ বাওঁফালে থাকে।

    য'ত প্ৰাৰ্থীসকলে নম্বৰ হেৰুৱায়

    • Decimal-ৰপৰা-binary ৰ ভাগশেষ ওপৰৰ পৰা তললৈ পঢ়া, শেষৰ পৰা প্ৰথমলৈ পঢ়িবৰ সলনি।
    • Foreign key ক অদ্বিতীয় ভবা, য'ত কেৱল primary key অদ্বিতীয়।
    • মেমৰি এককলৈ 1000 লিখা; কম্পিউটাৰ মেমৰিত 1024 ব্যৱহৃত হয়।
    • Octal এ bit তিনি তিনি আৰু hexadecimal এ চাৰি চাৰিকৈ গোট কৰে, সেয়া পাহৰি যোৱা।
    • Ctrl+Z (undo) আৰু Ctrl+Y (redo) ওলোটাই দিয়া।

    দুই সপ্তাহৰ পুনৰালোচনাৰ পৰিকল্পনা

    চাৰিটা সংখ্যা পদ্ধতিৰ base আৰু digit লৈ এটা তালিকা আঁকক, আৰু bit ৰ পৰা petabyte লৈ প্ৰতিটো খোজত 1024 লিখি এটা শ্ৰেণী আঁকক। প্ৰথম সপ্তাহত দিনে দহটা decimal সংখ্যা binary লৈ আৰু উলটি decimal লৈ সলাওক, ভাগশেষ উচ্চস্বৰে পঢ়ি ক্ৰমটো স্বাভাৱিক কৰি তুলক। ভুল হোৱা প্ৰতিটো ৰূপান্তৰ, সংজ্ঞা বা shortcut ৰ এখন চলিত তালিকা ৰাখক আৰু প্ৰতি তৃতীয় দিনে সেই তালিকাতে নিজকে পৰীক্ষা কৰক। শেষ সপ্তাহত কেৱল দুয়োখন তালিকা আৰু ভুলৰ তালিকা পুনৰালোচনা কৰিলেই যথেষ্ট।

    সঘনাই সোধা প্ৰশ্ন

    Primary key কি?

    Primary key হৈছে table ৰ প্ৰতিটো record অদ্বিতীয়ভাৱে চিনাক্ত কৰা field, যি খালী ৰাখিব নোৱাৰি।

    Decimal সংখ্যা 10 ৰ binary ৰূপ কি?

    10 ক বাৰে বাৰে দুৰে ভাগ কৰিলে ভাগশেষ 0, 1, 0, 1 পোৱা যায়, গতিকে 10 ক binary ত 1010 বুলি লিখা হয়।

    এটা kilobyte ত কিমান byte থাকে?

    এটা kilobyte ত 1024 byte থাকে, কাৰণ কম্পিউটাৰ মেমৰি 1000 নহয় 1024 ৰ পৰ্যায়ত বাঢ়ে।

    SQL ৰ full form কি আৰু ইয়াৰ কাম কি?

    SQL ৰ full form structured query language; database ত তথ্য সৃষ্টি, পঢ়া, আপডেট আৰু মচিবলৈ ই ব্যৱহৃত হয়।

    কাম undo আৰু redo কৰিবলৈ কোন চাবি ব্যৱহৃত হয়?

    Ctrl+Z য়ে শেষ কাম undo কৰে আৰু Ctrl+Y য়ে redo কৰে।
